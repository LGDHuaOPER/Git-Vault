## 重新定义产品

先说说什么是产品。我们往往理解产品是“一个东西”或者“一项服务”。比如说，手机是什么产品？那就是那个能上网能打电话的“东西”嘛。电子书是什么产品？就是一个我随时可以打开，阅读一个书库的权限。大家通常会把产品做这样的具象理解。

可如果你一旦站在用户视角来理解产品，就会发现，一个产品能被他感知到的远不止这些。

以iPhone为例，它除了满足传统手机的通讯需求，更是一种新的人与世界的沟通工具，是人类器官的自然延伸，摄像头是视觉的延伸，触控操作是触觉的延伸。除此之外，它的品牌宣传，广告，店面，网站，售后，包括升级换代的过程，这些也都是iPhone产品的一部分，当然，这些部分也都包含在了价格里。

同样的，对一本书来说，它在线上线下的宣传海报，书本身的封面、装帧设计、书里附带的卡片、补充内容的光盘或者二维码等介质，以及读者社群等等，都是这本书的一部分。

所以，站在用户视角，  *产品是满足了用户的某个需求，而被用户感知到的所有环节的总和。* 当我们讨论产品的时候，核心是站在用户的视角看，他能获得什么。

## 传统漏斗式增长

好，既然产品是用户能感知到的所有环节的总和，那增长必然也就是发生在这些环节上，这也就可以带来新的增长方式。

我们先来回溯一下传统的增长，其实就是大家普遍在用的“漏斗式增长”，如果要总结它的乘法公式，那大致可以写成：

增长 = 流量 x 转化率1 x 转化率2 x 转化率3 x ……

这其中，转化率1、2、3……就是一层一层的漏斗转化。比如说，流量是总共有多少人看到了我们的广告，而第一层转化率就是点击了“了解详情”的这个按钮，第二层转化就是进入了商品的支付页面，第三层转化就是付款成功，第四层转化就是没有发生“七天无理由退货”。只要你愿意，这个漏斗也可以做得更复杂。

这是我看到大部分业务在使用的乘法公式，大家都把精力花在如何把这个漏斗搭得更好。但不知道你有没有意识到 ，这个公式虽然能带来增长，但也有三个致命的问题：

第一，每一层转化率之间互相掣肘。

比如要卖汽车，“试驾”肯定是漏斗中的一环了。为了提升这一层的转化率，做个活动只要来试驾就送礼物发红包，试驾率上升了，但是从试驾到买车之间的这个转化率往往就下降了。如果负责每一级转化率的是不同的部门，那这些部门之间就会开始相互内耗、打架。

第二，这个公式里的每一个转化率因子都小于1，甚至远远小于1，导致哪怕不多的增长都需要巨大的流量支持。

比如某个业务从进群到付费的转化率是1%左右，那如果要增长1000个用户，就需要有10万人进群，结果发现这个业务连目标客户都不到10万人，那这个时候还怎么增长？

第三，也是最重要的一点，这个公式里，并没有把用户当做“人”来看待，而是当做流量，或者是一个抽象的数据来看待。长期使用漏斗作为增长的基础，会让团队失去对用户的直观感知和理解，就算数据分析做得好，很多讨论也都会是空中楼阁，没有用户基础。

所以，这种“漏斗式乘法”可能在某一个特定的阶段，尤其是能吃到流量红利的阶段，是能发挥还不错的作用，但是长期看，必然会陷入瓶颈。

## 重新定义增长乘法

那有没有什么增长方式，能规避掉这些问题呢？这就是我们这套课程要交付给你的，产品增长乘法公式。都铺垫到这儿了，请允许我先用比较慢的语速，正式发布这个公式，它就是：

**增长 = 需求 x 方案 x 共识 x 体验 x 场域 x 效率 x 口碑 x 流量**

这个公式我做了一张图片放在文稿中，你也可以写在你的记事本的扉页上，经常拿出来提醒自己。

![https://piccdn2.umiwi.com/uploader/image/ddarticle/2023050720/1807604932904254528/050720.jpeg](https://piccdn2.umiwi.com/uploader/image/ddarticle/2023050720/1807604932904254528/050720.jpeg)

你看，在这个乘法公式中，包含了八个独立的因子。这也是我们整套课的学习地图，我将从第2讲到第9讲，带着你依次抵达这八站，对这八个因子的内涵和行动方案一一展开。

下面，我简单带你对这八个因子有个初认识。

**第一个，需求。无需求，便无产品。** 道理简单，但为什么很多产品都抓不准用户的真实需求？你花了大量时间去做的那些问卷调研真的有用吗？我告诉你，可能未必能帮到你，甚至还把你带到了沟里。那如何能洞察用户深层次的需求，如何去伪存真？我从兜里掏出了三个我屡试不爽的方法，在第2讲教给你。

**第二个，方案。它指的是你的产品是用什么方式方法去满足用户的需求。** 这个环节非常考验对用户的理解和对产品的设计能力。同样的需求，用不同的方式去满足，会带来巨大的增长差异。那有价值的方案，背后的标准和共性是什么呢？我们在第3讲来拆解它。

**第三个，共识。你团队中的每一个人，是不是真的在做同一个产品？** 这么问好像很奇怪啊，但是我看到很多产品在面向用户时，各端的说法都不一致，如果再遇到退款、投诉等问题，更容易互相撕扯。既然产品是用户能感知到的所有环节的总和，那业务中的每个人，都在决定着这个产品的品质。如何确保团队真的能劲往一处使？第4讲，我将带你通过两个层次，来彻底做到团队共识。

**第四个，体验。它是“产品是所有环节的总和”这个说法的核心体现。** 很多人经常把一句话挂在嘴边，说“我们的用户体验要如何如何”。可是，到底什么是用户体验？用户感觉到喜欢、舒服、开心，就是好的用户体验了吗？我要告诉你，并不是的。那好的用户体验核心到底是什么？又要做什么？我在第5讲来解答这个问题。

**第五个，场域。你可以理解成，是你的产品和用户接触的场地。** 理论上来说，哪里人越多，我们就得带着产品去哪里“摆摊儿”，这也是大家为什么都会去微信和抖音上卖产品。可是，一旦陷入到这个逻辑，就又容易掉进漏斗式乘法中了。那第6讲，我们就要来探究，我们应该去哪里找用户，以及怎么能创造一个场域让他们自动聚集。

**第六个，效率。是说我们通过什么样的方式，来让用户真正认识你的产品。** 发传单是一种方式，开直播是一种方式，在路边、在电梯里投放广告也是一种方式，当然还有更多的方式，我们都要去做吗？哪些做哪些不做呢？有哪些事儿是你一旦做了，会让你在前期的准备工作都付之东流了呢？第7讲，我们将展开来详细说说。

**第七个，口碑。这是大家都不陌生的词。用户愿不愿意把你的产品介绍给别人，其他人又是否会买单** ，这些真的是由你的产品“好”或“不好”来决定的吗？都说转介绍很重要，那转介绍要怎么做才有效？第8讲，来为你的产品打造真正的口碑。

**第八个，流量。对，你没听错，很多人一上来就要聊的流量问题，是我们最后一个才考虑的问题。** 在前面的所有因子说清楚之后，流量的思考方式就会变得不同。如果用户需要增长1000人，那你需要多少流量？是10万，还是1万？最后你会发现，或许只是100。这是怎么做到的？这样不可思议的流量密码是什么？我们在第9讲来解码它。

当这八个因子被我们详细拆解完毕之后，我相信那时的你不仅能更全面深刻地理解自己的产品，而且更会坚定不移地依靠产品来驱动业务的增长，因为这个新的乘法公式，会带给你不内耗、不失焦、不浪费、不外求的增长力量，这也是我在最后一讲想跟你说的。

怎么样，说到这，你是不是已经迫不及待地想要赶紧发车去往第一站了？好，就让我们赶紧出发，一起解锁每一站的风景，从现在开始，就依靠我们手中的产品，一起白手起家做增长。

最后，请让我再重复一次，这个无比重要的产品增长乘法公式，这一次，你可以和我一起说出来：

**增长 = 需求 x 方案 x 共识 x 体验 x 场域 x 效率 x 口碑 x 流量**

好，内容听完了。

李睿老师把他的全部心法，都总结在了这个增长公式里。掌握了这个公式，你也可以白手起家，用产品撬动增长。
