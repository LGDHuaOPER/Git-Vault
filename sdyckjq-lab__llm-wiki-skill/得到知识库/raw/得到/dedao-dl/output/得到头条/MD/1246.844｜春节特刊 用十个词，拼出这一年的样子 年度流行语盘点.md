# 844｜用十个词，拼出这一年的样子：年度流行语盘点

精挑细淘，得到头条。我是李南南。 

今天是大年初三，继续我们的春节特刊。今天的主题是，年度流行语盘点。

前两个月，很多机构发布了年度流行词。国内的有国家语言资源监测与研究中心、《咬文嚼字》编辑部、《语言文字周报》编辑部，还有微博、小红书、B站等平台。国外的有牛津、剑桥、韦氏、柯林斯四大词典。

接下来，我们就通过这些词，回顾一下刚刚过去的蛇年。

先说第一个，  *敬自己一杯* 。

这是国家语言资源监测与研究中心评选的2025年十大网络流行语之一。官方解释说， 这个词是“年轻人以举杯仪式分享人生酸甜、自嘲过往经历，是对努力与平凡的接纳，实现自我和解与价值认同的温柔表达”。

你看社交媒体上，很多人会发“敬自己一杯”的内容。敬什么呢？敬那些努力过但没成功的事，敬那些不那么光鲜的日子。有人敬自己面试被拒了十几次还在坚持，有人敬自己一个人过了三十岁生日。

根据一些语言机构的解读，这个举杯的动作，它不是说“我放弃了”，也不是说“我认输了”，而是说“我接受了，我的人生就是这样，也挺好”。  *它不是那种“我很惨你们可怜我”的诉苦，也不是“我很好不需要你们”的强撑，而是在说，“我经历了这些，我承认这些，我不觉得丢人，我敬自己一杯”。*

我们要说的第二个词是，  *活人感* 。

《咬文嚼字》把它选进了2025年十大流行语。什么叫活人感？说白了，就是你在多大程度上，表现得像一个有血有肉，会犯错，会失控的人。

*这个词流行的原因之一，是人们对“演出来”的东西感到厌烦了，而那些“有瑕疵”的真实感，反而变得受欢迎。* 比如明星接受采访时卡壳或者说错话，或者UP主直播时突然被家人打断，手忙脚乱地解释，这些“不完美”的瞬间，反而让人觉得这是个“真人”。

但有意思的是，“活人感”这个词的流行，也带来了一个悖论。当“不完美”成了一种受欢迎的元素，那么它还能保持真实吗？也许，之后很多人会故意“表演不完美”，故意制造“翻车”的瞬间，精心设计“尴尬”的场景。

我们要说的第三个词是，  *致敬* 。

这是一个再普通不过的词，甚至有点老派。但B站数据显示，这一年里，“致敬”被发送超过2282万次，使用过这条弹幕的用户超过459万人，其中80%是“00后”，成为2025年增长最快的弹幕热词。

点开相关视频你会发现，有人在向小众的创意致敬，有人在向那些坚持拍摄龙卷风的人致敬。总之，这些“致敬”的对象，不一定是名人，不一定是大事件。  *只要你在做一件有价值的事，哪怕这个价值是微小的，或者是只针对你自己，大概率上就会有人在弹幕里向你“致敬”。*

我们要说的第四个词是，  *助我破鼎* 。

这个词来自2025年春节档的动画电影《哪吒之魔童闹海》。这句台词为什么这么火？因为很多人觉得，“鼎”这个意象也代表了自己所面对的挑战，比如加班、裁员、中年危机、房贷车贷。

但  *这个词的流行，有更深一层的原因。它不只是积极应对，更重要的是，它承认了“鼎”的存在。* 它不是说“我很轻松”“我很从容”“压力不算什么”，而是说“我压力很大，这个鼎很重，但我要破掉它”。

你看，这个表达方式和“活人感”“敬自己一杯”是一脉相承的，都是在追求真实，而不是伪装完美。  *不是说“我没压力”，而是说“我有压力，但我不被压垮”。*

我们要说的第五个流行语是，  *千百次练习只为这一刻* 。

这个词也是国家语言资源监测与研究中心评选的十大流行语之一。  *官方解释说，它“与‘台上一分钟，台下十年功’含义相近，强调学习过程‘从量变到质变’的规律”。*

这个词广泛出现在竞技体育、文艺表演等场合。你看奥运会，看到运动员在领奖台上的瞬间，镜头会回放他们训练的画面，配上这句话。你看综艺节目，看到演员的精彩表演，弹幕会刷屏“千百次练习只为这一刻”。

但这个词的流行，不只是因为它有道理，更因为它击中了一种普遍的情绪。在这个讲究“速成”“捷径”“风口”的时代，“千百次练习”这种老派的、笨拙的、日积月累的方法，反而成了一种稀缺的努力。

我们要说的第六个流行词是，  *主理人* 。

这是《语言文字周报》评选的十大流行语之一。最初，这个词指的是潮流品牌的所有者，但现在，它的使用范围已经扩展到时尚、艺术、餐饮等泛商业领域。

官方解释说，  *这个词呈现“万物皆可主理”的边界模糊性，年轻创业者更倾向以此标识身份。*

为什么？因为“主理人”这个词，听起来比“老板”更有调性，比“创始人”更接地气。它强调的不是规模，不是资本，而是你对这件事的态度和投入。你主理一家咖啡馆，不只是开店，而是把你的理念、审美、价值观注入其中。

“主理人”这个词的流行，某种程度上也反映了创业观念的变化。  *以前，创业是为了做大、做强、上市、融资。现在，很多年轻人的创业，是为了“做自己喜欢的事”。*

接下来的第七个词是，  *韧* 。

这是《咬文嚼字》2025年十大流行语的榜首词。原本是物理概念，  *指物体变形而不易折断的特性，后来引申为顽强持久的精神。*

2025年初，国家统计局在发布经济数据时，多次用“中国经济韧性强、潜力大、活力足”来总结态势。这个词从官方表述走进日常语境，在社交媒体上大量出现。  *它代表的是在不确定性环境下的一种状态——既有坚韧，也有柔韧。*  *不是硬扛，而是能屈能伸。*

接下来的第八个词，  *DeepSeek，深度求索* 。

国家语言资源监测与研究中心把它评为2025年度国内词。注意，不是“年度网络流行语”，而是“年度国内词”，分量更重。

*DeepSeek最大的特点不仅在于推理能力，更在于开源。也就是把核心技术公开，任何人都可以在它的基础上进行开发和创新。*

这种开源模式带来的影响，在2025年3月28日的缅甸地震中体现得特别明显。地震发生后，国家应急语言服务团需要紧急开发一个中缅英互译系统，用于救援协调。基于DeepSeek的开源技术，他们在7小时内就完成了系统的开发和部署。

而且，DeepSeek的流行，还有一个更深层的意义。 在AI领域，长期以来都是国外的模型占据主导地位。DeepSeek的出现，意味着我们已经开始在这个舞台上，有越来越多的话语权。

第九个词，  *具身智能* 。

2025年，这个词首次写入《政府工作报告》，与生物制造、量子科技、6G一起被列为需要重点培育的未来产业。

最直观的例子，就是去年的机器人运动大会，那些机器人不是在演示技术，而是真的在赛场上竞技。AI开始从虚拟世界走进物理世界。以前，AI只能帮你处理信息。现在，它可以帮你搬东西、做手术、在工厂里组装产品。  *它不再只是一个软件工具，而是一个能在物理世界里工作的“同事”。*

第十个词，  *赛博* 。

这是微博2025年的年度关键词。一年里，有1.5亿条博文提到“赛博××”的相关词汇。比如，赛博搭子、赛博闺蜜、赛博许愿池。这个原本科幻感很强的词，现在变成了日常用语。

赛博搭子，就是把AI当成一个随叫随到的朋友。你心情不好，跟它聊聊天。你想健身，让它给你制定计划。你要做决策，让它帮你分析利弊。

赛博许愿池，就是在社交媒体的评论区里许愿。你发一条“希望明天面试顺利”，会有一堆人在评论区回复“接好运”。这个评论区，就变成了一个虚拟的许愿池。

以前，我们说“上网”，意思是从现实世界进入虚拟世界。现在，虚拟在日常生活的占比越来越高。你在网上社交，在网上工作，在网上娱乐，网络空间已经不是一个“另外的世界”，而是你生活的一部分。

从这个角度看，  *“赛博”不再是一个科幻概念，而是一个生活状态。它是现实生活的外挂，是情绪的出口，是工具，也是栖息地。*

最后，借用一句今年流行语，来财。这个词来自歌曲《八方来财》，网民仿照创造出“来分”“来offer”等说法，表达对好运的期待。

在这里，也祝你新的一年，来财，来财。

## 划重点

1. “敬自己一杯”这个流行语，是一种自我接纳与和解的积极表达，代表着年轻人对自己的努力与平凡生活的认同。
2. “赛博”相关词汇的流行，不是科幻概念的简单应用，而是反映了虚拟与现实界限的模糊化，网络空间已从“另一个世界”转变为生活的有机组成部分。
3. “千百次练习只为这一刻”的流行，代表了一种稀缺的、踏实的努力方式，击中了人们对日积月累价值的重新认识。
4. AI技术，正在通过“具身智能”等概念向物理世界延伸，标志着人工智能应用范围的革命性扩展。

## 热门留言

左星星：这些流行语看似轻巧，其实在替我们给这一年的情绪做“归档”。

“敬自己一杯”不是自我感动，而是一种止损：承认努力未必有回报，承认普通并不丢人。它把人生从“必须赢”改成“我还能继续”，让人不再用失败来否定全部价值。

“助我破鼎”像一份宣战书。它先承认鼎很重——压力、债务、裁员、照护，都是真实存在的重量；然后才谈“破”。不是鸡血式乐观，而是把对抗写进语言里：我没装没事，但我也不准备被压扁。

“韧”提醒我们，真正能走远的不是硬扛，而是能弯、能复原、能调整策略。它把“坚持”从意志品质变成生存技能：在不确定里留弹性，在冲击后迅速重组生活。

“主理人”让我想到一种自我定位：不必等到拥有一家公司才算成事，只要你能对一块小领域负责，你就能把工作从“打工”变成“经营”。主理的关键不是头衔，而是你愿不愿意为结果背书。

“赛博”则揭示了新常态：我们把情绪、关系、决策的一部分外包给数字世界。它既是外挂也是陷阱——能扩展能力，也可能让人更依赖、更分心。这提醒我们，把AI当工具，把边界握在手里，别让算法替你过日子。

这些词其实在强调一种更真实、更有掌控感的活法——承认重量，保留弹性，认真主理，善用外挂。

美君：“敬自己一杯”有一种对自己的允许、接纳、看见和关照。

或许我们的事业并没有做得风生水起，但即便在并不理想的职场环境下，我们依然很有责任感，用心做好手里的工作，值得敬自己一杯🍷；

或许现状离我们的目标相差甚远，很多事情搞得一团糟，失败如影随形，但我们没有妄自菲薄，更没有一蹶不振，值得敬自己一杯🍷；

或许我们每天都会犯很多错误，时而失落，时而沮丧，但反思后我们总能有成长，值得敬自己一杯🍷。

过去我们总听到，因为你对我有恩，所以我敬你一杯；因为我们有深情厚谊，所以我敬你一杯；因为此时此刻我们在一起，所以我敬你一杯。

但现在，我们敬自己一杯，不一定是因为成功或完美，也不一定是因为此刻的难得，而是接纳自己的现状，尊重自己的感受，看见自己的付出。所以，敬自己一杯🍷。
