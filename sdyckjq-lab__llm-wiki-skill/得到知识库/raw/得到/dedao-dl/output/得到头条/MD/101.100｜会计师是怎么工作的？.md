# 100｜会计师是怎么工作的？

这里是《得到头条》，我是徐玲。 

今天我们从两个话题出发，为你提供知识服务。一是恒大陷入债务危机，二是上海迪士尼连夜排查新冠疫情。我们看看从这些话题背后，能学到点啥知识。

最近一段时间，恒大陷入债务危机，相信你已经看了不少报道。关于这场危机本身是怎么回事，我们就不重复了。不过，我们团队在跟进这件事的过程中，发现有个相关问题的讨论，值得给你汇报一下。

我们知道，恒大是一家在香港上市的公司，会定期公布财报报告。恒大的会计师事务所是全球“四大”之一的普华永道。但是，在审计恒大2020年财报时，普华永道没有给出任何风险警示。

这里补充一个知识点。审计报告的结论有五种：1.标准无保留意见；2.带强调事项段的无保留意见；3.保留意见；4.否定意见；5.无法表示意见。其中，风险提示等级是逐级上升的，“标准无保留意见”表示没有发现风险，而“否定意见”和“无法表示意见”则提示有高度风险。普华永道对恒大的审计意见是第一种，“标准无保留意见”。

就在10月15日，香港财务汇报局发布公告，指出普华永道在恒大2020年财报的审计意见中，只发表了无保留意见，也并没有提及持续经营的重大不确定性。为此，香港财务汇报局将展开调查。换句话说，普华永道可能因为恒大事件而被追责。

这样看起来，会计师事务所是一个风险挺高的行业。  *负责审计把关的会计师，可能因为自身业务不过硬，或者是因为职业道德问题，没有识别出潜在风险和账目造假，出现严重失职。*

这里我们不去讨论故意放水的职业道德问题，仅仅从业务技术层面来看，你会发现，要成为一名合格的会计师真的太不容易了，必须练就一双火眼金睛，才能发现造假的蛛丝马迹，他们做的简直就是福尔摩斯的工作。得到“前途丛书”里有一本书，叫 [《这就是会计师》](https://shop96693699.m.youzan.com/wscgoods/detail/2oja56pwvuatn8r?banner_id=seach.96501531~search~1~EXAZF3iu&words=这就是会计师&alg=0&slg=consumer-search,standardModify,731c53b3-c28d-284b-01cd-9eb398b202ff,726_dab1c93583e54aa587071d0e8e41c430&reft=1747042908817&spm=seach.96501531) ，这里面提到了很多会计师工作的真实场景。我给你说几个。这里说的会计师特指从事审计工作的注册会计师。

第一，会计师要像福尔摩斯那样注意细节。

想想看，厚厚的、满是灰尘的原始文件，让你去审计，你该最先注意啥？  *有经验的会计师会注意一些特别不起眼的细节。* 比如，这一页上为什么有折痕？那一页的右上角，为什么标注了一个不起眼的小星星，或者打了个对勾？为什么这一页纸特别新，或者特别旧？等等。  *这些细节是最好的路标，它意味着被审计客户重点关注过这里，可能有异常。*

比如有个会计师，就在一堆原始合同当中，发现有一个合同右上角标注了一个小星星，马上拿出来重点查看。发现这是一份销售合同，A公司卖给B公司货物。按说现在的销售一般都是送货上门，但这份合同却规定了由B公司自提货物，这样合同上就可以不必写明B公司的地址。再往下一看，合同还有一条送货上门的责任条款，规定如果运输途中货物损失，A公司要承担责任。这里就出现了明显的自相矛盾。深入一查，果然是一份虚假合同。

第二，会计师还要像福尔摩斯那样分析数据。

几年前，有家会计师事务所要审计一家游戏公司的账目。这家游戏公司在业内很有名气，打造出了十几个爆款IP，他们在2015年推出的一个新游戏，仅仅28天就流水破亿，不到一年流水破十亿，在海外销售也很火爆。按说，这样的公司应该不会查出什么问题。

但是，当会计师在审计这家公司的原始业务数据时，却发现了一个疑点，就是用户的充值时间很奇怪。按说，正常游戏玩家，不管是上班族还是学生，都应该是在周末或者工作日的休息时间，也就是午休和下午下班后，充值比较多。但是这家游戏公司的充值高峰，却是在上午9点~11点，以及下午2点以后的上班时间。更奇怪的是，会计师进一步去分析充值金额前100名的用户，发现里面有不少用户在差不多同一时间注册，每天的充值时间和充值金额也都差不多。你看，这就找到了一个充值造假的线索。

再比如，有家公司的主业是把石料抛入江中，以防洪水。它的每一次抛石作业都会详细记录时间和数量。但是，会计师怎么知道这些记录有没有造假呢？会计师去核对了每个抛石日期当天的气象日志，发现有时气象记录显示当天下着倾盆大雨或者其他极端天气，这时候肯定是不能进行作业的，但公司文件却依然记录了正常的抛石数量，这显然是在造假。

第三，会计师还要像福尔摩斯那样“反套路”。

比如，你是一名会计师，要去银行打印客户公司的对账单。你一进银行大堂，就有一个穿着工作服的客户经理迎上来，让你稍坐等候，他帮你办好了，把文件递给你。听起来没啥问题吧？这里头可能有很多猫腻。第一种可能，这个所谓的“客户经理”根本不是银行的人，他假扮银行职员，然后塞给你一张早就准备好的虚假文件。第二种可能，这个客户经理确实是银行的人，但是他已经和客户公司串通好了，他给你的文件也是假的。

怎么避免这样的套路呢？有经验的会计师，会到银行的任意柜台，随机找一个柜员，确认对方工号后，让他现场调取信息，把文件打出来。

我就不举更多例子了。类似的案例，在 [《这就是会计师》](https://shzf-h5.igetget.com/v2/product/detail/?alias=s9l9sfnizxjn) 这本书里到处都是，推荐你自己去阅读。一句话：  *作为资本市场的“看门人”，会计师，就是用数字发现真相的人。*

来看今天的第二条。

上周末，有一名新冠感染者到上海迪士尼游玩。这名人员确诊后，上海迪士尼立刻封园，园区内的所有游客就地接受核酸检测。从下午6点到晚上11点多，短短五个多小时，在医务人员、民警和志愿者的共同努力下，园区内几万名游客顺利完成了检测采样，全程井然有序。大家都为这样的组织能力和游客表现出来的高素质而点赞。

此外，还有一个细节引起了我的注意。在紧张地进行核酸检测的同时，迪士尼园区内的户外演出照常进行，当晚的烟火表演也按计划燃放。我看到现场的视频，游客们在美丽的烟花中完成检测采样，竟然有些莫名的激动。

为什么在紧急状态下，迪士尼不停止户外演出、不取消烟花燃放？除了给园内游客加油鼓气，还有别的用意吗？

也许可以从迪士尼的经营理念中去寻找答案。现在都在聊“沉浸式体验”，其实 迪士尼就是沉浸式体验的鼻祖啊。  *它经营的，不是某个具体的娱乐项目，而是一个童话梦境，迪士尼乐园就是一个“造梦空间”。*

那么，  *在这个童话梦境里头，最重要的是什么？是保证游客“不出戏”。* 即使是在新冠排查这样一种极端情况下，迪士尼也要尽力去维护这个“梦境”不灭。游客们可能永远不会忘记那晚的烟火。同样地，在迪士尼的日常管理中，也特别注重保护这样的梦境体验。举个例子，这是得到用户商磊，从东京迪士尼原运营总监齐藤茂一那里听到的。

东京迪士尼有一个人气很旺的项目，女孩儿们要打扮成迪士尼公主的样子，在灰姑娘城堡外，等待接受王子的邀请去城堡做客。城堡外有一圈半米高的台子，有一天，一个打扮成艾莎公主的小女孩爬上了台子，不仅在台子上走来走去，还模仿艾莎公主的样子做着各种危险动作。

怎么办？女孩儿沉浸在“艾莎公主”的想象中，如果工作人员直接上前劝阻，这样的美好体验就被破坏了。这时候，工作人员淡定地走到艾莎公主面前，深深地朝她鞠了一躬，说到：“尊贵的公主殿下，时间到了，王子已经在宫殿里等您了，请您随我前往宫殿吧。”说着，把一只手伸向小女孩。

女孩没有丝毫惊讶，而是配合地扬起了头，优雅地把右手交给工作人员，跳下了台子。一场危机就这么顺畅地解除了。

我想起前不久，北京环球影城也有一个类似的例子。一名游客朝着机器人威震天竖中指，这当然是一种应该制止的不文明行为。你猜现场是怎么处理的？没有工作人员冲出来制止，倒是威震天当场发飙了。他愤怒地对着游客喊道：“你这个手势太不礼貌了，你的爸爸妈妈没教过你吗？愚蠢的家伙，肮脏的人类。”当然，我们知道，这段话其实是扮演威震天的工作人员用电子变音说的。

再补充一个背景，威震天是《变形金刚》里的头号反派，人设就是人类的敌人。“愚蠢的家伙，肮脏的人类”这类短语是他的口头禅，非常符合他的人设。在场的其他游客看到这一幕，仿佛看到了一场人类与威震天的斗法，不但不会“出戏”，反而加深了体验。这段视频传到网上后，大家也纷纷力挺威震天，说它说得没毛病，是这名游客给人类丢脸了。

*有人说，管理的最高境界是“无痕”。在沉浸式的场景里，怎样把你的管理融入游客的体验，是一门值得深挖的大学问。*

左星星：曾经在四大从事审计工作5年，道听途说+亲身经历了不少奇葩事：
 
1.     有一次去客户那里审计，客户新来了一个应届毕业生，刚入职2个月，我们去导数据，她眨巴着单纯的大眼睛问我们：“我们有两套账，一套是给税局的，一套是真实经营的，你们想要导哪一套？” 我……
 
2.     有一家客户从事养猪产业，作为会计师，每年的12月31日都是存货盘点日，养猪场的存货自然是猪，当天去盘点的是一位小姑娘，于是她就在凌冽的寒风中，钻进猪圈，仔细的数清楚一栏有几头猪……
 
3.     在审计项目中，抽取凭证通常是安排给刚入职不久的新人来做，因为主要是体力活，但是其实通过抽取凭证，可以发现公司的很多问题。比如某企业差旅费的报销凭证里，就被翻出来在国外商店购买名牌高档包包的凭证，还有在境外迪士尼门票的凭证（那时候上海还没有迪士尼）。这些都说明公司报销管理方面存在严重问题。
 
4.     其实审计工作最大的问题是，很难取得完全的独立性。因为雇佣你的是对方公司，而你查的又是他们的账目，如果对方是个大公司，审计费很高，这样的公司会计师事务所也是「得罪不起」的，因为也怕丢了大客户。于是对于一些「致命性」的问题，会计师事务所会有自己的底线，但是对于一些小问题，有些会计师们可能就选择「睁一只眼闭一只眼」了。

沉浸式的感官体验、游购结合的消费特征、情感与社交的需求、线下与科技的联动……商业+模式，多样元素进行碰撞、交融、落地于实体，这将是未来主要消费群体所热衷的。

李十三：会计是统称，其中还可以细分审计会计、财务会计和管理会计。审计会计是今天课程的主角，可以跟他学如何抽丝剥茧，分析数据，通过数据发现真相；财务会计也可以称为“外部会计”，可以跟他学如何登记账簿，编制报表，向企业外界报告财务状况和经营结果；管理会计也可以称为“内部会计”，可以跟他学如何分析研究，预测决策，为企业内部管理者提供决策依据。
