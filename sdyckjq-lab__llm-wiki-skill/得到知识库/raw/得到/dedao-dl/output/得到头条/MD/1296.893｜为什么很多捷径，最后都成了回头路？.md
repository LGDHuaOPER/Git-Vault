# 893｜为什么很多捷径，最后都成了回头路？

精挑细淘，得到头条。我是李南南。

今天我们从一个有点扎心的数据说起。

过去两年，减肥针，也就是GLP-1受体激动剂，在全球掀起了热潮，其中最出名的就是被称为一代“神药”的司美格鲁肽。临床数据已经给出证明，很多人用了之后确实有效。

但今年年初，牛津大学发布了一项研究，发表在《英国医学杂志》上，针对的是“第一批大规模停药的人”的数据。结果发现，停药之后，那些没有同时改变生活习惯的人，平均每个月反弹0.4公斤，多数人不到两年，减掉的体重就全部回来了。

为什么会这样？很简单，因为  *这类药物解决的是“控制食欲”这个问题，但它没有解决更深层的生活习惯问题。* 药在的时候，食欲被压住了，药停了，食欲回来了，但新的饮食习惯、运动习惯还没有建立起来。

说白了，那个本来应该经历的过程，一点一点调整饮食结构，慢慢建立运动节律，被跳过去了。

所以这件事并不是在说减肥针没用。我们想说的重点，是由此延伸出的一个更广泛的联想。

为什么很多捷径，走着走着，最后都成了回头路？

比如，你有没有这样的经历：学了一个速记方法，感觉背单词超快，但真正要开口说话的时候，还是卡住了。报名了一个在线课程，每节课都刷完了，但一周后问你学到了什么，却说不清楚。引进了一个效率工具，感觉产出翻了好几倍，但真正要做判断、做决策的时候，还是得从头想。

*这些捷径未必是骗局，它们在某个维度上也许是真实有效的。* 我们要关注的，是那些“失效”是怎么发生的。

关于这个问题，摩根·豪泽尔，也就是《金钱心理学》的作者，曾经提出过一个论断，叫，  *“这事儿就应该难”* 。没错，应该难。

注意，这个道理本身并不复杂。但就是因为道理太简单，反而容易被很多人忽略。而  *摩根·豪泽尔最厉害的地方就在于，他特别擅长“重新点亮”那些我们习以为常的知识。* 说白了，与其说他擅长“教人”，不如说他擅长“劝人”。

比如他之前的几本书，《金钱心理学》《金钱的艺术》《一如既往》，你读完之后会发现，他要说的核心不外乎就是两句话。第一句，别嘚瑟。第二句，多存钱。别看道理浅显，但他总有办法把这个浅显的道理说到你的心坎里。

好，话不多说，咱们正式开始。关于“这事儿就应该难”，摩根·豪泽尔讲过这么一个故事。

早年美国有个国民喜剧，叫《宋飞传》，前前后后有180集。有一次，著名的节目制作人大卫·莱特曼跟宋飞聊起剧集。宋飞说，有个事很让我沮丧，电视台给节目配备了整整一个编剧团队，但这些人写出来的东西并不好笑。

莱特曼回了他一句：要是他们都能写出好东西，那才奇怪吧？

宋飞愣了一下。莱特曼说：你想想，如果这些人真的能天天源源不断地写出好笑的东西，那才叫不正常。喜剧本来就很难，不是谁坐那儿就能写出来的。

据说在宋飞后来的整个职业生涯里，他都把这句话当成座右铭：对，这事就应该难。

豪泽尔用这个故事说的是一个很简单的道理：  *当一件事的回报非常高时，它本来就应该很难。*  *这不是系统坏了，也不是方法不对，这就是它该有的样子。* 80%以上的职业基金经理长期跑不赢大盘，很多人用这个说投资行业“烂掉了”。但豪泽尔说，要是随便一个人都能轻松跑赢，那才叫奇怪。高回报天然就伴随着高难度，这是规律，不是缺陷。

再比如，脱口秀高手克里斯·洛克，每个包袱都精准。但有一个细节很多人不知道：克里斯·洛克每年都要在几十家名不见经传的小俱乐部里演出。他每次大型巡演前，要先在这种小场馆演四五十场。那些小俱乐部的演出，永远不会出现在他的履历里。豪泽尔说：你在舞台上看到的那个完美，只是他全部尝试的1.5%，你没看到的，是剩下98.5%的失败和磨砺。

听到这，有人可能会好奇，既然我们都知道“台上一分钟，台下十年功”，也知道很多事情不能偷懒，但为什么我们有的时候偏偏想尝试走捷径呢？

按照通常的设想，这是因为想偷懒，或者急功近利。但是豪泽尔有一个特别的洞见，他说，  *捷径的危险不在于它明显是假的，而是它在某些维度上是真的。* 这也恰恰是很多人选择它的原因。

比如，1846年的美国，有一批移民计划翻越内华达山脉前往加州。有个向导告诉他们：有一条路，比常规路线少走好几百英里。

其中有个家族，叫当纳家族，选择了这条捷径。首先，向导没有撒谎。其次，从地图上看，那条路真的更短。他们做出的，是一个看似完全“理性的”决定。

结果呢，他们遭遇了历史上最惨烈的求生事件之一：大雪封山，被困数月，粮食耗尽，最终不得不分食同伴遗体才活下来。出发时87人，最后只有48人活着抵达目的地。

在那一刻幸存者才明白：那个向导量的是直线距离，他量的没错。但他没有量的，是高山的海拔、积雪的深度、补给的消耗速度，以及那个窄得不能再窄的大雪尚未封山的时间窗口。

就像前面说的：捷径的危险不在于它明显是假的，而在于它在某个维度上是真的。捷径省掉的，往往正是那些你没有意识到，但至关重要的东西。

但问题是，我们的大脑天然倾向于忽略这些“潜藏的阻力”。心理学上有一个概念叫  *“流畅性错觉”* 。  *当我们做一件事感觉很顺、很流畅，大脑会自动把这种感觉解读为“我在进步”。* 节食的人看到体重计数字下降，以为减肥成功了；刷完一遍笔记的学生感觉很流畅，以为学会了；引进了效率工具的团队看到产出数量上涨，以为效率提升了。

我们之前讲过认知科学家罗伯特·比约克的研究。他用了几十年时间研究人类的学习，结果发现：  *让学习感觉更难的方式，往往让记忆更持久，理解更深。* 他把这个现象叫做“合意困难”。说白了，学完之后等几天再复习，比集中突击难得多，但记忆效果远超突击。先做题再看教程分解，比先看教程分解再做题难得多，但学习效果也好得多。

他在2011年的研究里总结道：我们能做的最有效的事，往往是让自己在学习过程中更难一点。

同样的规律在身体上也成立。2016年，《肥胖》期刊曾追踪了美国真人秀“超级减肥王”的参与者长达6年，发现极速减重之后，当事人的某些身体代谢率出现了变化，他们的身体开始主动消耗更少的能量。简单说，就是他们比减肥之前更容易发胖了。在选择捷径之后，身体用一个更强的反向机制来还这笔账。

*在摩根·豪泽尔看来，这些被省掉的东西，并不是障碍，而是过程本身。过程被省掉了，结果也就省掉了。*

那如果必要的困难绕不开，人应该怎么面对它？这里有一个很重要的心态上的调整。不是“我要更努力地忍受”，而是把这个困难重新定义，它不是我前进路上的麻烦，它是我想要的结果的一部分。

就像克里斯·洛克去小俱乐部演出，在他看来这不是在受苦，而是在打磨他的段子，他是在做这件事本来就需要做的那部分工作。

这个区别很重要。同样是在做一件困难的事，一个人认为自己在克服障碍，另一个人认为自己正在走这条路，感受完全不同，行动也往往不同。

*贝索斯说过一句话：如果你的工作生活能做到有一半是享受的，那已经非常了不起了。能做到这一点的人寥寥无几。*

这不是在说工作有多惨，而是说，大多数有价值的工作，本来就有很大一部分是枯燥的、困难的、缓慢的。以“有一半是好的”作为成功的标准，是对真实工作性质的诚实认知。

注意，说到这里，我们也要做一个很重要的区分，我们并不是在说，你要主动找苦吃，效率工具都别用了。

我们要说的重点是，不是所有的难都是必要的难。有些困难是可以优化掉的障碍，有些难是必须经历的过程。关键是区分二者。

比如，信息查找慢，可以用工具；重复性事务，可以自动化；格式整理、文档归档，AI做得比人快得多。这些是无意义的摩擦，优化掉是对的。

你看，克里斯·洛克也用麦克风录音，用软件整理段子，他从不拒绝工具。但他没有绕过在小俱乐部演四五十场这件事。他并不是崇尚苦难。他只是很清楚这件事的必要过程是什么。

还记得去年听万维钢老师讲自己借助AI写作。他说，在用了AI之后，自己投入的精力完全没有减少，写作的时间也没有缩短，反而变长了。为什么？因为他要用更多的精力去磨合结构，去搭建框架，去实现更好的效果。

换句话说，有时候你用了新工具之后觉得更累，也许未必是你用错了，反而说明你用得对。  *梯子的作用是让人爬得更高，而不是躺在上面睡觉。有时，那些必要的困难，不是挡在你和结果之间的墙，而是我们通往结果的路本身。*

关于这个话题，咱们先说到这。

## 热门留言

左星星：区分两种困难，其实可以用一个很直接的标准：它有没有在加深你对问题的理解？如果只是让事情变得更繁琐，比如反复调格式、复制粘贴数据、在不同系统之间来回切换，那更多是消耗精力的摩擦；如果是在逼你做判断、讲清楚观点、为结果负责，那往往是绕不开的过程。

这种差别在工作中很常见。比如同样参加项目复盘，有人把PPT做得很精致，但本质是在整理已有信息；也有人会主动指出决策问题、分析原因，哪怕表达还不够成熟，却在不断提升判断力。前者更轻松，后者更费劲，但时间一拉长，能力差距会逐渐显现。

放到AI的使用上，这条分界线就更关键了。让AI帮忙整理资料、搭建框架，本身没有问题；但如果连“我到底想表达什么”“这个结论是否合理”都交给工具，人就很容易停留在表面效率上。工具可以放大结果，却不能替代思考。

因此，更有效的做法，是主动把低价值的困难交给工具处理，把真正有价值的部分留给自己。减少无意义的消耗，同时保留那些能训练判断、表达和决策能力的环节。

很多时候，成长并不是因为事情变简单了，而是因为我们开始学会分辨：哪些石头应该搬开，哪些坡必须自己爬。

Leslie Ko：捷徑為何常變成回頭路？
高回報的事情，往往天然伴隨高難度；如果我們省掉了必要的困難，也可能同時省掉了真正的成果。

很多人慣常本能地追求捷徑，不是因為捷徑完全無效，而是因為它在某些層面確實有效。比如減肥針可以短期降低食慾、快速減重，但如果沒有同步建立飲食結構、運動節律與生活習慣，停藥後就很容易反彈。問題不在於工具本身，而在於它跳過了「人真正改變」的過程。

摩根・豪澤爾所說的「這事兒就應該難」，其實是一種非常清醒的現實感。學習、減肥、創作、投資、經營關係，真正有價值的部分，往往都藏在那些不舒服、慢、笨、反覆打磨的環節裡。這些困難不是多餘的摩擦，而是結果的一部分。

當然，不是所有困難都值得忍受。資訊查找、格式整理、重複性工作，可以交給工具優化；但深度思考、習慣養成、內容打磨、能力沉澱，不能被完全外包。真正的智慧，不是拒絕捷徑，而是分辨：哪些困難可以刪掉，哪些困難必須親自穿越。

捷徑最危險的地方，不是它是假的，而是它只讓你拿到表面的快，卻拿不到底層的穩。

王弈冬：这节课真正刺痛我的，不是“捷径会变成回头路”这个结论，而是它揭示了一个更隐蔽的认知陷阱：我们常常把“省时间”等同于“省过程”，却忘了过程的本质不是时间消耗，而是不可压缩的“能力沉淀”。

2026年4月的几起热点事件——学术造假、带货数据注水、加密庞氏骗局——表面看都是道德问题，但底层逻辑惊人相似：操作者都认为自己找到了“别人不知道的漏洞”。他们不是不知道风险，而是高估了自己“跳过去之后还能补回来”的能力。这种侥幸心理，恰恰源于对过程价值的无知。

什么是过程价值？它不是“花时间做完”的形式主义，而是只有亲身经历才能获得的那种非线性成长——比如看过一万个病人后的经验，比如看过无数本书后积累的知识。这些无法通过“跳过”来复制，就像你不能通过看视频学会游泳。

因此，判断一个捷径是“真优化”还是“假抄近道”，有一个极简标准：这个方法如果被所有人知道并采用，它还能成立吗？ 真正的方法创新（比如费曼学习法）是公开后依然有效；而造假、刷数据、资金盘一旦透明化，立刻崩溃。前者优化过程，后者绕过过程。

对我而言，最实际的启发是：宁可接受“慢但完整”的笨功夫，也不要赌“快但悬空”的技巧。因为回头路的代价，往往不是回到起点，而是失去继续走这条路的资格——学术诚信没了、平台账号没了、投资者信任没了。这些损失，无法通过任何捷径赎回。

张亭：【亭语心灯之一六八二】

1. 别迷信"快速验证"，要验证"真实问题"
很多创业者用AI生成问卷、快速投放，看似高效，实则绕过了最关键的"问题发现"环节。真正的洞察需要你亲自和用户聊天，观察他们的痛点，而不是让AI替你"想"用户需要什么。

2. 警惕"工具依赖症"，保持"笨功夫"能力
当AI能帮你快速生成商业计划书、市场分析时，别完全依赖它。那些看似"低效"的深度思考、实地调研，恰恰是你建立行业认知壁垒的关键。工具再强大，也无法替代你对市场的直觉判断。

3. 走捷径的本质是"绕过学习"，但学习才是核心竞争力
用AI快速写代码、做设计，看似节省时间，实则错过了理解底层逻辑的机会。创业者要明白，那些让你"费脑子"的过程，恰恰是在构建你的认知护城河。

4. 判断标准：这件事绕过去，你的能力会退化吗？
如果答案是肯定的，那就不能走捷径。比如用AI写融资路演PPT可以，但用AI替代对行业的深度分析就不行——前者是效率工具，后者是能力建设。
