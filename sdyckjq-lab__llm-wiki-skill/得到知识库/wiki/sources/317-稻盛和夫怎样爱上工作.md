# 稻盛和夫：怎样爱上工作

> "经营四圣"中最特别的一位——连续创办三家世界500强企业的稻盛和夫，其"工作即修行"哲学的核心密码

## 核心内容
稻盛和夫（2022年8月24日去世，享年90岁）是日本"经营四圣"中最特别的一位：唯一一位连续创业者（创办京瓷、KDDI两家500强，78岁接管破产日航第二年扭亏），也是唯一一位企业家中兼任管理学家的。其核心理念"工作即修行"：大部分人无法选择自己最喜欢的工作，但可以通过改变心态，爱上正在做的工作。关键方法：把工作分解为小目标，在每一个小成就中获得正反馈，形成"热爱-投入-成就-更热爱"的正循环。

## 适用场景
当你对当前工作感到厌倦、需要重新找到工作意义时；当需要激励团队成员从"被动工作"转向"主动投入"时；当面临职业转型需要锚定内在驱动力时。

## 反面案例 / 避坑指南
不要以为"爱上工作"等于"无条件接受一切不合理要求"——稻盛和夫说的是心态转变，不是放弃原则。不要把"工作即修行"误解为"996合理化"——修行的核心是投入和专注，而非时长。不要等到找到"完美工作"才开始投入——稻盛的核心洞见是"先投入，热爱会随之而来"。

## 实操SOP / 行动清单
1. 将当前最重要的一个工作任务分解为3-5个小目标
2. 每完成一个小目标，给自己一个正向反馈（记录/分享/庆祝）
3. 在每天结束时写下"今天工作中最有成就感的一件事"
4. 一个月后回顾：你对这项工作的感受是否发生了变化？
