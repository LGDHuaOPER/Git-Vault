# 想你的风，是怎么吹到哀牢山的？

## 核心内容
1. 一些高手会莫名其妙地在某一刻，突然变成一个生瓜蛋子，然后在寻死的路上一去不复返。

2. 高手失误的第一个原因是，人的心智有个悖论，在危险面前，方法和态度，二者天然是矛盾的。

3. 高手失误的第二个原因是，选择性忽略。促使他们选择正确答案的，不是理性，而是情绪。

4. 在极限挑战面前，管理知识靠的不是头脑，而是流程。不要高估自己的临场反应，也不要低估环境的复杂性。
