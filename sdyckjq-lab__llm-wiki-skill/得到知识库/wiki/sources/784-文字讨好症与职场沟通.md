# 文字讨好症与职场沟通

> 语言通胀让简单的话变啰嗦，职场沟通中越"讨好"越显得不真诚

## 核心内容
从ChatGPT用户说"谢谢"导致数千万美元电费切入，揭示"语言通胀"现象——词语表达力持续贬值，人们被迫用更多更夸张的词汇表诚意。称呼类通胀（宝贝/老师/亲）、情感类通胀（哈哈→哈哈哈哈）、标点类通胀（句号→感叹号→波浪号），最终导致职场"文字讨好症"，越努力讨好越显得虚伪。

## 适用场景
当你写工作消息习惯加大量语气词、表情包、波浪号时；反思自己是否患了"文字讨好症"时；希望提升职场表达简洁度和专业感时。

## 反面案例 / 避坑指南
不要为了"友好"牺牲效率——过度修饰反而增加对方理解负担。避免跟风使用膨胀词汇，保持真实简洁的表达往往更打动人。不把"文字讨好"等同于高情商。

## 实操SOP / 行动清单
1. 检查常用表达：是否过度使用"哈"、"呀"、"～"等膨胀词
2. 写工作消息时先删掉所有修饰，看核心信息是否清晰
3. 用句号代替省略号和波浪号，回归确定性表达
4. 重要信息不藏在客套话后面，开门见山
