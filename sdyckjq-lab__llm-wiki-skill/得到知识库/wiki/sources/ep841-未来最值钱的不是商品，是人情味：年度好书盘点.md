# 未来最值钱的不是商品，是人情味：年度好书盘点

## 核心内容
1. 第五消费时代的核心是，人们的消费从“买东西”变成“买关系”。未来最值钱的不是商品，而是“人情味”。——《第五消费时代》

2. 大债务周期的跨度大概是80年，上下浮动25年。对个人来说，要确保安全底线，把风险分散。国家层面，关键在于合作，而不是对抗。——《国家为什么会破产》

3. 马斯克最厉害的不是发明，而是“推墙”，就是推倒那堵我们习以为常、从不质疑的墙。——《马斯克逻辑：科技浪潮的律动与走向》

4. 花钱最大的陷阱，不是花在了哪里，而是花给了谁看。摩根·豪泽尔的建议是，不要去想买到了哪些“别人看得见的东西”，而是思考自己能买到哪些“别人看不见的东西”。——《金钱的艺术》
