# 大事敲定：“十五五”这些罕见措辞，透露关键信号

## 核心内容
1. “十五五”规划不是常规的五年计划，而是决定了未来五年中国经济的走向，也决定了人才的机会在哪里。未来五年将有三重变局，科技强攻、区域洗牌、内需转向。

2. 科技强攻是“十五五”规划的战略重点，不是简单的技术进步，而是要在集成电路、工业母机、基础软件等关键领域，国家要实现从“跟跑”到“并跑”，甚至“领跑”的跨越。

3. 东部加速、成渝崛起、中西部分化，这是未来五年的区域格局。同时，跨区域联动和城市群一体化将创造新的投资机会。

4. 经济重心正在转向内需，不是简单地扩大消费，从出口转向内需、从投资拉动转向消费驱动、从撬动项目转向撬动人。
