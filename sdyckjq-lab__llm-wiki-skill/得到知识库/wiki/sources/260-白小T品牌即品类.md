# 260｜怎样卖好一件白T恤？
> "任何一个品牌都有白T恤，但人们提到白T恤却很难联想到任何一个固定品牌。白小T的野心就是，开创一个'市场中有，心智中无'的新品类。"
## 核心内容
白小T：2019年创立的男装品牌，3年营收翻40倍，2021年近8亿。关键三步：1.定位——避开女装红海，切入30-50岁男性精英群体的职场休闲T恤空白 2.调性——主攻"科技感"（液氨面料、宇航服气凝胶、紫外线感应标）3.渠道——选今日头条/抖音的"货找人"模式而非传统淘宝的"人找货"，符合男性"不愿意挑"的行为模式。终极目标：品牌即品类——让白小T成为T恤的代名词。第二部分讲"解决问题七步法"：定义问题→分解问题（最关键）→划分优先级→制定计划→选择工具→综合分析→阐明观点。
## 适用场景
品牌从0到1的定位策略（找市场缝隙→定调性→选渠道）；男性消费品类的差异化打法；用"科技感"作为普适品牌调性；职场中结构化分析复杂问题
## 反面案例 / 避坑指南
女装品牌盲目强调"正宗"（消费者感知不到）、"销量大"（年轻人觉得没特色）、"国潮包装"（本末倒置）——先讲清楚产品卖点。解决问题时跳过分解步骤直接找答案——分解清楚了问题，方案就自动浮现。面试时被问是否该建新机场——不会分解就不会回答。
## 实操SOP / 行动清单
1. 品牌定位三步法：哪个市场有缝隙→用什么调性填→哪个渠道触达 2. 面对复杂问题先分解：机场问题→现有机场运力（跑道数/容量/利用率）→能否通过提高利用率满足需求 3. 职业选择四维度分解：内在能力成长/外在影响力/工作乐趣/薪酬回报 4. 每年按职业阶段给四个维度分配不同权重打分
