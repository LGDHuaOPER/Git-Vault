# 制造业向中餐学习

> 什么时候中国制造业发展到接近中餐的造诣，中国制造就真的崛起了

## 核心内容
政策焦点从龙头企业转向"专精特新小巨人"——制造业最大瓶颈是上游"五基"（基础零部件/元器件、基础材料、基础工艺、基础装备、基础软件）。工信部近5000家小巨人平均拥有98件专利。李平教授类比：德国机床业=中国餐饮业，底蕴深厚高手在民间，任何龙头倒下都有新龙头补上。商业模式："核心需求+极致低价"——海伦司小酒馆（啤酒7.8元、无DJ无调酒师、毛利率65%+）、五菱宏光MINI EV（2万多、砍掉快充/倒车影像/空调，续航120KM足够通勤）。海伦司三板斧：好地段差位置+省人工+自酿酒直采。

## 适用场景
产品定位面临"什么都想做"时（做减法）；市场下沉策略设计时；评估制造业投资方向时；通知/标题写作时。

## 反面案例 / 避坑指南
过去的产业政策只扶持龙头→上游"五基"卡脖子。产品功能堆砌≠竞争力——海伦司和宏光MINI证明砍掉非核心需求反而爆发。通知标题写"项目进度通知"不如写"请提交项目工作计划表"。

## 实操SOP / 行动清单
1. 产品设计：列出所有功能→问"用户核心需求是什么？"→砍掉非核心→极致低价
2. 选址策略：好商圈的差位置（近目标人群、租金低）
3. 通知标题：把具体事、人写进标题（"在前店村上车的同事必看"）
4. 创业方向参考：专精特新小巨人赛道（五基领域）
