# “消失的专业”，是社会变化的最后一环

## 核心内容
1. 到2025年，国家对专业的调整比例会达到20%左右。高校的专业变迁，其实是社会变化整个链条的最后一环。先是社会需求发生变化，之后这个变化才会传导到高校专业调整。

2. 选择职业可以提早开始，中学就有两个特别好的思考职业生涯的节点。一个是高一文理分科时，可以思考自己对未来的追求，一个是高考报志愿前，可以体验自己感兴趣的职业。

3. 一个人的职业竞争力结构中，专业只占三分之一。另外三分之二，分别是通用能力与人际能力。当专业遭受了震动，你还可以用人际能力和通用能力，重构自己的职业竞争力。

4. 想要转行的职场人，可以瞄准三个指针。分别是老领域的新机会、所在行业的上下游，以及离职前同事的去向。

## 适用场景
了解“消失的专业”，是社会变化的最后一环的相关背景。
