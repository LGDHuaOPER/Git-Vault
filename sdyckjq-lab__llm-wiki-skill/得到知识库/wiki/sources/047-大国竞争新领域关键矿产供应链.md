# 大国竞争新领域：关键矿产供应链

> 关键矿产的供不应求、储量集中、冶炼集中，使其成为大国博弈新焦点。

## 核心内容
清洁能源相关矿产（锂、钴、镍、稀土）比传统油气资源更稀缺且地理分布更集中。全球精炼锂60%在中国，钴72%由中国企业冶炼，引发美国"矿产外交"。同时讨论了"十倍改进"创业理论：新产品体验 = 现有体验 + 优化 - 用户转移成本 - 触达成本，只有十倍改进才能克服路径依赖。九号平衡车把价格从3-4万降到2000元，反过来收购了鼻祖赛格威。

## 适用场景
分析地缘政治和产业竞争格局时；评估创业项目是否有足够差异化时；理解供应链安全对国家战略的意义时；制定产品定价和市场进入策略时。

## 反面案例 / 避坑指南
不能只追求10%的小幅改进——用户转移成本远高于预期，小改进无法撬动市场。不能忽视冶炼环节的集中度——矿产控制不只是储量问题。技术上不能依赖单一矿产路线，需多元化布局。

## 实操SOP / 行动清单
1. 评估产品的"十倍改进"潜力：成本/效率/体验是否降低或提升一个数量级？
2. 计算用户转移成本，判断改进是否足以克服惯性
3. 关注关键矿产供应链上游布局机会
4. 创业时避免与行业巨头在"小幅优化"上竞争
