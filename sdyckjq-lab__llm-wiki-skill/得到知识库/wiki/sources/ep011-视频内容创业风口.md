# 视频内容创业风口

> 流量形态从文本转向视频，四变现通路已打通，赛道遇冷正是入局良机

## 核心内容
李丰判断视频内容创业风口来了，三原因：新文娱赛道投资冷门无人抢、互联网流量从文本转向视频（2019 Q4视频时长首次超过即时通讯）、内容变现四条通路全部打通（独立游戏/影视IP/衍生品/消费者直接付费）。另：FDA批准阿尔茨海默症新药阿杜卡马单抗引发争议——王立铭指出药物审批不完全是科学决定，还要考虑非科学因素（有无替代疗法、患者支付能力等）。另：链家门店转型社区第三空间。

## 适用场景
判断创业方向时；投融资赛道选择时；内容创作者选择平台/形式时；评估药物/技术审批决策时；线下门店转型设计时。

## 反面案例 / 避坑指南
追热门赛道→泡沫期后一地鸡毛。纯科学标准审批药物→忽略患者真实需求。线下门店只做交易功能→被线上替代。只做文本内容不转型视频→错过流量迁移。

## 实操SOP / 行动清单
1. 判断时机：赛道冷但趋势确定→入局窗口
2. 检查变现通路：四条通路（游戏/影视/衍生品/直接付费）是否已全跑通
3. 看用户行为信号：文本→视频的时长迁移是关键
4. 审批决策：科学证据+患者需求+支付能力 综合判断
5. 门店转型：从交易场所→社区便民空间
