# 648｜告别"琐事瘫痪"，给你一份低能量状态自救指南

> 能处理复杂工作却在小事上反复拖延？这不是懒，而是"琐事瘫痪"

## 核心内容
美国作家安妮·海伦·彼得森提出"琐事瘫痪"概念：能力出众的人，能处理复杂工作、参与高强度职场竞争，偏偏在小事上提不起劲、无限期搁置。核心原因不是懒惰，而是**倦怠**。当代年轻人面临经济压力、职场内卷、社交媒体焦虑三重挤压，精力被大事消耗殆尽，留给琐事的只有疲惫。解决办法包括：建立琐事处理惯例、降低决策门槛、抓住"做重要但不紧急的事"。

## 适用场景
- 工作高效但生活混乱的职场人
- 长期拖延报销、退货、缴费等琐事的"低能量人"
- 放假只想躺平的年轻人
- 管理者理解团队成员"倦怠"状态

## 反面案例 / 避坑指南
- 不要简单归因为"懒"——越自责，自我损耗越大，陷入恶性循环
- "低能量老鼠人vlog"虽是表演，但背后反映真实的倦怠情绪
- 彼得森指出：美国年轻选民投票率低，原因之一竟是"邮寄选票程序太麻烦"

## 实操SOP / 行动清单
1. 列出琐事遗留清单，设置明确DDL
2. 安排专门时间段集中处理琐事（如每周日下午）
3. 适当外包（如家政服务），不在琐事上浪费心力
4. 抓住"做重要但不紧急的事"，打破拖延循环
