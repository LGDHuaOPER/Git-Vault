# 过个“不看新闻”的五一假期，试试看？

## 核心内容
2. 真正重要的事情只有两种。第一种是，知道后能让你立刻做出更好的决策，一般不会出现在新闻中。第二种是，能让你跟这个世界产生联系，并且长期来看有助于成长的事，可以据此来判断资讯的价值。

3. 获取新闻的关键是怎么做好筛选。每个人都应该给自己准备一个媒体清单，长期关注权威的信息源，保持15%的陌生信息摄入，这或许是开阔眼界效率最高的方式之一。

美君：还记得我在南京上大学时，最喜欢买的就是《扬子晚报》和《金陵晚报》，每周都买，翻来翻去看新闻。

拿着报纸慢悠悠地看新闻，和现在在各类社交媒体上“被动”接受潮水般涌来的新闻完全是两种感受：前者需要注意场合，比如去买菜的间隙站那里看报纸就很有违和感，但惬意、自在；后者更方便快捷，随时随地，不受限制。

和报纸一起消失的，是报刊亭，过去的报刊亭，除了报纸还会有各类杂志，我学生时代最爱看的《意林》、《读者》、《青年文摘》、《萌芽》、《思维与智慧》、《演讲与口才》，还有一些恐怖/悬疑类杂志，捧起一本能反反复复看好久。

了解过个“不看新闻”的五一假期，试试看的相关知识。
