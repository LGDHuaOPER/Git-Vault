# 知识萃取三步法（得到压箱底的手艺都在这了）

## 核心内容
1. 知识萃取，就把知识从它所在的主体身上提炼出来，然后转述给别人听。这个过程的背后，隐含着管理注意力的能力、驾驭信息的能力，以及感知趋势的能力。

2. 知识萃取有一个简单的三步结构，包括问题是什么，答案不是什么，而是什么。问题+不是+而是，只有完成这个结构，你才算完成了一次知识的交付。

3. 知识的本质，不是概念，而是方案。只有把问题和答案连在一起，才叫知识。同时，引出旧答案，是为了倒逼增量价值。

左星星：知识萃取的关键并非简单的归纳与总结，而是创造性地为受众提供增量价值。在商业领域，这种“提供增量”的能力更为关键。比如，苹果的产品研发理念“关注用户需求背后的需求”，就是一种高水平的知识萃取。它通过反思传统电子产品设计的不足，提炼出“简化体验”的核心逻辑，将这一逻辑迁移到每一代产品的创新中，最终让苹果的产品形成了独特的用户黏性。
