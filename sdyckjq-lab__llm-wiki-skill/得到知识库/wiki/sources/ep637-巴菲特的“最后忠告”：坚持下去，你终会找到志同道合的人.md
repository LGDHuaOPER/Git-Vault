# 巴菲特的“最后忠告”：坚持下去，你终会找到志同道合的人

## 核心内容
1. 94岁的巴菲特在伯克希尔2025年股东大会上宣布退休，格雷格·阿贝尔将在今年年底接任CEO。阿贝尔接班之后，伯克希尔大概率将延续之前的经营模式，但目前的市场环境也将让它面临挑战。

2. 巴菲特的第一个忠告是，努力与那些你尊敬，你渴望成为的人，做朋友。和志同道合的人走在一起非常重要。万一找不到也没关系，继续做你手头的事情吧，坚持下去，你终究会找到和你一样认真思考的人。

3. 巴菲特的第二个忠告是，驾驭你的非理性，建立更长期的理性。首先，要想象一件事的长期终局，而不是短期的变数。其次，对所有不确定的事情保持谨慎。价值投资的本质之一，是不做多余的假设。

左星星：巴菲特的第二个忠告，关于理性，给了我很大的启发。它提醒我在各种诱惑、浮躁、信息爆炸的时代里，保有一颗不被打乱的心。如今，我们身处一个到处都在讲“风口”和“趋势”的年代，我们的决策很容易受情绪驱动，看到别人赚了，我们不想落后，听说某个机会大，我们也就想跟着赌一把。我们做的是“刺激下的决策”，而不是“深思熟虑后的选择”。

但如果我们开始训练自己从终局思考，不再被短期波动牵着鼻子走，就会慢慢培养出一种更深的判断力。比如，面对一份工作，问自己的是“十年后我想成为什么样的人”，而不是“这月工资多几千”；面对一个合作，也问“长期看是否靠谱”，而不是“今天能不能立刻见效”。
