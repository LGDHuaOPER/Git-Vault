# 月薪5000到年入千万，理财逻辑完全不同

> 尼克·马朱利《财富阶梯》：不同财富阶段的人，根本不该听同一套建议

## 核心内容
数据科学家马朱利将财富分成六层（净资产<7万→7-70万→70-700万→700-7000万→7000万-7亿→>7亿），每层核心矛盾不同：低层防意外（建缓冲垫）、中层提收入（别用研究投资逃避提升主业）、上层控消费欲（储蓄率比收益率更重要）、高层防豪赌（别拿已有生活去赌）、顶层靠企业所有权（工资和投资有天花板，系统赚钱才能指数级增长）。配套三工具：0.01%规则（不超净资产万一的消费不值得纠结）、1%规则（不能让净资产增1%的机会不值得投入）、成本意识（下一层不是免费的）。

## 适用场景
任何想建立个人财务策略的人理解自己的核心矛盾；破除"富人怎么做我就怎么学"的理财误区；帮助处于不同人生阶段的人找到当前优先级。

## 反面案例 / 避坑指南
不要在本金极少时花大量时间研究年化6%还是8%——当本金只有5万元，两者差距不过1000块。不要在中层阶段用"研究投资"来逃避"提升收入能力"——前者比后者容易得多。不要在高层阶段因为"错得起"就豪赌——很多第四层的人因此跌回底层。

## 实操SOP / 行动清单
1. 计算净资产，定位当前财富层级
2. 按层级匹配核心任务：低层建缓冲→中层提主业→上层控储蓄率→高层慎创业
3. 用0.01%规则清空小额纠结，用1%规则筛选高杠杆机会
4. 追求下一层之前，先计算成本（时间、健康、关系、自由）
