# 怎样讲好商业案例？

> 故事比认知更重要。人类通过归纳法学知识，"干货"没有记忆点和传播力。

## 英雄之旅叙事模型

把企业视为"英雄"，讲述"直面挑战—接受试炼—成功归来"的故事：
- **第一幕**：离开之幕。企业从日常经营中受到命运感召
- **第二幕**：启程之幕。进入"非凡世界"，接受试炼，战胜大BOSS
- **第三幕**：返回之幕。带着宝藏凯旋，境界升华

## 六种细分故事模型

| 模型 | 特点 |
|------|------|
| 工程师型 | 任务分解，各个击破 |
| 科学家型 | 不断试错，找到正解 |
| 侦探型 | 从结果倒推原因 |
| 运动员型 | 持续训练，突破极限 |
| 探险家型 | 开拓无人区 |
| 艺术家型 | 创意驱动，打破常规 |

## 核心原则

认知模式分演绎法和归纳法。人类擅长归纳法——从故事中总结道理，再应用到新场景。好知识的"湿度"来自丰富的故事，不能"干"讲道理。
