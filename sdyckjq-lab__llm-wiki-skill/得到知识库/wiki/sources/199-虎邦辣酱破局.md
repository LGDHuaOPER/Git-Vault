# 虎邦辣酱的破局点

> 面对"一超多弱"格局中的老干妈，不复制、不对抗、不硬拼——找到外卖这个高增长且无人占领的场景，另辟蹊径

## 核心内容
辣酱市场"一超多弱"格局：老干妈占各省第一，第二名是五花八门的地方品牌。虎邦辣酱三条路试错：①复制老干妈模式（定价更低、铺货更强）→ 死路；②纯线上电商降维打击 → 流量成本过高；③绑定外卖场景 → 成功。外卖优势：天然需要辣酱下饭、封闭购买场景排他性强、快速增长市场中无辣酱品牌入局。最终找到破局点："总有小草能从缝隙里钻出来，试图重新构建森林"。

第二主题：水泥行业减碳——碳中和的本质是产业升级，所有产业都值得用碳中和思路重做一遍。

## 适用场景
中小企业面对行业巨头时的竞争策略设计；寻找差异化破局点时；行业格局分析（判断是"一超多弱"还是"双寡头"等）时。

## 反面案例 / 避坑指南
不要正面复制巨头的模式——连包装都模仿老干妈哑铃瓶型的品牌基本都失败了。纯线上电商看似降维打击，但对低频消费品流量成本是关键障碍。破局点必须是巨头"看不见"或"看不上"的细分场景。

## 实操SOP / 行动清单
1. 分析行业格局：是一超多弱、双寡头还是完全竞争？
2. 列出巨头看不上的细分场景，从中筛选增长中的场景
3. 评估场景的排他性（封闭vs开放）、增长性、契合度
4. 先占领场景再扩展品类，而非先建品牌再找场景
