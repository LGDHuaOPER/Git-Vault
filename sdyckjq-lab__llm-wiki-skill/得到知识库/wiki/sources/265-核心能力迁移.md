# 265｜苹果怎么还不造车？
> "一个公司决定要不要进入一个新领域，最应该考虑的可能不是'这个市场有没有机会'，而是'我的核心能力能不能迁移过去'。产品可能消亡，能力永续长存。"
## 核心内容
苹果造车8年未果——不缺钱（3000亿美元现金）、不缺技术（CarPlay系统+自动驾驶专利）、不缺品牌，但核心顾虑是供应链管理能力无法复制到汽车行业。汽车供应链远超200家核心供应商，苹果无法像手机那样强控制每家。公牛插座入局充电枪——核心能力（电源连接标准化+安全性）完美迁移，天猫京东销量双第一。富士公司教科书级转型：从胶卷到化妆品（胶原蛋白+抗氧化技术）、医药（纳米分层渗透技术）、半导体（光刻胶），胶卷产值仅占1%但核心技术从未离开。第二部分："野性收集"——年轻人收集奶茶袋、汉服吊牌、晚霞照片，甚至有人靠"卖云"年入百万，将抽象事物商品化。
## 适用场景
企业评估新业务方向时判断核心能力是否可迁移；个人职业转型——你的底层能力是什么，能迁移到哪里；传统企业寻找第二增长曲线；如何从0到1创造新品类（想象力比执行力更重要）
## 反面案例 / 避坑指南
只看市场机会大就盲目进入——苹果1300亿美元现金也不敢贸然造车。柯达式转型：做运动摄像机、智能手机、时尚杂志——没有基于核心能力的转型注定失败。公牛启示：不造整车而做充电枪——找到核心能力匹配的最小切入点。
## 实操SOP / 行动清单
1. 做一张"能力-市场"匹配表：左列你的核心技术/能力→右列未来高增长市场→找交集 2. 富士方法：花两年时间盘点技术家底而非依靠拍脑袋 3. 个人职业转型：列出3项可迁移底层能力（如：复杂问题分解、跨部门沟通、数据分析），而非岗位名称 4. 从0到1创新：问"什么抽象的东西可以被商品化"
