# 时间日志

> 你不知道时间去哪了，是因为你从来没记过。时间日志就像记账一样，先记录，再分析，后优化。

## 详细说明

时间日志是一种简单但强大的时间管理工具：在一天（或一周）内如实记录每项活动的开始和结束时间，包括工作、休息、娱乐、通勤、饮食、睡眠等所有活动。通过累计记录和分析，你可以发现隐藏的时间模式：什么时候效率最高？什么活动是时间黑洞？有多少时间花在真正重要的事上？时间日志是时间管理的第一步——你无法管理你不测量的东西。

## 核心要点

1. 如实记录所有活动的时间起止
2. 持续记录至少一周才有统计意义
3. 分析阶段：识别时间黑洞和高效时段
4. 优化阶段：基于数据调整时间分配

## 增强分析

### 【核心定义】

像记账一样记录你每半小时在做什么。一周后你会震惊地发现：原来这么多时间花在了意想不到的地方。

### 【适用场景】

感觉"忙但没产出"的时候、想优化时间分配、准备开始时间管理但不知道从哪入手、自由职业者需要了解自己的工作效率。

### 【反面案例 / 避坑指南】

记录太细→变成负担放弃。只看不分析→记录失去意义。分析后不改→等于白记。用"应该"代替"真实"记录→美化数据欺骗自己。

### 【实操SOP / 行动清单】

1. 选工具：手机备忘录或时间追踪 APP。
2. 记一周：每切换活动时记录时间和内容，不需太细。
3. 分类统计：将活动归为工作、学习、娱乐、休息等类别。
4. 找问题：哪些活动耗时远超预期？哪个时段效率最高？
5. 定改进：将高价值任务安排到高效时段，给低价值活动设上限。

### 【模型联动】

与 [[紧急重要矩阵]] 结合→时间日志告诉你实际在哪象限花了时间。与 [[番茄工作法]] 结合→记录每个番茄的内容和效果。与 [[帕金森定律]] 结合→时间日志帮发现任务膨胀的证据。
