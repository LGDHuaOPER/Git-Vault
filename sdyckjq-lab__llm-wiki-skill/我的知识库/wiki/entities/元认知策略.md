# 元认知策略

> 大部分人只关注"学什么"，少数人关注"怎么学"——元认知策略就是学会管理自己的学习过程。

## 详细说明

元认知策略是关于"认知的认知"，即对自己思维过程的觉察、监控和调控。分为三类：(1) 规划策略——学习前设定目标、选择方法、制定计划；(2) 监控策略——学习过程中持续检查是否理解、是否按计划推进；(3) 调整策略——根据监控结果灵活改变方法、寻求帮助或修改计划。元认知是高效学习的核心能力，能将被动吸收变为主动管理。

## 核心要点

1. 三阶段：规划→监控→调整
2. 规划回答：学什么？怎么学？何时完成？
3. 监控回答：我理解了吗？进度如何？
4. 调整回答：什么有效？什么需要改变？

## 增强分析

### 【核心定义】

不是学知识，而是学"怎么学"。在学习前先规划，学习中随时检查理解，发现不对劲就立刻调整策略。

### 【适用场景】

自学新技能、准备重要考试、阅读复杂材料、培养长期学习习惯。任何需要主动管理学习效果的情境都适用。

### 【反面案例 / 避坑指南】

只规划不监控→计划沦为废纸。只监控不调整→发现问题却不改。过度监控打断心流→破坏深度专注。完美主义→永远在"准备学"。

### 【实操SOP / 行动清单】

1. 学习前：写下具体目标、方法、时间安排（5分钟）。
2. 学习中：每25分钟自查一次"我真的理解了吗？"。
3. 学完后：用 [[费曼学习法]] 讲给别人听，检验理解。
4. 遇到卡点：立刻换方法——查资料、问人、换教材。
5. 每周总结：什么方法有效？下次该改什么？

### 【模型联动】

与 [[费曼学习法]] 结合→最佳监控工具。与 [[番茄工作法]] 结合→每个番茄时段后做元认知检查。与 [[刻意练习]] 结合→元认知驱动刻意练习的反馈循环。
