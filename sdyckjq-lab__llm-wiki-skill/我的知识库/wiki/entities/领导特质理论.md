# 领导特质理论

> 优秀的领导者是否天生就具备某些特质？这个理论试图找出伟大领导者的共同品质。

## 详细说明

领导特质理论起源于20世纪初，该理论试图找出伟大领导者共有的个人特质。关键特质包括：智力和分析能力、自信、决断力、坚韧毅力、诚实正直、人际交往技巧、激励他人的能力。该理论强调个人特质是决定领导能力的关键，但受到批评：并非所有优秀领导者都具备全部特质，且具备这些特质也不保证成功。现代领导理论更关注行为、情境以及领导者与追随者的互动关系。

## 核心要点

1. 核心特质：智商、自信、决断、坚韧、诚信、人际、激励
2. 优点：直观易懂，为领导力选拔提供参考框架
3. 局限：忽略情境因素，有特质不等于能领导
4. 现代演进：从"天生领导"转向"可培养的领导力"

## 增强分析

### 【核心定义】

认为领导力来自某些稳定的个人品质——聪明、自信、果断、坚韧、正直、会沟通、能激励人。是一种"天赋论"视角。

### 【适用场景】

领导者选拔和评估、个人领导力自评、人才培养方向参考。适合用作发展清单，而非唯一标准。

### 【反面案例 / 避坑指南】

误以为"有这些特质就是好领导"→忽略情境匹配。用特质清单刷人→可能错过非典型但有效的领导者。自恋型人格可能被误判为"自信"。

### 【实操SOP / 行动清单】

1. 自评：对照七大特质给自己打分，找出短板。
2. 选一项最弱的特质，制定3个月提升计划。
3. 寻找该特质的榜样，观察其行为并模仿。
4. 在实践中检验：反思该特质的提升是否带来领导效果改善。
5. 结合 [[领导行为理论]] 确保特质转化为有效行为。

### 【模型联动】

与 [[领导行为理论]] 互补→特质是基础，行为是关键。与 [[刻意练习]] 结合→领导特质可通过刻意训练培养。与 [[SWOT分析]] 结合→用SWOT分析自己的领导力特质。
