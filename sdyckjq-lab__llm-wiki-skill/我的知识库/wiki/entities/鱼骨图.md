# 鱼骨图

> 一个问题背后通常有几十个原因。鱼骨图帮你把它们全部可视化，然后精准找到那条"最要命的鱼刺"。

## 详细说明

鱼骨图（因果图/石川图）由日本质量管理专家石川香一提出，是一种系统性原因分析的可视化工具。结构形似鱼骨：鱼头=问题/效果，鱼脊=主轴线，大鱼刺=主要原因类别（通常为人员、方法、机器、材料、测量、环境6M），小鱼刺=每个类别下的具体原因。创建步骤：定义问题→确定主要类别→逐层细分原因→分析全图找根因。鱼骨图的核心价值在于：把零散的猜测组织成系统性的因果网络，防止遗漏关键因素。

## 核心要点

1. 鱼头=问题，鱼刺=原因类别和具体原因
2. 常用6M分类：人员、方法、机器、材料、测量、环境
3. 原因要逐层细分，直到可采取行动为止
4. 团队共创效果最佳（结合头脑风暴）

## 增强分析

### 【核心定义】

画一条鱼：鱼头写问题，鱼刺写原因，每个原因再往下拆。最后看着整条鱼，找出最致命的那根刺。

### 【适用场景】

质量事故分析、项目失败复盘、生产流程优化、客户投诉原因追溯。任何需要"找到根本原因而非表面现象"的问题分析场景。

### 【反面案例 / 避坑指南】

原因分类太笼统→无法落实到行动。一个人画鱼骨图→缺少多视角容易遗漏。找到一堆原因但不排优先级→无从下手。把"人"作为万能原因→掩盖系统性缺陷。

### 【实操SOP / 行动清单】

1. 召集相关人员，在白板右侧写下问题（鱼头）。
2. 画主干线，从鱼头向左延伸。
3. 确定4-6个主要原因类别，作为大鱼刺。
4. 对每个类别进行 [[头脑风暴法|头脑风暴]]，列出具体原因。
5. 对每个原因追问"为什么"继续细分，最后投票选出最可能的根因。

### 【模型联动】

与 [[头脑风暴法]] 结合→团队共创原因列表。与 [[5W2H]] 结合→对每个鱼刺用5W2H深挖。与 [[持续改进法]] 结合→找到根因后用 PDCA 循环改进。
