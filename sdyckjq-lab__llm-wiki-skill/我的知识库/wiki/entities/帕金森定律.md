# 帕金森定律

> 给你一周时间完成的任务，你真的会用一周——即使三天就能做完。这就是帕金森定律：工作会自动膨胀，填满所有可用时间。

## 详细说明

帕金森定律由塞里尔·帕金森于1955年提出，最初发表在《经济学人》上。核心规律：一项任务的完成时间会自然地扩展到所有可用的时间。这意味着如果给一个任务分配过多时间，人们会拖延、过度复杂化、追求不必要的完美。五个应对策略：(1) 压缩期限——给自己更短但合理的截止时间；(2) 使用时间管理工具；(3) 制定优先级——先做最重要的；(4) 避免完美主义——完成比完美重要；(5) 拒绝不必要的工作。该定律也解释了组织膨胀现象：管理团队变大但效率不提升。

## 核心要点

1. 时间给得越多→任务膨胀得越大
2. 解决之道：设定更短的合理期限
3. 完美主义是帕金森定律的帮凶
4. 不适用于所有情况——复杂任务仍需充分时间

## 增强分析

### 【核心定义】

给你8小时，你会用8小时；给你2小时，同样的事你也能2小时干完。时间宽松=效率变低，时间紧迫=效率拉满。

### 【适用场景】

给自己和他人设定截止日期、对抗拖延症、评估任务真实耗时、组织瘦身减少冗余流程。任何发现"事情总是拖到最后一刻"的场景。

### 【反面案例 / 避坑指南】

所有任务都设极短期限→质量下降、团队 burnout。管理者利用定律压榨员工→降低期限但不减工作量。误用：复杂创意工作需要充分时间酝酿。

### 【实操SOP / 行动清单】

1. 预估：诚实评估一项任务如果全力做需要多久。
2. 压缩：将期限设为预估时间的70-80%。
3. 设检查点：把大任务的期限拆成几个小里程碑。
4. 记录：完成后比较实际耗时与预估，下次更准。
5. 复盘：哪些任务被膨胀了？哪些被合理压缩了？

### 【模型联动】

与 [[番茄工作法]] 结合→25分钟短期限对抗膨胀。与 [[紧急重要矩阵]] 结合→给重要不紧急的任务设短期限。与 [[SMART目标制定法]] 结合→T-时限是对抗帕金森定律的关键武器。
