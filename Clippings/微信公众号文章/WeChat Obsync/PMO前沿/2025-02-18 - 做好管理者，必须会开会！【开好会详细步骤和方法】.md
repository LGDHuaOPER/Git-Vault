# 做好管理者，必须会开会！【开好会详细步骤和方法】

对于初次担任管理职务的人来说，组织会议是一项重要且具有挑战性的任务。

会议不仅是管理者展示领导力的舞台，更是团队沟通、协作和决策的关键环节。

掌握高效的开会方法，不仅能提升管理者的气场，还能增强团队的凝聚力和工作效率。

以下从优秀领导的开会方式、提升气场的技巧以及开好例会的要点三个方面，为初次管理者提供实用的指导。

**1**

![](附件资源/做好管理者，必须会开会！【开好会详细步骤和方法】/img_1.png)

**优秀领导的开会方式**

把握 12 字开头：以“**我发现、我认为、我建议、我希望**”开启会议，能够清晰地传达会议目的，引导团队聚焦问题并找到解决方案。

**我发现：**指出近期团队出现的问题，让成员聚焦现状。

**我认为：**阐述不改正问题将造成的后果，引起成员重视。

**我建议：** 提出改进的标准化流程，给出解决方向。

**我希望：** 明确要求大家执行，确保会议目标落地。

围绕 4 句话展开：这 4 句话与 12 字开头紧密相连，分别从发现问题、阐述后果、提出建议和强调执行四个维度，系统地引导会议进程，使会议内容有条理且重点突出。

**2**

**提升气场的 4 个技巧**

**眼神与表达：**敢于正视别人的眼睛，不飘忽闪躲，适当放慢说话速度，提高音量，展现自信从容的态度，避免表现得巴结扭捏。

**语言表达：**脑子先思考，嘴巴后说话，少说“也许、可能、应该”等不坚定的语言，增强表达的确定性和说服力。

**肢体动作：**动作要坚定，告别小碎步，抬头挺胸走路带风，通过积极的肢体语言传递出坚定的气场。

**情绪管理：**管理好自己的情绪，遇事不慌张，保持冷静沉稳，这有助于在团队中树立可靠的管理者形象。

**3**

**开好例会的要点**

| ** 原则类别 **** ** | ** 具体内容 **** ** |
| --- | --- |
| 五有原则 | ** 有准备： ** 提前规划好会议内容和目标 **有主题：**确保会议围绕核心议题展开 **有纪律：**维持良好的会议秩序 **有程序****：**遵循合理的会议流程 **有检查：**对之前安排的工作进行检查和反馈 |
| 五不原则 | ** 不务虚： ** 避免讨论无实际意义的内容 **不跑题：**紧扣会议主题 **不讨论细节：**先聚焦关键问题 **不抱怨诉苦：**保持积极氛围 **不搞一言堂：**鼓励成员参与讨论 |
| 四框架结构 | 好的方面、存在的问题、提出改进措施、布置下一步工作 |

**总结**

| ** 阶段 **** ** | ** 具体事项 **** ** | ** 说明 **** ** | ** 建议与注意要点 **** ** |
| --- | --- | --- | --- |
| 会前 | 明确会议目标 | 清晰阐述会议期望达成的结果，比如 “确定下个季度销售目标及分解方案”，确保目标可衡量、可实现、有时限 。 | 目标表述避免模糊，应聚焦核心问题，防止目标过多导致会议方向分散。 |
|  | 确定参会人员 | 精准邀请与会议目标紧密相关的人员，像销售目标会议，需召集销售团队负责人、市场分析人员、财务人员等。 | 严格筛选参会人员，避免无关人员参会，既节省大家时间，也让讨论更具针对性。 |
|  | 制定议程 | 将会议内容细化为具体议题，合理分配每个议题的时间，例如： 1. 上季度销售情况回顾：15 分钟 2. 市场趋势分析：20 分钟 3. 下个季度销售目标制定：30 分钟 4. 目标分解与责任落实：25 分钟 | 议程设置应逻辑连贯，先回顾现状，再分析问题，最后讨论决策；预留一定弹性时间，应对突发讨论。 |
|  | 提前通知 | 提前 1 - 3 天，通过邮件、即时通讯工具等多渠道，将会议时间、地点、议程等关键信息传达给参会者。 | 通知务必确保送达，可要求参会者回复确认，避免因通知不到位导致人员缺席。 |
|  | 准备资料 | 收集整理如销售数据报表、市场调研报告等与议题紧密相关的资料，提前发送给参会人员。 | 资料要简洁明了、重点突出，避免冗长繁杂，可附上关键数据解读，帮助参会者快速理解。 |
|  | 布置场地 | 依据会议规模和性质，选择合适场地并布置，准备好投影仪、麦克风、白板、纸笔等设施。 | 场地布置要舒适、整洁，确保设备提前调试，如投影仪画面清晰、麦克风声音正常。 |
| 会中 | 准时开始 | 严格按照预定时间开启会议，不因为个别人员未到而拖延。 | 主持人开场强调守时重要性，长期坚持，让参会者养成准时参会的习惯。 |
|  | 主持人把控 | 主持人开场介绍会议目标、议程；引导讨论紧扣主题，对偏离话题的发言及时温和提醒；鼓励全员发言，把控发言节奏，每位发言者时间控制在 3 - 5 分钟 。 | 主持人要具备良好沟通与应变能力，遇到冷场主动引导，讨论激烈时及时平衡各方观点。 |
|  | 记录要点 | 安排专人详细记录会议讨论要点、不同观点、达成共识、待办任务、责任人及时间节点等。 | 记录者需具备速记能力，使用专业会议记录模板，会后及时整理核对，确保记录准确无误。 |
|  | 保持专注 | 参会者关闭手机或将其调至静音，全身心投入会议，认真倾听、积极思考与回应。 | 营造专注氛围，如有人员频繁走动、玩手机，主持人可委婉提醒。 |
|  | 解决冲突 | 当出现意见分歧或冲突，主持人引导大家冷静分析，从事实和数据出发，寻求共同利益点与解决方案。 | 避免冲突升级，不针对个人，聚焦问题本身，可暂时搁置争议较大问题，先讨论其他议题。 |
| 会后 | 整理会议纪要 | 会议结束 24 小时内，整理会议记录，形成规范会议纪要，清晰列出决议、任务、责任人、时间节点。 | 纪要语言简洁，格式统一，发送前请主持人或关键人员审核，确保内容完整准确。 |
|  | 跟进任务 | 责任人按照会议安排，按时推进工作，定期向团队汇报进展；会议组织者定期跟踪任务执行情况，建立跟进机制。 | 建立任务跟踪表，通过邮件、即时通讯工具等定期提醒责任人，对执行不力情况及时沟通协调。 |
|  | 总结评估 | 定期对会议效果进行总结评估，从会议目标达成、参会者表现、组织安排等方面分析，总结经验教训。 | 可采用问卷调查、小组讨论等方式收集参会者反馈，根据评估结果优化后续会议流程与安排。 |

对于初次担任管理职务的人来说，会议是展示管理能力和凝聚团队的重要契机。

通过学习优秀领导的开会方式，运用提升气场的技巧，遵循开好例会的要点，管理者可以更好地组织会议，提升团队的协作效率和执行力。

记住，高效的会议不仅是解决问题的工具，更是管理者树立威信、推动团队成长的重要途径。

通过不断实践和优化，你将逐渐成长为一名优秀的管理者，带领团队迈向更高的目标。
