# 项目管理和项目治理有什么不同？如何建立和实施项目治理？

![](附件资源/项目管理和项目治理有什么不同？如何建立和实施项目治理？/img_1.png)

**不会项目治理做不好PMO！大家都知道项目管理，但是项目治理很多人不是很清楚，**项目治理，项目管理和项目运营有什么关系呢？

**

![](附件资源/项目管理和项目治理有什么不同？如何建立和实施项目治理？/img_2.png)

**

**项目管理和项目治理的区别，我今天整理了他们之间的不同之处供大家参考。**

| ** 维度 **** ** | ** 项目治理 **** ** | ** 项目管理 **** ** |
| --- | --- | --- |
| 1. 定义不同 | 项目治理是通过领导,方向控制,监督来实现项目目标的过程。它关注决策和监控。 | 项目管理是通过规划,组织,领导,控制来实现项目目标的过程。它关注具体的执行。 |
| 2. 角色不同 | 项目治理主要是项目发起方和项目治理团队 | 项目管理主要是项目经理和项目管理团队。 |
| 3. 职责不同 | 项目治理负责高层决策、战略制定、风险控制、绩效考核。 | 项目管理负责具体计划制定、资源管理、执行推进、问题处理。 |
| 4. 侧重点不同 | 项目治理强调监督控制,决策效率。 | 项目管理强调过程管理,项目效率。 |
| 项目治理强调战略导向,关注长期效果。 | 项目管理强调操作导向,关注具体执行。 |  |
| 项目治理追求项目价值最大化。 | 项目管理追求管理过程效率最大化。 |  |
| 5. 工作产出不同 | 项目治理产出项目章程、政策等战略文件。 | 项目管理产出项目计划、报告等管理文件。 |
| 6. 工作重点不同 | 项目治理者更关注预防和治本。 | 项目管理者更关注解决具体问题。 |

组织项目治理是在组织治理基础之上，通过制定和实施适应性项目管理政策和流程，来确保项目的顺利实施、高效完成，同时提高项目的质量和效益。通过项目治理，将帮助组织更好地利用资源，有效满足客户/用户的需求，提高产品和服务质量与竞争力。

组织项目治理就像一个项目的掌舵人，负责项目整个过程的规划和把控，让项目如钢轨上的高铁，稳稳当当地开向成功终点站。

**如何建立和实施有效的项目治理机制以确保项目的成功和可持续发展呢？6步帮助你建立组织项目治理体系！**

![](附件资源/项目管理和项目治理有什么不同？如何建立和实施项目治理？/img_3.png)

### 第一步：确定项目治理的目标和框架

首先，需要设定项目治理的目标，包括提升项目成功率、提高决策效率、降低风险等。一旦目标设定完成，就需要创建一个项目治理的框架，框架应明确项目的所有角色和责任、决策过程、风险管理方法、以及信息的沟通机制。

- 项目治理目标是什么？ 清晰的目标是所有策略制定的基础。需要考虑的目标可能包括提升项目成功率、提高决策效率、降低风险等。
- 项目治理框架中的角色和责任如何分配？ 明确项目团队中每个成员的角色和责任。包括项目经理、团队成员、项目执行委员会等。
- 决策过程是什么？ 有效的决策过程应该确保所有重要的决策都可以被快速、公正、并且明智地做出来了。
- 如何管理项目风险？ 需要考虑风险的管理方法，包括风险的识别、评估、应对、监控和报告。
- 如何保证信息的沟通和透明度？ 项目的所有参与者都需要获取关键的信息，包括项目的进度、风险、决策等。并且考虑如何确保信息的有效沟通。
- 项目治理框架是否可持续并且具有灵活性？ 项目治理需要能够适应项目的变化和发展。项目治理框架是否具有足够的灵活性以应对可能的变化。

### 第二步：设定项目治理的组织结构

每个项目需要一套有效的组织结构，包括项目经理、项目执行委员会、风险管理委员会等。这些角色和责任需要在项目开始前被明确和传达。每个成员都要知道他们的职责并理解他们如何为项目的成功贡献力量。

- 项目治理结构包括哪些角色？ 需要明确所有的项目角色，如项目经理、项目执行委员会、风险管理委员会等。
- 各角色的责任和职能是什么？ 为每个角色定义明确的职责和职能，确保每个团队成员都理解他们的任务和责任。
- 决策权如何分配？ 在项目治理结构中，应明确哪些角色拥有决策权，并且在什么情况下可以行使这些权力。
- 信息流动和通信如何进行？ 应明确在组织结构中信息是如何流动的，哪些人需要接收到哪些信息，以及何时应传达这些信息。
- 如何处理角色之间的冲突和问题？ 需要设立一种机制，当角色之间的冲突或问题发生时，如何解决。
- 组织结构是否有利于项目的成功和持续发展？ 需要考虑你的组织结构是否有利于提高项目的效率、降低风险、以及适应未来的变化。

### 第三步：制定和实施项目治理政策和程序

还需要一套详细的项目治理政策和程序，明确项目应该如何进行。包括但不限于：工作流程的明确、决策制定的规则、风险管理的步骤等。并且需要定期更新以反映最新的最佳实践和反馈。

- 项目治理政策和程序包括哪些核心元素？ 需要确定政策和程序的主要部分，例如工作流程的明确、决策制定的规则、风险管理的步骤等。
- 这些政策和程序是如何支持我们的项目目标的？ 确保所有的政策和程序都是支持你的项目目标的，而不是妨碍它们。
- 如何通知和训练团队成员使用这些政策和程序？ 确定一个机制，确保所有的团队成员都了解这些政策和程序，并知道如何在他们的工作中应用它们。
- 如何监控和执行这些政策和程序？ 建立机制，监控政策和程序的实施，并确保他们被正确地执行。
- 如何接收和处理对政策和程序的反馈？ 收集和处理来自团队成员、项目干系人或者其他相关人员对政策和程序的反馈的机制需要建立起来。
- 如何定期更新和改进这些政策和程序？ 定期审查和更新政策和程序，以反映最新的最佳实践和反馈。

### 第四步：制定并监控关键绩效指标（KPIs）

需要定义一系列关键绩效指标来衡量项目的进展和成功。包括预算使用情况、项目进度、质量指标等。定期监控这些指标，可以更好地理解项目的状态并做出相应的调整。

- 我们需要监控哪些关键绩效指标？ 这可能包括预算使用情况、项目进度、质量指标等。
- 这些指标如何帮助达到项目目标？ 确保你选择的KPIs与你的项目目标和项目治理策略对齐。
- 如何收集和跟踪这些指标？ 你将如何收集和跟踪这些数据，包括使用项目管理软件或其他工具等。
- 如何确保这些指标的准确性和及时性？ 确保所有的KPIs都是准确和最新的。
- 我们如何分析和解读这些指标？ 如何使用这些数据来指导你的决策和改进项目。
- 如何持续改进我们的指标系统？ 定期审查和更新你的KPIs，以适应项目的变化。

### 第五步：建立风险和问题管理机制

项目风险和问题是无法避免的，但可以设定一套机制来识别、评估和处理这些风险和问题。在项目开始之前，就需要识别可能的风险和问题，并提前设定预防和应对措施。在项目进行过程中，需要不断的管理和监控这些风险。

- 如何识别可能的风险和问题？ 涉及到项目预评估、团队讨论、专家意见等。
- 如何评估这些风险和问题的重要性和紧急性？ 建立一个风险评估标准，考虑风险的可能性和影响。
- 如何制定预防和应对措施？ 对于每个识别的风险，需要有一个应对策略，无论是预防性的还是应对性的。
- 如何在项目中监控这些风险和问 题？ 需要定期检查风险和问题，看看是否有新的风险出现，或者已有风险的状态有所改变。
- 如何通报和处理突发的风险和问题？ 当新的风险或问题出现时，能快速通报并处理。
- 如何持续改进风险管理策略？ 定期审查和更新你的风险管理策略，适应项目的变化。

### 第六步：推动持续的改进和学习

无论项目的大小，都需要不断地学习和改进。需要定期审查项目的执行情况，了解效果如何，是否需要进行改进，以及可以从中学习到什么。

- 如何评估项目的执行情况？ 需要建立一套综合的项目评估标准，包括考虑项目进度、预算使用、KPIs等。
- 如何收集和处理项目的反馈信息？ 可以 从团队成员、干系人或其他相关人员那里收集和处理反馈。
- 如何识别改进的机会？ 通过分析项目的执行情况和反馈信息，可以识别出需要改进的地方。
- 如何实施改进措施？ 将你识别的改进机会转化为实际的行动。
- 如何测量改进的效果？ 在实施了改进措施之后，需要有一种方法来测量这些措施的效果。
- 如何确保从项目中持续学习？ 团队成员可以从项目的成功和失败中学习，方法包括定期的复盘会议、教训分享会等。
