# 什么是 LLM 可观测性，它如何起作用?

# ![](附件资源/什么是%20LLM%20可观测性，它如何起作用/img_1.gif)

探索大型语言模型的可观测性，如何能够为大型语言模型应用程序的性能提供更高的可见性，并提高输出质量。

_https://www.datadoghq.com/knowledge-center/llm-observability/_

01

什么是 LLM 可观测性?

自 GPT、LaMDA、LLaMA 等大型语言模型（LLM）发布以来，生成式AI迅速成为商业、金融、安全、研究和语言领域不可或缺的一部分。例如，微软推出了基于 LLM 的 Copilot 来提高日常办公效率，Stripe 与 OpenAI 合作管理欺诈并提高转化率。

尽管 LLM 的采用显著增加，但在生产环境中运行 LLM 应用比传统机器学习应用更具挑战性。这种困难源于 LLM 庞大的模型规模、复杂的架构和非确定性输出。此外，由于 LLM 决策过程的黑盒性质，排查 LLM 应用中的问题是一项耗时且资源密集的任务。因此，管理 LLM 需要持续监控，以确保持续的性能和安全性，同时产生准确和无偏见的响应。

**LLM 可观测性**提供了工具、技术和方法，帮助团队管理和理解 LLM 应用和语言模型性能，检测偏差或偏见，并在对业务或最终用户体验产生重大影响之前解决问题。

02

LLM 应用常见的问题有哪些?

由于人工智能和 LLM 工具尚处于初期阶段，可能会出现一些问题，这些问题既可能由用户引发，也可能存在于 LLM 的响应中。合适的LLM监控工具可以帮助组织跟踪 LLM 应用可能出现的问题，例如：

- 幻觉 ：LLM 驱动的应用可能偶尔产生虚假信息，这种现象被称为“幻觉”，特别是在面对它们没有答案的查询时。它们通常会给出看似自信但实际上有缺陷的回答，而不是承认自己缺乏知识。这种倾向可能会助长不准确信息的传播，这在将 LLM 应用于需要事实准确性的活动时尤为重要。
- 性能和成本 ：基于 LLM 构建的应用通常依赖第三方模型。这种依赖可能导致第三方 API 性能下降、算法变化引起的不一致，以及高成本(尤其是大数据量情况下)等问题。
- 提示词破解 ：提示词破解（有时称为提示注入）是一种用户可以影响 LLM 应用产生特定内容的技术。这种操纵可能导致 LLM 生成不适当或有害的内容。了解这个问题至关重要，特别是在面向客户的应用中部署 LLM 时。
- 安全和数据隐私 ：LLM 存在安全问题，包括潜在的数据泄露、由于训练数据偏差导致的输出偏见，以及未经授权访问的风险。此外， LLM 可能生成包含敏感或个人数据的响应。因此，严格的安全措施和道德实践对LLM至关重要。
- 模型提示和响应差异 ：LLM 接收的用户提示和生成的响应在长度、语言和准确性等属性上各不相同。用户可能对相同的查询收到不同的响应，这可能导致混淆和不一致的用户体验。这强化了对 LLM 应用进行持续监控和日志记录的需求。

03

LLM 可观测性有哪些好处?

![](附件资源/什么是%20LLM%20可观测性，它如何起作用/img_2.jpg)

随着 LLM 工具的快速发展，实施深入监控其应用的组织可以期待以下好处：

- 提高 LLM 应用性能 ：LLM 可观测性能够实时监控各种性能评估指标，如 LLM 应用的延迟和吞吐量以及响应质量。通过持续监控这些指标，数据科学家和工程师可以快速识别LLM性能的任何偏差或下降。这种主动方法允许及时干预，从而提高模型性能和用户体验。
- 更好的可解释性 ：通过 LLM 可观测性，你可以深入了解 LLM 应用的内部工作原理。通过可视化请求-响应对、词嵌入或提示链序列， LLM 可观测性增强了响应的可解释性。这种增加的透明度使利益相关者能够信任LLM应用的决策，并识别应用输出和逻辑中的任何质量问题或错误。
- 更快的问题诊断 ：对 LLM 应用运行的端到端可见性对于解决无响应或错误响应等问题至关重要。LLM 可观测性使工程师能够分析请求的后端操作和API调用，以找出问题的根本原因，从而减少解决问题所需的时间。
- 提高安全性 ：LLM 可观测性通过监控模型行为以发现潜在的安全漏洞或恶意攻击，在增强 LLM 应用安全性方面发挥着关键作用。通过跟踪访问模式、输入数据和模型输出， LLM 可观测性工具可以检测可能表明数据泄露或对抗性攻击的异常。这种持续监控有助于数据科学家和安全团队主动识别和缓解安全威胁，保护敏感数据并维护 LLM 应用的完整性。
- 高效的成本管理 ：观测 LLM 模型的资源消耗和利用情况，允许组织根据实际使用模式优化资源分配和成本。通过监控令牌消耗、CPU/GPU 利用率和内存使用等指标，可观测性工具有助于识别资源瓶颈或利用不足。这些洞察可以为资源的扩展或缩减决策提供信息，确保 LLM 应用的成本效益。

04

在 LLM 可观测性解决方案中应该寻找什么?

![](附件资源/什么是%20LLM%20可观测性，它如何起作用/img_3.jpg)

连接线表示这些功能是相互关联的

在考虑支持生成式AI和语言模型的 AI 可观测性解决方案时，请审查 LLM 监控工具提供的以下功能：

- LLM 链调试 ：大多数现代 LLM 应用是通过将 LLM 代理逻辑链接在一起构建的，其中一个的输出作为另一个的输入，然后返回最终输出给用户。这可能使理解为什么 LLM 代理循环或为什么链比预期慢变得困难。因此，LLM监控工具必须提供对 LLM 链完整操作的可见性，以便快速故障排除和问题解决。
- 完整应用栈的可见性 ：LLM 应用后端发生的问题症状会出现在应用的用户界面上。为了高效地进行故障排除，了解 LLM 应用栈的哪个元素（GPU、数据库、服务或模型）首先失败是至关重要的。你的LLM可观测性解决方案的范围应涵盖整个应用栈和与你需求相关的领域。
- 可解释性和异常检测 ：理想的 LLM 可观测性解决方案应该提供对AI模型决策过程的洞察，促进透明度和可解释性。此外，该解决方案应具备开箱即用的功能，能有效监控和分析数据输入和输出，以检测异常、偏见和用户反馈。
- 可扩展性、集成和安全性 ：LLM 监控解决方案应具有高度可扩展性，以处理不断增加的用户工作负载，同时无缝集成各种应用使用的 LLM 平台。它必须提供强大的安全功能，包括PII编辑、敏感数据扫描和防止提示破解。
- 全生命周期支持 ：虽然 LLM 可观测性对于生产中的平稳 LLM 运行至关重要，但它在开发阶段的模型实验和微调中也发挥着关键作用。
