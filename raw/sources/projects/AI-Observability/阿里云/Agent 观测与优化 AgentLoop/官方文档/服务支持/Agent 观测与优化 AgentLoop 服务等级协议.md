Agent 观测与优化 AgentLoop 服务等级协议

版本生效日期：2026年7月1日

本服务等级协议（Service Level Agreement，以下简称 “SLA”）约定了阿里云向客户提供的 Agent 观测与优化 AgentLoop（简称“AgentLoop”）的服务可用性等级指标及赔偿方案。

特别提示您，除非另有约定，本协议不适用于AgentLoop公测、邀测、免费的功能及版本。

1.定义

1.1服务周期：一个服务周期为一个自然月。如客户开通AgentLoop不满一个自然月，按照一个自然月计算。

1.2失败请求：失败请求包括下述情形：

（1）因AgentLoop系统原因导致的API、控制台或服务端域名返回5XX的请求；

（2）因AgentLoop故障导致的正常API、控制台或服务端请求未能到达AgentLoop服务器端的请求（通过故障前7天内使用AgentLoop相关服务入口的平均请求数计算）。

1.3有效的总请求：客户某一阿里云账号下AgentLoop服务器端接收到的所有API、控制台及服务端请求视为有效的总请求。

1.4每5分钟错误率：根据单一阿里云账号下AgentLoop的地域及实例/工作空间分别统计，以每5分钟为单位按照如下方式计算：

每5分钟错误率 = 该5分钟内失败请求数 / 该5分钟内有效的总请求数 ×100%

1.5月度服务费用：为一个自然月内单一阿里云账号下客户为其使用的 AgentLoop 资源用量实际支付的服务费用。如果客户一次性支付了多个月份的服务费用，则将按照所购买的月数或使用量比例分摊计算该月度服务费用。

2.服务可用性

2.1 服务可用性计算公式

AgentLoop服务可用性按服务周期统计，将根据服务周期内每5分钟错误率之和除以服务周期内5分钟的总个数计算出每5分钟错误率的平均值，从而计算得出服务可用性，即：

服务可用性 = 1 -（服务周期内每5分钟错误率之和 / 服务周期内5分钟总个数） \*100%

注：服务周期内5分钟总个数 = 12 × 24 × 该服务周期的天数。

2.2 服务可用性承诺

AgentLoop服务可用性不低于99.9%，如AgentLoop未达到前述可用性承诺，客户可以根据本协议第3条约定获得赔偿。

2.3除外情形

赔偿范围不包括以下原因所导致的失败请求或服务不可用：

（1）阿里云预先通知客户后进行系统维护所引起的，包括割接、维修、升级和模拟故障演练；

（2）任何阿里云所属设备以外的网络、设备故障或配置调整引起的；

（3）客户的应用程序或数据信息受到黑客攻击而引起的；

（4）客户维护不当或保密不当致使数据、口令、密码等丢失或泄漏所引起的；

（5）客户的疏忽或由客户授权的操作所引起的；

（6）客户未遵循阿里云产品使用文档或使用建议引起的；

（7）不可抗力引起的。
