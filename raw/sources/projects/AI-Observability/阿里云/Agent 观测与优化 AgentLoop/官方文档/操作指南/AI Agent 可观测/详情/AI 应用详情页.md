AI 应用详情页是对单个 AI 应用进行全方位观测的实体级监控分析页面。您可以查看应用级别的指标汇总，并下钻至应用包含的各个 Agent 进行深度分析。

## 前提条件

-   已开通云监控2.0服务并创建工作空间。
    
-   已完成 AI Agent 可观测数据的接入配置。
    

## 操作路径

登录[云监控2.0控制台](https://cmsnext.console.aliyun.com/)，选择目标工作空间，在 AI Agent 详情页的**关联拓扑**中单击 AI 应用节点，选择**打开实体**进入 AI 应用详情页。

## 功能说明

### 实体详情

展示当前应用的核心性能指标概览和多维度趋势分析。

核心指标（均含日同比）：

| **指标名称** | **说明** |
| --- | --- |
| 活跃会话数 | 当前应用中活跃的会话总数。 |
| 对话数 | 统计时间范围内的对话请求总数。 |
| 对话平均耗时 | 每次对话从请求到完成响应的平均时间。 |
| Token消耗 | 应用在统计时间范围内的 Token 总消耗量。 |
| 平均TTFT | Time To First Token，从发起请求到收到第一个 Token 的平均时间。 |
| 平均TPOT | Time Per Output Token，生成每个输出 Token 的平均时间。 |

分析区域：

-   **请求分析**：展示请求数趋势（按协议分组）、错误数趋势（含错误率）、平均请求耗时趋势。
    
-   **Token分析**：展示各模型 Token 消耗分布及趋势。
    
-   **模型分析**：展示各模型调用量分布、调用量趋势、调用错误趋势、TTFT 趋势、TPOT 趋势。
    
-   **工具调用分析**：展示各工具调用量分布、调用量趋势、调用耗时趋势、调用错误趋势。
    

### 关联拓扑

以有向图形式展示当前应用与下游实体的调用关系。包含两个子视图：

-   **关联实体拓扑**：展示 AI 应用 → AI Agent → 大模型/工具的调用链路，节点按实体类型以不同颜色标识，边上标注请求次数和平均延迟时间。
    
-   **UModel 探索**：提供大模型维度的探索分析入口。
    

### 链路追踪

提供当前应用相关的端到端调用链追踪能力。搜索条件已预填当前应用的过滤表达式。

主要展示数据：

-   **概览图表**：Trace 数、平均耗时、Token 消耗趋势。
    
-   **三种子视图**：Trace 列表、Span 列表、全链路拓扑。
    
-   **Trace 列表字段**：Trace ID、输入、输出、耗时、Total tokens、入口应用名称、用户ID、会话ID。
    

### 会话分析

提供当前应用的会话维度分析，搜索条件已预填应用的过滤表达式。

核心指标（均含日同比）：

| **指标** | **说明** |
| --- | --- |
| 会话数 | 当前应用的会话总数。 |
| 平均会话时长 | 每个会话从开始到结束的平均持续时间。 |
| 平均会话轮次 | 每个会话中的平均对话轮数。 |
| 用户数 | 参与对话的独立用户数。 |

支持会话视图和用户视图两种模式切换。会话列表展示会话ID、开始时间、会话时长、轮次、Token消耗（Total/Input/Output）、用户ID等信息。

### 模型分析

展示当前应用对底层大模型调用的详细性能分析。

核心指标（均含日同比）：

| **指标** | **说明** |
| --- | --- |
| 模型调用次数 | 当前应用调用大模型的总次数。 |
| 模型调用平均耗时 | 每次模型调用的平均响应时间。 |
| 模型调用错误次数 | 模型调用失败的次数。 |
| Token消耗 | 模型调用的 Token 总消耗量。 |
| 平均TTFT | 模型调用的 Time To First Token 平均时间。 |
| 平均TPOT | 模型调用的 Time Per Output Token 平均时间。 |

分析区域：

-   **Token分析**：各模型 Token 消耗分布及趋势、平均单次模型调用 Token 消耗趋势。
    
-   **模型调用分析**：模型调用次数趋势、平均耗时趋势、错误数趋势。
    

### 工具分析

展示当前应用工具调用的性能与可靠性分析。

核心指标（均含日同比）：调用次数、调用平均耗时、错误次数。

分析区域：调用次数趋势、平均耗时趋势、错误趋势，以及工具调用统计表格（展示各工具的详细指标对比）。

### RAG分析

按 RAG 流程分 Embedding 和 Retrieval 两个阶段展示分析指标。每个阶段均展示调用次数、调用平均耗时、错误次数（含日同比）及对应的时间趋势图。

**说明**

仅在当前应用存在 Embedding 或 Retrieval 类型的 Span 时展示相关数据。

### Agent列表

展示当前应用下所有 Agent 的运行统计和详细指标，是 AI 应用详情页独有的分析 Tab。

核心指标（均含日同比）：

| **指标名称** | **说明** |
| --- | --- |
| Agent数 | 当前应用下注册的 Agent 总数。 |
| Agent调用次数 | 所有 Agent 在统计时间范围内的总调用次数。 |
| Agent调用平均耗时 | 所有 Agent 调用的平均响应时间。 |
| Agent调用错误次数 | 所有 Agent 调用失败的总次数。 |

分析区域：

-   **Token分析**：展示各 Agent 的 Token 消耗分布及趋势、平均单次 Agent 调用的 Token 消耗趋势。
    
-   **Agent调用分析**：展示各 Agent 的调用次数趋势、调用耗时趋势、调用错误趋势。
    

Agent统计表格：

| **字段** | **说明** |
| --- | --- |
| Agent名称 | Agent 的名称标识。 |
| 调用量 | 该 Agent 在统计时间内的总调用次数。 |
| 错误数 | 该 Agent 调用失败的次数。 |
| 平均耗时 | 该 Agent 调用的平均响应时间。 |
| Token消耗 | 该 Agent 的 Token 总消耗量。 |
| TTFT | 该 Agent 的平均 Time To First Token。 |
| TPOT | 该 Agent 的平均 Time Per Output Token。 |
| 输入Token | 该 Agent 消耗的输入 Token 总数。 |
| 输出Token | 该 Agent 消耗的输出 Token 总数。 |

### 应用配置

AI 应用详情页独有的 Tab，包含**自定义配置**子视图，用于管理当前应用的采集规则、数据保留策略等运行时配置项。

### 日志探索

提供当前应用相关日志的查询与分析入口。Tab 名称后的数字表示关联的日志类型数量。

### 指标探索

提供自定义指标查询能力。Tab 名称后的数字表示预置的指标查询模板数量。

### 关联项

下拉菜单形式，展示当前应用关联的其他云监控资源项。
