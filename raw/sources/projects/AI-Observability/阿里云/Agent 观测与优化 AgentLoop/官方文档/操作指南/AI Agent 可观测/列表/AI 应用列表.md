AI 应用列表页面以列表形式展示所有已接入的 AI 应用，帮助您快速了解各应用的基本信息及模型调用关键指标。

## 前提条件

-   已开通云监控2.0服务并创建工作空间。
    
-   已通过 ARMS 探针或 OpenTelemetry 探针完成 AI 应用的接入。
    

## 操作步骤

1.  登录[云监控2.0控制台](https://cmsnext.console.aliyun.com/)，选择目标工作空间，在左侧导航栏选择**AI Agent可观测**。
    
2.  在顶部选择**AI Agent**页签，然后选择**AI 应用**子页签。
    
3.  在 AI 应用列表页面，您可以查看所有已接入应用的基本信息和模型调用指标。
    

## 功能说明

### 搜索与筛选

您可以通过页面顶部的搜索栏按应用名称搜索目标应用，也可以通过筛选按钮对应用列表进行条件筛选。

**说明**

搜索关键词需输入至少4个字符才能触发搜索。

### 列表字段说明

AI 应用列表包含以下字段信息：

| **字段** | **说明** |
| --- | --- |
| 应用名称 | AI 应用的名称，例如 `google-adk-a2a-protocol`、`ai-coding-agent-claude-code`、`agentscope-code-correction` 等。单击应用名称可进入该应用的详情页面。 |
| 探针类型 | 数据采集所使用的探针类型。支持以下两种： - **ARMS**：使用 ARMS 探针进行数据采集。 - **OpenTelemetry**：使用 OpenTelemetry 探针进行数据采集。 |
| 语言  | 应用的编程语言，例如 Python、Java、Node.js 等。 |
| 区域  | 应用部署的阿里云地域，例如 `cn-hongkong`。 |
| 平均模型调用次数 | 应用在选定时间范围内的平均模型调用数量。该列附带迷你趋势图，帮助您直观了解调用量的变化趋势。 |
| 平均模型调用错误次数 | 应用在选定时间范围内平均模型调用失败的次数。 |
| 平均模型调用耗时 | 模型调用的平均响应时间，用于衡量模型推理的性能表现。 |
| 每分钟平均 Token 消耗 | 应用每分钟消耗的 Token 数量。该列附带迷你趋势图，帮助您了解 Token 用量的变化趋势。 |

### 分页

列表默认每页展示10条记录，页面底部显示应用总数及分页控件。您可以翻页查看更多应用。

### 查看应用详情

在列表中单击目标应用的**应用名称**，即可进入该应用的详情页面，查看更详细的调用链路、模型性能指标等信息。
