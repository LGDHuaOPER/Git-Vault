空间管理提供查看智能体空间（AgentSpace）详情与删除智能体空间两类能力。

## **访问路径**

登录 [AgentLoop 控制台](https://agentloop.console.aliyun.com/) >选择目标空间> 系统管理 > 空间管理。

## **查看空间详情**

空间管理详情页包含**基础信息**与**资源绑定**两个区块。

### **基础信息**

| **参数** | **说明** |
| --- | --- |
| 空间名称（AgentSpace） | AgentSpace 全局唯一名称。 |
| 地域  | AgentSpace 所在地域，创建后不可变更。 |
| 描述  | 空间用途说明。 |
| 创建时间 | AgentSpace 创建时间。 |
| 最后更新 | 配置最近一次变更时间。 |

### **资源绑定**

资源绑定区块展示 AgentSpace 与下列阿里云产品资源的绑定关系。其中 MSE AI治理中心命名空间与 SLS 日志服务 Project 由系统在创建 AgentSpace 时自动创建并带**自动创建**标签，命名格式统一为 `agentloop-<32位编码>`；云监控 2.0 工作空间在创建时由用户选择新建或关联已有。

| **资源类型** | **说明** |
| --- | --- |
| 云监控 2.0 工作空间 | 关联的 CMS 2.0 工作空间。新建时命名格式为 `agentloop-<32位编码>` ；关联已有时显示用户选择的工作空间名称。单击**前往云监控 2.0 查看**跳转至对应控制台。 |
| MSE AI 治理中心命名空间 | 关联的 MSE 命名空间，带**自动创建**标签。单击**前往 MSE AI 治理中心 查看**跳转。 |
| SLS 日志服务 Project | 关联的 SLS Project，带**自动创建**标签。单击**前往 SLS 日志服务查看**跳转。 |

## **删除智能体空间**

**警告**

**此操作不可撤销**，AgentLoop 当前 AgentSpace 下的全部资源会被完全清理。如勾选关联云产品资源删除，则对应云产品绑定的资源也会被一并清理。

1.  在空间管理详情页底部，单击**删除空间**。
    
2.  在对话框中仔细阅读警示文案，并核对**同时删除的关联云产品资源**列表。该列表完整列出将被删除的资源描述。
    
    | **资源** | **同时清理范围** |
    | --- | --- |
    | SLS 日志服务 | 关联的 SLS Project 及其全部 LogStore |
    | 云监控 2.0 | 关联的工作空间 |
    | MSE AI 治理中心 | 关联的命名空间及其全部 Agent 资产，如Prompts、Skills |
    
3.  在输入框中精确输入当前 AgentSpace 名称（区分大小写）。
    
4.  单击**确认删除**，系统清理 AgentLoop 自有资源、已勾选的关联云产品资源，并删除AgentSpace 元数据。
