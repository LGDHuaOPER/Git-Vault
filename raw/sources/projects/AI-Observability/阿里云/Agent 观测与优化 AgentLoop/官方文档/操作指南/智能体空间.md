智能体空间（AgentSpace）是 AgentLoop 中组织和管理资源的基本单元，用于资源隔离、权限控制和计费归属。一个 AgentSpace 包含 AgentLoop 自有资源（数据集、评估任务、记忆库等），并关联云监控 2.0、SLS 日志服务和 MSE AI 治理中心的相关资源。

## 关联资源

AgentSpace 创建后，会与下列阿里云产品资源建立绑定：

| **资源类型** | **用途** | **关联方式** |
| --- | --- | --- |
| 云监控 2.0 工作空间 | 承载 Agent 调用链、模型监控等可观测数据 | 创建时由用户选择新建或关联已有 |
| SLS 日志服务 Project | 承载 Agent 审计日志、评估日志等日志类数据 | 创建时由系统自动创建 |
| MSE AI 治理中心命名空间 | 承载 Prompts、Skills 等 Agent 资产 | 创建时由系统自动创建 |

## 前提条件

-   已注册并实名认证阿里云账号。
    
-   已开通云监控 2.0、SLS 日志服务、MSE 微服务引擎（AI 治理中心）。
    
-   当前 RAM 用户已被授予 `AliyunAgentLoopFullAccess` 权限策略。
    

## 创建智能体空间

1.  登录 [AgentLoop 控制台](https://agentloop.console.aliyun.com/)。
    
2.  在控制台首页，单击**新建空间**。
    
3.  在**新建智能体空间**对话框中，配置以下参数。
    
    | **参数** | **说明** |
    | --- | --- |
    | 所在地域 | 选择 AgentSpace 所在地域。**创建后不可更换**。 |
    | 智能体空间（AgentSpace） | 空间名称。3–63 个字符，支持小写字母、数字、连字符（`-`）和下划线（`_`），所有用户全局唯一。**创建后不可更换**。 |
    | 空间描述 | 空间用途的简要说明。 |
    | 云监控 2.0 工作空间 | **自动创建**：系统创建命名为 `agentloop-<32位编码>` 的新工作空间。 **选择已有**：从下拉列表中选择当前账号下、同地域的 CMS 2.0 工作空间复用，便于与已有应用监控统一视图。 **创建后绑定关系不可更换**。 |
    
4.  单击**新建空间**，系统会自动创建 AgentSpace、SLS Project 和 MSE AI 治理中心命名空间，并完成资源绑定。
    

## 后续操作

创建完成后，可在**系统管理**的**空间管理**中查看空间详情、修改配置或删除空间。
