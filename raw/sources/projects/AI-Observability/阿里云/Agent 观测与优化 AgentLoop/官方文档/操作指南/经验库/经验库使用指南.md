当 Agent 应用已产生稳定的执行轨迹时，可以创建经验库开启经验挖掘与召回，让 Agent 复用经过验证的方法，减少重复试错。本文介绍从开启轨迹采集到接入经验召回的完整操作流程：开启 Agent 轨迹采集 → 创建经验库 → 等待经验挖掘 → 浏览经验或接入 Agent。

## 开启 Agent 轨迹采集

创建经验库前，需要先开启当前 AgentSpace 的 Agent 轨迹采集能力。开启后，AgentLoop 会将接入的 Trace 加工为标准 Agent 轨迹，供经验挖掘使用。

1.  登录 AgentLoop 控制台，进入目标 AgentSpace。
    
2.  从左侧导航栏选择**数据中心** > **Agent 轨迹**。
    
3.  确认轨迹采集已经开启。
    
    -   页面显示**关闭轨迹采集**按钮，表示当前已开启，无需操作。
        
    -   页面显示**开启轨迹采集**按钮，单击该按钮开启。
        

## 创建经验库

1.  从左侧导航栏选择**上下文工程** > **经验库**。
    
2.  单击**创建经验库**。
    
3.  配置经验库信息。
    
    | **参数** | **是否必填** | **说明** |
    | --- | --- | --- |
    | 经验库名称 | 是   | 仅支持小写字母、数字和下划线 |
    | 经验库描述 | 否   | 用于说明经验库的用途 |
    | 提取 Agent 应用 | 是   | 选择产生轨迹数据的 Agent 应用 |
    | 经验抽取起始时间 | 是   | 系统将从该时间开始处理符合条件的 Agent 轨迹 |
    
4.  确认配置无误后，单击**确认**。
    

**重要**

-   **提取 Agent 应用**和**经验抽取起始时间**在经验库创建后不可修改，请根据实际的 Agent 应用和 Trace 时间范围进行选择。
    
-   经验库只能挖掘已经完成轨迹采集和加工的数据。
    

## 查看经验挖掘进度

经验库创建后，AgentLoop 会按照固定挖掘间隔持续处理 Agent 轨迹并提取经验。进入经验库的**基本信息**页面，可以查看以下信息：

| **字段** | **说明** |
| --- | --- |
| 挖掘状态 | 当前经验挖掘任务的运行状态 |
| 已处理至 | 当前已经处理到的轨迹时间 |
| 数据来源 | 经验库绑定的 AgentSpace、Agent 应用和抽取起始时间 |

当**已处理至**时间持续向前推进时，说明系统正在正常处理轨迹数据。挖掘到经验后，可以在**经验列表**页面查看经验内容。

进入经验库的**经验列表**页面，可以浏览已挖掘出的经验并查看经验详情，确认经验内容是否符合预期。

如果长时间没有产生经验，请确认所选 Agent 应用在抽取起始时间之后存在可用的 Agent 轨迹。

## 为 Agent 接入经验召回能力

安装经验召回 Skill 后，Agent 在执行任务时可按需查询经验库，召回相关历史经验，参考已有的问题定位方法、解决方案和可复用工作流，从而提升任务执行效果和效率。

1.  进入经验库的 **API Key** 页面，创建并复制 API Key。
    
2.  进入**集成方式**页面。
    
3.  根据使用场景选择接入方式：
    
    -   **临时 Skill 安装**：适合快速验证或临时接入。
        
    -   **配置文件方式**：适合项目长期使用。
        
4.  按页面提示依次完成以下操作：
    
    1.  安装召回 Skill。
        
    2.  配置经验库 Endpoint 和 API Key。
        
    3.  执行一次召回验证，确认经验召回正常工作。
        

**说明**

建议直接使用**集成方式**页面每个步骤右侧的**复制配置**按钮。控制台会自动生成当前经验库对应的 Endpoint 和其他参数，可避免手工填写错误。

**警告**

API Key 属于敏感信息，请妥善保管，不要提交到 Git 或写入可公开访问的配置文件。
