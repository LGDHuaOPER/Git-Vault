会话分析页面从会话（Session）维度对 AI Agent 的交互情况进行多维度分析，帮助您了解会话级别的使用情况、资源消耗及用户活跃度，从而优化 Agent 的服务质量。

## 前提条件

-   已开通云监控2.0服务并创建工作空间。
    
-   已将 AI Agent 的可观测数据接入当前工作空间。
    

## 操作入口

登录[云监控2.0控制台](https://cmsnext.console.aliyun.com/)，选择目标工作空间，在左侧导航栏选择**AI Agent可观测**，单击**会话分析**页签。

## 核心指标

页面顶部展示4个核心指标卡片，帮助您快速掌握选定时间范围内的会话概览数据。每个指标均包含日同比变化率，便于您对比分析趋势。

| **指标名称** | **说明** |
| --- | --- |
| 会话数 | 选定时间范围内的总会话数量。 |
| 平均会话时长 | 所有会话的平均持续时间。 |
| 平均会话轮次 | 每个会话中用户与 Agent 交互的平均轮次。 |
| 用户数 | 选定时间范围内的活跃用户总数。 |

**说明**

每个指标卡片右上角提供设置、可视化、收藏和展开操作按钮，您可以根据需要对指标进行个性化配置或以图表形式查看趋势变化。

## 视图切换

页面右上角提供两种视图模式，您可以根据分析需求进行切换：

| **视图模式** | **说明** |
| --- | --- |
| 会话视图 | 默认视图。以会话为维度展示数据，每一行代表一个独立的会话记录。 |
| 用户视图 | 以用户为维度展示数据，聚合同一用户的多次会话信息。 |

## 搜索与筛选

页面提供搜索栏，支持您按关键词检索会话内容。在搜索栏中输入内容后按 Enter 键即可执行搜索。

**说明**

搜索栏支持 Shift+Enter 换行，方便您输入多行检索条件。

## 会话列表

在会话视图下，页面以列表形式展示所有会话记录。各列字段说明如下：

| **字段** | **说明** |
| --- | --- |
| 会话 ID | 会话的唯一标识。单击会话 ID 可跳转至会话详情页面。 |
| 开始时间 | 会话的开始时间戳。 |
| 会话时长 | 会话从开始到结束的持续时间。 |
| 轮次  | 会话中用户与 Agent 的交互轮次数。 |
| Total Tokens | 会话消耗的总 Token 数，包含输入和输出 Token。 |
| Input Tokens | 用户输入消耗的 Token 数。 |
| Output Tokens | Agent 输出消耗的 Token 数。 |
| 用户 ID | 发起该会话的用户标识。 |
| 操作  | 单击**详情**可查看该会话的完整交互记录及调用链路信息。 |

## **切换至用户视图**

1.  在页面右上角，单击**用户视图**。
    
2.  查看以用户维度聚合的会话统计数据。
    

## **查看会话详情**

1.  在会话列表中，找到目标会话。
    
2.  单击对应行的**会话 ID**或**操作**列中的**详情**。
    
3.  在会话详情页面中，查看该会话的完整交互记录、各轮次的 Token 消耗及调用链路等信息。
    
    | **字段** | **说明** |
    | --- | --- |
    | Session ID | 当前会话的唯一标识。 |
    | 开始时间 | 会话首条请求的发起时间。 |
    | 总耗时 | 会话内所有链路的累计执行耗时。 |
    | 轮次  | 会话中包含的对话轮数。 |
    | 总Tokens | 会话累计消耗的 Token 总数。 |
    | 输入Tokens | 会话累计消耗的输入 Token 数。 |
    | 输出Tokens | 会话累计消耗的输出 Token 数。 |
    | User ID | 发起会话的用户标识。 |
    
4.  页面左侧链路列表区域展示会话内所有链路（Trace）的执行时序。单击链路ID 可跳转到对应的 Trace 详情页面，进一步分析该链路的 Span 层级结构、推理过程与性能指标。
    
    -   顶部为时间轴，按时间顺序可视化展示链路的开始时间与耗时分布。
        
    -   每条链路以可展开卡片形式呈现，展开后显示链路的耗时甘特图条以及核心字段：
        
        | **字段** | **说明** |
        | --- | --- |
        | 链路ID | 当前链路的唯一标识，可单击跳转至完整的 Trace 详情。 |
        | 总Tokens | 该链路消耗的总 Token数。 |
        | 输入Tokens | 该链路消耗的输入 Token数。 |
        | 输出Tokens | 该链路消耗的输出 Token数。 |
        | TTFT | 首个 Token 响应时间 （Time To First Token）。 |
        | LLM调用 | 该链路中的 LLM 调用次数。 |
        | 工具调用 | 该链路中的工具调用次数。 |
        | 工具调用错误数 | 该链路中工具调用的错误数量。 |
        
5.  页面右侧会话消息区域以对话气泡形式按时间顺序展示完整的用户-助手交互消息流。
    
    -   **用户消息**：右侧对齐，标识为用户，展示用户在该会话中发送给AlI Agent 的原始输入内容（如文本、参数等）。
        
    -   **助手消息**：左侧对齐，标识为助手，展示 AI Agent 返回给用户的响应内容（如文本、生成的文件URI、结构化输出等）。
        
        每条消息显示发生时间，气泡支持长文本与结构化 JSON 内容的完整展示，并提供复制操作。
        
        页面右上角提供格式化与原始数据切换：
        
        | **模式** | **说明** |
        | --- | --- |
        | 格式化 | 以友好可读的方式渲染消息内容，便于人工阅读对话。 |
        | 原始数据 | 展示消息的原始JSON 数据，便于排查字段缺失或异常。 |
        

## **常见使用场景**

-   **对话回放与质量审计**：通过完整的消息流回放会话过程，分析 Agent 在多轮交互中的语义理解、回答相关性与上下文保持能力。
    
-   **多轮性能分析**：通过链路列表与时间轴查看每一轮的 TTFT、耗时、Token 消耗，识别响应缓慢或Token 消耗异常的轮次。
    
-   **异常会话排查**：定位到出现错误的链路后，单击链路ID 进入 Trace 详情查看具体Span 的错误堆栈与上下文，快速定位失败原因。
    
-   **用户行为分析**：结合 User ID 与会话消息内容，分析典型用户的交互习惯与提问模式，为Agent优化提供输入。
