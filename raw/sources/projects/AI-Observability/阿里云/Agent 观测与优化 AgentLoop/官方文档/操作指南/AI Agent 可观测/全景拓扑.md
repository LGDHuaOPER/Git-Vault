全景拓扑以可视化图形方式展示 AI 应用、AI Agent、工具（Tool）之间的调用关系和健康状态，帮助您快速掌握整体架构与运行状况。

## 前提条件

-   已开通云监控 2.0 服务。
    
-   已创建工作空间并接入 AI Agent 可观测数据。
    

## 操作入口

登录[云监控2.0控制台](https://cmsnext.console.aliyun.com/)，选择目标工作空间，在左侧导航栏选择**AI Agent可观测**，单击**全景拓扑**页签。

## 功能说明

全景拓扑页面包含两个子视图：**拓扑视图**和**健康视图**，您可以通过页面顶部的 Tab 进行切换。

### 拓扑视图

拓扑视图以有向图的形式展示 AI 应用、AI Agent 和工具之间的调用链路关系，帮助您直观了解各组件间的依赖与交互。

**图形结构**

拓扑图中的节点分为以下三类：

| **节点类型** | **说明** | **示例** |
| --- | --- | --- |
| AI 应用 | 顶层业务应用入口 | ai-coding-agent |
| AI Agent | 承载推理与编排逻辑的智能体 | claude-code |
| 工具（Tool） | Agent 调用的具体执行工具 | execute\\_tool Read、execute\\_tool Write、execute\\_tool Grep、execute\\_tool Glob 等 |

节点之间的连接线表示调用关系，线上标注关系类型（如 `request_to`、`calls`），调用方向由箭头指示。

**交互操作**

-   **缩放控制**：支持 10%~100% 的缩放比例，便于查看大规模拓扑结构。
    
-   **全屏模式**：单击全屏按钮可将拓扑图扩展至全屏显示。
    
-   **拖拽平移**：在画布上按住鼠标拖拽可平移视图区域。
    
-   **筛选器**：通过顶部筛选条件过滤特定的应用、Agent 或工具节点。
    

**说明**

当拓扑节点较多时，建议使用筛选器缩小展示范围，或通过缩放控制调整视图比例以获得最佳浏览效果。

### 健康视图

健康视图以卡片网格形式展示所有 AI Agent 的运行健康状态，便于您快速定位异常实体。

**卡片信息**

每个卡片代表一个 AI Agent 实体，卡片上显示以下信息：

-   **Agent 名称**：当前 Agent 的标识名称。
    
-   **健康状态**：以颜色标识当前健康等级（正常、警告、严重）。
    

**底部汇总栏**

页面底部提供全局健康状态汇总，包括：

| **指标** | **说明** |
| --- | --- |
| 总计  | 当前工作空间下的 AI Agent 实体总数 |
| 正常  | 运行状态正常的实体数量 |
| 警告  | 触发警告阈值的实体数量 |
| 严重  | 触发严重阈值的实体数量 |

**操作按钮**

-   **阈值设置**：单击右上角的**阈值设置**按钮，可自定义健康状态的判定阈值，包括警告和严重级别的触发条件。
    
-   **巡检配置**：单击右上角的**巡检配置**按钮，可配置自动巡检策略，实现定期健康检查。
    
-   **查看全部**：当 Agent 数量较多时，单击**查看全部**可展开完整的卡片列表。
    

**说明**

建议您根据业务实际需求调整阈值设置，避免因默认阈值不匹配导致误报或漏报。

## 使用场景

| **场景**        | **推荐视图** | **说明**                  |
| ------------- | -------- | ----------------------- |
| 了解 AI 应用整体架构  | 拓扑视图     | 快速掌握应用、Agent、工具之间的调用关系  |
| 排查调用链路异常      | 拓扑视图     | 通过可视化链路定位调用瓶颈或故障节点      |
| 监控 Agent 运行健康 | 健康视图     | 批量查看所有 Agent 的健康状态并识别异常 |
| 配置告警与巡检策略     | 健康视图     | 设置阈值和巡检规则，实现主动发现问题      |
