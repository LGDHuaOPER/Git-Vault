开服地域是指物理的数据中心，智能体空间（AgentSpace）创建成功后不能更换地域。本文介绍 AgentLoop 当前支持的地域。

## **支持地域**

开服的地域名称、Region ID 的对应关系如下表所示。

| **地域名称** | **Region ID** |
| --- | --- |
| 华东 1（杭州） | cn-hangzhou |
| 华东 2（上海） | cn-shanghai |
| 华北2（北京） | cn-beijing |
| 华北3（张家口） | cn-zhangjiakou |
| 华南1（深圳） | cn-shenzhen |
| 中国香港 | cn-hongkong |
| 新加坡 | ap-southeast-1 |
