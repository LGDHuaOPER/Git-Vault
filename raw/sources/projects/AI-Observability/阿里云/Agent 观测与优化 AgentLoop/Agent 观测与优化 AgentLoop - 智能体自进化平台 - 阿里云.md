## 产品功能

#### 无侵入数据采集

Agent 端到端无侵入采集链路、指标和日志等观测数据。

#### Agent 观测分析

还原用户输入输出与推理轨迹，以及耗时、Token 和状态等信息。

#### Agent 行为审计

为 Agent 行为构建不可篡改的执行轨迹证据链，支持 PIl 等敏感数据泄漏与高危行为检测。

#### Agent 评估

基于完整 Trajectory 轨迹进行深度评估，支持在线实时评估与实验回测评估，开箱即用。

#### Agent 持续优化

支持 Prompts/Skills 资产管理与调优，记忆库与经验库上下文自进化。
