# 代际管理差异

## 核心结论

**人类对美好生活的向往没变，但美好生活的表现形式随代际变化。** 管理者不能用自己这代人的经验要求下一代，要适应代际需求的变化。

## 各代际上课行为特征

| 代际 | 特征 |
|------|------|
| 50 后 | 靠精神活着，通宵没睡也能气定神闲认真上课 |
| 60 后 | 知道不该睡但忍不住打盹，硬撑着不趴下 |
| 70 后 | 睡觉前先观察有没有人注意，没人注意再睡 |
| 80 后 | 可以睁着眼睛睡觉，不仔细观察发现不了 |
| 90 后 | 困了直接夹书走回宿舍睡 |
| 00 后 | 看老师的目光充满挑衅 |
| 10 后 | 认同同好才能成为好友，好友不能抢自己的同好 |

## 关键论述

- **代际认知差异的本质是成长环境差异**：如晋惠帝"何不食肉糜"，只是在他的认知环境里讲实话，没有对错之分
- **传统管理口号失效**："爱岗敬业、以厂为家"对年轻人难以起效，因为年轻人本身就不把家当家
- **躺平观点的合理性**：年轻人认为努力了也不一定成功，不努力反而更舒服，有其现实背景
- **共识是管理的前提**：不认可代际差异、不适应形式变化，就无法形成基本共识，没有共识就无法开展有效管理
