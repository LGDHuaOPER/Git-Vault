# 沟通四要素

沟通包含四个核心要素：
1. **对谁说**
2. **说什么**
3. **怎么说**
4. **什么时机说**

把这四个要素吃透，沟通就不会出问题。

## 与管理分析框架的对应

沟通四要素是管理分析框架在沟通领域的映射。管理分析框架遵循"对谁、做什么、怎么做、什么时机"，结合历史现状未来梳理情景，抓住思想、制度、行为三条横线。

- 对谁说 → 对谁做
- 说什么 → 做什么
- 怎么说 → 怎么做
- 什么时机说 → 什么时机做
