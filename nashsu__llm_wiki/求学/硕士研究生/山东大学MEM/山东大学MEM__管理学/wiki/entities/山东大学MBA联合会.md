# 山东大学MBA联合会

[[山东大学]]MBA 学生组织，21 届联委会于 2019 年成立。在 2026-08-15 课程中由副主席[[张代]]介绍架构与活动。

## 主席团构成

- **主席**：杨全月
- **执行主席**：傅言
- **秘书长**：韩天宇
- **副主席**：王洪飞、段军义、张代、关谦

## 常设部门（7 个）

| 部门 | 职能 |
|------|------|
| 秘书处 | 统筹协调与财务管理 |
| 校企合作部 | 运营各行业俱乐部 |
| 校友服务部 | 对接优秀校友 |
| 学术交流部 | 组织各类商业赛事 |
| 职业发展部 | 发布招聘求职信息 |
| 文体部 | 负责文艺与体育活动 |
| 宣传部 | 负责官方自媒体运营 |

## 六大商业赛事战绩

- **国奖赛**：已启动，有专业选手提供培训
- **华创赛**：国家一等奖年度总冠军（去年，杨全月带队）
- **企创赛**：国家一等奖
- **佳峰时刻**：国家一等奖
- **MBA 创业大赛**：今年在上海交大举办，差一个名次进入总决赛
- **阿里大赛**：已晋级国赛分区赛，10 月下旬进行全国总决赛

## 文体活动

坚持"无体育不商学"理念，开展体育嘉年华、沙赛、葛赛、草赛、亚力联赛、香格里拉挑战赛等赛事。沙赛是最具影响力的赛事之一，能帮助学员认识自我、拓展人脉。全年四个季节均有文艺活动，目前正在筹备元旦跨年晚会。

## 公益项目

成立[[暖城公益社团]]，对接新疆昌吉学院学生开展公益帮扶。

## 纳新安排

9 月或 10 月初开启线上纳新，欢迎 26 级学员参与。
