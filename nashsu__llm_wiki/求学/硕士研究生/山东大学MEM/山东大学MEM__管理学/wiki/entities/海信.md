# 海信

海信从 2001 年到 2014 年坚持做手机（主讲人表述为"23 年"，存在数字矛盾待核实），主打品牌"金刚"。海信手机质量好，但营销能力弱。

## 做手机的逻辑

传统黑电白电厂商（海信、董明珠的格力等）无一例外想做手机，核心原因是布局智能生活场景需要手机作为入口。没有手机，要么向别人开放技术标准，要么放弃闭环，因此哪怕亏损也要坚持。

## 营销能力对比

海信手机质量好但"有能力不会讲"。对比 [[华为]] 智能手机发布会：华为发布会炫酷，海信智慧城市发布会第一环节竟是副总裁读 PPT，营销能力差距明显。

## 待核实

原文转录写"2001 年到 2014 年坚持做手机 23 年"，但 2001 至 2014 仅 13 年，存在数字矛盾，可能是"2014 年"应为"2024 年"或"23 年"为口误。
