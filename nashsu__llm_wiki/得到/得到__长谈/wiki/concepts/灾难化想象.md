# 灾难化想象

凯叔和脱不花在对话中指出的家长常见焦虑思维模式。家长因一件小事（如孩子打翻水杯）而无限联想，最终推导出灾难性后果（如人生失败）。

## 典型链条

- 孩子打翻一杯水 → "你怎么这么毛糙" → "我都说你多少遍了" → "你以后走上社会怎么办" → 人生完了
- 孩子出门忘穿衣服 → 可能会生病 → 永远不会照顾自己 → 我该怎么办
- 孩子迟到被老师批评 → 老师印象不好 → 影响升学 → 影响人生

## 根源

- **联想能力太丰富**：所有的焦虑都来自于联想
- **课题未分离**：把孩子的事、老师的事都背在自己身上
- **控制欲**：希望通过控制每一个细节来确保孩子走向自己期望的未来

## 应对方法

- 做好课题分离：分清什么是孩子的事，什么是自己的事
- 就事论事：一杯水打翻了，蹲下来和孩子一起擦干净，结束
- 相信孩子的韧性：闯不出多大祸
