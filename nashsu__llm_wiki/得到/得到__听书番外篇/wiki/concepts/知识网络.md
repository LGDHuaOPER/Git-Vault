# 知识网络

"知识网络"是戴维·温伯格在《知识的边界》中描述互联网时代知识存在形态的概念。它与[[知识无边界]]理论互为表里：知识无边界是理论主张，知识网络是具体形态。

## 核心特征

1. **所有客体都是网络的一部分**：互联网上的一切——文本、数据、图像、对话——都成为知识网络的组成部分
2. **人成为网络节点**：个体不再是知识的被动接收者，而是知识网络中主动的节点，参与互动、反馈、更新和颠覆
3. **即时互动**：知识的传递不再有传统模式中的延迟，互动和反馈时刻发生
4. **去层级化**：知识不再按照学科、权威、出版物的层级组织，而是以链接和关联的方式自由组合

## 与传统模式的对比

| 传统模式 | 知识网络模式 |
|---------|------------|
| 单向传递 | 多向互动 |
| 有延迟 | 即时反馈 |
| 有层级 | 去中心化 |
| 线性结构 | 网状结构 |
| 知识是成品 | 知识是过程 |

## 与相关概念的关联

- 与[[媒介即信息]]呼应：互联网作为媒介，其网络化特征本身就定义了知识的新形态
- 与[[口语传播与文字传播]]构成演进序列：口语传播→文字传播→网络传播
