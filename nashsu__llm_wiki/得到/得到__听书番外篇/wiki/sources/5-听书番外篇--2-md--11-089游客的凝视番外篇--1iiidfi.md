# 《游客的凝视》番外篇

这是「每天听本书」的特别节目听书番外篇，围绕约翰·厄里的《游客的凝视》展开讨论。

## 核心内容

本期番外篇从法国思想家米歇尔·福柯的“医学凝视”概念切入，阐释约翰·厄里提出的“游客的凝视”理论。福柯认为，医生凭借专业知识权威，用诊断性的目光将病人视为一堆器官而非完整的人，这种凝视暗含权力关系和不平等地位。约翰·厄里借用“凝视”一词，指出游客对景观的观看同样是被社会、文化、媒体等刻意建构出来的——人们在到达目的地之前就已形成对该地的想象和期待，这种凝视带有主观性和预设性。

## 关键论点

1. **游客的凝视是被建构的**：游客对景观的观看并非纯粹的个人体验，而是被旅游宣传、文化叙事等预先塑造。例如，人们在到达巴黎之前就已将其想象为“浪漫之都”，这种期待和幻想取代了真实的巴黎。
2. **游客凝视与医学凝视的类比**：两者都带有主观性和傲慢，都缺乏与被观看对象的真正互动和尊重。游客将景观视为满足自身想象的客体，正如医生将病人视为器官的集合。
3. **眼睛的独特认识论地位**：福柯推崇眼睛的力量，认为眼睛能“大智若愚”——看过即忘、只关注现在，这种明澈、疏远、开放的目光最接近真理。

## 与现有知识体系的关联

- 与 [[风景画作为再现]] 存在关联：游客凝视中的景观也是一种“再现”，而非本真。
- 与 [[风景画作为情感与想象的载体]] 存在关联：风景画和旅游景观都涉及观看者将情感与想象投射到对象上。
- 与 [[作者意图的失控]] 存在潜在关联：游客对景观的想象被外部力量建构，类似于作者意图在传播中失控。
- 与 [[隐喻作为认知机制]] 存在潜在关联：“凝视”本身是一种隐喻，暗示权力关系和认知框架。
