# 《事实》番外篇

你好，这是「每天听本书」的特别节目，听书番外篇。

这期音频要聊的这本书是《事实》，这本书用翔实的数据告诉我们一个事实，这个世界正在变得越来越好。但是，似乎大多数人都认为世界在变糟，为什么会有这样的认知偏差呢？这本书就总结了10中种困扰我们的思维误区，以及扭转思维误区的方法。

扭转偏见这件事，还真的是不容易，掌握方法已经很难，更难的是让大家承认自己目前有错误。 [用户@未来不怕]({"typeid":"231911517","type":80}) ，就分享了一个很动人的故事。《事实》这本书的作者汉斯·罗斯林，他的一生都在和偏见做斗争，他去过很多地方，做过很多职业，在大学当教授，在国际组织做顾问，在世界各地做演讲，甚至是在他病情恶化被送往医院的救护车上，他还随身带着《事实》这本书的草稿。这个时候，再看这本书的引言，才能明白这段话的分量：本书是我对全世界的无知宣战之后的最后一次战役，也是我希望自己能对这个世界产生一些正确影响的最后一次努力。

看完这段话，真的是非常感动，汉斯·罗斯林是在用生命去改变别人。我对这本书又多了一分敬意。

除了改变别人，我们也要改变自己，反身求诸己，看看自己是否也有无知和偏见。

[用户@自然猎人]({"typeid":"138050349","type":80}) 用他自己多年在非洲游历的经验，就给我们提供了另一个角度，西方人的眼中，常常对中国有很多偏见，但是我们自己其实也容易产生偏见，比如在面对非洲的时候。

国内很多人对非洲也是傲慢无知的，脑海中充满根深蒂固的偏见，比如他们觉得，非洲一定是贫穷落后的，到处都是饥荒、战乱和传染病。但是他看到的真实情况并不是这样。偶尔有个别国家发生政党反对派抗争，但是规模非常小，范围可控，更像是演一出闹剧。战争早已经成为记忆。

再来说传染病这个事，主要发生在赤道附近的热带雨林和河口三角洲，气候湿热地区，而且也不是一直都有。因为多年来的疫苗援助，非洲绝大多数地方并没有传染病。

但是自然猎人说，偏见的存在也未必是件坏事。因为哪里有偏见，哪里就有机会，谁能帮助大众克服偏见，谁就能享受扭转偏见带来的红利。

这给了我一个不一样的角度：我们为什么要学习书中的方法，扭转自己的认知偏差呢？其中一个原因，就是能更早的享受红利。

好了，有关这本《事实》，我们先说到这。感谢未来不怕和自然猎人给我们带来的启发。如果听完番外篇，对这本书有了新的兴趣，推荐你听听  **《事实》的完整解读**  **（点击链接进入听书）** 。
