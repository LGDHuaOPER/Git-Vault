# 《引爆流行》番外篇

你好，这是「每天听本书」的特别节目，听书番外篇。

今天我要聊的这本书叫《引爆流行》，讲的是流行是怎么引爆的。它的作者汤普森是《大西洋月刊》的财经编辑，也是个很会引爆流行的人。他做过一个经济普及视频，曾经在Youtube是年订阅量最高的在线视频。

[用户@李筱]({"typeid":"123345480","type":80}) 曾经在知识城邦领读过这本《引爆流行》，他提到了一个例子，很有意思。

我们一般会觉得，在互联网时代，什么东西火了，就是像“像病毒一样扩散”。2012年，雅虎做了一项研究，发现这个说法只是误会。他们研究了上百万条消息在推特网上扩散的路径，发现人们在推特网上看到的消息，大多数都直接来自最早的信息源。

《人类网络》这本书里也提到过一个类似的实验。实验人员在学校选出了12个孩子，让他们中的8个穿格子衬衫，4个穿条纹衬衫，同时跟他们约定好，他们要用一周的时间调整，最后大家都要穿同样的衬衫。实验的结果是，孩子们不约而同地选择了条纹衬衫。这个结果很奇怪啊，按理说，大家更有可能遵从多数，穿格子衬衫啊。

原来，实验人员特意挑选了学校里比较活跃的4个孩子穿条纹的。这些孩子活跃，条纹衬衫出现的概率就高了。

你看，少数服从多数，不只是客观数字的多少，还要看影响力。那些社会网络的关键节点，天然就代表了大多数。

这个观点，还有另一个表达方式，叫“个别人物法则”，就是在流行引爆的过程中，个别的人会起到至关重要的作用。它来自另一本讲如何制造流行的书《引爆点》，作者是著名作家格拉德威尔。 [用户@shadow]({"typeid":"225885727","type":80}) 告诉我们，《每日邮报》认为《引爆流行》其实延续了《引爆点》的很多观点和写法。汤普森自己也承认这一点，他甚至在《引爆流行》的封面上提到了《引爆点》这本书。不过，汤普森觉得，自己的观察和总结更到位。

《引爆点》把流行拆成了三个维度，一个是人的行为，二是流行事物本身，三是环境。《引爆流行》给出了一个简洁的公式，喜欢=熟悉+惊喜，也就是MAYA法则。

汤普森把社会的流行趋势算法化了，总结成了公式，这会让我们感到意外。但是仔细看看，他说的这个道理，我们又很熟悉。所以，这个公式本身就很符合MAYA法则，而且，确实更流行。

[用户@吴楚（辛格莱瑞特）]({"typeid":"223515416","type":80}) 活学活用，用MAYA法则解释了一个我们生活中常见的现象，品牌联名。

她说自己有了烤箱之后，就很少在外面买蛋糕面包了，但是有一天，她在逛好利来的时候，却毫不犹豫地买了好利来和孩之宝的联名款蛋糕“云朵芝士”。

联名款为什么好卖？秘诀就是MAYA法则，我们再来复习一下那个公式啊，  *喜欢=熟悉+惊喜* 。

汤普森认为，人身上同时存在着两种特点：“迷恋新奇事物症”和“恐惧陌生事物症”。制造流行既要有令人惊喜的内容，又要有足够的传统习俗，才能吸引核心观众。让熟悉的事物变陌生，让陌生的事物变熟悉，这就会同时激发它们身上的魅力。

对好利来来说，好利来的甜点，顾客都很熟悉了，偶尔来些新鲜的刺激，人们非常愿意为尝鲜买单。对孩之宝来说，它的产品中国人不一定熟悉，但嫁接上好利来的点心，感兴趣的人或许会去搜索，这是最好的广告。

我们每天看到的联名款还有很多，比如优衣库xKAWS、RIO鸡尾酒x六神花露水、MACx王者荣耀……这些联名都是期望达到1+1大于2的效果。

所以，联名款的秘诀就是：用一种全新的、令人惊奇的方式，打开一扇通往舒适、有意义、熟悉的大门。

不过，也有人说，MAYA法则不是汤普森原创的观点。 [用户@王思恺（Super Tank）]({"typeid":"125842","type":80}) 告诉我们，这个公式最早是一位叫雷蒙德·洛威的设计师提出的。他是美国20世纪最有名的工业设计师。就算你不熟悉这个名字，你肯定见过他设计的东西，比如可口可乐的经典玻璃瓶、壳牌石油的经典LOGO。这位大师在设计产品上或许很会“引爆流行”，但是在兜售自己观点的时候，就不够用心了。这件事再次更证明了引爆流行的重要性，  *再好的观点，也需要流行助力，才能影响世界。*

好，以上就是《引爆流行》这本书的番外篇，感谢李筱、shadow、吴楚和王思恺的分享。想了解流行背后的规律，请听一听  **《引爆流行》的完整解读**  **（点击链接进入听书）** 。
