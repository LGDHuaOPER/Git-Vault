# 《生命3.0》番外篇

你好，这是「每天听本书」的特别节目，听书番外篇。 

今天我要聊的这本书叫《生命3.0》，副标题是“人工智能时代，人类的进化与重生”。它的作者是迈克斯·泰格马克，麻省理工学院物理系终身教授。

关于人工智能是否对人类有益，专家们大概可以分成支持、反对和中立几个阵营。这些阵营各有各的道理，乍一看，真不知道该听谁的。泰格马克在《生命3.0》这本书里汇集了不同阵营的思想精华，它就像一本深度指南，帮助我们参与到这场关于人工智能的对话中。

泰格马克一个物理系教授，为什么要写这样一本人工智能深度指南呢？ [用户@王思恺（Super Tank）]({"typeid":"125842","type":80}) 告诉我们，这跟泰格马克对人工智能的观点有关。泰格马克发现，单一维度的人工智能观点会误导人们。比如，大多数人对人工智能的认识，很可能是从好莱坞科幻电影开始的，这些电影里经常出现机器人，它们往往被描绘成想要统治、甚至灭绝人类的样子，这种设定会在不经意间引导人们产生恐惧，担心机器人拥有意识，对人类不利。

泰格马克认为，好莱坞的这种引导是错误的，担心机器人做恶是杞人忧天。在他看来，高级人工智能的真正可怕之处不是它们是否对人类怀有恶意，而是它们的能力究竟有多强。如果人工智能真的拥有超级智能，那么根据设定，它会非常好地实现它的目标。人类首先需要确保的是，人工智能的这些目标与人类自己的目标一致。泰格马克还举了一个例子：一个人对蚂蚁并没有恶意，但如果这个人被派去在蚁巢上建设一个绿色能源水电站，这个举动对于蚂蚁来说就是毁灭性的。如果人工智能真的具有超级智能，人类就得确保它们的目标符合我们自身的利益，谁也不想让自己处在例子里那些蚂蚁的位置。

看来，泰格马克非常看好拥有超级智能的人工智能。再追问一下，究竟什么是“智能”呢？毕竟每个人对这个词的理解可能都不一样。泰格马克曾经在一次人工智能峰会上，解释过他对智能的理解，他说：智能是完成复杂目标的能力，一个目标越复杂，我们就需要越多的智能。说得再具体点，智能其实就是处理所有信息的能力，不管我们是用大脑细胞的碳原子来处理信息，还是用电脑GPU的硅原子或者使用其他人造技术处理，都是智能。

泰格马克还在《生命3.0》这本书里谈论了，通用人工智能。他预测说，通用人工智能的出现地点，很可能是中国，而不是美国。因为，中国是人工智能的一个重要阵地，泰格马克很看好中国，他说，中国现在是人工智能技术的世界引领者，中国不仅在人工智能研发方面首屈一指，还能保证人工智能会是安全和有益于人类的。

为什么泰格马克这么看好中国呢？他提出了一个乍一听有点反常识的观点。他认为，中国的传统文化有利于发展人工智能。泰格马克解释道，中国是人类最古老的文明，有非常强大的长期思考和长期规划的能力。作为西方人，他在这点上能够感受到中西方的差异，他说，大多数西方国家的人，听到别人谈论长远计划或者未来的事情都会大笑。他们认为，要真正到了那个时候才应该计划下一步的事情。泰格马克觉得，  *人类需要去考虑未来，西方人需要具备中国人的智慧，把很多事情放到全球的议事日程上来，知道未来我们人类发展的方向。*
