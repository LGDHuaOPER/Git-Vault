# 《脑与阅读》番外篇

你好，这是「每天听本书」的特别节目，听书番外篇。 

今天要说的书是《脑与阅读》。这本书从神经科学的角度，解释了阅读的本质。

这本书的作者叫斯坦尼斯拉斯·迪昂，是欧洲脑科学研究的领头人，也是全球最有影响力的认知神经科学家之一。

[用户@王思恺（super tank）](igetapp://user/detail?ddurlMinVer=5.2.0&uid=125842) 说，迪昂这么厉害，有一个很重要的原因，就是他在认知科学领域，绝对是根红苗正。

迪昂的老师叫杰柯·梅勒。这个名字，你可能没听过，但是梅勒的三位导师，也就是迪昂的三位师爷，你很可能听过。第一位是认知神经科学的创始人，乔治·米勒；第二位是语言学大师乔姆斯基；第三位，是在幼儿教育领域特别有名的皮亚杰，全都是各个学科里泰斗级的人物。

所以，迪昂做学术，那绝对是直接站在巨人的肩膀上。当然了，迪昂也很争气，曾经获得过“大脑奖”，这个奖号称是“神经科学领域的诺贝尔奖”。

[用户@帝亚·梵 ](igetapp://user/detail?ddurlMinVer=5.2.0&uid=34524182) 在得到电子书推荐了这本书，他的总结，我觉得很到位。他说，这本书能帮我们破除对阅读的妄念。

帝亚·梵很喜欢读书，像大多数爱书人一样，他尝试过很多快速阅读的技术，但是，效果都一般。看了这本书，他觉得自己放下了，这本书让他认识到，快速阅读是有极限的。很多所谓的高效阅读方法，从科学的角度来看，完全是无稽之谈。

这本书不仅能帮我们破除很多对阅读的妄念，也能给我们提供一些提升阅读能力的小妙招。

比如书里说，我们在阅读的时候，眼睛不是像扫描仪那样，咔嚓一下拍下所有看见的东西。你的眼睛必须扫视书页，就像一个快速移动的放大镜。

根据这个理论，科学家做了一个实验，他们找来一些人，把他们的头固定不动，然后在眼睛的正前方放一个屏幕。没错，头不动，眼睛也不动，而是屏幕上的字动。这个试验里，表现最好的人，阅读速度可以达到正常的3到4倍。

[听书组的 @王木头](igetapp://user/detail?ddurlMinVer=5.2.0&uid=100626) 听到这个实验，就开了一个很有意思的脑洞。他说，听完这个实验，他想到一个非常好的方法，可以提高看书和写稿的效率，值得在我们办公室大力推广。那就是把办公室里的显示器，都换成大屏幕，越大越好。

为什么呢？你想想我们刚刚提到的那个实验，当你的显示屏足够大的时候，你看书，不就可以头不动，眼睛也不用上下翻看了吗，只需要滑动屏幕上的字就可以了。

再给你一个更具体小建议，最好买那种可以旋转的屏幕，把屏幕竖过来，因为大多数电子书都是按照书的比例排版的，用竖屏的显示器，排版就更合适，阅读效率也更高。

听到王木头分享的这个阅读小妙招，我想到了一个道理：  *怎么去判断一个认知实验靠不靠谱？在很大程度上，就是要看他能不能投射到现实生活中去。*
