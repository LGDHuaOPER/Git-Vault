# 050｜怎样做好一个乙方？

这里是《得到头条》，我是徐玲。

今天我们从两个话题出发，为你提供知识服务。一是华为强调要“炸掉研发金字塔”，二是我国超高速风洞的最新进展。

最近华为内部有个事引起了大家关注，就是任正非签发了一篇文章，名字叫《华为到该炸掉研发金字塔的时候了》。这篇文章其实是一篇旧文，在2016年发表在华为内部论坛“心声社区”上。现在时隔5年，任正非重新签发这篇文章，引发外界很多猜测。  *在我们印象中，华为的长项是在硬件，这篇文章可能传递出一个信号，就是接下来华为要在软件方面发力，在它的整个营业收入中，加大软件服务的收入比例。*

同时，这篇文章也表明，软件开发是件相当复杂的事情，很容易出现“效率低下、专家能力缺失”等问题。而且，有过开发经验的人都知道，面向特定客户的软件项目还有一个难题，就是客户需求一直在变，什么样的需求该答应，什么样的需求该变通，什么样的需求该拒绝，这中间要耗费巨大的沟通成本。比如这篇文章里就提到，面对“客户支持”的各种要求和压力，程序员们白天都用来开会了，晚上才有时间加班加点编程序。你看，强大如华为，要在软件项目上当好一个“乙方”，也不容易。

其实这也不是软件开发的独有问题。面对客户提出的要求，怎么处理才合适，这里面非常考验乙方的水平。我来说一件最近从刘润老师那儿听到的小事。

刘润老师因为要举办一场演讲，需要找会务公司进行合作。其中有一家公司，态度特别好，工作人员随身带个小本本，刘润老师提出什么要求，他就马上掏出本子记下来。比如，刘润老师问：这个地方，会不会遮挡住观众视线了，需不需要撤掉一些椅子？工作人员说，好的，可以。记在了本子上。刘润老师又问，那个地方，屏幕的角度用不用调整一下，观众会不会看不清楚？工作人员又说，好的，可以。记在了本子上。

几句话下来，把刘润老师吓出一身冷汗。为啥呢？刘润老师说，如果无论客户提出什么请求，乙方都只会一味说好，只能说明一件事：这家公司没什么专业性，是一个小乙方。

*小乙方，是靠“服从性”吃饭，对客户的具体要求负责，言听计从、有求必应。* 那万一客户的要求是错的呢？那不管，反正你自己要求的，搞砸了不关我的事。你看，跟小乙方合作，你提要求的时候很爽，但后果可能很严重。

那么，大乙方应该是什么样的呢？

刘润老师说，他期待的回答是：这个地方，确实需要撤掉一些椅子，这样观众的视野会更开阔。不过那个地方，调整屏幕的角度也解决不了问题，整块屏幕可能都得换掉。这样的问题我们以前碰到过，一般有两种解决方案，A方案的优劣是什么，B方案的优劣是什么，这两套方案的成本大概是这样。根据我们的经验，用B方案最好。哦对了，还有一些另外的问题，可能你之前也想到了，但我还是必须告诉你。这几项，是咱们必须重点关注的。等等。

你看，这样下来，客户是不是就放心多了？

*大乙方，是靠“专业性”吃饭，对客户的最终任务负责，不是让客户感觉爽，而是让客户做成事。* 对客户提出的要求，该解释解释，该拒绝拒绝。同时，对完成任务很重要，但客户没有想到、没有说出的要求，大乙方会帮客户考虑到。

你发现没有，  *大乙方的本质，是清楚地知道客户在这件事情上的OKR是什么。* O就是客户要达成的任务目标，你要对这个任务目标负责；而KR，也就是关键结果，需要你去帮客户来定义。因为你在这个领域比客户更专业，你比客户更清楚为了达成那个O，应该用什么样的KR。

再补充一个小例子。一位老顾客给母亲过生日，在饭店订了一个包间，饭店经理需要把包间号发给所有被邀请参加寿宴的客人。按照常规流程，经理只需要直接发包间号，比如108，就可以了，但这次经理做了个小处理，他特意把包间号改成了名字“南山厅”，寓意“寿比南山”，让客人又惊喜又感动。你看，这就是搞清楚了客户的O，然后经理自己来制定KR的过程。

借用一下李南南老师的金句：  *做乙方，从来都不是讨好客户，而是成就客户。*

来看今天的第二条。

之前我们聊过，今年东京奥运会上中国代表团取得了好成绩，其中有一部分功劳要归于中国航空科技。在游泳、赛艇、自行车等运动项目中，都用到了航空科技中的风洞技术进行训练。风洞，就是以人工方式制造气流，用来模拟飞行器周围气体的流动情况，是研发飞行器的重要装置。比如中国赛艇队，他们就进入了测试歼20战斗机的风洞中进行特训，通过在风洞中模拟出赛艇运动员不同姿态的空气动力学环境，比如抓水、驱动、出水、回桨等等，找到气动阻力最小的编组方案。

今天，青年科学家彭天放老师的“硬科技报告”，为我们带来了中国超高速风洞建设的最新进展。目前，中国正在建设一座超高速风洞，位于北京的怀柔科学城，预计明年建好。它可以模拟40-100公里高空，时速每秒钟10公里的飞行环境，也就是相当于大概30倍音速。建成之后，它将成为世界上最先进的超高速风洞之一。

*风洞被称为飞行器的摇篮，它的建设水平和技术指标，预示着国家下一代飞行器的发展方向。* 为什么风洞装置对于飞行器的研发这么重要呢？

这主要是因为，飞行器和空气的相互作用，是人类迄今为止面临的最复杂的物理现象之一。比如，其中一个基础力学方程，也叫N-S方程，被评为世界上最重要的七大数学难题之一。有人悬赏100万美元征集答案，至今还没有人拿到这个奖金。目前人类对于很多空气动力学问题，都没法精确计算，而只有近似的答案。

所以，飞行器的设计过程，跟很多其他的机械设计不同，需要经过特别多的实验研究。其中最重要的实验装置，就是风洞。  *一款飞行器从设计到投入实用，通常都要经过上万次的风洞实验。*

随着气流速度的提升，风洞的技术难度也逐步提高。低于音速的风洞，简单来说就是一个大的电风扇；但是，接近或者超过音速的风洞，它的技术难度就大了，其中很多的技术环节跟航空和火箭发动机的技术类似；而大于五倍音速的超高速风洞，产生高速气流本身就非常困难。

这次我国正在建设的超高速风洞，采用的是一种叫做爆轰驱动的原理。简单来说，就是在一根长度上百米，直径几米的管道的一头制造爆炸，让爆炸产生的气流从管子里面吹过去，来制造高速气流。我在文稿区放了一张照片，你可以看出这根爆轰管道的样子。我要特别指出的是，这种爆轰式超高速风洞，是中国科研人员在钱学森、郭永怀等老一辈科学家的思路上，自主开发的一条技术路径。

![https://piccdn3.umiwi.com/img/202108/29/202108291109182498741918.jpg](https://piccdn3.umiwi.com/img/202108/29/202108291109182498741918.jpg)

为什么要花大力气建造超高速风洞呢？目前，在飞行器领域，一个最为前沿的方向就是“高超音速飞行器”，可以以5~20倍音速飞行。其中最典型的应用就是天地往返飞机，这是一种可以在地球大气层和太空之间进行多次往返飞行的设备。和我们熟知的可回收火箭，比如美国的猎鹰九号火箭不一样，这种天地往返飞机更加灵活。比如，天地往返飞机可以在大气层中停留更长的时间，可以在发射之后临时调整目的地，可以在1小时左右的时间内实现全球部署，等等。  *这些特点，让天地往返飞机能够在地球和太空之间进行快速物资交换。对于未来的空间站，甚至太空基础设施的建设，都有重要的实用价值。*

令人自豪的是，不论是高超音速飞行器还是天地往返飞机，目前我国的技术进展都是处于世界领先的水平。等明年这座超高速风洞建成之后，我们会在星辰大海的探索中，走得更远。

📑刘润：《所有的合作，都要有专业的价值：如何成为一个大乙方？》

晓曦教授：我们所有人在某些时刻都是乙方，因为我们要给别人提供服务和价值。这个“别人”可能是客户，可能是老板、同事、下属，甚至是配偶、父母和孩子。我们对他们的要求总是倾向于有求必应，但真正提供价值，不是讨好对方，而是成就对方。也就是让他们觉得，跟我在一起，他们变成了更好的人。这需要我们细心揣摩对方的价值观、目标和优先级。有时候他们的OKR可能显而易见，而更多时候别人的OKR甚至很难直接说出口，需要你长期收集信息和思考分析，甚至帮他们一起定义目标和关键结果。这自然耗时耗心力，但努力工作并不是单纯加班加点，而是要努力到点子上。不然每天工作12小时也依然是懒惰。

庸人不自扰：软件开发行业，还需要警惕的一点是『乙方心态』

什么是『乙方心态』?甲方付钱给乙方，购买软件开发服务。甲方的老板，并不是最经常使用软件的人，但他决定付钱，他是客户；真正的用户，是公司的全体员工。

客户在付钱，但是不怎么用产品；用户在用产品，但是并不付钱。而软件公司为了取悦甲方老板，开发出一款对于员工并不好用的产品，这就是『乙方心态』。

『乙方心态』的后果，是对用户真正需求的洞察能力，最终失去的是信任和市场。所谓『专业』，可以理解为既能服务好客户，又能让真正的用户满意，而有时候，用户比客户更重要，这时候坚持对用户负责，也是『立场』。

Tian：1⃣️不要卑躬屈膝人，而是要关注价值
交易双方是合作关系，而不是某一方的服从。在交易关系中，强势不是看自身的所处的位置，而是要看自我的价值。

因此，作为乙方，需要展现的是自身解决问题的能力和突显出自己的价值。

2⃣️不要言听计从，而是要分析需求
好的乙方，不是要所有事情都能够面面俱到，也不是所有事情都言听计从，而是能够从甲方的话语中分析出真实的需求，从而给出自己的建议。

3⃣️不要默默奉献，而是要打动人心
所有的交易都可看作是一种相互合作。
乙方在合作的过程中，不是默默的奉献，而是能够通过其自身的专业性，为甲方解决棘手的问题，从而深入人心。

📕在这个过程中，展示自我的专业性显得尤为重要。📕作为广告公司的乙方，稀缺在哪？在策略思维，在目标感，在创意能力，在执行能力，在对占领用户心智方法的洞察，在与奋战在市场一线的客户一起成长的心态。

📕为什么成熟的广告公司会有像“超级符号”、“品牌大理想”这一类成体系的品牌理论作指导？因为这些公司知道，自己的这一套体系，能够很好的彰显自己的专业性&稀缺性，能更好地帮助甲方赋予品牌长久的生命力。
 
📕相比之下，忽略自身价值，大多纠结于细节，一味讨好甲方的乙方广告公司，不仅显得卑微，活路也会变窄。以上，供大家参考，也请徐玲老师指教，谢谢。

庸人不自扰：如何做一个合格的甲方——专业、有服务意识、有立场。

用专业，赢得信任和尊重；用服务意识，提供优质解决方案和问题解答；用立场，坚守服务原则，保证团队权益。

以工作经历为例👉在给企业做宣传片过程中，专业性就是在提案的时候不仅要讲明片子框架和核心亮点，还要准备好不同片子分别用作风格参考、文案参考、配色参考等等，目的是进行『预期管理』，让甲方在拍摄前就知道成片大致的效果，同时协商调整想要替换的策划元素；拍摄前，还需要由摄影师导演和甲方现场勘景，确定用什么型号的机子、需要多少灯光、甲方员工的配合等等，并提前给出拍摄排期，便于甲方协调时间，不影响自身工作。

服务意识多体现在拍摄过程中，机子笨重很容易破坏场地，所以我们会在拍摄当天会很多时间提前在场地上铺好木板等防护，严格按照排期计划拍摄对应场景，避免企业群演多余的等待。

有立场则是前期提案对于甲方一些要求，我们不会为了签约就满口答应，大部分是因为预算问题，如果答应要么亏本做，要么做出来远低于预期，这样损耗的是团队权益，甲方也很难满意。如果一旦签约，过程中因为突发情况造成的损失，则必然由我们承担，那时候哪怕面临亏损，也得把活干好，毕竟口碑是会相互传播的，一锤子买卖做不长。

云淡风轻：风洞（wind tunnel）即风洞实验室，是以人工的方式产生并且控制气流，用来模拟飞行器或实体周围气体的流动情况，并可量度气流对实体的作用效果以及观察物理现象的一种管道状实验设备，它是进行空气动力实验最常用、最有效的工具之一。和谐号动车组的车头模型就经过了苛刻的风洞测试最终才定型。

2008年，“国家重大科研装备研制”项目支持了 “复现高超声速飞行条件激波风洞（JF12复现风洞）”的研制，旨在建立飞行高度25-50公里、飞行速度1.5-3公里/秒、气流总温1500-3500度、喷管出口直径2.5米的复现高超声速飞行条件实验能力。2016年，JF12复现风洞项目负责人姜宗林获得美国航空航天学会“地面试验奖”，标志着该风洞达到世界领先水平，并得到国际同行广泛认可。 

2018年，国家自然科学基金委员会“国家重大科研仪器研制”项目立项支持“爆轰驱动超高速高焓激波风洞（JF22超高速风洞）”研制，旨在建立飞行高度40-80公里、飞行速度3-10公里/秒、气流总温3000-10000度、喷管出口直径2.5米的超高速高焓流动试验研究能力。
