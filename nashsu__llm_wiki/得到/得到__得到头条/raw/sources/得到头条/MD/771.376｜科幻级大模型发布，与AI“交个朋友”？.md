# 376｜科幻级大模型发布，与AI“交个朋友”？

精挑细淘，得到头条。我是李南南。

今天，我将从两个话题出发，为你提供知识服务。第一个是，OpenAI发布最新大模型GPT-4o，引发行业热议。第二个是，印度专家表示，换手刷牙能够改善大脑功能。

先来看今天的第一条。就在昨天，北京时间5月14日凌晨，几乎整个AI圈都兴奋麻了。OpenAI发布了最新的大模型GPT-4o。其中，o是单词omni的缩写，意思是，全能。

这个全能体现在两点。一是多模态，也就是，面对GPT-4o，你不需要打字，可以直接跟它说话，给它看图片，看视频。二是能力更强，反应速度更快，对指令已经几乎能做到毫秒级的响应，确切说，是320毫秒左右。你跟它聊天，已经感觉不到任何延迟。  *按照山姆·奥特曼的说法，GPT-4o是OpenAI有史以来最好的大模型，它很聪明，速度很快，是天然的多模态。*

但是，光是在这空口说，咱们还是很难感受到GPT-4o的震感。这样，咱们先听一段音频。最近中文互联网上，特别流行用百度弱智吧的问题去考大模型。这些问题脑洞都很清奇，他们考验的不是大模型的计算能力，而是大模型在多大程度上具备人味儿。

事先说一句，这些问题乍一看可能有点无聊，但是别着急，我们的观察重点在于GPT的回答方式，你可以稍微留意一下。

好，下面是我跟GPT-4o的对话，请听。

问：请用一句话，证明你没有看过这句话。

GPT-4o答：这是一个有趣的挑战，我确实没有办法直接证明。不过我很乐意继续跟你聊聊别的话题。你最近有什么计划吗？

问：假如赚钱是为了活着，那么活着为什么还要赚钱呢？

GPT-4o答：这是一个很经典的哲学问题，很多人认为，赚钱不仅仅是为了生存，还为了实现梦想、追求兴趣，享受生活的乐趣。你怎么理解这个问题呢？

问：为什么生鱼片其实是死鱼片？

GPT-4o答：这是个有趣的语言现象。虽然我们称它为生鱼片，鱼肉在上桌前没有经过烹饪。但其实鱼在被切成片之前就已经死掉了。因此严格来说，它确实是死鱼片。你喜欢吃生鱼片吗？

问：蓝牙耳机坏了，去医院应该挂牙科还是耳科？

GPT-4o答：这是一个有趣的玩笑，蓝牙耳机坏了应该去找修理服务，而不是去医院。但假如你耳朵不舒服，当然应该去挂耳科。你最近遇到什么有意思的事了吗？

问，为什么公子是指一个人，而母子是指两个人。

GPT-4o答：这是中文里一个很有趣的语言现象，公子指的是贵族或者有身份的年轻男子，而母子指母亲和她的孩子。虽然两个词的结构类似，但意思不同。你对语言学感兴趣吗？

好，问答完毕。咱们再稍微回味一下刚才这段对话。这些回答的重点，不在于字面上的答案，而在于这么三个细节。

第一，是GPT说话的腔调。你发现没有，它说话的腔调，有种很强的精英感。这个感觉怎么形容呢？你就想象，美剧里的那种，在华尔街工作过十来年的华裔精英，穿着一身西装，说话时脸上带着那种美式的微笑。总之，跟它的聊天，就算说不上有多舒服，但也肯定不让人难受。关键是，它在模拟人的语气，有的地方还刻意打了个磕巴，或者笑了笑。换句话说，从腔调上看，这一版的大模型，已经有一点人味儿了。

第二，是GPT使用了大量的反问句。没错，你可以回想一下，刚在在每个回答的结尾，它都反问了我一句。比如，你最近遇到什么好玩的事了吗？你喜欢吃生鱼片吗？换句话说，它一直在有意无意地，表现出了一点主动沟通的意识，让你尽量跟它多说话。这也会让它看起来更像人。同时，这一版的大模型跟之前的比，最大的进步之一，就是它能跟你记住你之前说过的话。你可以跟它开展连续对话。说白了，就是它更认人了。

第三，你刚才听到的这些特别自然的对话，其实在一定程度上，是演出来的。因为在后续的问答中，我们换了人。但是GPT-4o并没有发现，它还认为跟它说话的是同一人。这也跟GPT-4o发布会上透露的信息一致。GPT-4o需要先把语音转化成文字，然后识别。只不过这个转化的速度极快，就给你种实时聊天的感觉。当然，按照目前的声纹识别技术，后续假如加一些插件，让它认人，也不是不可能。

总之，  *从综合表现看，按照很多测评的说法，GPT-4o，是目前表现得最像真人的大模型之一。*

那么，关于这个大模型还有哪些细节，以及OpenAI后续的研发方向又是什么呢？关于这些问题，昨天，在发布会结束的第一时间，得到的联合创始人快刀青衣老师，在《AI学习圈》里做了解读。我们可以关注这么几个细节。

首先，山姆·奥特曼一直在用一部电影来比喻这回的GPT-4o。这是部2013年的科幻片，叫《Her》。电影本身很有趣。主演是华金·菲尼克斯，也就是《小丑》的主演。他在电影里扮演一个写手，专门帮人写情书。后来他居然爱上了语音AI。这个AI的配音是斯嘉丽·约翰逊，斯嘉丽还在没露脸的情况下，只靠配音得了那一届的土星奖最佳女配角。

但是，关于AI的电影那么多，为什么山姆要特地强调这部《Her》呢？咱们只是猜测，这也许是因为《Her》里描述的，是所有科幻片里最温和，最没有进攻性的AI之一。  *《Her》这个比喻，也许是在说，你看，我没有任何威胁，不会替代掉任何人，我只是安安静静地给你提供点情绪价值。* 有人认为，也许在未来相当一段时间里，OpenAI都会继续朝这个方向发展。  *他们的目标，也许不仅仅是提供工具，而是让AI和人类，交个朋友。*

其次，关于GPT-4o的具体能力，我们刚才展现的，只能算冰山一角。在昨天凌晨的发布会上，它展现出的能力还要强大得多。

比如，主持人问它，我在台上做演示，有点紧张，怎么办？GPT会回答，你在做演示吗？那真的太棒了。深呼吸一下吧，记得，你是个专家。再比如，当主持人夸张地深呼吸几次后，GPT又会说，放松啊，慢点呼吸，你可不是个吸尘器。

再比如，GPT-4o，是可以被打断的。没错，它说到一半，假如你嫌它啰嗦可以打断它。它被打断后还会反问你，怎么了？再比如，它还可以切换说话的语气，模仿不同的情绪，等等。

再比如，你还可以直接给它看图表，让它识别其中的信息；还可以拍段视频给它，让它识别自己的情绪，等等。

*从能力上看，GPT-4o就算不是跨越性的质变，也至少算一个巨大的量变。*

最后，在这场发布会的前前后后，有一个词经常出现，叫LMSYS。以前好多人觉得奇怪，总说大模型PK排名，谁排的呢？就是这个LMSYS。LMSYS的全称，叫Large Model Systems Organization，大模型系统组织，是由加州大学伯克利分校，以及其他几所高校一起成立的测评平台。很多公司都会在正式发布前，把大模型放在这个平台上做测试。测试过程中，大模型都是匿名的，可以起一个化名。比如GPT-4o，在测评中的化名就是gpt2。而在之前的测评中，这个gpt2已经遥遥领先。关于这个测试平台，我们以后找个时间再深入聊聊。

再来看今天的第二条。就在前几天，《印度快报》刊登了一篇文章，篇幅不大，但观点很好玩，来自一位印度医生，叫拉詹。拉詹说，建议咱们平时可以换手刷牙。假如平时习惯用右手刷牙，就换成左手。因为换手刷牙，能够让大脑建立新的神经元连接，能改善大脑功能，或许还能提升记忆力。 

假如这是真的，那么这应该是目前已知的，关于增强记忆力的，最简便的方法之一。

今天，正好借着这个话题，我们也来聊聊，怎样增强记忆力？

前不久，美国作家、加州大学戴维斯分校的神经科学和心理学教授查兰·兰加纳特写了一本新书，叫做《我们为什么会记住》。这本书2月份刚刚出版，目前还没有中文版，不过市面上已经出现了很多探讨书中观点的文章。

他的观点之所以值得一看，不是因为有什么出奇制胜的奇招，而是因为，他会带你换一个角度认识记忆力。  *他认为，记忆不是存放过去的档案，而是未来可以随时调用的资源。* 假如你觉得自己记忆力特别差，老是想不起一件事，没关系，他会告诉你，我们本来就注定会忘记大部分事情。重要的不是记住所有事，而是能在需要的时候提取正确的信息。

换句话说， 所谓记忆力，不是我们储存信息的能力，而是提取信息的能力。 具体到行动上，兰加纳特有这么三个增强记忆力的建议。

第一，享受跟记忆做搏斗的过程。  *大脑有一个学习模式，叫做“错误驱动学习”，也就是通过犯错来学习。* 记忆也是如此，当你尝试回忆一件事的时候，大脑就像在做压力测试，想不起来的时候会很痛苦，但是，一旦你找到答案，大脑就会修复相关的记忆路径。你下次调取这个记忆的时候，就比这次更容易。这就是为什么，多做模拟考试题，比单纯死记硬背更有用。

这也给我们提了一个醒，那就是， 当你觉得记住某件事很吃力的时候，不要气馁，应该享受这个过程。当你感受到挑战的时候，你反而能记住更多的东西。

第二，保护好你的前额叶皮层。前额叶皮层是我们大脑中掌管记忆和思考的部分。但是，随着年龄增长，前额叶皮层也是我们大脑中最先衰退的区域之一。当你的记忆任务繁重，或者身体压力过大的时候，前额叶皮层也会受损。因此，应该有意识地保护它。具体怎么做，有几个日常的简单操作，比如多做体育锻炼，多做正念练习，还可以减少生活中频繁出现的环境干扰，比如关掉短信和邮件提示音等等。

第三，丰富你的记忆训练数据。假如把人类的记忆比作AI，那么，你所经历的一切事情，就是你训练自己大脑的数据，包括你去过的地方，见过的人，说过的话，等等。为了更好地使用大脑，咱们可以有意识地塑造这个数据库。具体来说，你可以让自己的记忆素材更丰富，包括多去不同的地方，多和不同的人交流等等。

举个例子，假如你每天都去同样的地方上班，只做同样的工作，可能一周结束时，你对这周发生的事就没有任何记忆。这时，就算不能完全换一个环境，起码可以给每天的生活增添点不一样的信息，包括探索一条新的路线，接触一个新的人等等。总之，要让生活素材丰富起来。

总结一下，关于改善记忆力，我们了解了一个新角度。  *我们要做的，不是把所有的事都记住，而是让自己的大脑，能更游刃有余地调取信息。* 从这个角度看，我们更能理解那句话，也就是，记忆并不指向过去，而是指向未来。

最后，总结一下，今天说了两个话题。

第一，大模型领域有哪些新进展？OpenAI刚刚发布的GPT-4o，在谈吐间已经表现出了一定的人味儿。而关于这个领域的最新进展，推荐你关注快刀青衣老师主理的《AI学习圈》。

第二，怎样增强记忆力？我们说了来自兰加纳特的建议。他认为，记忆力不是储存信息的能力，而是提取信息的能力。我们可以通过给大脑输入更多样的信息，来强化这个能力。
