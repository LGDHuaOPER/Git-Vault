# 057｜互联网产品怎样做“无障碍改造”？

这里是《得到头条》，我是徐玲。

今天我们从三个话题出发，为你提供知识服务。一是东京残奥会闭幕，二是宠物经济爆发式增长，三是微信上线了儿童手表版。

上周末，东京残奥会闭幕了。中国代表团获得了96枚金牌、207枚奖牌，以碾压式优势，连续第5届获得金牌榜和奖牌榜双第一。向中国残奥健儿祝贺！你们太牛了。“于残缺中演绎完美，于苦难中予人希望，于平凡中展现伟大。”（人民网）

残奥会结束了，但我们需要记住举办残奥会的初衷，就是改变社会对残疾人的偏见，改变残疾人的生存环境。根据中国残联的统计，截至2020年，中国有8500万残疾人，是一个不小的群体。能不能让他们和普通人一样，过上便利、高品质的生活？如何让科技为残疾人赋能？这是时代交给我们的任务。

我看过一篇报道，1984年，跳远运动员平亚丽为中国队夺得了残奥会历史上的第一枚金牌。平亚丽是一名视障人士，那年残奥会上她第一次知道，世界上还有专门为盲人领路的导盲犬。当时她不禁感叹，我什么时候也能有一只导盲犬？队友给她泼冷水：别做梦了，人家一只导盲犬几万美元，咱哪有那个钱？直到2007年，平亚丽终于有了自己的导盲犬；2008年北京残奥会，她的导盲犬领着她完成了火炬接力。

的确，这些年中国经济的快速发展，公共场所无障碍设施的快速普及，让残疾人的生活环境获得了巨大改善。但同时，科技的发展又给残疾人带来了新的挑战。

比如最简单的场景，视障人士怎么用手机拍照？现在已经有了比较成熟的解决方案，就是读屏软件，把屏幕上需要“看”的信息，转换成可以“听”的。只要把手指滑动到屏幕上相应的按钮，读屏软件就告诉你，这里是“相机”。点击打开后，举起手机，读屏软件会提示：“检测到人物，人物居中，拍照。”

再比如，我们很习惯的图形验证码，视障用户就无法处理。有的软件为此做了特殊配置，如果使用者是视障用户的话，就不会出这种图片题，而会出一些文字题，比如“以下哪个是你的好友”，读出用户名，视障用户就能选出来。

但是，如果遇到不能读屏的场景怎么办？比如，输入密码。这是个比较棘手的问题，有的软件为了安全，不会把密码键盘的读取权限放开；就算放开了，把密码读出来也会有泄露风险。前不久，支付宝就为视障用户推出了一种叫“划一划”的密码输入功能，用户提前录入一个一笔连成的图形，输密码时只需要划下这个图形就可以了，软件会根据轨迹和触屏习惯来判断真假。

当然，  *功能性只是无障碍改造的第一步。对无障碍改造更高的要求，是照顾到用户的心理感受。* 比如，一个页面正在加载，普通用户会看到那个不停转动的圈圈，你知道等一会儿就行了。然而，对于视障用户来说，这个过程相当于没有反馈，他们不知道发生了什么，心里会很慌。有没有可能，加载的时候添加一个等待提示音，尽量消除未知和等待带来的不安全感。

像这样的细节还有很多，要做到这一点，需要开发者有更多的“同理心”。此外，现在有了一种新职业，信息无障碍体验测评师。视障群体可以担任这个工作，直接参与到互联网产品的测试中，帮助开发者把好无障碍的关。

如今，  *“互联网不能落下任何一个人”，已经成为全社会的共识。科技发展的最高目标，是让每个人更平等、更有尊严地生活。*

今天的第二条，我们来关注宠物经济。

先上一组数据，你感受一下最近宠物经济有多火。根据艾媒咨询的数据，2020年中国宠物经济产业规模达2953亿元，同比增长33.5%；2015-2020年复合增长率为20.2%，预计2021年市场规模将达4000亿元，到2023年或将接近6000亿元。参考一个数据：2020年全国日用品零售额为6500亿元，相当于宠物经济这条赛道可以与整个日用品市场体量相当，这个想象空间太大了。

但是我想提醒你注意，虽然宠物经济正在风口，并不意味着开一家宠物店就很容易。这儿有一个数据，2018年全国新开宠物店超过8000家，但关店数量超过5000家，宠物店的淘汰率高得吓人。假如我是一名新手创业者，有50万资金，想开一家宠物店，怎么才能提高门店的存活率？连锁宠物店新零售负责人张瑞，写了一篇 [得到锦囊]({"typeid":"igetapp://question/detail?questionId=117594","type":99999}) ，介绍他的经验。

第一，宠物店的收入来源主要有三个。在扣除人力成本之后，利润最高的是宠物活体销售，其次是宠物用品销售，利润最低的是宠物服务，也就是给宠物洗澡、美容之类。卖出一条3000元左右的狗，利润相当于给100条小型犬洗澡。

第二，连锁宠物店的打法，一般是靠宠物服务来吸引客流，甚至是亏本获客，因为它们有资本加持。但是，如果个体经营者也跟着这么做，很容易熬不到开始赚钱的时候就倒闭了。更何况，做宠物服务对经营管理的要求比较高，新手很难做好。所以，  *创业新手要以宠物活体销售为主。*

第三，  *宠物活体销售，最重要的不是品牌和服务，而是门店选址。* 虽然资金有限，但门店一定不要开在社区里，哪怕是高档社区也不行。对宠物活体销售来说，人员的流动性差，购买力就非常有限。宁可店铺面积小一点，也一定要开在“90后”女孩爱聚集的商圈，因为现在购买宠物的主力军就是年轻单身女性。

第四，  *优先选择沿街店面，而不是大商超里的店铺。* 一方面，很多大商超对活体销售的要求非常严苛，有些甚至禁止售卖；另一方面，沿街店面更便于展示宠物，吸引顾客进店。

第五，如果有两处可选的沿街店面，该怎么选呢？  *最好的办法就是“数人头”* ：拿出一周的时间，按照你准备营业的时长，比如早上十点到晚上十点，站在街边数人头。用房租除以人数，就得到大概的“单客曝光成本”，成本越低的就越好。

第六，宠物店想要达到收支平衡，一般要4~6个月时间。要是超过这个时间还不能盈利，建议及时止损。

看完张瑞老师的锦囊，我有一个强烈的感受，  *就是不管是创业，还是开展一项新业务，在动手之前多找行业内的前辈高手问问情况，不但可以少走弯路，而且可能直接决定了成败。* 你还可以点击文稿中的链接，查看 [锦囊原文]({"typeid":"igetapp://question/detail?questionId=117594","type":99999}) 。

来看今天第三条。

最近，一家市场调研机构发布了2021年第二季度全球智能手表市场份额报告，品牌份额前四名依次是：苹果 28%；华为 9.2%；三星7.6%；小天才（imoo）6%。你可能会疑惑，苹果、华为、三星不用说，第四名的“小天才”是啥？

当然，如果你是小学生家长，就不会觉得奇怪，由步步高出品的小天才，是儿童智能手表领域的行业龙头，最高时曾占国内50%的市场份额。蔡钰老师在 [《商业参考》](igetapp://class/article?courseArticleId=94282&ddurlMinVer=5.2.0) 里讲过小天才：“小学生戴的智能手表分两种，一种叫小天才，另一种叫其他。”

为什么小天才这么牛？最重要的一点可能是，  *小天才是第一个做儿童社交的智能手表厂商。* 儿童智能手表是从2013年出现的，但早期手表的设计，都是站在家长的角度考虑，如何联系孩子，如何追踪定位，等等。

直到2015年小天才手表腾空出世。小天才是“蹲下来做产品”，从孩子的角度出发设计产品。孩子有社交需求吗？肯定有。但是，家长一般不愿意让孩子用手机，智能手表就成了孩子社交需求的最佳载体。小天才内置“微聊”作为社交工具，两块手表轻轻一碰，就能实现交友和聊天，一下子俘获了孩子的心。

有人说，小天才卖的不是手表，而是孩子们的社交门票。因为小天才是一个类似于苹果的封闭系统，它只支持同品牌手表互相加好友。当一个班大部分同学都在用小天才，你不用就会被孤立，被排除在同学的网络社交圈之外。所以，孩子会在购买什么品牌的手表上力争话语权，告诉家长“不是小天才的手表我不要”。

想想看，如果一代小学生都习惯用小天才的“微聊”，等他们长大后，会发生什么？网上流传一句话：未来打败微信的，很可能就是小天才的微聊。这就让微信很有危机感了。

我们注意到最新消息，就在8月底，微信推出了儿童手表版，可装在华为、米兔、读书郎、OPPO等品牌的儿童手表上，与手机微信互通。有人说，微信这招可能对小天才形成合围之势，毕竟对家长来说，用微信和孩子联系更方便。

这场“微信大战微聊”的走向目前还看不清，  *但这场战役的结果可能会揭示一个非常有意思的谜底，就是在中国家庭当中，到底是家长说了算，还是孩子说了算？*

至尊女宝：现在的大数据时代、信息化时代，在国内就能实现一部手机行天下，钱变成了存储在卡内或APP里的一串数字，但是正如老师说的八千万的残疾人，从公平竞争的角度来说，他们真的没有优势。

左星星：宠物经济，也被称为「孤独经济」。根据马斯洛需求理论，吃饭喝水这样的生理需求，或者是买车买房这种安全感需求，都能通过消费来解决。而随着社会的发展，在马斯洛需求层次中的第三层，爱与归属感的需求，也能通过消费来解决了。年轻人养宠物，其实就是在消费中解决对爱和归属感的需求。
 
年轻人对于爱和归属感有如此强烈的需求的一个很直观的原因是，现在年轻人的结婚率在不断地下降。年轻人中的多数都在外地工作，远离家人，饲养宠物就成了他们应对孤独感的重要手段。
 
而宠物公司也刻意的在打造这个行业，比如不少宠物公司为了让自己的产品在市场当中能脱颖而出，着重增加了产品的情感属性。
 
例如宠物零食花样繁多，要说宠物需不需要这些东西？其实可能不需要。但是它们能给宠物的主人提供一种和宠物互动的方式，这就增加了零食的情感属性。
 
另外还有宠物医疗，基本上和人类已经没什么区别了，能给人做的手术，在宠物身上都可以做。
 
宠物经济的背后，服务的对象并不是宠物本身，而是在宠物身上投射了大量情感的人。

儿童是一个怎么样的特定群体？ 
抛开儿童心理学上的细分，儿童的群体相对简单。 
会说，会听，会动（非电子产品上） 
不全会读，不全会写，不全会操作（电子产品上） 
行为不知轻重。 
群体细分没有成年人复杂。 

所以，总结起来，这就需要做好三个重要「识别」。 
识别出「儿童」。 
识别出「不可以给他们用的」，并设法阻止或引导。 
识别出「可以给他们用的，且他们喜欢的」，并设法加强。
