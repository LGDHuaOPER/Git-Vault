# 873｜“野心”，正在成为这个时代的稀缺资源

精挑细淘，得到头条。我是李南南。 

不知道你注意到没有，这个春天，很多科技公司都在集中“发大愿”。没错，大愿。

有多大呢？比如，黄仁勋说，英伟达要在2027年底创造1万亿美元收入，这几乎意味着要在两年内，再造两个英伟达。马斯克说，2026年要量产1万台人形机器人，还要往火星发射5艘星舰。OpenAI计划2026年融资1000亿美元。

有人可能会说，这不是科技公司的一贯作风吗？一上来就设定个“超大目标”，一来能自我激励，二来也能提振员工和投资人的士气。说好听点叫“志存高远”，说难听点叫“画大饼”。

但是最近，我正好看了一本书，创业教练丹·沙利文写的 [《为什么10倍增长比2倍更容易？》](igetapp://ebook/detail?ddurlMinVer=5.2.0&ebookId=164128) 。我发现，这个现象还有另外一个理解角度。这个思考角度不仅适用于企业经营，也适用于个人，尤其是在AI崛起的今天，就更值得说说。

*丹·沙利文的主张可以用一句话概括，叫，比起制定“十拿九稳”的小目标，制定“看起来很难”的超大目标，是更明智的选择。*

乍一听，这好像有点奇怪。毕竟，很多观点都告诉你，人最宝贵的德行就是对自己有点数，有多大饭量用多大碗。比如长辈会跟你说：“你要根据自己的实际情况设定目标，不要好高骛远。”做项目的时候，同事会说：“咱们就是个小团队，别想那些大公司才能做的事。”

确实，在过去很长一段时间里，这个逻辑是对的。因为你的能力、资源、人脉，基本上决定了你能做什么。

但在AI崛起的今天，这个逻辑正在受到冲击。

为什么？ 首先，AI正在压缩“小目标”的生存空间。

你想想，过去我们设定目标，通常是这样的：我要把这件事做到70分、80分，在行业里算是中上水平，就能有不错的收入和发展。但现在，AI出现了，它能把很多工作做到70分。比如写文案、做设计、写代码，AI都能做到中等水平，而且成本要比真人低得多。

这也许意味着，市场对“70分水平”的需求未来会快速坍塌。不是说这个水平不好，而是说当AI能做到这个水平的时候，企业为什么还要花更多的钱雇人呢？

你看，自从2026年开年以来，科技行业裁员就特别猛。比如，支付金融领域的巨头Block，一次性裁掉40%的员工，Meta裁了1.6万人。Block的CEO说：“不是公司没钱赚，而是AI能让小团队比以前的大组织干得更好。”

换句话说，  *那些“做得还不错”的小目标，那些“中等水平”的技能，正在失去市场价值。如果你的目标只是“做到70分”，那么你其实是在和AI竞争同一块蛋糕。*

但好消息是， AI在压缩“小目标”生存空间的同时，也在放大“大目标”的可能性。

过去你想做一件大事，需要一个团队。比如你想做一个App，需要产品经理、设计师、前端工程师等等，少说也得五六个人。但现在不一样了。就像扎克伯格说的：“过去需要多个团队协作的项目，如今仅需一名极具能力的人就能完成。”

这就带来一个很有意思的变化：过去限制你的是能力，未来限制你的或许是野心。

过去你会想：我不会设计，所以我做不了这个产品。我不会写代码，所以我做不了这个项目。但现在，AI能帮你补齐这些能力。关键是，你能不能定义清楚你要什么。

这也就是为什么说，AI时代更需要大目标。因为小目标让你陷入和AI的竞争，大目标会逼你做AI做不了的事，定义目标、判断价值、做最终决策。更重要的是，这个超大目标会倒逼你跳出原来的思考路径，跳出同质化的内卷，进而去思考你真正擅长的东西。

你看，假如你的目标只是增长20%、30%，你会怎么做？无非是在原来的基础上多加一点班、多开几次会、多做一点优化。方法还是旧方法，路径还是旧路径，区别只是更辛苦一点。

但如果你的目标突然变成原来的10倍，那么原来的那套东西立刻就不够用了。你必须重新思考：到底哪件事最关键？哪些业务根本不该做？哪些机会看起来不错，其实是在分散注意力？我自己到底有什么别人都不具备的优势？

换句话说，  *2倍目标让你在旧框架里找答案，修修补补；10倍目标让旧框架根本撑不住，你被迫从头想起，反而更容易找到真正有效的路径。*

比如，英伟达的CEO黄仁勋有个理论，叫“零亿美元市场”。什么意思呢？要么零，要么亿。除非不成功，成功了就是数以亿计的回报。换句话说，就是要去追那些现在看起来不存在、规模为零，但未来可能是数以亿计的大市场。

黄仁勋的原话是：“没有客户的地方，也就没有竞争对手。所以我们选择一个没有客户的市场，一个零亿美元市场。”因为之前的经验告诉黄仁勋，每次他们在现有市场做出一个成功的产品，一年后就会被AMD、英特尔、高通这些巨头踢出市场。这几乎是按年为单位发生的。你想想，你辛辛苦苦做出一个产品，刚有点起色，巨头就进来了，用更多的资源、更低的价格把你挤出去。这种感觉有多绝望。

所以黄仁勋想明白了：  *既然在现有市场竞争不过巨头，那就去一个巨头还没注意到的地方。*

比如，2006年，英伟达推出CUDA架构。这是一个让GPU不仅能做图形处理，还能做通用计算的技术。当时市场的普遍反应是：这有什么用？华尔街当时给CUDA的估值是零。英伟达的股价在一年内暴跌了80%。

但黄仁勋每年投入5亿美元研发CUDA，相当于公司营收的六分之一。这个投入持续了10年。10年里，CUDA几乎没有带来任何收入。但2012年，转折来了。多伦多大学的两个学生用英伟达的显卡训练了一个叫AlexNet的神经网络，在图像识别比赛中以84.7%的准确率横扫对手，第二名只有26.2%。关键是，他们只用了6张英伟达的显卡，而谷歌用了16000颗CPU和1000台计算机。

这一刻，神经网络算法的时代大门被推开了。而英伟达，因为10年前押注了一个“零亿美元市场”，成了这个时代最大的赢家。

你看，如果英伟达的目标只是“把显卡做得更好一点”，那就是一个普通目标。但黄仁勋的目标是“创造一个新市场”，这是一个超大目标。这两个目标，调用的是完全不同的思维方式。普通目标让你在现有市场里和巨头竞争，超大目标逼你去一个巨头还没注意到的地方。

况且，  *假如你有个100分的目标，即使失败了，或许也能获得一堆80分的副产品。但如果你的目标只是70分，即使成功了，也只是70分。*

你看黄仁勋押注CUDA，假如AI时代没有到来，CUDA会不会白费？不会。因为在这10年里，英伟达积累了大量的技术专利、工程经验、人才团队。这些东西，即使CUDA失败，也能用在其他地方。

说到这，你可能会问：道理我都懂了，但具体应该怎么做呢？

在这里，丹·沙利文有三个建议。

*第一个，找到你的20%。*

比如，拿出一张纸，把你现在正在做的所有事情列出来。工作上的项目、日常的任务、业余的学习，全部列出来。然后问自己一个问题：如果我只能保留其中20%，我会保留哪些？这个问题会逼我们做选择。你也许会发现，很多事情你以为很重要，但真要砍掉的时候，其实也没那么重要。而那些你真正舍不得砍的，才是创造价值的核心。

找到这20%之后，接下来要做的，不是把剩下80%也做好，而是想办法把这80%外包出去、自动化掉，或者干脆不做。

*第二个建议，给自己的时间“分级”。可以把它分成，专注日、缓冲日和自由日。*

专注日，就是集中心力做那最重要的20%，全力输出。缓冲日，是为专注日做准备，处理团队协调、行政这类事务。自由日，彻底从工作中脱离，恢复精力。这三种时间不是三个独立建议，而是一个系统。自由日恢复精力，缓冲日做好准备，专注日才能全力输出。

而大多数人的状态是，一年365天都是混合日。随时可以工作，随时被打断，随时处理各种事。看起来很勤奋，但专注日从来没有真正专注过，自由日也从来没有真正放松过。

*第三个建议，每次有人找你做一件事，或者你自己想启动一个项目，先停一秒，问自己两个问题：*

第一，这件事和我的大目标有关系吗？

第二，有没有人比我更适合做这件事？

如果两个问题的答案都是否定的，那么按照丹·沙利文的标准，它大概率不该在你的清单上。这不是说你在偷懒，而是说你在做经济学意义上的理性选择。

最后，还有很重要的一点，野心和冲动不一样。  *冲动从情绪开始，而我们今天说的野心，是从“思考”开始。即使暂时不行动，对超大目标的思考，或许也能帮助我们更好地审视自己的规划。*

就像拉里·佩奇说的，“把目标设成10倍，其实并不比10%难多少。因为10%的目标，你会下意识地在旧框架里找答案；但10倍的目标，旧框架根本撑不住，你被迫从头想起。”

关于这个话题，咱们先说到这。假如你想了解更多这方面的思考，可以读读丹·沙利文的 [《为什么10倍增长比2倍更容易？》](igetapp://ebook/detail?ddurlMinVer=5.2.0&ebookId=164128) 。这本书在得到就有电子书。

## 划重点

1.AI时代，那些“做得还不错”的小目标以及“中等水平”的技能，正在失去市场价值。
2.2倍目标让你在旧框架里找答案，修修补补；10倍目标让旧框架根本撑不住，你被迫从头想起，反而更容易找到真正有效的路径。
3.关于野心这件事，丹·沙利文有三个建议：第一，找到你的20%；第二，给自己的时间“分级”；第三，决定做一件事之前，先问自己两个问题，这件事和我的大目标有关系吗？有没有人比我更适合做这件事？

目标太小，路径就只能在旧框架里打转；
目标足够大，反而会逼着你重新思考——
什么才是最重要的？
什么该舍弃？
什么才是自己真正不可替代的地方？
所以，所谓“野心”，未必是浮躁，也未必是空喊口号。
真正有价值的野心，是一种更高维度的自我要求：
不再满足于优化旧答案，而是逼自己去寻找新问题。
