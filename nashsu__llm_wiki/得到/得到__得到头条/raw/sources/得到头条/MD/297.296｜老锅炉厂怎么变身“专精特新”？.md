# 296｜老锅炉厂怎么变身“专精特新”？

这里是《得到头条》，我是徐玲。

今天我们从两个话题出发，为你提供知识服务。一是欧盟扩大生物甲烷生产，二是生鲜电商“每日优鲜”陷入经营困境。

来看今天的第一条。今年上半年，受俄乌冲突影响，欧洲天然气价格一路暴涨，出现严重的能源短缺。目前，欧盟正在寻求替代能源解决方案，准备投入830亿欧元，把生物甲烷的产量提高一倍。

生物甲烷，也就是通常说的“沼气”，把粪便、谷壳、麦秆等各种农业废料经过一系列发酵分解并提纯，就能得到生物甲烷。生物甲烷可以替代天然气，并入天然气管网，直接通到居民家中。欧盟表示，到2030年，欧盟生物甲烷产量将增加10倍，相当于代替2021年进口俄罗斯天然气总量的1/5。有了欧盟的政策支持，现在欧洲各地正在加快建设沼气厂。

消息就是这样，来看看能学到什么知识。

欧洲是为了解决能源危机而不得不寻找替代能源方案；在国内，我们为了实现“双碳”目标，也在积极寻找新的能源替代方案。除了在发电领域，用清洁能源替代传统化石能源，另外有一个难题需要攻克，就是在工业领域，用更环保的锅炉替代传统燃煤工业锅炉。

我国拥有世界上最多的燃煤工业锅炉，2012年巅峰时，保有量超过50万台，每年消耗标准煤4亿吨，占全国煤炭消耗总量的1/4。燃煤锅炉运行能效低、污染严重。国家从2014年开始，禁止新建小型燃煤锅炉，并且逐步取缔市场上的小型燃煤锅炉。

那么，原来生产小型燃煤锅炉的那些企业，该怎么办？要么等着被淘汰，要么主动转型。正好得到口才营有一名淋淋同学，她就来自一家成功转型的锅炉企业，他们企业在去年还入选了国家“专精特新”小巨人。我们专门找她聊了聊他们企业的故事。

她所在的企业，是位于哈尔滨的哈东新春锅炉，有30多年历史，原来专门生产35吨以下的小型燃煤锅炉。前面说了，国家从2014年禁止新建小型燃煤锅炉，新春锅炉在那之前就已经在规划产品转型。

第一步，选择方向，也就是决定接下来要做什么样的产品。不生产小型燃煤锅炉了，那生产什么？

当时面临两种选择：一是相对容易的转型，就是从生产小型燃煤锅炉，转为大型燃煤锅炉，或者燃烧清洁煤粉的锅炉，它们的工业效能比小型燃煤锅炉要高，对新春锅炉来说，技术研发的难度也不大。二是比较困难的转型，从传统燃煤锅炉直接变成以燃烧稻壳、秸秆为主的生物质锅炉。这是一个完全不同的系统，需要从头做技术研发，而且市场前景不明确。

想想看，如果你是新春锅炉的负责人，你会怎么选？最终，新春锅炉选择了困难的那条路，他们决定生产以秸秆为燃料的小型生物质锅炉。

新春锅炉位于农业大省黑龙江，黑龙江每年产生的秸秆占全国的八分之一。过去，秸秆都是就地烧掉，会造成严重的空气污染，黑龙江连续多年出台了禁烧政策，从重点区域禁烧，到全面禁烧，到出台惩罚制度，秸秆的处理成为一个大的环保难题。

但其实，如果秸秆经过专业加工，在清洁炉具内燃烧，就可以大幅减少有害物质排放，并且秸秆焚烧处理后还可转化为氮、钾肥等有机肥料，从全产业链来看，几乎可以实现零碳排放。所以，新春锅炉因地制宜，选择了生物质锅炉这个方向。

接下来要考虑的，是怎样制造出能效合格的产品。这就来到了转型的第二步，研发产品。

生物质锅炉的本质，是通过燃烧生物质燃料，产生高压蒸汽，再转化为工业生产的动力。它要和市场上的燃气锅炉、电锅炉等对手竞争，要想突围，必须提高燃烧效率，实现用能的高性价比。  *客户最终是为锅炉的高性价比买单，而不仅仅是环保概念。*

新春锅炉投入了大量精力去做技术研发，和哈工大等高校合作，成立了黑龙江生物质锅炉研究中心。首先，从锅炉本身出发，用技术解决了一系列燃烧排放问题，比如不完全燃烧、脱硫、脱碳、除尘等等。接着，是在燃料端提效，原始的秸秆必须要压制成成型燃料颗粒才能燃烧，新春锅炉设计了玉米秸秆、大豆秸秆、稻壳、花生壳等十几种生物质的压制标准，包括原料的水分、颗粒的规格等等，最终比同类产品的性价比提升了10%以上，与燃烧天然气相比，成本下降60%。

更厉害的是，新春锅炉还给锅炉设计了数字化控制系统，产品在使用时可以实时监测各项技术指标，比如燃料数据采集、燃烧效率测算、蒸汽压力采集等等，实现锅炉的透明化使用，并且可以以天为单位调整燃烧计划。这样一来，生物质锅炉就可以实现比天然气更低的成本、更高的能效。

好，有了产品优势，接下来，新春锅炉还面临进入市场的问题。锅炉是特种工业设备，不是随随便便就能安装的，又事关生产大事，客户替换掉老设备的成本很高。怎么降低客户的替换成本？这是新春锅炉转型的第三步，商业模式的创新。

具体来说，如果客户愿意购买锅炉，那么新春锅炉给你提供使用锅炉的一条龙服务：从前端的秸秆燃料供应，到锅炉定制，再到后面锅炉投入生产后的运维，都有解决方案。如果客户一时半会儿还下不了决心买锅炉，也没关系，新春锅炉把自己的业务拆分成了8个标准化模块，客户可以不买锅炉，而单独购买其中的一两个服务模块。

这8个标准化模块包括：秸秆原料回收、成型燃料制作、锅炉主机、锅炉辅机、设备运维、设备检修、设备维护改造、共建投资项目。这样一来，比起单纯销售锅炉，用户群体有机会大大拓展。对于已经拥有生物质锅炉的客户，可以只选前面两个燃料模块；还在使用其他类型锅炉的客户，也可以选择购买专业的运维模块。

新春锅炉还建立了十几个全套的标准化示范应用场景，用户可以对照应用场景来选择模块组合。可以说，  *新春锅炉把传统的锅炉行业，做成了类似SaaS的订阅制服务。对于那些只选购了某一两个模块的用户，只要把它们服务好了，它们迟早会成为新春锅炉的大客户。*

2021年，新春锅炉实现了1.53亿元的收入，在东北、西北的各农业大省占据了50%的市场份额。这家拥有30多年历史的老锅炉企业，画出了一条漂亮的第二曲线。

来看今天的第二条。 

最近，有“生鲜电商第一股”之称的每日优鲜接连传出负面消息。先是主营业务“30分钟极速达”服务关闭，然后又传出公司的资金链断裂，准备原地解散或者重组。对于网络传言，每日优鲜回应说，公司截至目前没有发布任何公告，网络流传的《关于每日优鲜资金断链无法经营的通知》是假的。从股价看，每日优鲜从一年前的5美元左右跌到现在只有0.1美元，总市值从20多亿美元跌到了现在的2300多万美元，只剩下原来市值的1%。

消息就是这样，来看看能学到什么知识。

每日优鲜的直接困境在于资金链。从今年年初开始，就陆续有供应商爆料被每日优鲜拖欠货款和押金。按说，现在每日优鲜的市值真的是白菜价了，才2300万美元，合人民币1个多亿。哪个大佬随便掏出一两个亿来，就能把这家头部生鲜电商收入囊中，怎么看怎么划算。有报道说，每日优鲜的创始人徐正也一直在试图寻找买家。

问题是，为什么没有一个大佬愿意来捡这个漏呢？除了资金链问题，每日优鲜还面临一个深层问题，就是活跃用户数在不断流失，这不是靠砸钱就能解决的。根据易观千帆的数据，今年4月份，每日优鲜的月活用户还有1357万，而到了6月份，月活用户就骤降为807万，退回到了2020年的平均水平。活跃用户数骤降，这才是每日优鲜最致命的问题。

今天我们不去分析每日优鲜的具体困境，而是想强调，对任何互联网平台，用户活跃度都是一项核心指标。通常我们是看日活数和月活数，另外，硅谷用户增长大神Andrew Chen还提出了一个“超级用户曲线”（Power User Curve），据说很多硅谷公司都用这个指标来检查自己的用户活跃度情况。

![https://piccdn.umiwi.com/uploader/image/ddarticle/2022080220/1781813167886776304/080220.jpeg](https://piccdn.umiwi.com/uploader/image/ddarticle/2022080220/1781813167886776304/080220.jpeg "图片来自《硅谷增长的新指标——超级用户微笑曲线》")

我在文稿里放了一张某个社交产品的“超级用户曲线”图，你可以看一下。先看这幅图的左边，在所有月活用户当中，一个月只上线1天的用户占17%，上线2天的用户占10%，上线3天的用户占7%，比例逐渐减少。再来看这幅图的右边，一个月上线29天的用户占3%，而一个月上线30天，也就是天天都来的超级用户，占7%。

看上去，这个超级用户曲线是一个向左倾斜的微笑，每个月只上线一两天的用户居多，同时有一群稳定的超级用户会每天都来。一般来说，社交平台的超级用户曲线都是这样的微笑形状，大部分人偶尔来，一小部分人每天来。内容创作平台也是一样，比如在B站所有的UP主里面，大部分人偶尔发内容，小部分勤奋的UP主会每天发内容。

提升用户活跃度，不是简单去拉升日活、月活，而是改善这个超级用户曲线，把它从一个向左倾斜的微笑，变成一个向右倾斜的微笑，让每天都来的超级用户在全部月活用户数里的占比越来越高。就像脸书的超级用户曲线，是一个非常向右倾斜的微笑，它的最后一格，也就是每天都来的用户占了全部月活用户数的60%以上。当然，如果你做的是SaaS产品，是和工作相关的，那么你的超级用户曲线不应该是以月为单位，而是以周为单位，改善一周之内的微笑形状。

为什么改善微笑曲线很重要？有人说过，  *企业获得盈利性增长的唯一途径，就是拥有一批忠诚用户，并且把他们变成自己的超级推销员。*

来说说咱们得到的事儿。 

今天，得到电子书独家首发了一本新书《 [软瘾](igetapp://ebook/detail?ddurlMinVer=5.2.0&ebookId=73078) 》，柔软的软，上瘾的瘾。软瘾是指在不经意间反复出现的行为和情绪，像是无聊地刷几个小时手机，在工作中控制不住地走神，在购物网站买买买停不下来等等，这些都是软瘾。看似没有太大危害，但是日积月累，会逐渐榨干你的时间、精力和财力。

怎么戒除软瘾呢？书里提供了很多实用方法，有一个方法很有意思，就是给软瘾写封绝交信。把软瘾当成你的前男友或者前女友，赞美和肯定它的积极作用，客观地描述它的负面影响，最后，对它说再见。用这种仪式感，帮自己理清软瘾的影响，切断跟它的心理联系。

比如说，有人特别爱不分场合地走神、做白日梦，就可以给白日梦写一封绝交信：“亲爱的白日梦：你好。和你在一起我很开心。小时候我受了欺负，是你让我暂时忘记烦恼，可以想象自己又高又壮，痛打那些追我的恶霸。然而渐渐地，我滥用了你。我不是用你来放飞想象，而是用你来麻痹意识。你耽误了我做家务、完成工作以及开展正常的社交生活。我为你付出了很高的代价，我现在得离开了。再见。”

写完信后，需要把信件粉碎，边粉碎边想象正在释放自己的软瘾，然后把碎片埋起来。听起来，这是一个很有美感的行为艺术。如果你也被软瘾困扰，想对它做一次彻底的剖析，并且收获克服软瘾的方法，推荐你亲自来阅读《 [软瘾](igetapp://ebook/detail?ddurlMinVer=5.2.0&ebookId=73078) 》这本书。

左星星：超级用户是这么一群人，和普通用户相比，他们极度热爱某一产品，对这类产品的使用率极高，有的甚至到了痴迷的地步。他们通常具有如下特征：

1.	不仅愿意在某类产品上花大价钱，还对开发产品新用法有强烈兴趣，并且行动力很强；

2.	不仅花钱购买产品，还对产品投入感情，他们能从产品中获得更多的意义；

3.	他们的识别度很高，大数据以及社交媒体就能帮你找到他们；

4.	他们愿意买更多的产品，甚至可以招来其他购买者。

如今越来越多掌握时间、资源和场景的人，实际已经成为各个企业的“超级用户”。三四线城市的宝妈，是母婴行业的“超级用户”，便利店老板是生鲜行业的“超级用户”，医生是健康消费行业的“超级用户”，门店个体创业者是连锁加盟的“超级用户”。

如何才能获得、接触和利用超级用户？有一些建议：

第一，从数据中找，比如可以使用公司已有的客户数据、销售数据等等，例如，得到知识城邦每天坚持课程留言写笔记的，就是超级用户；新课上线就买的，也是超级用户；

第二，绝不能轻视客户，而要随时了解他们的需求，要建立和超级用户定期沟通的渠道；

第三，倾听之后有反馈，要尊重超级用户的意见，感谢他们的反馈，并且有行动；

第四，和超级用户建立利益共同体，期待超级用户引流，公司和超级用户获得共赢。

芊阅：我的软瘾是深夜吃东西。白天比较理智，都控制得挺好的，饮食也很健康，但到了晚上意志崩溃，明知这种习惯不好依然很难改变。

大多数的胖子都有深夜吃东西的习惯，这是由于白天需要做的事情很多，工作生活中的一些事情会分散我们的注意力，但是到了深夜，对于胃口好的人来说，简直就是折磨，控制不了自己的食欲又胖在肥胖的路上越走越远，内心很是煎熬。

那么，如何对抗掌握深夜吃东西的软瘾？自己总结有：

1、早餐宜高蛋白
早餐要以高蛋白为主，这是因为高蛋白的早餐不仅能够满足我们身体所需营养，而且会抑制白天的饮食欲望，所以，早餐喝杯牛奶、吃个鸡蛋，使人一整天都不会去想零食，能够有效控制深夜吃东西的想法。

2、白天要吃好
很多减肥的人都不敢多吃，所以不管是何时何地，身体总是处于饥饿状态，在夜里这种感觉会更加明显，所以白天要吃好，大脑神经得到满足之后，自然会控制晚上的食欲，而且白天相对运动较多，相比晚上吃多，白天吃好晚上吃少能够更好的起到减肥的作用。

3、晚上要认真审视自己
在每天晚上要认真审视自己一遍，白天都吃了什么，吃了多少，是否补充了足够的蔬菜水果，如果不够，就需要多吃一些蔬菜水果，然后再告诉自己深夜吃东西有多少害处，想清楚之后，然后尽快去睡觉，这样对控制深夜食欲也有不错的效果。

国家环保制度层面要求各个企业需积极组织制定、实施高效节能环保工业锅炉整体产业化方案，与此同时，还需建立相应的阶段工作进展情况性总结和全流程的监督制度。应鼓励各类科研单位及社会团体对工业锅炉数字化以及节能减排的技术研发和装备制造。其他各级职能部门对相关项目建立协作联动机制，区域内形成整体效应，政企联动合力推广，加强工业锅炉高效节能低排的宣传教育，在社会上形成节能减排氛围，提高我国全民环保意识。
2、努力提升监测效率
以提升智能监测的准确度、稳定性为目标，对所使用的传感器提出更高要求。不仅实现对工业锅炉的六大系统运行情况进行实时监测，而且保障所获取数据的准确性和有效性，从而形成相关数据库。随着智能制造的发展，还可以运用大数据、云端存储等技术融合对相关运行数据经网络上传至相关平台，实现设备监控和故障远程诊断。
3、实现数据智能处理
根据日常对数据采集形成规模性的数据库，进而对相关数据进行智能化分析，当出现实时运行数据异常时，可马上通过智能硬件停机停炉，这种保护对事故预防有着重大意义。另一方面，就算万一锅炉保护系统失效不幸发生事故，技术人员还可以根据云端保存的历史数据，对锅炉事故发生原因进行研判，有效警惕此类事故的再次发生。
4、不断优化数字化系统，提高系统适应性
只有不断优化系统功能，才能使数字化真正保障工业锅炉运行节能、环保和安全。实时监测锅炉的运行数据并分析其性能，需采取相应的优化措施。此外，还应建立相应的数学模型，分析锅炉排烟、温度、耗能情况及其他影响因素，对分析锅炉的运行情况进行整体评估，才能够更有效地对数字化系统进行优化，达到进一步优化设备和系统运行的目的。

新式核芯：今日得到：
1、从我的认知中，锅炉真的不是什么高精尖产业，无非就是转化能量，无论是烧什么，或者用电，整个机理好像没有那么复杂，但很早就又听说，好几个大学都有锅炉专业，而且还全国知名，当年也是觉得很神奇。今天通过徐老师的介绍，感觉开了眼界。对于锅炉的转型或者是产业升级，我认为和大部分行业都类似。
	首先，从转型的痛点或者限制点入手，对于锅炉，就是烧什么的问题，新春锅炉在这个问题上可以说是借用了地利人和之便，他在煤炭被限制的时候，看到了农作物的次生产物，同时国家又不允许自行焚烧秸秆，那生产生物质锅炉就是多方受益的事情，有了很好的基础。同时也解决了原料来源的问题，但是这种方式在农业不够发达的地方可能难以复制；
	其次，解决产品性能的问题，锅炉的核心指标应该就是燃烧效率和清洁程度，所以提升关键指标，不因原料的变化而带来性能下降，这个很关键。核心竞争力还是要打造好；同时借助数字化提升自身效率和产品效率。
	再次，就是商业模式的问题。这点上新春锅炉确实创新度非常大，把锅炉行业服务化，这点从互联网人看好像没有什么。但是对于传统行业有这样的转型好像不那么容易，所以跨行业的商业模式的借鉴也是商业模式创新的一个来源。
2、互联网平台的用户曲线第一次看到，按照原来我的直观概念，应该是一个不断衰减的单边曲线，但是没有想到竟然是个微笑曲线，学习到了。
