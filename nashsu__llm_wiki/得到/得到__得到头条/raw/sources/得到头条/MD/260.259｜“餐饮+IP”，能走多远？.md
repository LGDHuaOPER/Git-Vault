# 259｜“餐饮+IP”，能走多远？

这里是《得到头条》，我是徐玲。

今天我们从两个话题出发，为你提供知识服务。一是红餐网发布2022餐饮调查报告，二是今年高考以围棋术语为作文题目。

先来看今天的第一条。最近，红餐网发布《2022年疫情背景下餐饮企业调研报告》。我们知道，疫情之下，最先受到冲击的就是餐饮行业。这份报告显示，2022年4月，餐饮行业收入同比下降22.7%，创下了2020年5月份以来的最大降幅。有79.6%的受访企业表示它们的营收在减少，有68.5%的受访企业表示，目前的账面资金仅能维持近3个月的经营。

另外，在去年上半年，很多大型连锁餐企，像是百胜中国、海底捞、巴比食品、海伦司等等，采取了逆势扩张的策略，加快开店节奏。但没想到，疫情影响周期远远超出预期，很多新开的门店都在亏损，出现了快速扩张后又快速关店的情况。像海底捞、呷哺呷哺、海伦司等企业，2021年的利润都是负数。

最近，我听说很多餐馆都举行了“誓师大会”，憋足一口气，要打好这个夏天的开门红。

消息就是这样，来看看能学到什么知识。

我们发现，  *为了快速聚集人气，很多餐厅都在尝试一条新路，就是和知名IP结合，利用IP的内容和影响力来为餐厅引流。* 而且，餐饮跟IP结合的玩法，也在一步步升级。

*第一类，也是最容易想到的方式，就是跟明星IP结合。*

我们在第177期节目中聊过，前些年，除了麦当劳、肯德基这样的洋快餐外，国内餐饮企业基本上是不请明星打广告的。但是这些年情况发生变化，本土连锁餐厅也喜欢找明星代言了。比如，目前正在冲击IPO的“老乡鸡”找了知名相声演员岳云鹏做代言；半天妖青花椒烤鱼请了新生代明星张一山做代言；轻食品牌“新元素”请网球明星李娜做联名，等等。另外，明星用自己的IP亲自下场开餐厅的也不少。

不过，跟明星IP结合，只是解决了最开始的传播问题。  *餐饮业说到底拼的是服务和体验，明星IP在体验层面帮不上什么忙。* 就算我是冲着李娜来吃轻食的，但进店之后，我不太可能认为，“李娜联名款”意面吃起来更香。

那么，什么样的IP能让一碗面吃起来更香呢？  *这就要说到第二类玩法，跟故事IP结合。*

这种模式一开始是主题乐园在做。比如最知名的，环球影城里的哈利·波特餐厅，以及由电影《阿甘正传》授权的“阿甘虾餐厅”，这些主题餐厅的地点一般是在主题乐园内部，要专门去到乐园才能体验。而现在，有越来越多的主题餐厅落地城市商业区，比如在很多城市都有的宫崎骏动漫主题餐厅，以及去年英国伦敦开设了全球首家“蝙蝠侠”主题餐厅。

我注意到，除了这些国外大IP，国内的原创故事IP也开始落地自己的主题餐厅。比如国产原创动画《灵笼》在武汉光谷落地了首家主题餐厅，电视剧《陈情令》在上海田子坊落地了首家主题餐厅。

在这家餐厅的空间设计上，划分为“莲花坞”和“云深不知处”两大场景，这是两个主角生活的地方；餐厅里随处陈设着电视剧里的各种名场面和名道具，像乌篷船、冷泉、农家院、静室等；菜品研发上也还原了电视剧里出现过的菜，像莲藕排骨汤、天子笑、辣糯米粥、羡羡烤鱼等；餐厅服务员一律古风着装，并且称呼顾客为“仙首”，还会在上菜时对菜品进行故事解释，打造沉浸式的就餐体验。

餐厅对自己的目标消费群体很清楚，就是“电视剧粉+演员粉+CP粉”，餐厅的定价也相对高端，人均在150~200元。不过，我看到媒体对这家餐厅负责人的采访，他自己有一个担心：光靠《陈情令》的现有粉丝撑不起高频的高端消费，餐厅的未来发展需要靠《陈情令》IP的持续传播，而这不是餐厅自己能决定的。  *有可能，成于IP，也困于IP。*

那么，有没有一种IP形式，无论是不是粉丝，都能够接受呢？

*这就得说到餐饮IP化的第三类，跟美食纪录片IP结合。*

*用美食纪录片IP打造出的门店，既有IP的内容体验，又跟正常的门店氛围不违和，无论是不是粉丝都可以快速融入* ，餐厅客流就可以突破故事IP的粉丝局限。

比如，B站大火的纪录片《人生一串》，是一部以烧烤为主题的美食纪录片，创作团队拍摄了500多家传奇烧烤摊，讲述了市井中的烧烤风味。纪录片一播出就反响热烈，三季的累计播放量超过4亿，被誉为B站的镇站之宝。目前，《人生一串》已经授权开出了5家烧烤店，不仅仅是开业的时候人流拥挤，直到现在也是热度不减，长期占据大众点评的必吃榜和人气榜。

来到“人生一串”烧烤店，首先会看到满墙“西门烧烤”“高老庄特色烧烤”等片中出现过的美食门店招牌，一秒拉你回到《人生一串》的剧中。店里摆放着跟纪录片中一样的塑料桌椅，和用集装箱支起来的桌子。菜品设计上，店内几乎一比一还原了纪录片中最受欢迎的美食，如三里桥烤心管、百色爆浆烤猪眼、茄子温泉蛋……

在餐厅二楼，设置了游戏娱乐区、动漫文化展示区、英雄联盟世界赛观赛点等等。食客可以在这里看比赛，买周边，拍照片。这些设置让人生一串不仅仅是一家烧烤店，更是人气美食、潮流文化、圈层兴趣的集合体。消费者第一次来店里，或许是出于猎奇，但很容易被店内的氛围、特色的烧烤留住，成为这家店的常客。这家店也就能长久地经营下去。

你看，  *初阶的IP只能吸引流量，中阶的IP可以满足猎奇心，高阶的IP可以与门店融为一体，打造不腻烦的沉浸式体验。*

来看今天的第二条。

你可能听说了，今年的高考作文题之一，是以围棋术语“本手、妙手、俗手”为话题，写一篇文章。高考题的原文材料是这样的，我给你念一下：

“本手、妙手、俗手”是围棋的三个术语。本手是指合乎棋理的正规下法；妙手是指出人意料的精妙下法；俗手是指貌似合理，而从全局看通常会受损的下法。对于初学者而言，应该从本手开始，本手的功夫扎实了，棋力才会提高。一些初学者热衷于追求妙手，而忽视更为常用的本手。本手是基础，妙手是创造。一般来说，对本手理解深刻，才可能出现妙手；否则，难免下出俗手，水平也不易提升。

这道高考题公布以后，围棋界人士很兴奋，聂卫平发微博说：出题人通过我们专业的围棋术语来命题，他一定是懂围棋的，更是希望各位考生能通过我们的围棋术语有更深入的人生感受，所谓“人生如棋，棋如人生”。

消息就是这样，来看看能学到什么知识。

为什么初学者不可贪图“妙手”？为什么又说“棋如人生”？我不懂围棋，我特意去找了韩国围棋名将李昌镐的自传来读，还真找到了部分答案。

你知道，李昌镐曾经在十多年的时间里称霸世界棋坛，获得过18个世界冠军，是当代棋坛的顶级棋手。然而，业内公认，他的棋风一点也不凌厉霸气，而是以“拙”著称。李昌镐的好友、中国围棋名将常昊说，李昌镐的棋很“淡”，看上去略显吃亏、迟缓乃至笨拙；另一名围棋名将马晓春说，如果一手棋的效率满分是10分的话，那么李昌镐的棋，每一手最多只能打6到7分。

而这种棋风，是李昌镐的刻意为之。他在一次采访中说，  *自己从不刻意追求妙手，也从不追求一举击溃对手。* “我只要觉察到对局中有百分之一的可能，会被对方逆转，那么我就会放弃可能大比分赢下对方的棋路，转而耐心等待。”有一次，他的老师曹薰铉问他：为什么不走那一步“妙手”？李昌镐回答：“按我的走法，下一百盘保证赢一百盘，虽然都是以半目取胜。”的确， 在实战当中，李昌镐往往是前半盘落后，而后半盘反超，并且以半目取胜。

这是怎么做到的？还是常昊一语道破天机：“  *虽然内心充满了对胜利的渴望，但无论对手如何出招，是挑衅或是诱惑，李昌镐总能用强大的心理控制住自己的冲动，始终按照自己的思维和方针行棋，极少出错。* 如果局面有利，他会用最简洁、最稳妥的方法行棋，纵然对手攻击力超强，在他闪转腾挪、谨慎出击的行棋方式下，也很难有用武之地；如果局面不利，他也能够不急不躁，利用后半盘的精准计算蚕食对方。只要对手稍有失误，便会遭到他的致命一击。”

所以有人总结，  *“极品的妙手，就是看破妙手的诱惑后，落下的平凡一子。”*

李昌镐把这种棋风总结为“不得贪胜”，这也是他这本自传的书名。“不得贪胜”这四个字，来自中国古代典籍《围棋十诀》。据说《围棋十诀》对于围棋选手，就像“圣经十诫”对于基督徒一样重要。而《围棋十诀》中的第一条，也是统领其余九条的最高纲领，就是“不得贪胜”。意思是，越是对胜利存有贪念，越是得不到胜利。

可能原因在于，人在求胜心最强的时候，往往也是最不冷静的时候；对对方攻击最强的时候，往往也是自己防守最弱的时候；如果一击没得手，反而会给对方留下巨大破绽。这也是为什么李昌镐在对局中会尽量回避直接的“对杀”。他说，回避对杀不是因为害怕对杀，而是尽量减少由对杀带来的不可预见的失误。在围棋中，最后的胜利并不属于攻势最强悍的一方，而是失误最少的一方，减少失误即为成功。

*“虽不贪胜，胜利却更有可能如水到渠成般自然而来。”* 围棋如此，人生亦如此。

左星星：财务报表的附注为什么重要呢？因为它会告诉你数字背后的「故事」。

例如，企业会在报表附注你告诉你，它是按照什么规则编制的财务报表，这个规则就是会计政策，会计政策的变更，是可能增加企业的利润的，比如：

某公司买了一台机器花了100万元，预计能用5年，根据折旧常用的年限平均法（也叫直线法），每年的折旧费用是100/5=20万元，可购买设备之后，第一年业务做得不好，实在没法向投资人交代，于是他们就修改了会计政策，把折旧年限延长到了20年，这样一来，折旧费用就变成了100/20=5万元，利润平白无故就增加了15万元。

而这一切，都只会在财务报表附注里用很小很小的字告诉你。

此外，财务报表的附注还会包括：公司业务概要；经营情况讨论与分析；股份变动及股东情况；董事、监事、高级管理人员和员工情况等，企业的「秘密」，基本都藏在报表附注里了，所以，有经验的财务在分析报表之前，会先看附注，去了解数字背后的故事。
