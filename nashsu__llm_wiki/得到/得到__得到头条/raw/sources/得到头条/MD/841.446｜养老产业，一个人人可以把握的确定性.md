# 446｜养老产业，一个人人可以把握的确定性

精挑细淘，得到头条。我是李南南。 

今天，我们先说说来自养老产业的洞察，而且是养老产业中，难度最高的一个类别，针对阿尔茨海默患者的照护。

根据中国疾病预防控制中心的数据，从1990年到2021年，30年的时间里，中国阿尔茨海默的发病数量越来越高。1990年，每10万人里有59.8人发病。而到了2021年，每10万人里有204.8人发病。

对阿尔茨海默患者的照护，跟一般的养老还不太一样，难度要高得多。首先，阿尔茨海默患者可能有语言障碍，很难清楚地表达需求。其次，很多患者认知能力下降，可能会出现走失之类的情况。还有的人会出现抑郁和焦虑，或者攻击性行为。这就进一步增加了风险。

我们今天要讲的，就是针对这部分阿尔茨海默老人的照护。按照通常的想象，针对这部分老人的，应该是个加强版的养老院才对，有更严格的作息时间，更严谨的管理方式。

但是，我们团队前段时间去采访了一个很特别的养老机构，叫康语轩老年公寓。康语轩主要做的就是认知症老人的照护，其中有90%以上的老人都有不同程度的认知症。但是，他们号称是零卧床，没错，一个没有卧床老人的养老院。

康语轩的创始人叫金恩京，她在2016年创立了康语轩，这也是国内最早的，针对认知症老人的养老机构之一。康语轩的模式，早期借鉴的是瑞典的group home，也就是“教养院”模式，经过这几年的发展，逐渐有了自己的模式。借用金恩京的话说，康语轩就是把家里的三室一厅做得大一点，给老人做了个更大一点的家庭。他们的目标是，同时兼顾自由与安全。

但是，自由与安全，这两件事对于认知症老人来说，好像天然就有点矛盾。怎么同时保证呢？接下来，咱们就说说康语轩的三个核心设计。

*第一，不设边界。* 老人在康语轩自由到什么程度？说个真事儿，我们在采访金恩京老师的时候，其间还有老人走进办公室，跟着听了一会儿。后来可能觉得不感兴趣，就摆摆手走出去了。再比如，康语轩的员工会议，经常有老人在开会期间走进来，有的时候还会一起参与讨论。

再比如，整个养老院，除了最外面的大门有个密码锁，其他门都不上锁。老人可以在各个房间任意穿行，包括员工休息室和院长办公室。老人四处走动，熟悉了环境，自然就容易放松下来。

再比如，康语轩是没有作息时间表的。老人要是10点才起床，介护员就给他留一份早饭；要是夜里12点不睡觉，可以去书吧看书。

再比如，康语轩实行单元管理模式，一个生活单元，就像一个微型的社区。里面有卧室、书吧、客厅、餐厅、多功能厅等等。卧室普遍有落地窗，老人站在窗前就能看见蓝天、晒到太阳。

*康语轩的第二个设计叫做，最小化干预。也就是，能不干预的尽量不干预，尽可能不让老人觉得自己是病人。*

比如，大小便失禁是认知症老人的常见难题。一般的方法，就是给老人戴尿不湿。但这对老人的自尊心是一种伤害。还有研究表明，长期戴尿不湿会加速老人的认知能力衰退。因此，康语轩的员工会观察收集老人的生活规律，什么时候喝水、吃东西，多久需要去卫生间，然后定期带老人去上厕所。

在康语轩，一个生活单元，大概住20名老人，护理人员按照531配置。也就是，5名介护员，3名社工和康复理疗师，1名护士。这个配置的目的，就是确保有足够多的眼睛，去观察每一位老人。包括老人的小名是什么、他喜欢别人怎样称呼他、他的孙子的名字是什么，以及他最亲近的人是谁。这些信息康语轩的每个员工都得掌握。

再比如，跌倒问题。常见的处理方式是给老人提供一些辅助，比如装个扶手。但康语轩会逐个分析每位老人跌倒的原因，看看是下肢没有力量，还是服药引发的精神乏力，或者是血糖高引发的头晕，然后针对性地制定照护方案。

*康语轩的第三个设计是，把真实社会搬进养老院。* 要知道，认知症最麻烦的地方就在于，它会把一个老人和真实社会的关系一点点切断。与他人的交流会越来越少，自己能做的事也越来越少。

怎么办？  *既然老人远离外部社会，养老院就把外部社会搬进来，让老人尽可能体验真实的社会活动。*

比如，模拟购物。他们给老人发购物券，员工摆摊。老人可以像在外面逛街一样，在这里购物。这个活动的目的，一是让老人多做数学运算，二是锻炼日常沟通能力。

康语轩还有每月一次的跳蚤市场，请外面的人到公寓内摆摊。不仅家属可以随时过来探望，那些想来参观学习的人，进来也可以和老人打打招呼，聊上两句。公寓的一楼，还做成了对外营业的咖啡馆和酒吧，开放程度很高。

再比如，康语轩还会定期举办各式各样的活动，请外面的老师来，教老人画画、刺绣、做手工，这些作品还可以放在跳蚤市场上出售。

没错，听到这，你可能发现了，康语轩的设计，非常像一所学校。  *他们的照护方式，不像对待退化中的患者，更像对待成长中的孩子。借用金恩京老师自己的话说，认知症患者首先是一个大写的人，然后他患了小小的病，仅此而已。*

再来看今天的第二条。最近，有个穿衣风格很火，叫植物系穿搭。在小红书上，“植物系穿搭”的相关笔记，超过了17万篇。7月30日，小红书还在北京亮马河公园举办了“植物系穿搭趋势秀”。植物系穿搭，就是以棉麻、薄纱之类的面料为主，衣服普遍偏大，穿起来特别舒服。 

但是，跟这个趋势相对的，穿起来没有那么松弛舒服的牛仔裤，销量就一般了。比如，李维斯年初就宣布，要在全球范围内裁员10%到15%。日本牛仔裤的代表品牌福神，已经全面停止了在日本的生产线。更早之前的2020年，被称为“牛仔裤之王”的真维斯的澳洲公司就宣布破产。

牛仔裤为什么失宠了？有这么三方面的原因。

第一，不够舒服。去年，日本TBS电视台采访了涩谷的年轻人，很多人给出的理由就是，牛仔裤穿起来不舒服。这个苗头最开始出现，据说是疫情期间。根据美国商务部2020年的统计，疫情居家隔离期间，几乎所有类型的服装销量都下降，唯独运动服的销量上涨了。他们猜测，这或许是居家办公变得普遍，导致人们更注重衣服的舒适性。

第二，牛仔裤的生产成本偏高，导致它更容易受到市场波动影响。商家一旦发现销量不好，就索性不做。说白了，最容易被放弃的事，就是那些费力不讨好的事。就在今年4月，美国牛仔服品牌Lee还推出了首个男士高尔夫系列，干脆换了个赛道。

牛仔裤的生产成本有多高呢？2012年，德国人专门拍摄了一部纪录片，叫做《牛仔裤的代价》。这里面就提到，从棉田到棉布，再到洗衣机，一条牛仔裤需要消耗3480升水。什么概念？以成年人每天需要摄入2升水计算，一条牛仔裤用掉的水，够一个成年人喝5年。做旧效果的牛仔裤成本更高，为了打造出自然的做旧效果，染色全程大约会用到2500种化学物质，之后还要反复经过20多次脱水、打磨、漂白和重新上色。

显然，这么复杂的工艺，一旦销量不好，商家就更容易放弃。这就加速了牛仔裤的失宠过程。

第三个原因是，牛仔裤的时尚光环消退了。这是我在自媒体IC实验室上看到的一个解释。

你看，最开始李维斯发明牛仔裤，目的是给淘金工人提供一种耐磨耐穿的裤子。但是后来，随着好莱坞西部电影的流行和马龙·白兰度、猫王、玛丽莲·梦露等明星的代言，牛仔裤逐渐成了当时年轻人心中的时尚单品。

而现在，更年轻的一代人，在穿着上追求与上一代人不同。按照日本时尚评论家石原裕子的话说，以前的年轻人觉得牛仔裤很酷，但现在的年轻人经常追求更新事物，会觉得牛仔裤太普通太无聊。

说白了，  *就是对这届年轻人来说，牛仔裤不再时尚了。借用意大利著名设计师艾尔莎·夏帕瑞丽的话说，时尚的本质就是不同，因此时尚必须是颠覆性的。*

好，关于牛仔裤这个话题，咱们先说到这。

最后，总结一下，今天说了两个话题。

第一，怎样照护认知症老人？我们说了康语轩的设计思路。老年公寓的本质，是为老人提供一个大一点的家，还原他们的真实社会体验，而不是只提供简单的居所。

第二，牛仔裤为什么过时了？一来，牛仔裤的时尚光环正在消退。二来，人们越来越看重舒适性。三来，牛仔裤的制造工艺本身就很复杂，这就加速了商家放弃它的过程。

好，以上就是今天的内容。《得到头条》，明天见。

第一个时代隐喻是，今天的西方世界对文化多样性的包容诉求，也覆盖到了身材发胖领域。如今在全世界，肥胖的人口比例一直在增加，在这种肥胖增速面前，瑜伽裤虽然也跟牛仔裤有相似的地方，也同样是紧紧包裹身体，但它的弹力更强、更柔软，对发胖身材有更好的包容性。而过去的这10年，正是Lululemon现象级增长的10年，李维斯和Lee努力求生的10年。

第二个时代隐喻是，人类正在系统性地告别工业时代、进入信息时代。在工业时代，牛仔裤的耐磨抗造，被赋予了自由、强悍、酷和反叛的意义。信息时代取代了工业时代之后，“自由”的象征变成了算力和5G，有算力才有自由，有带宽才有自由。人们不再需要在工作时间调用肌肉、磨损膝关节了，这可能也让牛仔裤在流行百年之后，开始成为非刚需消费品。

康宇轩有三个核心设计。第一，不设边界，老人可以自由走动；第二，最小化干预，尽可能不让老人觉得自己是病人；第三，把真实社会搬进养老院，让老人参与真实的社会生活。老年公寓的本质，是为老人提供一个大一点的家，还原他们的真实社会体验。

Atumen：照护认知症老人，首先是人，然后是老人，再次是病人，按照这个逻辑顺序来照护，付出最多的是交流，大量的交流才能让他们感知自己是人，我们能做的就是，给他们生命内容以丰富。为这家养老院思路点赞，也为我们在家庭照护时提供参考经验。

大百事：阿尔茨海默患者的照护确实与一般养老存在较大差异，难度更高。

一方面，语言障碍使得患者难以清楚表达需求。这就要求照护者更加细心观察患者的行为、表情和身体语言，通过经验和耐心去猜测他们的需求，如是否饥饿、口渴、身体不适等。同时，照护者需要花费更多时间与患者交流，尽管可能无法得到清晰的回应，但持续的沟通可以让患者感受到关爱和安全感。

另一方面，认知能力下降带来的走失风险是一个重大挑战。照护者需要时刻保持警惕，采取一些预防措施，如为患者佩戴定位设备、在患者衣物上标注联系方式、确保居住环境的安全性等。同时，要与周围的社区、邻居建立联系，以便在患者走失时能够及时得到帮助。

此外，患者出现抑郁、焦虑或攻击性行为也增加了照护的难度和风险。对于出现这些情绪和行为问题的患者，照护者需要给予更多的理解和包容，尽量避免刺激他们。可以通过创造安静、舒适的环境，提供适当的娱乐活动来缓解患者的情绪。同时，照护者也需要关注自己的心理健康，避免因长期照护压力而产生疲劳和焦虑。

总之，阿尔茨海默患者的照护需要照护者具备更多的专业知识、耐心和爱心，以应对各种复杂的情况。

芝兰之室：照护阿尔茨海默症的老人需要综合考虑患者、照护者、居室环境和资源等多个方面。以下是一些具体的照护建议：

1. 日常生活护理

饮食护理：

固定用餐时间，食物宜健康、易消化。

帮助患者养成定时如厕的习惯，必要时使用成人尿不湿或护理垫。

出行安全：

佩戴智能手环或卡片，写清住址和家属联系方式，以便走失时方便寻找。

尽量减少患者单独外出，外出时要有家人陪同。

个人卫生：

亲自帮患者洗浴，观察体表有无伤口、淤青等。

注意口腔清洁，适时给患者梳妆打扮。

2. 安全护理

居住环境：

房间应少门槛、多扶手，地面要注意防滑，以防患者跌倒。

房门应安装不易开启的密码锁，以防患者走失。

家中危险物品要妥善管理，以防意外伤害。

活动安排：

安排患者做一些力所能及的事，如定时如厕、洗漱、穿脱衣等。

鼓励并协助患者参与其感兴趣的活动，如下棋、打扑克、朗读、唱歌、做游戏等。

3. 沟通与心理护理

沟通技巧：

与患者沟通时要语气平和，耐心倾听，了解老人的生活习惯、兴趣爱好。

沟通前先称呼患者的名字，说话要简单，每次只说一件事。

尽量不用疑问句，降低语速，耐心等待患者回答。

配合实物图片和照片，并利用肢体语言适时安慰、鼓励和表扬患者。

心理支持：

做一个良好的倾听者与陪伴者，提供他们需要的支持与关怀。

当患者表达困惑和不安情绪时，要试着安抚他们而非反驳或争辩。

4. 充分利用资源

家庭资源：

请亲属、朋友等共同帮助照料老人，缓解自身的压力。

与日间照料中心、社区、医院等保持联系，及时获得支持和帮助。

社会资源：

利用互联网对家庭照顾者进行干预及护理，提高其居家照护知信行水平、生活质量和满意度。

5. 避免过度照护

照护者要避免过度照护，否则会使患者的残存功能丧失速度加快。

合理安排患者的活动，保持其生活自理能力。
