# 854｜伊朗战火，可能会触发哪些连锁反应？

精挑细淘，得到头条。我是李南南。

最近，全网都在关注美军对伊朗的空袭。当地时间2月28日，美国和以色列对伊朗发动了军事打击。伊朗最高领袖，已经统治伊朗35年的哈梅内伊，在这场空袭中死亡。

那么，这场军事打击为什么会在这个时间发生？后续可能会产生哪些连锁反应？

这周，得到App [《国际参考》](igetapp://class/detail?classId=1070&ddurlMinVer=5.2.0) 的主理人刘怡老师、 [《投资参考》](igetapp://class/detail?classId=1073&ddurlMinVer=5.2.0) 的主理人何刚老师，都做了专门的分析。今天，我们就结合两位老师的观察，展开说说。

首先，这场战争为什么会在这个时间点爆发？要回答这个问题，得先了解一个背景，就是美伊在  *“核问题”* 上的分歧。

这个分歧早在1980年，也就是美伊断交之后，就出现了。伊朗一直想要发展核技术，按照他们自己的解释，发展核技术是为了和平利用核能。但美国始终认为，伊朗的真实目的在于发展核武器。这个争议持续了很多年。而且因为这件事，美国也一直换着花样对伊朗实施制裁，而且不仅自己制裁，还呼吁其他国家一起制裁。这也对伊朗造成了很大的经济压力。

于是，伊朗为了缓解制裁压力，2015年，伊朗与美国等六方达成了一个协议。大概内容是，伊朗承诺限制核计划，国际社会解除对伊朗的经济制裁。到这步，看似双方各退一步，皆大欢喜。但没多久，在2018年，新的变量出现，这就是特朗普。这一年，特朗普宣布退出这个协议，理由是协议不够严格，无法阻止伊朗发展核武器。

退出协议后，美国对伊朗实施了更严厉的制裁。伊朗的回应是，既然你们不遵守协议，我们也不遵守。于是，  *从2019年开始，伊朗逐步突破协议限制，开始用更大的力度发展核技术。* 比如，提高铀浓缩丰度，增加浓缩铀储量，等等。

你看，事情到这步，是不是已经有点“纷争升级”的意味了？

有人可能会说，难道在这期间，双方没有试着再沟通，再谈判吗？不是没试过，而是没谈拢。

最近的一次谈判是2月6日。根据刘怡老师的观察，这场谈判从一开始就有点反常。你看，双方谈判的主题是什么？是  *核技术* 。但双方出席的谈判团队里，却没有任何一位核技术专家。美方的谈判代表甚至不是职业外交官，而是特朗普的密友和女婿。

且不管双方的谈判态度如何，至少，核技术专家的缺失，让这场谈判在技术层面上，就很难有深入的可能性。

最终，谈了一个多月，伊朗愿意接受的最大让步，就是回到2018年特朗普退出的旧版协议。而且态度很明确，你们想让我们做的事，我们不是不能做。只不过，我们得谈条件，你得给好处。至于具体是什么条件，每一步都得单独谈。

显然，这是美国人无法接受的。于是，谈判就陷入了僵局。这也为之后的空袭埋下了伏笔。

那么，美军为什么偏偏选在2月28日动手？

刘怡老师认为，有这么几个推动因素。

*首先，是以色列的选举压力。*

2026年是以色列的大选年，现任总理内塔尼亚胡正在争取连任。对他来说，伊朗问题是个双重挑战。

一来，伊朗的核计划和导弹威胁是实实在在的。伊朗距离以色列主要城市只有1200公里，伊朗的导弹随时可能打过来。这是以色列选民最关心的安全问题。

二来，如果能一举化解伊朗的导弹威胁，他就有了稳定胜选的筹码。而且，他的支持率一度并不高，急需一个重大的外交或军事成果来扭转局面。

要知道，以色列是美国在中东最重要的盟友。以色列的利益考量，也会对特朗普的决策产生一定程度的助推，更何况，特朗普本来就对伊朗的核计划非常不满。

*其次，除了以色列的助推，特朗普自己的压力也是个关键因素。*

美国与伊朗，过去一年针对核技术开展的几乎所有谈判，都是由伊朗方面掌控节奏。具体细节在这里就不展开了。总之，对于特朗普来说，今年假如还继续让伊朗掌控节奏，对自己的政治形象会非常不利。他必须得想办法让伊朗“服软”，假如不服，就考虑动用武力。

事实上，在今年2月底，美国在中东就已经部署了两个航母战斗群、约160架舰载机、近4万名陆军。按可用兵力算，美军把超过40%的空中力量配置到了伊朗周边。

好，以上就是整件事的大致经过。

那么，这件事可能会如何发展呢？刘怡老师认为，要想回答这个问题，我们需要考虑这么几个因素。

*第一，是这场军事打击之后，伊朗也许会出现权力真空。*

毕竟，哈梅内伊去世后，谁来接班？截止到哈梅内伊去世时，他没有副手，也没有指定的继任者。按照伊朗的规定，需要由一个委员会选出新的最高领袖。但问题是，在这场空袭中，伊朗总统的官邸也遭到了轰炸。从候选人到有资格投票的选举人，他们自己的安全都没有保障。因此，这个推选程序能否正常启动，存在不确定性。而且就算启动了，能不能确保被有序执行，这些都是问题。假如伊朗在短时间内无法产生新的最高领导人，就可能会出现权力真空。

那么，假如出现权力真空，伊朗国内的主导权会由谁掌握呢？可能是革命卫队。这个“革命卫队”是伊朗的一支特殊军事力量。它不同于伊朗的常规军队，直接听命于最高领袖，掌握着伊朗最精锐的部队和导弹力量。假如出现权力真空，那么伊朗国内的主导权，就可能会落到革命卫队将领手里。

而现在，这些将领面临两个问题：  *一是要应付美国和以色列的新一轮空袭，二是缺乏跟对手对话的渠道。* 尽管特朗普发布视频说，让伊朗革命卫队“立即放下武器”。可问题是，美国在伊朗既没有外交人员，又没有地面部队，双方靠什么展开接触呢？

刘怡老师认为，  *后续比较可能的情况是，革命卫队将领和伊朗外交人员暂时结成联盟，尝试稳定局面，并寻找和美国对话的机会，争取让空袭尽快停下来。*

而革命卫队手里最重要的筹码，就是伊朗残余的军事力量。它虽然无法有效抵御空袭，但足以保证伊朗的社会秩序不会立即崩溃。从这次美军作战的细节看，伊朗导弹部队在哈梅内伊等高级领导人失联的情况下，依然能发起一定规模的反击。这说明革命卫队的指挥系统还在运转，它并没有失去对伊朗军事资源的控制。

那么，从目前的情况看，这场袭击可能会在全球范围内产生哪些连锁反应呢？关于这个问题，何刚老师在 [《投资参考》](igetapp://class/detail?classId=1073&ddurlMinVer=5.2.0) 中，做了专门的分析。这些影响包括三个层面。

*第一个层面，是对全球能源供应的直接威胁。*

中东本来就是全球主要的原油产区。而进出中东的咽喉要道，霍尔木兹海峡，3月1日已经被伊朗军方宣布封锁，海上原油运输暂停。这个海峡有多重要？每年经过这里的原油，大约占全球海运石油贸易量的30%。其中包括大量出口到中国和日本的原油，都要经过这里运往东亚。

霍尔木兹海峡被封锁后，中东地区替代性的原油管道运输能力有限，全球原油供应可能会出现较大的短缺危机。实际上，截至2月27日，2026年以来国际原油期货价格，已经比2025年底上涨17%以上。

但这是短期情况。何刚老师提醒，要注意区分油价短期变化与中长期供需关系。如果美国与以色列能控制伊朗局势，尤其是早日迫使伊朗解除对霍尔木兹海峡的封锁，让中东原油航运恢复正常，那么国际油价更有可能出现短暂情绪性飙升，然后逐步回归供需常态。

为什么这么说？因为最近几年全球原油需求总体并不旺盛，而且在中东地区之外，美洲、欧洲、非洲和亚洲的主要产油国总体产能充足，随时可以增产。换句话说，只要霍尔木兹海峡的封锁解除，或者其他产油国的增产到位，油价就可能会回落。

*第二个层面，是对金融市场的影响。*

比如，贵金属在地缘政治冲突增加的情况下，避险功能会进一步体现，会有更多的人看多黄金白银。

再比如，对待国际原油，很多人会选择“审慎看多”。前面说了，短期内油价可能飙升，但中长期看，全球原油需求不旺盛，其他产油国产能充足，油价不会长期高位。所以需要注意区分短期机会和中长期趋势。

再比如，还有很多人会看多国防军工板块。根据过去的经验，每一次发生重大地缘冲突，全球主要国防军工板块都会上涨。因为所有担忧自身安全的国家，都有可能增加国防预算。

*第三个层面，是对全球地缘格局的影响。*

何刚老师认为，地缘博弈可能会明显升级。从中东地区来看，伊朗及其在中东的代理人组织，比如黎巴嫩真主党、伊拉克民兵、也门胡塞武装等，将由此进入全面战备状态。它们与以色列等亲美阵营的对抗可能将加剧。而沙特、阿联酋等海湾国家，将面临“选边站”的压力，中东格局也许将更为复杂。

到这里，我们大致整理了伊朗危机的背景、起因，以及后续的可能影响。假如你想了解更多，可以关注刘怡老师的 [《国际参考》](igetapp://class/detail?classId=1070&ddurlMinVer=5.2.0) ，以及何刚老师的 [《投资参考》](igetapp://class/detail?classId=1073&ddurlMinVer=5.2.0) 。两位老师本周都在深入讲解这个话题，推荐你来看看。
