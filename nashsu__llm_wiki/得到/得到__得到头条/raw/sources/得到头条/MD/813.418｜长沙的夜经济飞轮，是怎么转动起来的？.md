# 418｜长沙的夜经济飞轮，是怎么转动起来的？

精挑细淘，得到头条。我是李南南。

今天是一期特别节目 。要跟各位同学汇报一个好消息。我们专栏为你请到了一位常驻的特约策划人。而且这位老师很多同学估计都熟，著名的消费行业专家、零售咨询顾问，黄碧云老师。

不瞒你说，早在半年前，我们就有这个念头。为什么一定要请黄碧云老师？三个理由，  *一线的洞察、近处的机会、即插即用的方法。* 一线的洞察，指的是黄碧云老师常年奔走在消费领域。她带回的全都是独家的一手洞察，仅此一份，别处看不到。那么，这个洞察对你有什么用？这就要说到另一个关键词，叫，近处的机会。没错，黄碧云老师带来的，往往是离我们非常近的，极其具体的机会。最后，看到这个机会之后我们该怎么做？这就要说到最后一个关键词，即插即用的方法。而且这些方法，都经过黄碧云老师实地考察，亲测有效。

从今天起，黄碧云老师会在我们的节目里，以每半月一次的频率，为你带来她的《黄碧云消费观察》。欢迎黄碧云老师。

今天是黄碧云老师消费观察的第一期。我们要说一个每到夏天就特别火的话题，这就是，夜经济。要说全中国哪的夜经济规模最大、最有特点，长沙肯定算一个。

长沙已经连续三年，入选中国城市夜经济十大影响力城市。当地的夜间消费，占全天消费的60%，从业人员超过100万。还有个特别有趣的数据，2017年，赛诺菲中国和腾讯健康联合发布过一份《中国网民失眠地图》，长沙居然杀进了前三，成了在熬夜指数上，唯一可以和北上广深一战的城市。但不少长沙年轻人熬夜，不是加班，而是因为长沙晚上好玩的太多，舍不得睡。

那么，长沙的夜经济，是怎么发展起来的呢？针对这个问题，黄碧云老师做过一轮深入的调研采访。我听完最大的感受就是，今天的夜市，绝对不是什么草台班子，它的专业化程度，已经超过很多人的想象。

接下来，我就为你转述来自黄碧云老师对长沙夜市的观察。

咱们先明确一个主线，  *一个完备的夜市生态，并不是七拼八凑出现的，而是以一座城市为基础，一层层长出来的。*

对长沙来说，夜经济的第一层地基，就是长沙这座城市本身。首先，长沙是省会城市里少有的房价洼地。今年6月的新建住宅均价还不到1万元，跟同级别的省会城市比，要低上不少。其次，长沙的教育资源分布均匀，全市各处的学校，数量和质量都够用。家长也就不用砸钱拼学区。换句话说，一个家庭最大的两座山被搬开了，长沙人自然就更有意愿消费。

其次，长沙这座城市的传播能力很强。湖南卫视就在长沙，当地也有很多传媒从业者，这就导致长沙的夜晚，更容易被作品传播出去。比如，前两年有部现象级的纪录片，叫《守护解放西》，讲的是长沙坡子街派出所民警的办案日常。坡子街，是长沙最繁华的步行街之一。因为来来往往的人太多，派出所总能遇到各式各样的奇葩事，但他们总有办法解决。表面上看，这是在讲派出所的故事。但实际上，这也向外界发射了一个信号，长沙的夜晚很安全，你可以放心来玩。现在长沙的杨帆夜市门口，还挂着一句大标语，叫，杨帆夜市很安全，警察叔叔在对面。

最后，长沙市政府打造夜经济的意愿很强。比如，长沙的四方坪夜市，是2021年火起来的。但在火之前，这个地方已经有6年的夜宵排档，只不过都是零零散散的小摊，并没有形成一个统一管理的夜市。因为生意不错，来的人多，加上管理没跟上，就时常出现扰民问题。

怎么办？是驱赶商贩？还是统一管理？长沙市政府就算了一笔账。一来，一个摊位可能代表了一家人的生计，单纯地赶走不合适。二来，即使把商家驱散，他们也会分散到别的地方摆摊，到时摊位散落在各个街区，管理难度更大。三来，这一带已经有了不错的流量，人气基础已经比较成熟，驱散了就太可惜了。

经过这么一掂量，长沙就决定，索性以四方坪现有的摊位作为基础，政府牵头组织物业公司和第三方运营商，把这个地方打造成一个规范化的夜市。搭建好水电之类的基础设施，同时做好噪音管理。

你看，这么一来，夜市就有了长期经营的基础，而不用想着打一枪换一个地方。

好，这是夜经济的第一层，也是最底层的基础，城市。简单做个回顾，一个适合发展夜经济的城市，往往需要具备两个条件。首先，居民的消费意愿强，而房价低、年轻人多、教育资源平均，或许是产生消费意愿的基础。其次，这座城市有打造夜经济的意愿，并且愿意提供资源。借用黄碧云老师的话说，  *假如你要从事夜经济，小到摆摊，大到经营一座夜市，一个有包容度的城市，是这门生意最大的杠杆。*

说完城市，咱们再聚焦一步，看看夜经济的第二层，也就是夜市。

过去提起夜市，好多人的第一反应，这就是个草台班子，正所谓，夜市大舞台，想卖你就来。但是，  *一个厉害的夜市，早就不是什么草台班子，而是一个被精致设计过的经济生态。*

比如，黄碧云老师前段时间采访过一位夜市品牌创业者，叫唐兆。唐兆是房地产商出身，现在有自己的夜市公司，叫长沙夜市智造。在长沙的40多个成熟夜市中，唐兆经营的夜市占了三个。所谓经营夜市，就是唐兆攒局，提供场地，出租给商贩们。

他们的夜市设计，有三个重点。

首先，品类搭配。注意，重点来了，已经经过验证的一个夜市的品类模型是，40+6+1+X。

40，指的是夜市里的小摊不能太重样，要确保不少于40个类型。再强调一句，这是经过验证的数字。一个夜市里，生意最好的状态，就是有不少于40个分类的小摊。这样消费者会觉得有的逛，不重样。摊主们也会觉得，同类竞争没那么激烈，愿意来摆摊。否则一个夜市里全是烤肠、臭豆腐、大鱿鱼，这谁受得了？

6，指的是6个集装箱品牌。集装箱品牌，就是有连锁店的大品牌，在夜市里摆摊。比如，海底捞、正新鸡排、良果芭水果茶，都已经开始在夜市摆摊了。这些集装箱品牌，能够增加夜市的品牌效应。

1，指的是自营品牌摊。也就是，夜市的经营者，自己也要下场，经营自己的摊位。这能够提升夜市的识别度。比如前面说的四方坪夜市，就有意把自己做成一个带有文旅性质的品牌，他们设计了自己的吉祥物，还有很多周边产品。

X，指的是异业联动，也就是，跟不同行业合作，增加夜市的趣味和丰富程度。比如，跟啤酒品牌联动，承办啤酒节。像唐兆经营的夜市，就把狼人杀和密室逃脱搬进了夜市，在夜市里搭建了专门的场地。

总之，  *一个夜市要想生意好，它的内部生态需要足够丰富。* 比如前面提到的四方坪夜市，整个夜市的主街区有340个摊位。除了这个主街区之外，还有三个延伸街区。第一个街区在四方坪新大门入口，有56个承担引流功能的网红摊位。这些摊位对摊主要求更高，必须得有很强的表现力，能说能唱能直播。假如你满足这些要求，租金上还会给你很大的优惠。第二个街区是跳蚤市场，主要卖吃穿用度的小玩意，跟主街区形成互补。第三个街区叫休闲微醺慢生活区，主要卖精酿啤酒、柠檬茶，还有各式各样的咖啡饮品。

你可以想象一下这个布局。假如你精力足够充沛，至少可以一个晚上在里面体验好几场。第一场是吃小吃，第二场是逛市场，第三场是逛累了之后跟朋友去喝杯啤酒。

好，前面说的是，夜市的品类搭配。

其次，除了对品类有要求，现在的夜市对人也有要求。  *一个厉害的夜市，最好是能做到，全民IP。也就是，每个摊主都会直播，都能成为IP。* 注意，会做短视频和不会做短视频，在摆摊时的差异会非常大。

比如，在长沙的赤岭夜市，有一个网红摊主，叫无声意面。无声，是因为摊主是听障人士，没法在摊位上吆喝。一般来说，这么摆摊肯定吃亏。但这个摊主把自己的摆摊过程拍成短视频，情况就不一样了，有很多人觉得他很励志，专门奔着他来。这么一来，摊位就从原来的摊等人，变成了人找摊，生意自然就有了。

假如一个夜市里的几十个摊位都去拍短视频，就相当整个夜市有了几十个流量入口。即使个体流量不大，叠加在一起，没准哪天就火了。

最后，夜市除了对人、对商品有设计，还要留意跟周边生态形成互补。比如，一般的商场10点关门，而10点之后的夜生活没有着落。这时，把夜市开在商场门口就是个不错的选择。它能承接顾客10点以后的夜生活，而且还可以跟商场的会员体系联动，商场会员去夜市可以打折之类。

再比如，石家庄的正定夜市。夜市本来是正定小商品批发市场的停车场。早前因为生意冷清，当地就从2012年开始，在这里规划了夜市。这么一来，顾客可以白天逛市场，晚上逛夜市。等于夜市和市场，互相带动流量。

好，刚才咱们说了  *夜市设计的三个要点，分别是，品类的搭配、对人的要求，以及与周边生态的配合。*

你看，夜市的设计，是不是比很多人想象得精巧得多？说到这，假如你觉得夜市是一门有趣的生意，有意愿，而且也有时间尝试一下，那么接下来，最后的第三部分，建议你认真听听。我们要说的是，目前夜市的摊位里，比较有生命力，并且可以做成连锁摊的品类。

第一个品类，是主食。毕竟，小吃再丰富，也很难替代主食。加上很多上班族，是下班后空着肚子去夜市的，因此主食也就成了夜市上的刚需。

比如，长沙的小二炒饭，在当地开了70多个连锁摊位，现在摊位已经开到了深圳跟东莞。炒饭很容易标准化，操作简单，流程很容易被掌握。同时，炒饭还是一个损耗极低的品类。用来做炒饭的米饭需要冷藏，当天卖不完也不会坏掉。而且主食的销量相对稳定，从周一到周五相差不大，也就更容易计算备料。

第二个品类，是酸甜口味的小吃。比如，最近几年的网红单品，柠檬凤爪。这类东西的好处是，可以提前加工制作，年轻人喜欢。而且更关键的是，可以同时卖给B端。卖给餐厅当凉菜，或者卖到超市都可以。当然，前提是取得相应的资质。

第三个品类，是卤味。它的特点是毛利高，且容易形成护城河。因为卤味的技术门槛相对高，你的口味差一点，顾客就不买账。但是，一旦你达到这个口味，就可以马上把工艺固定下来，形成稳定的护城河。同样，卤味也可以同时在别的地方卖，销路更广。

当然，夜市上的东西，各有各的优势。而前面说的这三类，都有连锁品类的成功先例，或许更容易做成连锁品类。

好，关于夜市，咱们先说到这。

刚才是我为你转述的，是来自黄碧云老师的第一期消费观察。我们以夜市为样本，分成三个层面，讲了夜经济的三个核心要素。  *第一层，是城市层，需要一个消费意愿强，且包容度高的城市。第二层，是夜市这类平台层，需要在这个层面，构建夜市的生态。让经营者之间形成互补，而不是相互竞争。第三层，是具体的经营者。适合的品类和直播技能，是经营摊位的关键。* 这三个层面的参与者共同发力，也让一座城市的夜经济飞轮，越转越快。

假如你的身边有人想试着做夜市生意，或者对这个事感兴趣，也推荐你把这部分内容转发给他。

好，以上就是今天的内容。《得到头条》，下周见。

## 划重点

长沙的夜经济是怎么做大的？
整个过程，就像推动一个飞轮。其中有三个因素很关键。一是城市层，要具备打造夜经济的意愿与包容度。二是夜市这类平台层，它的总体设计要能让经营者之间形成互补。三是具体的经营者，要有IP制造能力。

左星星：早在民国初年，长沙已经有了“夜经济”的雏形，彼时小吃摊的柴油灯一亮就是一宿。上世纪八九十年代，歌曲、本土相声、湘剧等夜间表演伴着星光闪亮登场。时至今日，“夜经济”早已成为湖南人的日常。长沙的“夜经济”，何以绵延不绝？

本世纪初，湖南卫视、芒果TV等“电视湘军”异军突起，长沙凭借传媒影视行业的出色表现，积攒了大量粉丝。吃到了第一波红利后，长沙又频频发起网络、媒体与城市文旅营销的互动。游客去长沙的门店，不一定最关心吃什么，但记录下来发朋友圈是必须的。长沙开始走上“网红“之路。

其次，得年轻人者得天下，长沙深谙此道。长沙不断推出“适配”年轻人的饮食生活品位和消费习惯。有着千年学脉的岳麓山下，围绕着湖南大学、中南大学等20多所高校，夜爬岳麓山，看一场橘子洲头的烟花秀，再去后湖畔吃一顿烧烤，这是许多学子的独家记忆。在夜的刺激下，青春和创意，在这里肆意生长。

最后，市井深处藏着民间潮流和创意，发生着意想不到的多巴胺反应。长沙的店铺灯箱形态各异，但长沙并没有实施“整治”，而是为此立下“规矩”：只要在“安全”范围内，商户招牌想怎么有个性就怎么有个性。于是我们看到，这些个性十足的灯箱，成了刺激夜间消费的“助燃剂”。

如何让“夜经济“从”网红“变”长红“？真诚是必杀技。当一座城市用真诚持续打动每一位游客，人与城就产生了共情。

魏红亮：418｜长沙的夜经济飞轮，是怎么转动起来的？

得到头条这边在讲长沙的夜经济，商业参考刚刚讲了两期“ChinaTrave”的主题，这属于遥相呼应啊，但稍微一想我们就发现这两则之间有很多都相通性。

一件事能不能成不仅仅是事本身，还要看各种配套是不是到位，各种服务是不是完善，各种流程是不是顺畅。政府这几年的服务意识已经非常明显了，帮企业解决各种各样的问题从而减少经营过程中的摩擦力。

“ChinaTrave”为了方便国境游客在移动支付住宿等管理办法做调整就是一个非常典型的例子，长沙夜经济中“疏替代了堵”的做法现在在很多地方也比较常见了。这是时代的进步，长沙走在了时代的前列！

猫奴出圈：经过碧云老师的讲述与分析，我对长沙夜市真的是太期待了。老师提到的夜市已经记下来了，下次回去一定要打卡。

说到成熟的夜市经济，给我留下最深印象的，是西双版纳的星光夜市。去到星光夜市，大家都会开启“小火车”模式：逛吃逛吃逛吃······

星光夜市，夜市提供东南亚6国特色小吃如越南卷粉、巴拉达、烤罗非鱼等。烧烤也特别棒，老挝奶茶/奶咖浓郁丝滑，泰国烤榴莲，价格也还算公道。舂木瓜真的太上头了，能吃辣的话一定要多加辣椒。

除此之外，手工艺品和纪念品，在夜市中占有一席之地。可以购买到傣族特色的手工艺品，如刺绣、银饰、竹编工艺品等。
