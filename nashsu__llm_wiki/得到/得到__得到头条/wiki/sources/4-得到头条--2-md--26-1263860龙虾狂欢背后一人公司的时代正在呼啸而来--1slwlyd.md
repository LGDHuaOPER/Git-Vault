# 860｜“龙虾狂欢”背后，一人公司的时代正在呼啸而来？

## 概述

本期《得到头条》由主持人李南南播报，聚焦近期爆火的AI工具 OpenClaw（昵称“龙虾”）。节目以电影《龙虾》的设定引入话题——跟不上趋势就会被变成动物——进而讨论 OpenClaw 火爆背后的深层原因、三大关键设计、安全隐患、使用成本，以及创始人彼得·斯坦伯格的“周末项目”方法论。

## 核心论点

1. **OpenClaw 火爆的关键原因是“平民化”而非技术先进性**。它的内核是 Claude Code，程序员早已在用，类似工具还有 Cursor、GitHub Copilot。OpenClaw 的突破在于把入口变成聊天工具（微信、钉钉、飞书），让不懂编程的普通人也能让 AI 操作电脑。

2. **OpenClaw 与很多其他 AI 的本质区别在于记忆、判断与主动思考**。它不只是执行指令，还会定期回顾日志、提炼信息，越用越懂用户。

3. **对待新技术的方式应是“周末项目”而非盲目 all in 或原地焦虑**。创始人彼得·斯坦伯格以好奇心驱动尝试，从自身需求出发创造工具。

## 关键案例：傅盛的“三万”AI助理

2026年春节，猎豹移动 CEO 傅盛因滑雪受伤卧床14天，用 OpenClaw 搭建了名为“三万”的 AI 助理：

- 14天内发送1157条消息、22万字，每天聊到凌晨四五点
- 4分钟内给611名员工发送个性化拜年消息，零失误
- 24小时搭建完整网站：59个HTML页面、7070行代码、76张图片素材、38页PPT手绘图、41个技能详情页
- 传统团队需6人耗时2到3周、成本约20万元；“三万”24小时完成，token成本仅115美元
- 大年初一摔伤后，“三万”判断“第一大可能是髋关节脱臼”，并主动提出联系傅盛的人类助理 Abby——而 Abby 是五天前傅盛随口提过一次的名字

## OpenClaw 三大关键设计

1. **统一入口**：把所有 AI 能力整合到一个聊天界面，无需在多个工具间切换
2. **持久化记忆**：存储对话、习惯、需求，定期自动 review 日志，让 AI 从“工具”向“伙伴”迈进
3. **插件生态**：开源插件市场，类似 App Store；过去4个月已有300到400位来自全球12个国家的开发者参与

## 风险与成本

- **安全隐患**：工业和信息化部2026年3月发布风险提示，指出 OpenClaw 在默认配置下拥有系统级权限，可能因指令诱导、配置缺陷或被恶意接管而执行越权操作。插件市场中部分插件含恶意代码，可能窃取 API 密钥、钱包凭证、邮箱密码。
- **使用成本**：免费额度可用，但复杂任务一天可消耗上百美元。心跳机制默认每30分钟唤醒一次，本身消耗不少 token。

## 创始人故事

彼得·斯坦伯格，奥地利人，连续创业者。2021年卖掉 PDF 工具公司，获得约1.19亿美元后“提前退休”。OpenClaw 最初只是他的周末项目：2025年11月某个周末，他用一小时把聊天软件和 Claude Code 连接起来做了个小工具，后开源。项目先后命名为 Clawdbot、Moltbot，因商标问题最终改名 OpenClaw。4个月后成为现象级产品。2026年1月25日正式发布，2026年2月16日加入 OpenAI，项目转交独立基金会运营，OpenAI 提供资源支持。

## 政策与市场动态

- 深圳龙岗区发布“龙虾十条”政策，对基于 OpenClaw 的初创企业最高给予1000万元股权投资
- 闲鱼上代安装龙虾服务价格涨到500元左右，有的程序员靠替人装龙虾一天能挣好几万元
- 腾讯云、阿里云、字节推出 OpenClaw 一键部署方案，月费38到99元不等
- 猎豹移动基于 OpenClaw 原版打造 EasyClaw，省去繁琐专业环节

## 划重点

1. OpenClaw 的火爆，不是因为技术最先进，而是因为它把“一小撮人的能力”推到了普通人面前。它也许不是技术最先进的，但它是“平民化”做得最好的 AI 工具之一。
2. OpenClaw 跟很多其他 AI 的本质区别在于，它不只是执行，它还有记忆、会判断、会主动思考，更像一个会主动思考的智能伙伴。
3. 对待新技术的方式，或许不应该是盲目 all in 或原地焦虑，而是应该像彼得·斯坦伯格那样，用好奇心驱动尝试，根据自己的需求，创造新的工具。

## 热门留言要点

- **猫先生**：OpenClaw 火爆原因可理解为极致简单且开放包容——系统化整合、熟人化（持续记忆）、开源生态。技术负责奔跑，监控负责划线。
- **牛犇犇**（口腔科医生）：行业错过很多精彩内容，但使用门槛会越来越低，期待更多类似程序。
- **山石**：深圳龙岗区“龙虾十条”是对 OpenClaw 创新生态的政策背书，印证“AI 普及，平民化设计比技术先进性更关键”。
- **小庄**：一人公司不是简单的自由职业，而是全新的生产组织方式，代表技术赋能、消费升级、价值观转变三重力量的交汇点。
- **花花**：深圳部分政务部门开始用龙虾提高工作效率，但安全性仍是门槛。
