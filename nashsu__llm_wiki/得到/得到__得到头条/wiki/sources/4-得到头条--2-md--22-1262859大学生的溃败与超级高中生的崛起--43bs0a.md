# 859｜大学生的溃败，与超级高中生的崛起

《得到头条》第859期，主持人李南南。本期从硅谷企业 Palantir Technologies 招收高中生的反常消息切入，讨论全球范围内学历门槛松动的趋势、部分大学生关键能力在大学期间退化的研究证据，以及新型大学作为应对方案的出现。

## 核心论点

1. **全球企业招聘正在去学历化**：越来越多的公司不再以学历作为硬性筛选标准，转而看重解决实际问题的能力。
2. **部分大学生关键能力在大学期间退化**：学历证明的只是"在学校待了四年"，不能证明学到了什么，更不能证明解决问题的能力。
3. **新型大学是应对方案**：打破传统边界，让教育与产业深度融合，培养"能解决问题的人"而非"有文凭的人"。
4. **选大学逻辑从"起点高"转向"起点早"**：大学与城市产业集群深度绑定，选大学即选职业路径。
5. **能力认证方式将从一次性学历转向持续更新的能力证明**。

## 关键证据

- Palantir Technologies 2025年正式招收高中生，500人报名录取22人（录取率4.4%），转正年薪17万美元（约119万人民币）。
- Google、Meta、OpenAI 三家公司在2024-2025年累计录用超过300名未完成大学学业的年轻人。
- IBM 取消80%岗位的学历门槛，改用"技能徽章"筛选候选人。
- Indeed 数据显示，2024年52%的招聘岗位完全没有学历要求；本科要求的岗位比例从2019年的20.4%下降到2024年的17.8%；87%的行业对本科学历的需求在下降。
- 字节跳动"ByteCamp"训练营向中学生开放；腾讯"少年开发者计划"不限学历；华为"天才少年"计划放宽学历限制。
- 猎聘数据显示，2025年"不限学历"岗位数量比2024年增长45%；过去一年中国超过150家互联网中小企业移除本科硬性要求。
- 2021年《自然·人类行为》研究：在中国、美国、印度、俄罗斯四国调研3万多名理工科学生，发现不少学生批判性思维能力在大学四年出现下降，中国学生下降幅度最大。
- 普林斯顿大学历史学家安东尼·格拉夫顿发现大一新生词汇量和语言能力明显不如往届。
- 加州大学圣地亚哥分校2025年秋季数据：过去五年需参加数学补习班的大学生数量暴涨近30倍。
- 世界经济论坛2025年报告：到2030年，39%的工作技能将发生转变。

## 新型大学案例

- **大湾区大学**：2025年首招（仅广东省内），2026年扩招至广东、广西、湖南、湖北、河南及港澳地区，新增人工智能、未来机器人、智能计算、通信工程、光电信息科学与工程、电子信息材料6个专业。办学特点：大类招生、双导师制（学术导师+企业导师）、产教融合。
- **西湖大学**：施一公教授筹办，办学5年，科研导向，学生从入学第一天就进实验室。
- **福耀科技大学**：平均每个学生配4个导师（学业导师、科研导师、书院生涯导师、企业实践实训导师）。
- **南京集成电路大学、深圳理工大学、宁波东方理工大学**：同为新型大学。

## 热门留言要点

- **晓曦教授**：用经济学"signaling theory"解释学历价值——文凭证明的是完成四年、服从规则、延迟满足的能力；美国高等教育正在经历"迟到的重新定价"，学历溢价收窄、技能溢价扩大。
- **你先走**：教育是工业文明流水线遗产，新型大学是教育的"柔性供应链"，从"批量生产"到"按需定制"。
- **牛犇犇**：反驳性观点——传统通识教育并没有问题，有研究证实上过大学的人收入高于只读高中的人；教育变革滞后，可在局部领域先做改变尝试。
- **王志文**：以华为"天才少年"张霁为例（本科为普通三本院校，凭技术实力获最高档年薪），说明真本事比学历重要。
