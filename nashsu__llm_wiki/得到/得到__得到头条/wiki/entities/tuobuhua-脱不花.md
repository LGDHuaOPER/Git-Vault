# 脱不花

## 概述

脱不花是得到平台的管理专家，拥有20年管理经验（新生成版本）。既有版本称她为得到《管理者沟通训练营》的讲师。她在《得到头条》的不同节目中分别分享了"怎么提意见，才能让下属听得进去"和"管理任务布置公式"。

## 提意见四原则

来自既有版本对应的《得到头条》234.233期（《为什么"好体验"不等于"好服务"？》）：脱不花在课程中回答了"怎么提意见，才能让下属听得进去"的问题，给出四条建议：

1. **表明盟友立场**：要跟下属说明白，你不是在对他指手画脚，而是在为了双方的共同利益共同努力。前一种是旁观者，后一种是盟友。只有双方先成为盟友，才能把"我"的目标转化成"我们"的目标。
2. **带具体方案**：带着具体的方案和建议来给下属提意见。这表明你不是在给他一个负面评价，而是在真的想办法解决问题。
3. **私下提**：当众给下属提意见可能会打击到他的自信心，影响他的工作状态，可以在会后单独跟下属沟通。
4. **第一时间提**：针对眼下的事情进行即时反馈，下级会觉得你在帮助他。如果当下不说，攒了一轮再说，就变成了"秋后算账"，会激发下属的抵抗心理。

## 管理任务公式

来自新生成版本对应的《得到头条》第256期（来源为"剧本杀的脑洞能有多大？"）：脱不花分享了管理任务布置公式：

**目的 + 目标 + 动作 + 达标标准 = 一个对方可执行的任务**

1. **交代目的**（"为什么"）：只有知道为什么而战的士兵才是不可战胜的。
2. **明确的目标**：要有衡量标准并且尽量单一，警惕"我要……我还要……最好还能……"的多目标系统。
3. **动作要求不能过细**：强调关键动作，非关键动作允许变通。
4. **达标标准要形成共识**：综合考虑效果、效率、成本和长远价值等要素。
