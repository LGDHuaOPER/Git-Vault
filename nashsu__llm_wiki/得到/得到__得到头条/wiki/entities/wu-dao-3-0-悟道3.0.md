# 悟道3.0大模型系列

2023年6月10日，北京智源人工智能研究院在第五届智源大会上正式发布的国产大模型系列，全部开源。

## 组成

- **天鹰语言大模型系列**：首个具备中英双语知识、支持商用许可协议、国内数据合规要求的开源语言大模型。
- **天秤大模型评测体系**：大模型评测体系。
- **视界视觉大模型系列**：视觉大模型。

## 意义

悟道3.0的发布意味着今后可用的AI工具更多了，而且完全免费。
