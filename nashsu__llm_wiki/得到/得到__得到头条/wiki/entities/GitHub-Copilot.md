# GitHub Copilot

GitHub推出的AI编程助手，是AI从对话工具转变为生产力工具的典型代表。

## 关键数据

- **用户数**：2025年初突破1500万，意味着全球有1500万程序员在用AI辅助编程。
- **行业意义**：作为[[AI员工]]在编程领域的具体落地，Copilot展示了AI如何成为实打实的生产力工具。据Menlo Ventures报告，2025年企业生成式AI支出达370亿美元，编程是其中重要的应用场景之一。
