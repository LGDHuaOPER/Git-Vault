# Microsoft 365 Copilot

微软于2023年3月发布的"王炸级产品"，在[[得到头条/MD/468.073｜ChatGPT自曝 哪些工作“我”一定抢不走？.md|073期节目]]中被描述为"一套搭载了GPT-4的Office"。

## 意义

Microsoft 365 Copilot的发布是GPT-4上线后行业连锁反应的一部分，与PyTorch 2.0、文心一言等共同构成"AI组团上线"的图景，支撑[[ai-de-iphone-shi-ke|AI的iPhone时刻]]的论点。
