# 尼基尔·辛加尔（Nikhyl Singhal）

尼基尔·辛加尔（Nikhyl Singhal）是硅谷职场教练。在《得到头条》第147期中，其提出的[[公司发展四阶段]]框架构成“职业发展的投资坐标”的核心内容。

## 核心观点

辛加尔认为，人们在跳槽时通常会考虑收入、发展空间、共事团队、职场文化等因素，但这些都不是应该首先考虑的因素。应该增加一个宏观视角：**首先考虑这家公司处于什么样的发展阶段，这个阶段是不是跟你的能力特点相匹配**。

## 四阶段框架

辛加尔把科技公司的发展分为四个阶段：

1. **产品探索前期**：产品尚未正式推向市场，处于从0到1的探索期
2. **产品和市场适配期**：已有核心产品和最早一批用户，但还在不断试错迭代
3. **飞速发展期**：用户快速增长，公司开拓新业务线，团队急剧扩张
4. **规模化期**：成为平台巨头，即通常说的“大厂”

## 匹配建议

- 拥有天马行空创意、快速学习能力、拥抱变化和冲突者 → 第一阶段（探索前期），风险最大、收益最高
- 在某个领域深耕5到10年的资深专业人士 → 第二阶段（适配期），凭专业技能独当一面
- 执行力强、善于做从1到N工作、有规模化能力者 → 第三阶段（飞速发展期），成为攻城略地的主力干将
- 做事有清晰边界、喜欢稳定环境和清晰晋升路径、希望有经验丰富上级带领者 → 第四阶段（大厂）
