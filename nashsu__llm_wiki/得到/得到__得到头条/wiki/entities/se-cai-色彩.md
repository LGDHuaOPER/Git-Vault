# 《色彩：看不见的影响力》

一本书，作者是[[fa-er-man-法尔曼夫妇]]（凯列·法尔曼和肯尼斯·法尔曼），两人都是设计师。书中提出若干[[se-cai-xin-li-xue-色彩心理学]]观察，包括：

1. 蓝色使人有力，粉色使人无力
2. 红色增进食欲，蓝色抑制食欲
3. 棕色和红色代表浓郁，蓝色和黄色代表稀释
4. 原色→性价比，紫色→成本高，黑/银/金→高科技

核心设计原则：好的设计一定有清晰的功能指向，功能不仅包括使用功能，也包括[[qing-xu-gong-neng-she-ji-情绪功能设计]]。得到有电子书。
