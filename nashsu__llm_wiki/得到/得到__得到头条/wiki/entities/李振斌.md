# 李振斌

李振斌是 IETF 互联网架构委员会（IAB）委员、华为首席 IP 协议专家。在《得到头条》第170期中，他作为 IPv6+ 技术的解释者，向主播[[徐玲]]解释了 IPv6+ 技术的原理与能力。

## 主要观点

- IPv6 替代 IPv4 的主要原因是 IP 地址不够用（IPv4 地址约 42.9 亿个，IPv6 为 2的128次方）。
- IPv6+ 只需要用一张网就能覆盖所有业务，通过[[网络切片]]功能保证业务之间不相互干扰。
- IPv6+ 能做到紧急需求的快速响应：临时增加直播或采访信号，以往需要 3 天以上，本届冬奥会几分钟即可部署完成。

## 信源局限

本期对 IPv6+ 的效能描述主要来自李振斌（华为专家），存在利益相关方信源偏差的可能，缺乏独立第三方验证。参见查询页 [[ipv6+的效能描述是否存在信源偏差]]。
