# 华为云

华为云是国内云计算大厂，根据 Gartner 数据，2021 年华为在全球云计算市场份额排名第五。

## 业务现状

- 以 [[iaas|IaaS]] 为主，利润率长期在个位数。
- 与 [[aliyun-阿里云|阿里云]]、[[tencent-cloud-腾讯云|腾讯云]] 情况类似，面临 [[运营商云]] 强势崛起的竞争压力。

## 转型方向

正从亚马逊模式转向微软模式，从主要做 IaaS 到重点发展 [[paas|PaaS]] 和 [[saas|SaaS]]。
