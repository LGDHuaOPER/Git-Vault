# GitHub

GitHub是全球最大的开源软件社区和代码托管平台。

## 在程序员荣誉体系中的角色

- 任何人都可以在GitHub上发布或参与[[开源项目]]
- 公司招聘程序员时，GitHub页面是重要参考，展示候选人对开源项目的贡献
- 程序员也通过公司在GitHub上的开源投入来评价其技术实力
- 是[[程序员荣誉体系]]的核心载体
