# Riot Games

## 概述

Riot Games 是开发了《英雄联盟》（LOL）的游戏公司。

## 与腾讯的关系

据《得到头条》062期播报，腾讯对 Riot Games 持股100%。Riot Games 是腾讯全球游戏投资版图中完全控股的公司之一。
