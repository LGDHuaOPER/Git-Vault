# 雅鲁藏布江下游水电工程

2025年7月国家宣布的超级工程，投资1.2万亿人民币，是全世界有史以来投资最大的单体工程。工程利用雅鲁藏布江2000多米的天然落差，建设五座梯级电站。

## 关键指标

| 指标 | 数值 |
|------|------|
| 总投资 | 1.2万亿人民币 |
| 年发电量 | 3000亿千瓦时（相当于3个三峡） |
| 满足用电人口 | 3亿人一年 |
| 替代石油进口 | 1.5亿吨/年 |
| 年均经济贡献（未来十年） | 超2000亿增量 |
| 拉动就业 | 上百万人 |

## 战略意义

- **能源安全**：中国石油进口依存度约70%，进口石油80%走马六甲海峡。雅江水电可替代1.5亿吨石油进口，与西北风光电基地联网后构建"不依赖海运"的陆上能源大动脉。
- **清洁能源补充**：水电能对不稳定的风光电形成稳定补充。

## 个人机会

- **基建上下游**：钢铁煤炭、民爆炸药、土木建设等领域直接受益。
- **投资市场**：开工消息公布后，土建、民爆、钢煤、化工、盾构机等相关企业股价大幅上涨；期货市场焦煤、焦炭、多晶硅等品种直接涨停。
- **西部发展**：工程建成后西藏将成为最大供电省份，带动西部基础设施建设，形成产业集群效应。
