# 弘润清源

一家做空气集水（从空气中收集水）的初创公司，技术可用于沙漠地区的农业灌溉。创始人林腾宇是清华毕业的"95后"。

## 小订单案例

中东买家带着需求咨询了中国外交部，外交部又咨询了清华，清华正好有这个项目。林腾宇很快做了样机，对方觉得不错，又追加了大笔订单。

这是[[xiao-ding-dan-luo-ji-小订单逻辑]]的典型案例：不要低估任何一个来自中东的小订单。
