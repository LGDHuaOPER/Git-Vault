# 韩立波

韩立波是 [[didichuxing|滴滴出行]] 老年版产品经理。在《得到头条》第 175 期中，她分享了滴滴老年版在 [[app-aging-adaptation|APP 适老化改造]] 中如何做取舍，很有启发。

她的分享涵盖四个层面的取舍：

1. **功能取舍**：舍弃地图功能（调研发现老年人基本不看），保留紧急联系人、分享行程和 110 报警等提供安全感的功能。
2. **信息呈现取舍**：撤掉汽车图形，直接用汉字标注车辆颜色（调研发现老年人不知道图形颜色代表派单车辆颜色）。
3. **算法取舍**：在就医场景下为老年人优先派单。
4. **客服术语取舍**：客服术语“去专业化”，用口语化表达替代专业术语。

韩立波的分享体现了 [[product-manager-tradeoff|产品经理权衡取舍]] 的方法论价值——调研驱动取舍。
