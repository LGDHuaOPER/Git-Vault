# 世界记忆锦标赛（World Memory Championship）

自1991年开始举办的记忆力比赛，发起人为英国人托尼·博赞。全球60多个国家选手参赛，比赛中创造的新世界纪录可直接计入《吉尼斯世界纪录》。

## 比赛项目

参赛选手按年龄分儿童、少年、成年、乐龄（老年人）四组，共10个项目，分三类：

- **记数字**：5分钟内准确记住更多数字、1小时内尽可能多地记住随机数字。
- **抽象记忆**：记住随机词组、大量虚拟历史事件和日期、给定抽象图形。
- **记扑克牌**：5分钟内准确记住一副扑克牌顺序、1小时内记住几副扑克牌顺序。

## 第32届赛事

第32届世界记忆锦标赛于2023年12月8日至10日在三亚举办。中国选手黄尽尧以3金3银3铜的成绩获全球总决赛全场总冠军，使用2位数编码。
