# Luis von Ahn

[[duolingo-多邻国]]创始人，来自危地马拉。根据热门留言（左星星）介绍，他想建立一个让人们在任何地方都能免费学习英语的平台，最好用"众包"方式让所有人帮助所有人。

多邻国刚推出时只提供西班牙语和德语学习。当人们询问特定语言课程时，Luis会回答："不，我们没有，你能帮我们创建吗？"他分享了开设语言课程的工具，第一周约5万人申请添加一种语言。多邻国因此被誉为"巧妙利用众包获得商业成功的最佳范例之一"。

Luis确保所有帮助创建语言课程的无偿贡献者保留所创建内容的所有权。课程免费，通过自动广告和会员费盈利，会员费已贡献超1亿美元收入。
