# 雅马哈

雅马哈（Yamaha）是日本一家以多元化著称的企业，被吴伯凡用作“藤蔓式生长”的典型代表。

## 藤蔓式生长路径

雅马哈的多元化并非事先规划，而是从核心业务中自然延伸：
1. 修钢琴 → 发现质量不好 → 自己造钢琴
2. 造钢琴（木质） → 顺便造木质家具 → 造木质飞机螺旋桨 → 进入航空领域
3. 生产飞机引擎 → 生产汽车引擎 → 造机器人

每一个新业务领域都是在做旧业务时自然而然生长出来的，体现了典型的藤蔓式生长模式。
