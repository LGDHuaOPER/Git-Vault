# Xbox Game Pass

微软的游戏订阅服务，被称为"游戏界的奈飞"。玩家只需要每个月花10美元的会员费，就能享用微软游戏库里上百个游戏。

## 核心特点

- 以前花40—60美元才能买一个游戏，现在买两三个游戏的钱就能开通一年的会员，畅玩上百个游戏。
- 是Xbox Series对阵PS5时"内容为王"策略的关键。
- 与索尼的订阅制服务形成对比：索尼包含的游戏大多数是不知名的小游戏，稍微知名一些的游戏就要更高的订阅费。

## 热门留言中的观点

- **左星星**：微软XGP走的是"订阅收入"路线，与"被动收入"概念直接相关。微软用XGP平台开创了新的游戏售卖形式。
- **林曦**：XGP"接地气"的四个原因——价格亲民、量大管饱、有PC端（依托Windows系统庞大用户基数）、数据共享（账号和存档互通）。
- **静默风**：内容包年模式容易走向"量大于质"，若索尼反过来走精品游戏订阅模式，"鹿死谁手尚未可知"。
