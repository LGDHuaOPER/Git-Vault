# 峰瑞资本

峰瑞资本（FREES FUND）是一家风险投资机构，创始人为[[li-feng-李丰]]。2023年，峰瑞资本发布关于[[xin-neng-yuan-hou-shi-chang-新能源后市场]]的专门报告，提出五大商业机会。

## 报告要点

1. 轮胎保养需求增加（新能源车车重较大，轮胎磨损更严重）。
2. 智能化相关配件保养需求增加（底盘复杂、摄像头雷达等零部件维修）。
3. 二手车交易平台增多（零部件数量少、标准化程度高、车况透明）。
4. 车衣改色、车辆改装市场（年轻车主个性化需求）。
5. 新能源汽车衍生品（车载冰箱、车载咖啡机、户外帐篷等）。

## 在动漫IP赋能品牌模式中的作用

峰瑞资本同时投资了[[liang-dian-shi-fen-dong-man-两点十分动漫]]和[[jiang-xiao-bai-江小白]]。在一次峰瑞资本组的局上，两点十分创始人[[wang-shi-yong-王世勇]]与江小白创始人[[tao-shi-quan-陶石泉]]相识，由此促成了《我是江小白》动漫剧的合作，开创了[[dong-man-ip-fu-neng-pin-pai-动漫IP赋能品牌]]的商业模式。
