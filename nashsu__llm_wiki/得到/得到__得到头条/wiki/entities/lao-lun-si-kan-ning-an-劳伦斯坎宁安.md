# 劳伦斯·坎宁安（Lawrence Cunningham）

乔治华盛顿大学研究教授，从1996年以来帮[[wo-lun-ba-fei-te-沃伦巴菲特|巴菲特]]撰写股东信，相当于巴菲特的"御用编辑"。

## 著作

著有《超越巴菲特的伯克希尔》（[[chao-yue-ba-fei-te-de-bo-ke-xi-er-超越巴菲特的伯克希尔]]），该书回答"假如没有巴菲特，伯克希尔还能好吗"这一问题，论证[[bo-ke-xi-er-ha-sha-wei-伯克希尔哈撒韦|伯克希尔]]可以超越巴菲特。
