# 亚马逊（Amazon）

亚马逊是全球最大的电商平台之一，也是本来源中直播带货“起个大早，赶个晚集”的典型案例。

## 直播带货历程

- **2016年3月**：首次推出Style Code Live直播秀，仅展示时尚单品，不支持直播中下单，因功能单一、无法形成商业闭环，一年后停播
- **2019年**：推出直播购物频道Amazon Live，但不温不火
- **2022年**：在TikTok、脸书和YouTube跑通直播购物后奋起直追，重点发力直播带货

## 2022年Prime Day

7月中旬举办Prime Day“夏日活动季”大促（相当于京东618）。直播购物频道Amazon Live邀请众多明星和网红当带货主播，包括喜剧演员凯文·哈特、模特米兰达·可儿等，还花重金从TikTok和Instagram挖头部网红。预计大促期间销售额125亿美元，同比增长8%。

## 背景

自2021年7月贝索斯卸任CEO以来，亚马逊股价跌去40%，电商业务增长停滞，直播带货被视为扭转电商颓势的方案。

## 其他

亚马逊也是入局毫米波雷达智能家居应用的科技巨头之一。
