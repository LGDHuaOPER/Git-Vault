# Hybrid 3

Hybrid 3是通用汽车推出的碰撞测试假人系列，1977年投入市场，是全世界最通用的假人。

## 特点

- 用完之后可以重新校准，重复使用。
- 是Hybrid系列经过几次迭代后的第三代产品。
- 中国湖南赛孚汽车科技已可生产Hybrid 3系列假人。

## 背景

1966年美国国会通过国家交通和机动车安全法，规定汽车强制配备安全带，并要求企业开发高准确度的碰撞测试假人。通用公司随即推出Hybrid系列第一代，经迭代后于1977年推出Hybrid 3。参见 [[peng-zhuang-jia-ren-碰撞测试假人]]。
