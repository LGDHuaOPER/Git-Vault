# 李春宇

[[bei-jing-shi-hai-dian-wei-lai-xue-xiao-北京市海淀未来学校]]科学课负责人，观察并总结了"允许打小抄"案例中学生小抄的两极分布现象。

## 发现

- 处在两极的学生（学习好到什么都不需要抄、或学习差到不知道要抄什么）都很少，绝大多数学生处在中间地带。
- 小抄内容可诊断学习问题：
  - 抄文字推理过程 → 对深层次逻辑推理问题没有把握。
  - 抄大量细节、重点难点 → 总体知识结构理解没问题，只是没有充分练习掌握细节。
  - 抄易错点 → 经常在该点犯错，可能尚未将解决问题的思路流程化。
