# True Accord（真正协议）

True Accord（中文译名"真正协议"）是一家美国催收公司，在谷歌上评分高达4.8分（满分5分），被评价为"美国有史以来最受欢迎的催收公司"。其特别之处在于，表达感谢的不仅有债权人，还有很多债务人——债务人表示多亏这家公司帮助自己摆脱债务困扰。

## 核心方法论

True Accord的做法可概括为一句话：**不是把债务人当对头，而是把债务人当成用户，为债务人提供良好的催收体验**。其本质是把债务人当成用户，为他们提供好用的产品。

## 三阶段产品设计

1. **预催收环节**：开发[[retain]]SaaS产品，用于债务正式到期前的提醒。银行、商超可用它提醒债务人还款，消费者也可管理账单、设定还款时间和自助支付。
2. **逾期环节**：设计[[recover]]产品，从不打电话只发邮件，保住债务人面子。邮件标题由软件根据债务人公开信息（年龄、性别、欠款金额）自动生成，实现[[qian-ren-qian-mian-you-jian-biao-ti-千人千面邮件标题]]。Recover每周只发三次邮件，却创造65%的开信率。由于机器发邮件成本极低，接单标准低至3美元债务。
3. **弹性还款**：派专人提供人工服务，讨论还款弹性、讨价还价甚至给出折扣。催收公司佣金通常为20%-30%，长期欠款甚至超过50%，让渡5%收益换取还款完全值得。债务人还可提出自己的还款方案，双方共同商讨。

## 成效

通过逾期前置管理、个性化催款邮件、有弹性的还款服务三阶段设计，True Accord催收成功率比同行高出50%。
