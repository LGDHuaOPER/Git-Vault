# IPv6

IPv6 是"互联网协议第6版"（Internet Protocol Version 6）的英文缩写，是最新一代互联网协议。目前广泛使用的还是 IPv4（互联网协议第4版）。

## 为什么需要 IPv6

在 IPv4 协议下，全球的 IP 地址数量不够用了。随着互联网在发展中国家逐渐普及，以及各种智能设备爆发式增长，需要越来越多的 IP 地址。到 2019年11月26日，欧洲网络协调中心（RIPE NCC）宣布 IPv4 地址耗尽，不会再有 IPv4 地址分配给网络提供商。

## 地址数量对比

- IPv4 地址数量：2的32次方，约 42.9 亿个
- IPv6 地址数量：2的128次方，是天文数字，就算给地球上的每一粒沙子都分配一个 IP 地址也绰绰有余

## 其他优点

IPv6 除了扩展 IP 地址外，还有更高的安全性、更大的扩容性、更简化的格式等优点。

## 与 IPv6+ 的关系

北京冬奥会使用的奥运专网，是建立在 IPv6 协议上的新一代网络技术，叫做 [[IPv6+]]。IPv6+ 是 IPv6 的增强演进，具备网络切片、快速部署等能力。
