# 腾讯云

腾讯云是国内云计算大厂，以 [[iaas|IaaS]] 为主，利润率长期在个位数。

## 业务现状

- 与 [[aliyun-阿里云|阿里云]]、[[huawei-cloud-华为云|华为云]] 情况类似，面临 [[运营商云]] 强势崛起的竞争压力。
- 正从亚马逊模式转向微软模式，从主要做 IaaS 到重点发展 [[paas|PaaS]] 和 [[saas|SaaS]]。

## SaaS 竞争

企业微信是腾讯在 SaaS 业务竞争中的重要产品。钉钉、企业微信、飞书杀成一团，其实不只事关单个产品，而是对 SaaS 业务的争夺。
