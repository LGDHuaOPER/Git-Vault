# Linux

Linux是最成功的[[开源项目]]之一，持续更新超30年，全球数万程序员参与开发。

## 文化意义

- 是[[大教堂与集市|集市模式]]开发的典范，挑战了[[布鲁克斯法则]]的普适性
- 对Linux内核贡献1%的代码，即可在[[程序员荣誉体系]]中获得顶级声望
- 与[[GitHub]]共同构成开源文化的核心基础设施
