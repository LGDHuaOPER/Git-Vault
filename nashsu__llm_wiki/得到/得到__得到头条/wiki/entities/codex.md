# Codex

Codex 是 OpenAI 开发的超大型神经网络模型，经过数以亿计的代码训练后，能够通过阅读人类语言，理解语言想表达的意思，去掉与解题无关的多余信息，同时把语境背后的隐含条件补齐，最后用编程语言写出来。

## 核心能力

- **自然语言到代码的翻译**：将人类语言描述转化为可运行的编程代码，是[[codex翻译机制]]的核心载体。
- **隐含条件补齐**：能够理解文字背后的隐含知识（如扑克牌52张、4种花色），这是[[隐含条件补齐]]的关键实现。
- **普通人开挂**：不会写代码的人也能通过自然语言描述生成可运行的游戏程序。

## 应用示例

- **解数学题**：麻省理工学院等四所高校联合研究团队使用Codex开发的神经网络程序，可解答微积分、线性代数等大学数学题，正确率达100%（数月前同类题最高正确率不到10%）。
- **生成游戏**：2021年8月Codex发布会上，演示了用几百字文字描述自动生成飞机大战、躲砖块等游戏。

## 德州扑克题翻译示例

原题："在德州扑克游戏中，拿到两副对子的概率是多少？"

Codex翻译后："一副牌有5张，从13组牌、每组4张、共52张牌中，随机抽取。抽到两副对子，要求5张牌中一共有3种牌，每种数量最多两张。请问抽到两副对子的概率。"

## 相关讨论

- Codex的"理解"本质是真正的语义理解还是大规模模式匹配，仍是开放问题（见[[codex能否真正理解自然语言]]）。
- 与Wiki中[[低代码开发]]、[[人人都是开发者]]概念高度相关——Codex是自然语言编程的典型代表。
- 有读者指出，AI可以学习理解语言的通用含义，但恐怕无法破解语言背后的情绪、一语双关等。
