# OpenClaw

OpenClaw，昵称“龙虾”，是一个住在用户电脑里的私人助理型 AI 工具。只要是需要使用电脑完成的事情，它大多数都能干，前提是使用方法得当。

## 技术内核与定位

OpenClaw 用到的技术并非全新。它的内核是 [[Claude-Code]]，程序员早已在使用，类似工具还有 [[Cursor]]、[[GitHub-Copilot]]。这些工具的本质都是让 AI 帮你写代码、改代码、操作电脑。对专业程序员来说，让 AI 接管电脑、自动执行任务并不新鲜。

OpenClaw 火爆的关键原因在于**平民化**：它把“一小撮人的能力”推到了普通人面前。它也许不是技术最先进的，但它是“平民化”做得最好的 AI 工具之一。它把入口变成了聊天工具——打开微信、钉钉、飞书就能对话，让它处理文件、发邮件、写报告、整理日程，不需要学编程、不需要懂技术。

## 三大关键设计

1. **统一入口**：把所有 AI 能力整合到一个聊天界面，无需在多个工具间切换
2. **持久化记忆**：存储对话、习惯、需求，定期自动 review 日志，越用越懂用户
3. **插件生态**：开源插件市场，类似 App Store，驱动飞轮效应

## 发展时间线

- 2025年11月：创始人 [[彼得-斯坦伯格]] 用一小时把聊天软件和 Claude Code 连接起来，做了个小工具，后开源
- 项目先后命名为 Clawdbot、Moltbot，因商标问题最终改名 OpenClaw
- 2026年1月25日：OpenClaw 正式发布
- 2026年2月16日：斯坦伯格加入 [[OpenAI]]，项目转交独立基金会运营，OpenAI 提供资源支持
- 2026年3月：工业和信息化部发布安全风险提示

## 生态与市场动态

- 过去4个月已有300到400位来自全球12个国家的开发者参与贡献插件和功能
- 深圳龙岗区发布“龙虾十条”政策，对基于 OpenClaw 的初创企业最高给予1000万元股权投资
- 闲鱼上代安装服务价格涨到500元左右，有的程序员靠替人装龙虾一天能挣好几万元
- 腾讯云、阿里云、字节推出一键部署方案，月费38到99元不等
- [[猎豹移动]] 基于 OpenClaw 原版打造 [[EasyClaw]]，省去繁琐专业环节

## 安全隐患

工业和信息化部2026年3月发布风险提示，指出 OpenClaw 在默认配置下存在较高安全风险：它拥有系统级权限，可能因为指令诱导、配置缺陷或被恶意接管，执行越权操作。目前很多运行 OpenClaw 的电脑直接连在互联网上且没有安全防护，黑客理论上可直接发起攻击。插件市场中部分插件含恶意代码，可能窃取 API 密钥、钱包凭证、邮箱密码。

## 使用成本

费用跨度非常大。很多 API 提供免费额度，只使用这些额度几乎不花钱。但一旦启动稍微复杂的任务，token 消耗极快，一天花出去上百美元并非难事。此外，[[心跳机制]] 默认每30分钟唤醒一次，本身消耗不少 token。
