# 国家电网

国家电网是中国大型能源企业。2025年开始批量招聘“电网巡检AI训练师”，招的不少人是干过十年以上一线巡检的老师傅。

## 岗位特点

电网巡检大量用无人机加AI识别，AI经常出错（如把树叶阴影识别成绝缘子破损，或漏掉真正危险的螺栓松动）。老师傅不写代码，而是坐在屏幕前看AI标注结果，一个个判断对错，把判断反馈给算法团队。他连接的一端是算法，另一端是电网上那些只有老师傅才知道的经验。
