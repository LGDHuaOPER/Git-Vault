# IPv6+

IPv6+ 是建立在 IPv6 协议之上的新一代 IP 网络技术，具备网络切片、快速部署等能力。北京冬奥会使用的奥运专网即建立在 IPv6+ 技术上，这也是 IPv6+ 技术第一次应用在大型国际比赛上。

## 技术背景

IPv6（互联网协议第6版）是最新一代互联网协议，替代 IPv4 的主要原因是 IP 地址不够用。2019年11月26日，欧洲网络协调中心（RIPE NCC）宣布 IPv4 地址耗尽。IPv4 地址数量约 42.9 亿个（2的32次方），IPv6 为 2的128次方，是天文数字。

## 核心能力

- **一张网走天下**：通过[[网络切片]]功能，把一张网切成不同专用频道，替代以往每个业务单独建专网的模式。不同业务既可以同时跑在一条网上，又有安全隔离。
- **紧急需求快速响应**：临时增加直播或采访信号，以往需要 3 天以上，本届冬奥会几分钟即可部署完成。

## 在冬奥会的应用

北京冬奥会设"两地三赛区"，从北京赛区到张家口赛区约 200 公里，共 87 个奥运场馆，超过 15 万台终端设备接入冬奥会专网。IPv6+ 支撑了 8K 超高清直播、[[自由视角]]、[[子弹时间]]等转播技术。

IP 网络是 5G 网络的上游：5G 只解决从基站到移动端的网络，数据到基站后还需通过有线传输汇聚到骨干网（IP 网络）。如果 IP 网络传输不给力，5G 再厉害也发挥不出作用。

## 信源与局限

本期对 IPv6+ 的效能描述主要来自华为首席IP协议专家[[李振斌]]（IETF 互联网架构委员会 IAB 委员），存在利益相关方信源偏差的可能，缺乏独立第三方验证。热门留言中[[中国联通]]被反复强调为冬奥网络建设主体，华为与联通在冬奥网络中的具体分工边界并不清晰。
