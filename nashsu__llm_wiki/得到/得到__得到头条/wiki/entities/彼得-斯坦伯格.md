# 彼得·斯坦伯格

彼得·斯坦伯格（Peter Steinberger），奥地利人，连续创业者，[[OpenClaw]] 的创始人。

## 背景

2021年，他把自己创立的 PDF 工具公司卖掉，获得约1.19亿美元，随后“提前退休”。

## 周末项目与 OpenClaw 的诞生

OpenClaw 最初只是他的一个周末项目。2025年11月的某个周末，他用一个小时把聊天软件和 Claude Code 连接起来，做了个小工具自己用着玩，发现挺好用就开源了。项目先后命名为 Clawdbot、Moltbot，因商标问题最终改名 OpenClaw。4个月后，这个周末项目在程序员圈子里爆火，成为现象级产品。

## 加入 OpenAI

2026年1月25日，OpenClaw 正式发布。2026年2月16日，斯坦伯格加入 [[OpenAI]]。OpenClaw 项目转交给独立基金会运营，OpenAI 提供一切资源支持。

## 方法论意义

斯坦伯格对待新技术的方式被称为“周末项目”——不是盲目 all in，也不是原地焦虑，而是好奇心驱动的尝试。他不是因为看到了商机才做 OpenClaw，而是因为自己有需求，想做个工具自己用。结果做出来了，发现好用，就分享出来了。这一方法论是本期节目的重要启示，详见 [[周末项目]]。
