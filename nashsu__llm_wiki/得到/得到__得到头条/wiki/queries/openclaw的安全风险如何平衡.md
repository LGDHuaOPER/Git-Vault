# OpenClaw 的安全风险如何平衡？

## 问题背景

[[OpenClaw]] 在安全风险尚未完全解决时已大规模流行。工业和信息化部2026年3月发布风险提示，指出 OpenClaw 在默认配置下拥有系统级权限，可能因指令诱导、配置缺陷或被恶意接管而执行越权操作。插件市场中部分插件含恶意代码，可能窃取 API 密钥、钱包凭证、邮箱密码。
