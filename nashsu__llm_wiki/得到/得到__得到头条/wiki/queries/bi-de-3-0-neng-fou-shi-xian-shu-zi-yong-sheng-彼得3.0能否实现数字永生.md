# 彼得3.0能否实现数字永生？

## 问题背景

[[peter-scott-morgan]]认为，未来作为"赛博格"存在的他死了，而这些年记录了他的全部生活数据、由他的思想驯化出来的人工智能还将不断进化，将作为"彼得3.0"继续活下去。

热门留言中"啊辉"提出类似疑问：彼得3.0会不会自动升级为4.0？未来能否在生前输入足够多的数据到AI、足够多地训练AI模型，从而"永存在网络里面"？

## 开放问题

1. **技术可行性**：由生活数据驯化的AI能否真正延续一个人的"存在"？这涉及AI是否具备自我意识的问题，参见[[ai-shi-fou-ju-bei-zi-wo-yi-shi-ai是否具备自我意识]]。
2. **伦理边界**：热门留言"钱清渠"指出，脑机接口等技术应用越来越广，但"对于生命、对于伦理也会有新的边界跟含义"。
3. **数字人格延续**：彼得3.0的设想涉及数字人格延续的伦理问题——由数据驯化的AI是否可以被视为原初人格的延续？
