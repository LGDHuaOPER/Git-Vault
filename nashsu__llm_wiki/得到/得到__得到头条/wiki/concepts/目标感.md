# 目标感

目标感是[[脱不花]]在得到沟通训练营中重新定义的一个职场概念。传统理解中，目标感强意味着“知道目标并努力去做”，但脱不花指出，**目标感的真正内涵是将大目标分解为若干个小台阶的能力，并清楚当下每一个动作与终极目标的关联**。

## 核心定义
- **不是**知道终极目标是什么。
- **而是**把遥远的大目标拆解为今天就能做的小目标，一步一步推进。
- 即使最终未达成大目标，目标感强的人也不会沮丧，而是看到已有的进展并继续想办法。

## 销售场景示例
对于销售而言，“成单”是终极目标，但目标感强的做法是：
1. 客户没有挂断我的电话 → 小目标达成
2. 客户同意拜访请求 → 下一个台阶
3. 约到面谈十分钟 → 再下一个台阶
4. 在微信上保持联系 → 持续推进
5. 最终指向签单结果

## 领导反馈的解读
当领导说“你目标感不强”时，批评的不是你不知道目标，而是你不知道当下每一个动作与终极目标之间的关联，以及缺乏一步一步推进的能力。
