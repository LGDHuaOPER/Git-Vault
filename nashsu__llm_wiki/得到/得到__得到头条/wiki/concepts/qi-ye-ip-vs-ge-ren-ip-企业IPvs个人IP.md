# 企业IP vs 个人IP

企业IP与个人IP是直播电商领域的两种IP类型，本文的核心论点围绕二者的区别展开。

## 核心区别

**个人IP不可能24小时在线，只能是脉冲式地"搞事情"，而企业IP可以24小时不打烊，给你充分的确定性。**

个人IP说白了就是用户信任这个人，比如他卖的东西肯定是正品、东西出了问题能在第一时间得到赔付、大牌商品能拿到特别划算的价格。个人IP的局限在于无法持续在线，且依赖单一个体的状态。

企业IP则是一个"24小时不打烊的百货商店"形象：东西好、营业员素质高、无论什么时候去它都在。一旦直播间在用户心中树立了这样的"百货商店"形象，它就是一个来买东西的地方，而不是一个围观名人表演的舞台。
