# 动漫IP赋能品牌

动漫IP赋能品牌是一种商业模式：用动漫故事为品牌做形象代言，通过故事与用户建立情感连接，从而为品牌创造长久稳定的品牌载体。

## 核心机制

1. **动漫偶像永不塌房**：与真人明星不同，动漫形象不会出现偶像塌房事件，不会把代言品牌拉下水。
2. **与企业永久绑定**：明星与品牌的合作是暂时的，明星不是品牌的永久资产；动漫IP则与企业永久绑定，营销费用能积累到品牌自身。
3. **用故事建立情感连接**：动漫的本质是用形象讲故事，用故事跟用户发生情感连接。

## 典型案例

### 江小白

2016年，[[liang-dian-shi-fen-dong-man-两点十分动漫]]与[[jiang-xiao-bai-江小白]]合作创作《我是江小白》动漫剧，被评为2017年年度十大国漫，全网播放量超10亿次，每集主角名字被提到10次以上，相当于品牌被传播了100亿次。

### 游戏行业

动漫不仅能为消费行业赋能，还可以为任何想与用户保持情感连接的行业赋能。例如为游戏角色塑造丰满形象，让玩家爱上游戏角色，延长游戏生命周期。两点十分与网易游戏阴阳师工作室、《王者荣耀》等均有合作。

## 商业模式结构

两点十分目前总营收中，1/3来自番剧和动漫电影制作，2/3来自与消费品牌和游戏厂商的合作。这一盈利模式反过来支撑原创动画之梦。

## 与相关概念的关系

- [[kua-hang-ye-jie-ti-跨行业解题]]：动漫IP赋能品牌是跨行业解题的具体应用——动漫公司在本行业（播出平台、IP变现）内难以盈利，答案在行业之外（为品牌赋能）。
- [[nei-rong-ip-vs-xing-xiang-ip-内容IPvs形象IP]]：动漫IP赋能品牌本质上是为形象IP注入内容，使其向内容IP转变。
