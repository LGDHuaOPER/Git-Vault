# 香蕉等效剂量（BED）

香蕉等效剂量（Banana Equivalent Dose，BED）是科学界通行的衡量核辐射剂量的单位，以"相当于吃了多少根香蕉"来描述受辐射量。

## 科学基础

香蕉含有放射性元素钾-40，在全世界所有钾元素中，钾-40约占0.01%。一根香蕉的钾含量约为0.1微西弗（微西弗是衡量辐射剂量的单位），这个数值方便计算。

## 日常辐射量对比

| 场景 | 辐射量 |
|------|--------|
| 办公室正常工作 | 约100蕉 |
| 身边有人睡觉 | 约0.5蕉 |
| 吃100克巴西坚果 | 约100蕉 |
| 牙科X光片 | 约50蕉 |
| 胸部透视CT | 约62000蕉 |
| 坐飞机 | 约每小时100蕉 |
| 英国人一年受辐射剂量 | 约27000蕉 |
| 美国人一年辐射量 | 约62000蕉 |

## 安全边界

- 一个月内吃掉5000万根香蕉才达到辐射致死剂量
- 一天7根香蕉为摄入上限，吃多了容易钾超标，影响心脏正常跳动
- 香蕉中的钾元素能帮助稳定心脏跳动，可放心食用
