# 医疗3.0（Medicine 3.0）

医疗3.0是阿提亚（Peter Attia）提出的医疗范式概念，主打预防，在离衰老还很遥远时就开始做准备。

## 三个时代

- **医疗1.0**：19世纪那会儿的医疗，属于不了解原理，治病靠碰运气。
- **医疗2.0**：现在正在发展中的医疗科学，医疗水平高了，原来很多高致死率的疾病都有治了。但很大程度上针对的是已经出现症状的疾病，对那些伤害身体但没有显示出症状的疾病就没法解决。
- **医疗3.0**：主打预防，在疾病症状出现前干预。

## 医疗2.0的局限

医疗2.0最没办法应对的是"四骑士"——心脏病、癌症、2型糖尿病、神经退行性疾病。这些慢性病不会像急性病那样突然要命，但却是真正的健康杀手，也是现在导致死亡最多的慢性病。

例如：
- **2型糖尿病**：美国糖尿病学会标准是血红蛋白A1c达到6.5%时开始用药，但在此之前患者已经是不健康状态，甚至不健康很久了。
- **心血管疾病**：主要原因是动脉粥样硬化，过程非常缓慢，很可能在一个人很年轻的时候就开始了，要想改善就得提前很久干预。
- **阿尔兹海默症**：很可能跟基因有关，但医学研究发现开展"认知训练"是很好的预防。
- **癌症**：很多癌症发现时已是晚期，最佳策略仍是早筛查、早发现、早治疗。
