# 呼吸链断裂

**呼吸链断裂**是《90%的不舒服，呼吸就能解决》一书中提出的核心解释框架，用于将多种看似无关的身体不适症状统一归因于呼吸方式错误。

## 连锁反应机制

呼吸链断裂描述了一个多米诺骨牌式的连锁反应：

1. **呼吸变浅** → 吸入的氧气减少
2. **血液含氧量下降** → 血红蛋白携带的氧气不足
3. **线粒体功能受阻** → 细胞的"能量工厂"无法正常工作
4. **细胞能量不足** → 各器官运作不良
5. **各种不适症状出现** → 慢性疲劳、肩膀酸痛、驼背、代谢下降、肥胖等

## 典型表现

- **慢性疲劳**：即使睡够8小时仍觉疲惫，可能源于夜间浅呼吸导致氧气供应不足
- **肩膀酸痛与驼背**：浅呼吸时身体不自觉地耸肩，用肩膀和脖子肌肉辅助呼吸，长期导致肌肉紧张僵硬
- **代谢下降与肥胖**：细胞能量不足导致基础代谢率下降，更易囤积脂肪，且疲劳使人更不想动，形成恶性循环

## 根本原因

现代生活方式（久坐办公、压力大、生活不规律）与人类在远古狩猎时代定型的呼吸系统不适配，导致人们不自觉地使用错误的呼吸模式。
