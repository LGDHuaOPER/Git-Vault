# 超级IP

超级IP指具有极强个人影响力和粉丝号召力的主播或个人品牌。在董宇辉离职事件中，董宇辉被[[liang-ning-梁宁]]称为"超级脉冲"式的超级IP，其才华、亲和力和悲剧感催生出"丈母娘天团"，生发出逆天的影响力。

## 超级IP的特征

- 不可复制：超级主播没法复制，伴随很大随机性（[[xiang-shuai-香帅]]）
- 效益集中：公司大量投入，但产出的效益集中在主播这个容器里而非公司容器（[[liu-run-刘润]]）
- 自带角色感：影视行业概念，指演员自带的可被代入角色的特质，是"选出来的"而非塑造出来的

## 与稀缺视角的关系

节目结尾指出，董宇辉的IP属性很大程度上属于个人稀缺性。从[[zi-yuan-shi-jiao-vs-xi-que-shi-jiao-资源视角vs稀缺视角]]看，资源集中在公司手上，而稀缺性往往集中在个人身上。这与[[x-yin-su-X因素]]概念高度相关——稀缺性很大一部分来自"X能力"，不可刻意而为之，而是天性与天赋在生活的刀光剑影中磨练出来的。
