# 强准备

强准备是一种将不确定性转化为确定性的行动哲学，也是一种通过提前准备获得秩序感与掌控感的方法论。

## 理念出处

不同来源对“强准备”的提炼背景有不同的表述：

- 依据 [[得到头条/MD/1234.833｜“假如这件事需要靠运气，我根本不会开始”.md]]，强准备源自美国攀岩家 [[亚历克斯-霍诺德]] 的徒手攀岩实践。
- 依据 [[得到头条/MD/182.181｜怎样当好一名外卖骑手？.md]]，强准备是热门留言（美君）从外卖骑手案例中提炼的核心方法论。

## 核心理念

### 攀岩案例中的核心理念

亚历克斯的名言概括了这一哲学的精髓：

> “如果我需要靠运气才能成功，那我根本不会开始。”

强准备的核心主张是：真正的勇气并非依赖运气或临场反应，而是通过极致的准备，在自身具备充分确定性的前提下，去应对挑战。

强准备划定的边界是：**不能在“自己本身就很不确定”的情况下，去“拥抱不确定性”**。准备的质量决定了拥抱不确定性的资格。

### 外卖骑手案例中的要点

在骑手案例中，热门留言（美君）将“准备两台电动车、随身携带充电宝、不乱停放”等做法总结为强准备。表面上是做事周到细致，实质是通过强准备让自己更有秩序感和掌控感，从而在做事过程中呈现出踏实稳重的状态。其要点包括：

1. **强准备**：提前想好可能遇到的各种情况，心里总有 Plan B。
2. **利他就是利己**：为别人节省时间（核对仔细、拍照沟通），让自己做事高效的同时更真诚靠谱。
3. **磨刀不误砍柴工**：提前扫清障碍，掌握足够的信息颗粒度。

## 三步法（攀岩案例）

强准备的具体实施包含三个步骤，统称为 [[拆解不确定性]]：

### 1. 拆解目标

将宏大目标拆解为可记录、可执行的动作序列。例如，亚历克斯将台北101的101层拆解为若干段，每段详细记录抓握点、蹬踏位置、重心移动和身体感受。通过拆解，整体挑战变为一组可分别应对的小挑战。

### 2. 反复练习

通过大量重复，将动作刻入身体，形成本能反应。其神经科学基础是 [[髓鞘化]]：反复练习同一动作时，髓鞘包裹神经元轴突，大幅提升电信号传递速度，使动作最终变为本能。

### 3. 预演风险

提前想象最坏情况，将恐惧从“未知”变为“已知”，并制定应对预案。亚历克斯在攀登前一天会专门花时间想象握点断裂、失手坠落等最坏场景，并为每一个“假如”准备应对方案。

## 生活化应用（攀岩案例资料）

强准备方法论可迁移至多种场景：

- **演讲准备**：拆解为开场、核心观点、互动等部分；对着镜子反复练习至每句话对应特定手势和语气；预演忘词、被质疑、时间不足等风险并准备预案。
- **外语学习**：将5000个单词拆解为每日30-50个的定量任务；通过大声朗读、联想记忆等方式反复练习。
- **项目管理**：将复杂项目拆分为小段，明确交付物和检查点；提前列出易出错的关键步骤并反复核对；预演数据晚到、需求变更等意外情况。

## 与其他概念的关联

### 攀岩案例资料中的关联

- 与 [[可控风险]] 互补：强准备是实现可控风险的具体路径。
- 与 [[确定性逻辑]] 和 [[探索性逻辑]] 的辩证关系：在拥抱探索性目标时，需要通过确定性的准备来铺平道路。
- 与 [[框架内灵活]] 相通：在充分准备的框架内，保留应对意外的灵活性。

### 外卖骑手案例资料中的关联

- 与 [[跑单系统工程]] 的“装备不掉链子”环节直接相关。
- 与 [[信息颗粒度]] 概念相通——都需要提前下功夫。
- 热门留言（Ricky）引用 [[侯世达定律]] 论证预留时间的重要性，与强准备理念一致。

## 适用边界（攀岩案例资料）

强准备适用于可提前规划、有充足准备时间的场景。在需要快速响应、无法充分准备的“混沌”场景下，其适用性可能受限。这一问题值得进一步探讨。
