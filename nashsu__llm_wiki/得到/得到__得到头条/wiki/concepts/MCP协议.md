# MCP协议（模型上下文协议）

MCP，全称Model Context Protocol（模型上下文协议），是一套标准化接口，让AI能像人一样自主学习和使用各种外部工具。

## 核心功能

MCP为AI模型提供了标准化的"门窗"，使其能够：
- 看到外部世界的工具
- 自主学习如何使用这些工具
- 不受特定软件生态的绑定，自由调用各种工具

## 发展历程

- **2024年底**：MCP协议首次发布，当时为实验性项目
- **2025年3月26日**：经历重大更新
- **2025年11月底**：发布一周年更新，定位为"实用基础设施"

## 技术意义

MCP协议是打破软件功能封闭性的关键技术。传统软件公司通过封闭生态绑定用户，而MCP使AI能够跨生态调用工具，哪个工具好用用哪个，从根本上瓦解了软件行业的生态壁垒。

Claude Cowork的插件系统即建立在MCP协议之上。
