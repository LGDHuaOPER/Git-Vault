# 新能源五大方向

新能源领域的主要方向只有五个：风、光、车、储、氢，即风能发电、光伏发电、新能源汽车、储能和氢能。大多数上下游产业布局都围绕这五个分支展开。

## 各方向成熟度

| 方向 | 状态 |
|------|------|
| 风（风能发电） | 相对成熟，机会大但竞争激烈 |
| 光（光伏发电） | 相对成熟，机会大但竞争激烈 |
| 车（新能源汽车） | 相对成熟，机会大但竞争激烈 |
| 储（储能） | 正值爆发当口，有很多快速增长的公司 |
| 氢（氢能） | 处于技术早期阶段 |
