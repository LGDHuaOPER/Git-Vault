# 生命1.0/2.0/3.0（生命三层次）

人工智能专家[[tai-ge-ma-ke-泰格马克]]提出的理论框架，将生命分为三个层次，用以解释生命能力的获取方式。

## 三个层次

- **生命1.0**：不会制造工具，一切能力都需要靠进化来获取。地球上所有的生命，除了人，都属于生命的1.0阶段。
- **生命2.0**：硬件靠进化，而软件可以自己设计。身体来自先天，无法自我改造，但大脑里的知识可以通过后天学习获取。人就属于这个阶段。
- **生命3.0**：硬件和软件都可以自己设计。科幻电影里的AI机器人就属于这个层级，它们可以任意改造自己的身体和程序。

## 在黄仁勋演讲中的运用

[[huang-ren-xun-黄仁勋]]借用这一理论框架解释其对AI终极图景的判断：未来AI发展的终极图景就是生命的3.0版本——"能够设计程序的程序，能够创造AI的AI"。黄仁勋早前曾说过，未来一定会出现能够设计程序的程序、能够创造AI的AI。

**注意**：这一"生命3.0"图景属于黄仁勋和泰格马克的预测性观点，而非已实现的事实。来源将其作为黄仁勋对AI长期趋势的研判来呈现。
