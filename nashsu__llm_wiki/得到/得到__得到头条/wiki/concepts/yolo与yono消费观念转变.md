# YOLO与YONO（消费观念转变）

描述消费观念从"今朝有酒今朝醉"到"精打细算"转变的两个口号。

## YOLO（You Only Live Once）

"你只活一次"，信奉今朝有酒今朝醉。过去被认为是年轻人的消费观念。

## YONO（You Only Need One）

"你只需要一个"，代表精打细算，绝不多买。年轻人从YOLO进化到YONO，反映了消费观念的转变。

## 在504期中的角色

文章以YOLO到YONO的转变为引子，指出年轻人量入为出可以理解，但不寻常的是很多富有的人明明很有钱却舍不得花——引出[[jin-suo-xing-xiao-fei-zhe|紧缩型消费者]]的话题。
