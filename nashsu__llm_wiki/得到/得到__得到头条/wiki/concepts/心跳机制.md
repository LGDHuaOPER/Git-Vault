# 心跳机制

心跳机制是 [[OpenClaw]] 的一个技术细节，也是其使用成本的重要来源。

## 定义

心跳机制指 OpenClaw 不会彻底休息，而是时不时就要“站起来，在电脑里溜达一圈”。具体说，是默认每30分钟唤醒一次，光是这一项就要消耗不少 token。

## 成本影响

心跳机制是 OpenClaw 使用成本的重要组成部分。虽然很多 API 提供免费额度，但一旦启动稍微复杂的任务，token 消耗极快，一天花出去上百美元并非难事，心跳机制进一步加剧了消耗。
