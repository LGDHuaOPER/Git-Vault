# 学校作为互相成就的生态系统

李希贵校长对理想学校组织结构的比喻。每个人都有自己的位置，同时每个人都在为别人的成功而努力——因为别人成功了，自己才能成功。

## 正向循环链

- **学生成功** → 老师脸上有光，工作有成就感 → 老师会想方设法支持学生。
- **老师成功** → 班级好，年级就好 → 年级组长工作顺利 → 年级组长会想办法给老师提供各种支持。
- **教学体系成功** → 学校声誉好 → 财务、人力、行政等部门的工作才有价值 → 支持部门主动服务教学一线。

## 评价原则

- **你盼着谁好，你就服务谁。**
- **你服务谁，你的工作成果就由谁评价。**
- 学生可以评价老师，老师可以评价支持部门。

## 核心效果

一旦一个人盼着别人好，他就会主动靠近对方，去观察对方的个性化发展。好的生产关系能激发生产力。
