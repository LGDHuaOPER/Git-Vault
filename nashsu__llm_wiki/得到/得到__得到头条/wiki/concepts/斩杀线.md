# 斩杀线

"斩杀线"原为游戏术语，指一个Boss在承受足够伤害后，达到"濒临崩塌"的临界点——只需一击即可将其彻底斩杀。跌破这条线后，再强大的Boss也只有等死的份。

## 社会现象引申

2025年末，"斩杀线"被用来描述一种美国社会现象：个人财务状况跌破某个临界点后，触发一连串连锁崩溃，最终无力回天。

### 典型连锁链条

1. 突发疾病 → 欠下医疗账单（数千至数万美元）
2. 医疗账单付不起 → 信用分暴跌
3. 信用分暴跌 → 车贷违约 → 车被收回
4. 没有车 → 无法上班（美国很多地方依赖汽车通勤）
5. 信用差 → 房东拒绝租房 → 失去住所
6. 失去住所 → 无法通过雇主背景调查 → 失业
7. 失业 → 收入归零 → 债务滚雪球
8. 最终沦为流浪者

### 结构性背景

- 美国是经合组织国家中少数没有实施全民医保的国家
- 大量人口没有医疗保险
- 医疗费用极高（一场急诊可能花费数千至数万美元）
- 保险公司拒赔率高，即使有保险也可能因各种理由被拒赔

## 普遍意义

尽管"斩杀线"现象高度依赖美国特定制度（医保、信用体系），但其揭示的**财务脆弱性连锁崩溃机制**具有普遍意义：一次意外冲击可能触发一系列不可逆的负面连锁反应，最终导致财务底线彻底失守。
