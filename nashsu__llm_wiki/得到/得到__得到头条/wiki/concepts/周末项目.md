# 周末项目

周末项目是本期节目提出的对待新技术的方法论，源自 [[OpenClaw]] 创始人 [[彼得·斯坦伯格]] 的成功路径。

## 定义

周末项目指好奇心驱动的个人项目开发方式——不是盲目 all in，也不是原地焦虑，而是从自身需求出发，做个小工具自己用。斯坦伯格不是因为他看到了商机才做 OpenClaw，而是因为自己有需求，想做个工具自己用。结果做出来了，发现好用，就分享出来了。

## 案例

2025年11月的某个周末，斯坦伯格用一小时把聊天软件和 Claude Code 连接起来，做了个小工具自己用着玩。4个月后，这个周末项目在程序员圈子里爆火，成为现象级产品。

## 方法论启示

对待新技术，不用那么焦虑，不用担心被时代抛下。如果你好奇、有需求，那就试试；如果暂时用不上，那就先等等，等它更成熟、使用门槛更低。但千万别丧失对新事物的好奇与兴奋。正如山姆·奥特曼所说：“跟随你的好奇心。让你兴奋的事情，对其他人来说也常常是令人兴奋的。”
