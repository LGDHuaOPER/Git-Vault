# 成于IP，困于IP

描述依赖单一IP的粉丝局限的概念。故事IP主题餐厅依靠IP的现有粉丝引流，但粉丝规模有限，且IP热度衰减不受餐厅控制。

## 出处

《陈情令》主题餐厅负责人自述的担忧：光靠《陈情令》的现有粉丝撑不起高频的高端消费，餐厅的未来发展需要靠《陈情令》IP的持续传播，而这不是餐厅自己能决定的。有可能，成于IP，也困于IP。

## 与IP三阶论的关系

“成于IP，困于IP”是[[ip-san-jie-lun|IP三阶论]]中中阶IP（故事IP）的核心局限。高阶IP（美食纪录片IP）如《人生一串》可突破粉丝局限，因为纪录片IP与门店氛围不违和，无论是否粉丝都可快速融入。

## 边界与张力

- 故事IP与纪录片IP的边界并非绝对清晰，纪录片IP也可能面临IP热度衰减问题。
- 为[[po-quan-li-lun|破圈理论]]提供边界条件：故事IP恰恰受限于粉丝圈层，只有纪录片IP才能突破圈层。
