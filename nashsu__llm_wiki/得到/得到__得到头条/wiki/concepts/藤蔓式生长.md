# 藤蔓式生长

藤蔓式生长是一种自下而上的适应性企业战略，由吴伯凡提出。其核心特征是：新业务并非事先规划，而是在解决旧业务实际问题时自然生长出来。

## 核心特征

- **非规划性**：新业务不是顶层设计或战略蓝图的结果
- **问题驱动**：在解决现有业务的具体痛点时发现新机会
- **能力溢出**：核心业务积累的能力自然延伸到相邻领域
- **渐进式跨界**：像藤蔓一样螺旋式延伸，而非跳跃式进入全新领域

## 与“按图施工”的对比

| 维度 | 按图施工 | 藤蔓式生长 |
|------|----------|------------|
| 方向 | 自上而下 | 自下而上 |
| 驱动力 | 前瞻性规划 | 适应性响应 |
| 典型特征 | 看到蓝图，逐步实现 | 解决问题，自然延伸 |
| 代表案例 | 华为5G/鸿蒙 | 华为智能验收平台/数字能源 |

## 典型案例

### 雅马哈
修钢琴 → 造钢琴 → 造木质家具 → 造飞机螺旋桨 → 造引擎 → 造机器人

### 华为
- 代理交换机 → 自研交换机
- 基站验收难题 → 智能验收平台 → 赋能电力、煤矿等行业
- 基站供电需求 → 智能配电技术 → 数字能源系统（成立子公司）

### 互联网行业
- **支付宝**：解决淘宝交易信任 → 第三方支付工具 → 金融生态产品
- **美团**：团购业务 → 外卖 → 即时配送网络 → 送药/社区团购
- **亚马逊**：电商业务 → AWS云服务
- **京东**：电商业务 → 自建物流

## 与暗能力的关系

藤蔓式生长与[[暗能力]]高度相关。暗能力是企业在解决核心业务问题时无意中培育出的能力，藤蔓式生长正是这些暗能力被识别、产品化并推向市场的过程。

## 组织条件

藤蔓式生长需要适宜的组织文化支撑：开放、鼓励从需求出发的创新、允许试错。如果战略规划是“土壤”，那么这种文化就是支撑藤蔓生长的“墙”。

## 对个人的启示

藤蔓式生长同样适用于个人发展：把眼前能做的事做到极致，新的机遇和方向会自然出现。路是走出来的，不是原地等出来或想出来的。
