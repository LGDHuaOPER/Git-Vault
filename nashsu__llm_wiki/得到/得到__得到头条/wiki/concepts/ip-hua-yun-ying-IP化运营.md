# IP化运营

IP化运营是指将游戏角色打造成虚拟偶像的策略。据《得到头条》360期分析，把游戏角色IP化可以"一石三鸟"，同时解决游戏行业三大难题。

## 解决的三大难题

1. **生命周期短**：游戏研发成本高（动辄上亿元），但平均生命周期只有8—12个月。当游戏角色成为虚拟偶像，热爱它的粉丝们会更愿意长久地玩下去，从而延长游戏生命周期。
2. **收费模式遭诟病**：免费游戏靠道具卡牌让玩家氪金，花样多了容易招致不满。粉丝们为自家偶像氪金出手大方、毫不心疼。
3. **拉新难**：让不玩游戏的人首次尝试玩游戏比较难。粉丝们会自发进行传播，帮偶像完成破圈。

## 四大具体手段

以[[yuan-shen-原神]]为例：

1. **联名**：与必胜客、高德地图、凯迪拉克等品牌合作推出联名产品。
2. **话题营销**：制造话题事件引发关注和传播，如38米高"派蒙"充气人偶漂流泰晤士河、"传送锚点打卡活动"。
3. **人物动画**：为角色制作动画放大角色魅力，如"云堇"动画爆红；与飞碟桌（ufotable）合作启动动画项目。
4. **二次创作激励**：与B站合作推出"UP主激励计划"，鼓励各类型UP主基于游戏内容再创作。

## 核心理念

正如[[cai-hao-yu-蔡浩宇]]所说："我们不是在做游戏，而是在做IP。"
