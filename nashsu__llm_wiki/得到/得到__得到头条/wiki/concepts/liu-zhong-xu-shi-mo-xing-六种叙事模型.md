# 六种叙事模型

《得到头条》在[[hero-journey-英雄之旅]]框架下总结的六种细分叙事模型，用于处理不同类型的商业案例。每种模型都有固定的叙事结构，并配有第一季的实际案例。

## 六种模型

### （一）工程师型：任务分解，各个击破

叙事结构：主角遇到挑战 → 目标拆分为ABC三个子目标 → 三个子目标分别实现 → 战胜挑战

案例：中国积木品牌挑战乐高垄断（拆分为品牌、技术、IP三个子目标）；阿里云推广制造业方案（说服领导层、工艺工程师、一线操作员）

### （二）科学家型：不断试错，找到正解

叙事结构：主角遇到挑战 → 尝试办法A失败 → 尝试办法B失败 → 找到办法C成功

案例：美图秀秀盈利模式探索（拍照手机失败、美妆电商失败、VIP订阅和SaaS化成功）；草根知本投资策略（跟风口失败、投牛人失败、回归产业投资控股成功）

### （三）侦探型：抽丝剥茧，发现真凶

叙事结构：主角实现不可思议目标 → 表面原因A → 更深层原因B → 真正原因C

案例：宜宾崛起（1.0版本五粮液财政优惠、2.0版本地理位置、3.0版本提前布局产业生态）

### （四）英雄型：神挡杀神，佛挡杀佛

叙事结构：主角想要宏大目标 → 难题A用办法A解决 → 难题B用办法B解决 → 难题C用办法C解决

案例：欧特力（OATLY）进入中国市场（B端供应商策略、OATLY Inside避开价格战、切入C端场景）

### （五）流氓型：有金手指，开挂练级

叙事结构：主角想要目标 → 无意中得到金手指 → 难题用金手指解决 → 再遇难题还用金手指解决

案例：微软Xbox用"内容为王"对抗索尼PS；雪糕品牌的"冰柜战略"（和路雪、伊利、蒙牛、东北大板）

### （六）梁山好汉型：一同落难，殊途同归

叙事结构：大家遭遇同样困境 → 一人用A方法解决 → 另一人用B方法解决 → 都有光明未来

案例：波司登走高端化、鸭鸭做"羽绒界的优衣库"；晨光转型文创、得力转型智能化办公

## 四步写作流程

1. **搜集素材**：一手采访或查找资料
2. **匹配模型**：判断素材最适合哪种叙事结构
3. **剪裁补充**：根据叙事结构拣选素材
4. **动笔写**
