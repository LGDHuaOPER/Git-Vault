# 疫情引发的金融震荡是否会演变为全球性金融危机？

## 问题来源

2020年3月，全球金融市场经历剧烈震荡：美股10天内熔断4次，多国股市陆续熔断，恐慌指数VIX飙升至2008年以来最高水平。[[香帅]]在《邵恒头条》中指出，虽然金融危机尚未“实锤”，但已出现危机兆头。这一问题的答案取决于新冠疫情后续发展。

## 关键变量

- 疫情能否在短期内得到有效控制
- 各国的防疫战略是否得当、得力
- 全球经济能否快速恢复
- 全球协作程度

## 两种情景

### 乐观情景
疫情在较短时间内得到有效控制 → 全球经济快速恢复 → 市场震荡平复 → 剧烈金融危机可能避免（但经济仍会经历疲软）

### 悲观情景
疫情持续扩散 → 全球经济下行 → 大量服务业企业破产倒闭 → 失业率上升 → 金融市场波动下行 → 金融信贷机构面临倒闭清盘风险 → [[信用崩塌]] → 全面金融危机
