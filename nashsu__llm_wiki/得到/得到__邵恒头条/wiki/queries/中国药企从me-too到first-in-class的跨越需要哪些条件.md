# 中国药企从me-too到first-in-class的跨越需要哪些条件？

[[百济神州]]的[[泽布替尼]]已证明中国药企能够开发[[best-in-class药物]]，但从me-too/best-in-class到[[first-in-class药物]]的跨越需要更强的底层创新能力。这涉及基础研究的突破、全新靶点的发现、原创药物设计能力、高风险临床试验的承担意愿，以及支持长期、高投入、高失败率研发的资本环境和制度保障。中国药企何时能诞生首个first-in-class新药，仍是开放问题。
