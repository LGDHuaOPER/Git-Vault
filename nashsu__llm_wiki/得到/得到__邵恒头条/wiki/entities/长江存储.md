# 长江存储

**长江存储**（Yangtze Memory Technologies Co., Ltd.）是中国著名的半导体存储企业，成立于2016年，总部位于武汉。由紫光集团联合国家集成电路产业基金等多只政府背景的基金发起，整合了大量中国芯片产业资源和人才，承载着明确的国产芯片战略使命。

## 技术突破

- **起点**：2016年成立时从32层[[NAND闪存]]起步，与世界一线产品差距约4-5年。
- **追赶**：2019年64层闪存芯片量产，差距缩小到约2年。
- **跨越**：2020年4月13日宣布跳过96层，直接研发成功**128层QLC NAND闪存**，在面积最高密度、单颗最高容量（1.33Tb）、业界最快速度（1.6G/s）三个维度达到业界第一。

这一突破使长江存储与三星、SK海力士、东芝、美光、英特尔等全球存储巨头站在同一水平线，标志着中国在存储芯片领域率先进入世界第一梯队。

## 产业背景

全球存储芯片市场长期被少数巨头垄断，竞争激烈。在2014年国家半导体产业基金成立之前，中国在芯片领域的技术积累和投资都较为薄弱。长江存储的突破被视为国产芯片的一次重大胜利。

## 疫情中的坚守

作为半导体晶圆厂，长江存储在2020年武汉疫情期间克服巨大困难，维持了365天不间断的生产运转和产品研发，直至迎来技术突破。
