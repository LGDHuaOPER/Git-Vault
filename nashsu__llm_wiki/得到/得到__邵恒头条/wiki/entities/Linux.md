# Linux

Linux是一种开源操作系统，在微软的转型故事中扮演了标志性角色。

## 在微软转型中的象征意义

Linux曾是微软封闭文化的“反面教材”：
- 微软前任CEO鲍尔默曾将Linux和基于Linux的开源软件称为“癌症”
- 这体现了老微软“四面树敌、妄自尊大”的企业文化

在萨提亚·纳德拉上任后，Linux成为微软文化转变的标志：
- 微软在Azure云计算上使用的操作系统更多基于Linux而非自家的Windows
- 这一转变象征着微软从封闭对抗走向开放合作

## 战略意义

接纳Linux不仅是文化象征，更具有实际战略价值——Azure需要支持多样化的技术栈来服务不同客户，对Linux的支持是赢得云计算市场的必要条件。
