# 好时巧克力公司

全球六大巧克力生产商之一，世界500强企业。发源于美国宾夕法尼亚州的一个小镇，企业壮大后盘活了整个小镇的周边产业链。

## 制造业外流案例

2007年因业绩大幅下滑，好时决定将10%产能迁至墨西哥：

- **企业层面**：一次性成本5.5亿美元，每年节省1.8亿美元，三年回本
- **社区层面**：3000名员工失业 → 消费水平下降 → 零售、住宿、娱乐等行业受冲击 → 人口外流 → 税收下降 → 近1000名公务员下岗

这一案例被邵宇和陈达飞用作“微观理性与宏观非理性”的典型例证。
