# Nifty Gateway

Nifty Gateway 是一个主流的NFT交易平台，专注于数字艺术品的发售与交易。

## 核心规则：创作者版税

Nifty Gateway 的关键创新在于其创作者版税机制。平台规定，NFT作品在未来的每一次交易中，都将按比例分配10%的收益给创作者。这一规则使得艺术家能够持续从其作品的后续增值中获利，彻底改变了传统艺术品“一锤子买卖”的交易模式，是支撑NFT吸引艺术家的核心商业逻辑之一。
