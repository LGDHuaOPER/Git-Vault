# Savage x Fenty

Savage x Fenty 是由美国歌手蕾哈娜（Rihanna）创立的内衣品牌。

## 品牌理念

该品牌以强调多样性著称，在品牌宣传和产品设计中选用不同肤色、身材的模特，与千禧一代追求包容、平等的消费理念高度契合。

## 与维密的对比

Savage x Fenty 的多样化模特策略与[[维多利亚的秘密]]传统的单一审美形成鲜明对比，代表了新一代内衣品牌对“美”的重新定义。
