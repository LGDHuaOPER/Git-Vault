# WordPress

WordPress 是 [[Automattic]] 公司旗下的网站构建系统，全球使用量排名第一。全世界的网站中约有三分之一使用 WordPress 搭建，知名客户包括美国国家航空航天局（NASA）、纽约时报、时代杂志等。
