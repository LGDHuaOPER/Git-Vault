# Model 3

Model 3是[[特斯拉]]于2016年推出的第一款低价轿车，对特斯拉的业务能力和商业模式构成了极大挑战。它是特斯拉从高端市场走向大众市场的关键产品。

## 量产与质量

- **量产历程**：截至2019年，特斯拉已卖出35万辆Model 3。在产能紧张时期，特斯拉曾在超级工厂停车场搭建全新生产线，将产能提升三倍。
- **以速度换质量**：早期为追求量产速度，Model 3存在较高的瑕疵率，主要问题集中在车身（车漆、缝隙）、内饰（粘胶、磨损）以及软件/触摸屏。
- **质量改善**：自2019年起，产品质量趋于稳定。2019年第三季度的车主投诉相比2018年同期下降了44%。

## 用户反馈

根据《[[彭博商业周刊]]》对5000位车主的调研：
- **满意度**：99.6%的车主认为Model 3的驾驶体验非常愉快。
- **推荐度**：99%的车主表示会推荐给家人和朋友。
- **售后服务**：1/3的用户需等待10天以上才能预约上客服，是当前最大的短板。

## 技术与性能

- **电池**：锂离子电池损耗表现出色，行驶1万英里后充电能力下降不足1%。
- **自动驾驶**：支持[[智能呼叫]]（Smart Summon）功能，上线首月被使用一百万次，但稳定性和安全性仍有待提升。
