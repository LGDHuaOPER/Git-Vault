# Gryphon Technologies

狮鹰科技（Gryphon Technologies），一家成立于1996年的美国军工企业。

## 天龙星座项目

2020年，Gryphon Technologies被[[DARPA]]选中，作为“天龙星座”（DRACO）核动力火箭项目的主要承担方，获得1400万美元研究经费。该项目旨在研发核动力推进系统，为美国提供地月快速航行能力。目前披露的信息有限，初期工作集中在技术演示和验证上。
