# 运动想象

运动想象是当前非侵入式脑机接口实现操控的核心方法。由于抽象概念（如“向左”“向右”）对应的脑电信号尚未被破译，受试者需要通过想象身体部位的运动来间接产生可被机器识别的脑电信号。

## 工作原理
- 想象动左手 → 信号转化为“向左移动”指令
- 想象动右手 → 信号转化为“向右移动”指令
- 想象双手一起动 → 信号转化为“向上移动”指令
- 想象双手放松 → 信号转化为“向下移动”指令
- 斜向移动需想象双手运动的比例，无法用语言准确描述，只能靠受试者自行感受

## 局限性
- 操控方式反常识，与人们直觉中的“意念控制”差距巨大。
- 每个受试者需经过长时间训练才能适应这种特殊的思考方式。
- 能实现的操控动作非常有限。
- 揭示了当前脑机接口技术的根本局限：我们对脑电信号的理解还太少。
