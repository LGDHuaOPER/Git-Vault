# 领导者角色转变

领导者角色转变是指在去中心化、实验驱动的组织文化中，管理者从传统的"决策拍板者"转变为"服务者、示范者和战略对齐者"的过程。这一转变是实验性公司文化得以落地的关键条件之一。

## 转变方向

| 传统角色 | 转变后角色 |
|---------|-----------|
| 给意见、定方向 | 提供基础设施和培训服务 |
| 做决定、拍板 | 用"我们测测看"代替"我认为" |
| 控制与审批 | 以身作则，亲自参与实验 |
| 结果问责 | 战略对齐，确保自主行动不偏离公司目标 |

## 典型案例：Booking.com 的高管行为准则

在 Booking.com 的实验文化中，高管的作用被重新定义：

- **服务者**：提供标准化的测试模板、自动化监测系统，以及五个"卫星团队"为各部门提供测试培训和帮助。
- **示范者**：高管以身作则，有想法也用AB测试验证，而非直接下指令。对员工的建议，最好的回答是"我不知道，我们测测看"。
- **战略对齐者**：让每个员工理解，他们所做的每个测试与公司战略目标的关系和贡献。

## 与相关概念的对比

- 与 [[一言堂文化]] 形成根本对立：领导者角色转变要求高管"放下自我"，而非强化个人权威。
- 与 [[魅力型领导副作用]] 形成互补：通过制度化的角色转变，降低组织对魅力型领导者的依赖，使创新体系可持续运转。

## 关键挑战

在赋予员工高度自主权的同时，如何确保战略对齐而不滑向微观管理，是领导者角色转变中的核心张力。Booking.com 的案例展示了方向（通过培训和沟通让员工理解战略），但未深入探讨这一过程中的潜在冲突。
