# 中国经济恢复指数

中国经济恢复指数（China Economic Recovery Index, CERI）是微众银行“揽月”智能资管平台构建的一项基于城市出行数据的实时经济指标，用于量化新冠疫情后的复工进展。

## 编制方法
- **基准选取**：选取元旦工作日的出行数据作为城市节前常态水平；选取春节假期一周的出行数据最低值作为城市维持基本运转需要的出行水平（假期最低水平）。
- **计算公式**：
  ```
  CERI = (正月初一后出行水平 - 假期最低水平) / (常态出行平均水平 - 假期最低水平)
  ```

## 关键发现（2020年）
- **2019年对比**：正月二十一，各大城市基本接近100%复工。
- **2020年疫情后**：正月十五（2月8日）出行数据触底后反弹；2月25日复工率接近40%。
- **区域差异**：2月底，福建、浙江、青海、湖南恢复至50%以上；广东、上海、山东等10个省市达到40%。

## 优势
- **实时性**：无需等待企业上报汇总，微众银行在2020年2月29日即发布了相关数据。
- **细粒度**：可对比不同城市和省份的恢复差异。

## 局限
- 出行数据受疫情特殊时期通勤方式变化影响（如私家车替代公共交通），可能导致指标失真。
- 单一数据源需与其他指标（如[[卫星生产指数]]）交叉验证。
