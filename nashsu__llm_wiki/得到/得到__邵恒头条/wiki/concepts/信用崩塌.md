# 信用崩塌

信用崩塌是金融危机的本质定义。[[香帅]]指出，现代社会的经济运行建立在信用基础上，金融危机本质是信用崩塌——如果全球信用没了，各种危机都会接踵而至。

## 与价格的关系

价格是信用的显性化表达。一个企业的信用削弱会导致融资成本升高、借贷能力降低，或者遭到抛售，引发更大信用危机。因此，任何机构（国家或企业）面对价格下挫、价值蒸发的情况都需要非常警惕。

## 传导路径

在2020年3月的新冠疫情金融震荡中，香帅描述了信用崩塌可能的传导路径：

1. 疫情持续扩散 → 全球经济下行
2. 大量服务业企业破产倒闭 → 失业率上升
3. 金融市场波动下行 → 金融信贷机构面临倒闭清盘风险
4. 信用崩塌 → 全面金融危机
