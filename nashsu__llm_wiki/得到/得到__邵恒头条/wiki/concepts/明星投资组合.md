# 明星投资组合

明星投资组合是指以某明星代言的所有上市公司股票构成的模拟等权投资组合，用于衡量该明星的“商业价值”或名人效应在资本市场的映射程度。该概念由《巴伦周刊》中文版作者张苏昊在分析王一博代言效应时提出。

## 构建方法

1. 筛选某明星在特定时间段内代言的所有品牌
2. 剔除非上市企业
3. 剔除代言时间过短（如不足3个月）的企业
4. 对剩余上市公司股票构建等权组合
5. 计算组合在观察期内的平均收益率

## 案例数据（2020年）

| 明星 | 组合平均收益率 |
|------|---------------|
| 王一博 | 32.58%（剔除名创优品后24%） |
| 张若昀 | 30.57% |
| 易烊千玺 | 9.71% |

王一博组合成分股：伊利、燕京啤酒（A股）；小米、阿里巴巴（港股）；宝洁、百胜、高露洁、阿里巴巴、耐克、Monster Energy（美股）。

## 方法论局限

1. **事后归纳偏差**：组合是事后构建的，存在cherry-picking风险
2. **样本量过小**：仅9只股票，统计意义有限
3. **未控制变量**：未剥离行业、市值、市场β、公司基本面等因素
4. **时间窗口短**：不足一年的观察期，无法排除短期波动
5. **因果倒置风险**：能请得起顶流明星的公司本身基本面不差，经纪公司也会筛选优质品牌方，收益率好可能是“选择效应”而非“代言效应”

## 价值与意义

尽管存在方法论局限，明星投资组合作为一种另类指标，仍能提供观察名人商业价值的独特视角。它反映了市场对“名人效应可转化为企业价值”这一假设的定价，也为粉丝经济的量化研究提供了新思路。
