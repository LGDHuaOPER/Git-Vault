# 309 | 2020年美国大选的“决战地”在哪？

策划人：韩亮

你好，这里是《邵恒头条》，我是邵恒。

下周二，美国大选将迎来投票日。我注意到，在选前最后的冲刺阶段，拜登和特朗普这两位总统候选人已经用尽全力拉票，而拉票的重点就在亚利桑那、佛罗里达、宾夕法尼亚和北卡罗来纳等几个摇摆州。

你也知道，摇摆州历来在总统大选中都是两党必争之地。但我在关注选情的时候发现，在这几个摇摆州中，有一个州显得特别突出，无论是特朗普还是拜登，似乎都对这个州高度重视，倾注了最猛的“火力”。这个州，就是位于美国东北部的宾夕法尼亚州。

为什么说宾州突出呢？稍微梳理一下新闻你就明白了。近一个月以来，特朗普和拜登先后多次前往宾夕法尼亚州进行演讲。仅26号一天，特朗普就在宾州连开了三场竞选集会。另一方面，拜登也是火力全开。你也知道，出于对疫情的考虑，拜登一向对那种面对面的现场竞选集会不怎么积极，但这两个月来，拜登在宾州简直像是在巡回演出，密集地走访费城、匹兹堡、葛底斯堡等地区，大力为自己造势。此外，他还把奥巴马为他助选的首次出场地点也设在了宾州。看得出，特朗普和拜登双方都对宾州摆出了一副势在必得的架势。

我最近在美国《新闻周刊》上看到一篇文章，对这背后的原因给出了深度解读。文章认为，在2020年美国大选中，宾夕法尼亚州已经成为具有决定性意义的关键州。什么叫决定性意义？就是说，谁拿下了宾州，谁就能赢得这次大选。宾夕法尼亚州，将是拜登和特朗普真正的“决战地”。

你可能会有疑问，一场全国性的大选结果，不应该是看最后综合的选票统计吗？怎么会被一个州所左右呢？在今天的《邵恒头条》中，我就结合这篇文章，来给你讲一讲宾夕法尼亚州的特殊之处。

说宾州重要，并不单单因为它是摇摆州。说起来，美国的摇摆州也不少，从地理位置上看，主要分布在两大地区，一个是美国南部气候温暖的“阳光地带”，其中就有弗吉尼亚、北卡罗来纳、佛罗里达、内华达、新墨西哥、亚利桑那等州；一个是中西部制造业比较发达的“铁锈地带”，包括明尼苏达、威斯康星、宾夕法尼亚、俄亥俄、印第安纳、密歇根、伊利诺伊等州。我在文稿中附上了一张简要的美国地图，你可以点开对照着看一看。

![https://piccdn3.umiwi.com/img/202010/29/202010292243210336031016.png](https://piccdn3.umiwi.com/img/202010/29/202010292243210336031016.png)

别看摇摆州不少，但它们的重要程度也是有区别的，而宾州就属于重要的那一批。为什么呢？因为数学。

你也知道，美国总统大选不是由获得普选票最多的候选人当选的，而是由获得最多选举人票的候选人当选的。每个州根据人口数多少，各占有一定数量的选举人票，总数加起来有538张。要想赢得大选，候选人必须拿到超过半数，也就是至少270张选举人票才行。

那普通选民的投票，又起到啥作用呢？这些投票决定的是：选民所在州的选举人票全部都投给谁，注意，是“全部都投给谁”。简单说，也就是一个“赢家通吃”的规则，什么意思呢？两党谁在普选票中得票多，谁就能拿到全部的选举人票。举个例子，如果这个州有更多选民投给了民主党，那民主党就会拿到这个州所有的选举人票，哪怕得票率只高一个百分点，这个州的选举人票也都会全归这个党所有。

这么看你就明白了，显然那些有着更多选举人票的州更重要啊，赢下这些州更有价值。那么，宾州的选举人票有多少呢？有20票。

在摇摆州中，20票算是相当多的了。像亚利桑那州和威斯康星州，同样是摇摆州，选举人票只有10票，而新墨西哥州和内华达州只有5票。刚才也说了，要想赢得大选必须拿到270张选举人票才行，所以，宾州这20张选举人票的分量就很重了。

而在这次美国大选中，宾州这20票的作用还要更关键。有多关键呢？美国选情分析网站FiveThirtyEight使用统计模型后得出了一个结论：如果宾夕法尼亚州变成红色，也就是20张选举人票被共和党拿下，那特朗普就有84%的机会留在白宫。如果宾夕法尼亚州变为蓝色，也就是民主党通吃所有选举人票，那么拜登就有96%的机会入主白宫。

连拜登在宾州匹兹堡演讲的时候都说：“如果我能击败特朗普，它就将发生在宾夕法尼亚。”

不过，宾州的重要性也不仅体现在选票数量上。我在这篇文章中还看到了一个很有意思的观点，那就是：宾州本身也已经成了美国选情的一个缩影。

文章给出了两个理由：  *首先，宾州的选民结构很有代表性。*

从选民构成上来说，没有大学学历的非拉美裔白人选民，和受教育程度更高、更多元的选民在人数上大体相等；从选民身份上看，宾州拥有大量从事高科技和医疗保健等行业的白领人士，同时也有大量能源和制造业的蓝领工人；从分布上看，民主党的支持者更多集中在人口密集地区，而共和党的支持者更多集中在人口较少的郊区和乡村。从这三个维度来说，宾州和美国当前整体的选民情况非常相似。这种相似度，让宾州有了很强的代表性。

从民调上看，在宾州，拜登在支持率上小幅领先特朗普，而特朗普在拥有大学学位的白人、少数族裔、女性、老年人群众当中支持率不佳，这和美国的总体情况也基本吻合。这是我们说，宾州是美国缩影的第一个理由。

第二个理由是，  *宾州有一个能代表两党竞选主张分歧的典型问题* 。什么问题呢？水力压裂技术（fracking）。如果你关注了之前拜登和特朗普之间的大选辩论，就会发现两人在水力压裂技术上展开过激烈交锋。

“水力压裂技术”这个术语听着很专业，其实不难理解，我一说你就明白了。简单来说，它就是一种油气开采技术。这种技术利用液压，把添加过化学物质的水浆注入岩层中，把岩层压碎，释放其中的石油和天然气。水力压裂技术极大地提高了油气田的产量，甚至可以说它促进了美国油气工业的繁荣。

可另一方面，水力压裂技术又会带来环境问题，每次开采都会浪费数百万吨的水，同时水中添加的大量化学物质直接打入地层又会污染地下水。所以多年来，水力压裂技术一直遭到环保主义者的严厉抨击。目前，马里兰州和纽约州已经通过了相关法案，禁止再使用水力压裂技术。

那么，水力压裂技术为什么成为宾州的典型问题呢？因为天然气是宾州的支柱产业，关系着近10万人的就业。一旦对水力压裂技术采取限制，就意味着很多人可能因此丢掉饭碗。特朗普就在大选中一直狠狠地抓着这一点，说拜登想要禁止水力压裂技术，他还发推特说“宾州一旦没了水力压裂技术带来的工作岗位和大量美元，绝对会死！”拜登则澄清说，他并没有要禁止水力压裂技术，他只是想更多地用清洁能源替代石油和天然气。

你看，  *水力压裂已经不是一个单纯的技术问题，它更是能源、经济、环保和就业问题* 。拜登和特朗普在这个问题上的表态与交锋，也体现了他们在竞选主张以及策略上的差异。从全国范围来看，这些分歧和差异是很典型的。

好了，总结一下，在今天的《邵恒头条》中，我跟你分享了宾夕法尼亚州为什么会成为决定2020年美国大选结果的关键州，成为拜登和特朗普的“决战地”。一方面，宾州的20张选举人票，对于两位候选人赢得大选意义重大。另一方面，宾州本身也已经成了美国选情的一个缩影，无论从选民结构还是核心议题上，都相当具有代表性。

总的来说，我看完这篇文章觉得很有启发。之前我们更多关注的是疫情的出现给特朗普连任带来的变数，但这篇文章却没有把着眼点放在疫情上，而是透过宾夕法尼亚州，来谈大选所反映出的美国社会当前的矛盾、混乱与阵痛。这个视角，其实更有意义。就像文章中所说的，在宾夕法尼亚州发生的一切，既是美国这个国家的真实写照，也将决定这个国家的命运。

好了，这就是今天的《邵恒头条》。我是邵恒，我们明天见。
