# 看看大自然修复自己，人间值得

今天的人间值得，我想告诉你一条好消息。那就是一些在澳大利亚山火中受伤的考拉，在人类的救治下已经恢复健康，逐渐重返自然了。

你肯定有印象，去年从9月开始，澳大利亚因为气候干燥，发生了一场山火，这场大火一直持续到今年1月才逐渐消散。

澳大利亚的国宝考拉，在这场山火当中受到了不小的影响。根据一项数据显示，这场大火导致了10亿只动物死亡，其中包含6000~10000只考拉。对于整个考拉种群来说，这是一个很不乐观的数字。

主要负责对考拉进行救治的，是澳大利亚麦格理港的一家医院，这家医院就叫做考拉医院，每年都会有200多只考拉住院，接受治疗。

这次因为火灾住院的考拉，一共有79只。它们的情况可一点也不好，这群考拉因为大火，都遭遇了比较严重的烧伤和脱水。一被送进医院，就要接受麻醉、输液，医生还得进行会诊，大家一起确定治疗方案，和对待重症病人没什么两样。

不过，这家医院做的，可不仅仅是救死扶伤而已。

你要知道，进入这家医院的考拉都是野生动物，从医院出院之后也是要回归大自然的，所以在救治的整个过程中，医生还要时刻考虑怎么做能够不影响它们的生活习性，或者说把这些影响最小化。

比如，给考拉治疗烧伤需要清理伤口、切除死皮，涂上药膏之后贴敷料，每隔几天都需要更换一次。但是一旦等到考拉不需要敷料的时候，医生就会让它们从病房搬出来，在室外的围栏中生活。毕竟野生动物，还是需要一个充满阳光和新鲜空气的环境。

再比如说，这家医院还有比较严格的规定，那就是在整个治疗的过程中，如果没必要，就必须减少和考拉的接触，甚至规定医护人员不能和考拉说话。这件事挺难的，毕竟你想，考拉那么可爱，谁都想和它们多呆一会。

所以治疗考拉的过程的确挺不容易的，不过好在经过了半年多的治疗，考拉们已经开始分批返回大自然了。

其实，受伤的考拉重回大自然，得同时满足两个条件，一个是考拉自己的身体状况良好，可以适应野外的生存。另一个是它们的栖息地得恢复过来，让考拉有个家。

好消息是，今年澳大利亚的降水量很大，所以虽然说山火带来的损失惨重，但是大自然重生的速度很快，已经可以随时欢迎考拉回家了，这比考拉医生们预计的速度，要快两个多月。

从四月的下旬开始，考拉医院就逐渐把康复出院的考拉放归大自然，第一批就有26只考拉重回自然。

我在文稿中放了一张图，就是其中一次放生的过程。你可以看到，一只考拉妈妈在放生之后，背着自己的考拉小宝宝趴在树上，十分有爱，在这里我也希望它们能够在大自然中，找到自己的新家园。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。
