# 在海边观星，人间值得

今天的人间值得，我想和你分享一次特别美妙的海边观星体验。

在526得到四周年的那两天，为了庆生，公司给同事们放了两天假，让大家出去放风。我们有一组同事，就去了秦皇岛的度假胜地阿那亚。你可能听说过：阿那亚那里有特别著名的孤独读书馆，是一个文艺青年必须去的打卡胜地。

当然，阿那亚，想去随时可以去。但我们同事，做了一个特别安排：他们带上了高爽老师一起出行，也就是《天文学通识30讲》的课程主理人。晚上，同事们和高爽老师在海边，一起观星。你想象一下，一位天文学家在海边，带着大家看星星、讲天文学知识，这个画面，想想就觉得很美。

不过我的一位同事Lusa告诉我，这次旅途最特别的，还不止如此。这回最有意思的是，他们团队成员里有个小朋友，是一位同事的孩子，名叫小礼。

Lusa说，那天晚上他是全场捧场王，他们一群大人就像是小礼和高爽老师的观众，小朋友充满好奇，而高爽老师更是能接住他的脑洞，回答得特别精妙，最后还能很自然地回到专业知识上。

比如观星一开始，高爽老师就问：“为什么有的星星会一闪一闪的？”小礼同学立刻抢答：“因为有其他星球的遮挡！”

高爽回答说：“你说得对，天文学家观察到，有些星星规律性地明暗，后来发现是有围绕其旋转的行星，就像地球绕着太阳转一样。”接着，高爽老师又补充：“还有一个原因，是有些星星离地球比较近，比如这颗星，它之所以闪烁，是因为地球大气对反射光造成的干扰，就像天气特别热的时候，柏油马路上的物体看起来都在抖动。”

Lusa说，当时她听到这个问题，还真是一愣，自己小时候肯定也对这个问题好奇过，但是长大了看星星，却再也没注意过这个问题，更没想过找找答案了。

小礼还会问很多问题，比如，小礼问：“为什么那颗星星特别红？”

高爽老师回答说：因为那是一颗红巨星。一颗恒星在发光发热很多年后，就会慢慢变老，会膨胀，变得很红很大，温度降低。这颗星星这么红，是它已经太老了，已经快死了。

你看，这次观星很特别，除了有一位天文学家在场，还有一个很重要的原因，她发现了“童心”这件事格外美好。大人们总是带着理性知识去想问题，但少了好奇心和童心。Lusa说，看星星这件事，无论大人还是孩子，拥有的都是同一片星空，但是当你把你的童心交出来，用孩子的视角去观察，这个星空就变得更丰富和美妙了。

这还不算完，整场海边观星最让他们震撼的一个瞬间，是高爽老师掏出了一支激光笔，直接指到北极星的那个时刻。

我特意要了一张Lusa拍的照片，你可以感受一下。

那一刻，他们全场惊呼，Lusa说她差点流下眼泪。对于天文学家来说，整个星空，都是他的PPT。

听完她的讲述，我真是后悔没跟他们一起去。你是不是也特别羡慕？

我觉得你也不妨找个周末，约上几个好友，去阿那亚住两天，感受一下海边观星。最重要的是，可以准备一支高爽老师的同款激光笔，到时候直指星空，绝对震撼全场。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。
