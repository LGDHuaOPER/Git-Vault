# 405｜为什么内容行业，仍然存在大量机会？

策划人：李仲轲 

你好，这里是《邵恒头条》，我是邵恒。

上周，我看到 [内容产业服务公司新榜发布了一份《2021年内容产业年度报告》]({"from":"promise","url":"https://mp.weixin.qq.com/s/32b_-bCLMbtjrD36THcEFA", "typeid":0,"type": 3}) 。新榜每年的这份报告，都会探讨内容行业当前的生态。从今年的报告中我读出来一个重要的信息：  **内容行业虽然日益拥挤，但是仍然存在大量的机会。**

在今天的《邵恒头条》中，我就和你分享一下新榜这份报告的内容。

其实关于内容行业，去年一直有两个完全相反的论调。

一个论调是，内容行业迎来了一波爆发期。我们从数据上看，在过去的一年中，抖音多出了1.3亿的创作者；创作者的积极性也是非常高涨，抖音去年百万大号每月发布的视频数量，同比增加了59.6%。

如果你在日常的生活中会看视频的话，肯定在去年留意过一些突然爆红的内容创作者。比如我在B站看到一位叫做林晨同学的up主，这位up主在2020年之前发布的视频播放量都维持在几万的水平。但是在去年1月22号，这位up主发布了一期武汉街头实拍的视频，获得了1000万的播放量，这让他一战成名。去年像林晨同学这样从草根崛起的up主并不少见。

但是另一方面的论调是，内容行业的繁荣是“假繁荣”。这是因为很多分析，内容行业能在过去一年出现这样的景象，和大环境的变动有很大关系。去年因为新冠肺炎疫情的影响，线上消费大幅增加，这也激发了内容创作者的热情。

但是你知道的，在国内疫情控制得还是挺好的，我们已经能够在线下正常生活了。如果在之后线上的“红利”消失，流量的潮水一退，内容行业又涌进来不少人，是不是会呈现出“假繁荣、真拥挤”的情况呢？

其实并不是，接下来我就和你说说背后的具体原因。

首先一个原因是，  **内容行业的赛道在不断变宽** 。

你肯定知道，目前中国网民最喜欢的内容消费形式是短视频。根据统计，在2020年中国网民有四分之一的上网时间都花在了短视频上，比起2019年增加了50%。为了响应这样的趋势，在去年一年中，微信、微博、小红书、知乎这种以图文为主的平台，都上线了和视频有关的功能。这可能会带来大量的新机会。其中，微信的视频号尤为关键。

根据新榜的统计来看，  **国内三大主流的视频平台——也就是抖音、快手、B站——已经逐渐呈现出一副“赢家通吃”的架势。**

比如说，这三大主流视频平台之间，每周Top100的创作者中有将近五分之一的重合度。也就是说你在抖音上看到的五个热门视频中，可能有一个也会在快手看到。

但是微信视频号的崛起缓解了这种赢家通吃的局面。  **视频号和三大主流视频平台Top100创作者的重合度都在5%之下，其中视频号和B站的重合度甚至只有1%。**

而且，视频号更让人心动的，还有它所携带的巨大流量。根据估算，中国目前的短视频用户有9亿人，视频号用户只有2亿人。而且，视频号背后是微信这个国民级别的App，日活有12亿。按照这几个数字推算，视频号还远远没有到它的天花板。

我给你打个比方，之前的抖音、快手、B站像是一班列车，很多内容创作者为了在这班车中抢一个座位都挤破了头。但是现在视频号等平台作为一班空车缓缓驶来，给了内容创作者快速上车，走上快车道的机会。

而且，内容行业还不只是出现了新的创作平台。我在新榜的报告里，还看到两个小趋势，这两个趋势也代表着行业里的新机会。

一个趋势是，  **大众对于内容的偏好正在逐渐转移** 。

你可能知道，之前的内容行业最受关注的还是休闲娱乐的内容，但是在疫情之后，休闲娱乐内容的热度在逐渐下降，而健康防护、生活技能、课程学习类的内容热度都有上升，涨幅都超过了10%。面对这种变化，各个内容社区也做了调整，比如B站在去年6月就上线了知识区这个一级分区。

另外一个趋势是，  **内容领域正在变得更加细分、垂直** 。

我给你举个例子你就明白了。对于内容创作者来说，美妆是一个非常传统的领域，头部玩家林立。但是这并不意味着美妆领域没有机会，因为美妆已经细分到了夸张的程度。有专门做眼妆的博主、有做眉形的博主、有做化妆品平价替代（平替）的博主。这些博主只要服务好这个垂直领域的用户，就可以在美妆这个红海立足。

我还在新榜报告上看到，目前B站内容的标签数量已经达到了千万级别，并且还在以43%的速度增长。新榜的报告说，内容创作的类型已经像毛细血管一样，分布在了各个领域的最深层。

你看，从过去的一年中来看，  **内容行业作为一条大河，它的流量在不断增大，与此同时这条大河下面的支流数量也在不断增加。一个内容创作者只要盯准一条小支流，就能找到属于自己的机会。**

不过，我们刚才所说的，都是“流量”在哪里的问题。对于内容行业来说，还有一个更重要的问题，那就是“钱在哪里”？毕竟之前的内容行业中，一分钱难倒英雄汉的现象那真是屡见不鲜。

新榜的报告也给出了这方面的回答，内容行业本身也变成了一个赚钱的香饽饽。其实在去年，各大传统媒体平台加大对于视频的投入，就是看准了视频内容强大的吸金能力。

新榜的报告显示，在未来一年中有一半以上的品牌商，都打算增加内容营销的预算。他们其中的60%计划进行短视频或者直播形式的营销。

**一方面品牌商往内容营销上投入的资金增加了，而另一方面，各大内容平台又在加强自己的基础设施建设，帮助内容创作者赚钱。** 比如快手这样的平台会和京东合作，弥补自己在供应链和商品品类上的短板；再比说去年，抖音在北京著名文玩市场潘家园设立直播基地，吸引文玩商家入驻，这个基地还会为入驻商户提供质检、物流、仓储、主播孵化、商户运营等全方位服务。

所以你看，  **一位内容行业的新人完全不用去操心供应链之类的事情，他只需要深耕内容，依靠平台打造的基础设施来获得利润，就可以在整个行业中生存下来。**

好，总结一下，在今天的《邵恒头条》中，我为你分享了新榜刚刚发布的《2021年内容产业年度报告》。从这份报告中，我们可以看到两个大趋势：

**第一， 内容行业的赛道在不断扩宽的同时也在不断细分，为这个行业增加了不少新流量；**

**第二， 不少品牌加大了在内容营销上的投入，再加上内容平台的扶持，让内容从业者的变现能力得到增加。**

其实我作为一个内容行业从业者，我对这个行业仍然非常看好。蔡钰老师在她的《商业参考》中提到了一个词叫做情绪价值。  **消费者往往只愿意为一个产品支付市场平均价，但他们愿意为产品带来的情绪价值支付很多溢价。而产品的情绪价值，往往就是通过好内容带来的。**

如果你在过去的一年中，发现了一些有意思的内容创作者，也欢迎你在留言区分享。

好了，这就是今天的《邵恒头条》。我是邵恒，我们明天见。
