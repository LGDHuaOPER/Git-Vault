# 242 | 为什么快手会踩中直播红利？

策划人：李仲轲

你好，这里是《邵恒头条》，我是邵恒。

最近我注意到一条新闻，5月10号，格力的董事长董明珠在短视频平台，快手上直播带货。

这次董明珠带货的成绩那是相当亮眼，整场直播董明珠只出现了半个小时，但是在这期间，商品的成交额突破了1个亿。整场直播三个小时下来，成交额有3.1个亿。

什么概念呢？董明珠之前透露过，格力的网上商城在2019年，电器的销售额是3.5个亿。也就是说，这次格力三小时的直播带货成果，逼近格力网店去年一年的业绩。

我看到有不少人在讨论的时候，都会提到说，没想到快手的老铁这么有购买力，之前是小瞧他们了。但其实你想过一个问题没有，那就是直播这个商业模式，其实并不新鲜。手机直播已经兴起了四五年了，无论是这次的快手，还是我们熟悉的抖音在这个赛道上只能算是后来者。

这两个平台为什么能后来者居上，成为最火的直播带货平台呢？

我最近在公众号圆首金老汉上，看到了一篇文章叫做《花点时间重新认识直播行业》，这篇文章的一个核心观点是，  *抖音和快手能在这两年崛起，是因为他们各自通过自己的方式，打破了直播这个行业的天花板。* 在今天的《邵恒头条》中，我就来和你说说为什么抖音和快手能够“破局”。

现在我们说到直播带货，经常会说一个词，叫“全民直播”。但其实在两年前，直播还是一条相对狭窄的赛道。

我在文稿中附上了一张图，这是2016年在网上流传很广的一张图。那一年被大家称为“移动直播元年”，爆发了所谓的“千播大战”，这张图里面的软件，就是当时加入“千播大战”的部分玩家。这听起来是不是特别有“外卖大战”“团购大战”的感觉？当时还有几家公司，被大众普遍看好，比如YY孵化的虎牙直播，奇虎360搞的花椒直播。

![https://piccdn3.umiwi.com/img/202005/14/202005142240499870429458.jpg](https://piccdn3.umiwi.com/img/202005/14/202005142240499870429458.jpg)

但是，“千播大战”的结果并不美好，没有哪一家企业是真正的赢家。直到“千播大战”过后的两年，也就是2018年，移动直播的市场规模还不到500亿人民币。2018年，直播平台的日活用户加在一起，还不到5000万。现在，仅仅是一个抖音，日活就有4亿人，是当年整个直播市场的8倍。

从这个现象来看，仅仅是2年前，直播行业的天花板还很低。这背后是什么原因呢？根本原因是直播本身的内容形式。在此前，直播吸引用户的方式非常单一，主要就是两种，一种是看的，也就是主播的颜值身材；另一种是听的，也就是这个主播讲了什么有趣的段子，发表了什么观点。

在这种内容形式下，能满足条件的主播数量其实很有限。直播平台为了吸引头部主播进驻，往往需要花费高额的“转会费”，争抢头部主播。

这些问题反映在商业模式上，就成了这个行业的天花板。  *直播并没有把越来越多的人卷进自己的网络里，而是走上了头部玩家通吃的老路。* 当然，即便是头部玩家，也仍然免不了内容单一的问题。在过去的这两年，移动直播的日活用户始终没有实质性的增长，就算是巅峰时期的斗鱼，日活也只有1500万左右。

听到这里估计你会说，哦，我明白了，抖音和快手之所以能后来者居上，是因为它们拥有巨大的流量，在这个基础上开展直播业务，自然盘子就大。

但是你想过一个问题没有？按照之前直播的内容生产逻辑，抖音和快手就算盘子再大，也依然卡在头部主播数量有限，以及内容单一的瓶颈上。迟早也会撞上天花板，不过是这个天花板在几层而已。

为什么这两个直播平台的业绩可以一直增长呢？就拿快手来说，在去年12月底，快手直播的日活用户突破了一个亿。与此同时，直播收入也呈倍数增长。2017年第三季度，直播每月的流水是5亿，到了2018年底，已经达到了单月20亿，进入2019年，根据推测，已经达到了30亿。

根据这篇文章的分析，这是因为抖音和快手在开拓直播业务的时候，各自采用了一套方法，打破了天花板。

抖音你肯定很熟悉，就是通过算法，为用户推送他们感兴趣的内容。快手的打法可能相对陌生一点，圆首金老汉在文章中把它叫做：  *建立真实的关系链，从而让每个人都成为内容生产者。*

什么意思呢？很多人描述快手用户的时候，会提到一个词，叫“下沉市场”。金老汉在文章中分析，这些用户在现实中的关系链比较简单，他们日常生活接近两点一线，微信好友大概只有同事、亲戚和同学，朋友圈可能刷15分钟，就刷到前天的内容了。

快手就给了他们一个社交平台，他们在上面可以表达、倾听和共鸣的。他们在快手上，能遇到有着同样感受、关心着同样事情的朋友，在快手上能获得的归属感可能比现实生活还要强。在快手上认识的朋友可不就是所谓的“老铁”么？

快手的创始人之一宿华说，2018年开始，快手转型成为半熟人半陌生人共存的社区，平台里有大量的社交关系，比如校友、同事、同行。在这个过程中，快手也在实践自己的“公平算法”，也就是说，把原本聚集在头部的流量资源，拿出来一部分分给普通人，这就让普通用户创作的内容，也有被看到的机会，让每个内容生产者都能获得正反馈。

其实你联系一下微信就能想明白，为什么咱们有事没事，都爱发朋友圈呢？是因为在朋友圈我们可以获得正反馈，而且还是来自于我们真实社会关系的正反馈。  *快手就是这样通过建立类似的关系网，让所有人都有了生产内容的动机，从而打破了头部主播模式的天花板。*

在此基础上，快手对于直播也进行了设计，实际上快手的直播入口藏得非常深，基本上你不关注一个人，就找不到他的直播入口。这也很符合真实的社会关系，只有你关心一个人，才会进一步获取他们的动态。

金老汉在聊快手直播的时候，有一句总结非常好。他说  *快手老铁看直播，本质上是“连麦”，他们关心的不是节目精不精彩，而是谁在和自己互动。*

好了，听到这你可能要问了，快手的这套打法，虽然现在看起来很美好，但可能只在下沉市场有效，这个下沉市场会不会成为快手的天花板，让它没办法破圈，获得持续增长呢？

这个问题得分两个层次来看。首先，我们其实应该重新审视“破圈”这个词对于快手的意义。一般我们说“破圈”，指的是某个产品从一个相对小众的圈层，走入一个大众圈层。但快手用户的基本盘，才是中国社会的绝大多数。所以“破圈”这个词，用在快手上并不合适。

第二，如果换一种说法，我们讨论的问题其实是，快手能不能进入一二线城市？其实，快手的用户增长引擎，正在逐渐发生改变，到了2019年的下半年，快手上一线、新一线和二线城市的用户月活占比，已经能达到30%以上了。

事实上，快手也在做很多尝试，比如在疫情期间，它专门成立了运营团队，联合尤伦斯当代艺术中心，举办了一场名为“良樂”的线上音乐会。这场音乐会的嘉宾，有给电影《末代皇帝》配过乐的坂本龙一，还有新裤子乐队的键盘手庞宽，你要知道无论是坂本龙一还是新裤子乐队，他们的主要受众都是一线城市的居民。

在“良樂”音乐会结束当天，音乐会的主持人，同时也是尤伦斯的副馆长尤洋念了一位观众的留言：Low的不是老铁，而是有色眼镜下的偏见。

对于快手未来会发展成什么样，我也不能下定论。但是我在快手身上，看到了一种独特的气质，那就是  *它不仅把自己定义成一个内容的消费平台，它还想为每一个用户赋能。让用户通过快手表达自己，同时也看到更大的世界。*

好了，这就是今天的《邵恒头条》。我是邵恒，我们明天见。

破罗君：#邵恒头条#

曾经的“千播大战”并不是长久之计，他们的存在就是直播，并且很多直播是依存于游戏产业。大量的游戏职业玩家入驻直播平台，直播平台看中的是游戏玩家自带的流量。可是游戏直播的内容长久以来不仅单一，而且极为无聊。对于普通人来说也不是很友好。

抖音快手却不同，不仅仅是用户流量。他们首先是创造了一个所有人容易进入的“赛道”——短视频。这个内容看起来很平凡，但是经过一段时间的积累，人们不仅为了拍出好的素材把生活过得越来越丰富，而且技巧能力越来越强。也就是说，抖音快手创造了一个全民直播的培训平台，在条件成熟之后，不仅人们的直播技巧成熟了，而且内容也比曾经的游戏直播平台更加丰富。

海子：直播行业给每个普通人一个与外界交互的机会，可以看到除了自己身边小圈子以为的世界，同时让我们每个普通人都有可以成为主角的机会。

像快手之所以火，它不仅带动了人与人之间的连接，人与社会的连接，它还让很多普通人通过自己的努力在直播行业获得红利和收益。

直播门槛低，普通人都可以进入，大家都是以草莽的姿态入场，往前冲就好了，然后有的人在里面深耕个几年就能累积一定资源和粉丝达到腰部，那有的人不仅拼入场还早不断抓住机会往上冲就可以在直播行业成为头部，就像我们今天看到的李佳琪，薇娅这样的头部直播。

所以直播行业的兴起在于它可以给每个普通人机会，对于每个人都是平等的，只要你肯努力，就有机会从草莽，到腰部甚至走向头部，这都是有可能的。


刘溜溜：直播的模式最早得到验证，以至于很多人都扎堆杀向直播行业，很多公司也加入了直播平台的竞争中。到最后，大家都按照固定的格式进行竞争，最后赢的就那么一个两个，或者谁都赢不了。
