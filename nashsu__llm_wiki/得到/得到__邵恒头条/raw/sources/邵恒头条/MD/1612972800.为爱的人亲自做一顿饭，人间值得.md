# 为爱的人亲自做一顿饭，人间值得

策划人：李仲轲

你好，这里是《邵恒头条》，我是邵恒。

今天是大年三十，我在这里代表《邵恒头条》团队，给你拜个年！

我相信，无论你选择了回家过年还是就地过年，都会很期待今天晚上的年夜饭。年夜饭具体吃什么，咱们丰俭由己，但我特别想鼓励你，今年的年夜饭亲自下一次厨，给自己或者家人做一道菜。

我今天想跟你分享我身边两个姑娘的故事，她们的故事让我觉得，做菜不仅仅是对美食的追求，更是对爱的人最好的表达。

我这两个朋友是室友，一个叫Helen，也就是海伦·凯勒的那个“海伦”，另外一个叫Jane，也就是《简·爱》的“简”，我们都叫她“老简”。

她俩是我和身边朋友们公认的，最爱做饭招待客人的人。每逢节日，老简一定会做上一桌丰盛的菜肴，招呼一大帮朋友到家里吃饭、聊天。而且她做的还不是普通的家常菜，而是经过自己的设计创意发明出来的菜，什么百香果汁椰子肉沙拉、空气炸锅炸出来的越南粉皮牛肉馅饼、椰子奶油巧克力果冻等等。反正我每次去她俩家，我都觉得像是免费去了一趟黑珍珠餐厅。

现在，这两个姑娘在一起创业，做了一个分享科学饮食理念的公司。 [最近她们在小红书上开了一个美食博客]({"from":"promise","url":"https://www.xiaohongshu.com/user/profile/5fc9c340000000000100a1d1?xhsshare=CopyLink&appuid=56a23f37b8ce1a1cdd37dd0b&apptime=1613014662", "typeid":0,"type": 3}) ，她们不仅在博客上分享食谱，而且还分享一些有趣的食物实验，比如弄一只脸盆那么大的港式大墨鱼，花上好几个小时拆卸清洗，用广东卤水的做法卤出来，或者搞一只恐龙时代存活下来的鱼类，日式安康鱼，研究鱼肝里的营养成分。

但说来有趣的是，她们俩原本的职业轨迹，其实跟食物完全不相干。两个人走上现在这条创业路，完全是一场意外。

海伦是从剑桥大学经济系毕业的高材生，浙江人，回国以后开始做投资。老简则是马来西亚的华裔。2013年她来到北京，后来成了央视的一名记者。两个人在朋友聚会上偶然认识，因为聊得投缘，于是就成了室友。

但没想到，2015年，她们之间的关系，甚至她们的人生，却开始通过食物发生了翻天覆地的变化。

那时候，海伦因为工作压力大，加上不擅长照顾自己，突然患上了两个罕见的免疫性疾病。这两个疾病一个叫肌炎，一个叫系统性硬皮病。这两个疾病会给患者带来很大的痛苦。肌炎是全身的肌肉细胞发炎破损。硬皮病则会让患者的结缔组织慢慢硬化，各个关节的活动范围变小。如果任其发展，就连内脏都会硬化。

海伦的病情发展得非常快。在发现病情3个月之后，她出现了浑身肌肉无力的情况，早上起来去拿一杯水，就要回床上躺一整天。嘴巴闭不上，手抓不紧，甚至没办法拧开水瓶。但是，尽管看了全国最好的医生，海伦的病情也没有得到缓解。

你想象一下，一个人得了这种疾病，那真是被宣判了无期徒刑，只有躺在床上数日子了。

作为海伦的室友，老简非常着急。她特别想做一些力所能及的事来帮助Helen康复。情急之下，老简在网上疯狂搜索了各种资料，结果碰巧在一些自身免疫病人的博客里，发现了一种饮食疗法。

抱着死马当活马医的心态，老简说服海伦尝试一下这个食谱疗法。

反正是吃东西，也不用吃药打针受罪，干吗不试试呢？

但没想到，这个食疗做起来，远没有想象得那么简单。原因是，按照这个食谱，海伦能吃的食材非常有限。

比如常规的谷物、豆类、奶类都不能吃，面包不能吃，酱油也不能用了。做饭变得束手束脚，吃起来味道也不怎么样。

为了实践这个饮食疗法，那段时间，老简不得不花了很多额外的心思。每天给海伦做饭只是最基础的。为了能够让饭食更好吃，老简在国外的网站搜罗各种可以替换的食材和酱料，请国外的朋友人肉带回国。比如用椰子做的酱油替换普通酱油，用木薯面粉替换面粉。两人还经常一起去逛有机市场——这些资源当时在国内都不太好找。

再比如说，为了监督和鼓励海伦吃饭，老简每天都会在工作间歇跑回家，陪海伦一起吃饭，吃完再赶回公司上班。这么一做就连续做了3个月。

其实本来，两人对这个食谱也没抱太大希望。没想到，按照食谱吃了一段时间，Helen的身体状况还真的得到了改善。坚持两个月之后，她可以出门了，坚持11个月之后，她重新捡起自己的运动爱好，能打羽毛球了。

当然，康复是不是就是因为这个食谱，我不是医学专家，这我不懂。

但就因为这段经历，这两人的生命轨迹来了一个180度的大转弯。在海伦逐渐康复之后，老简决定辞职，跟海伦一起做一家创业公司，推广科学饮食的理念。

最直接的原因当然是，他们觉得从自己发现的食谱中受益，所以想把这种饮食方法分享给更多人，帮更多人认识到饮食对免疫系统的影响。

但是，我更想跟你分享的，是她们创业的另一层原因，  **就是她们觉得食物是一个很强大的情感载体，值得被更郑重地对待。她们也希望使用这个载体，联结更多的人。**

为什么这么说呢？

就拿海伦来说：在她最困难的时候，吃饭不仅是治病的需要，更是她精神上的“定海神针”。你想，那时候她什么都做不了，但起码有一件事还算是“力所能及”，就是坚持好好吃一顿饭，用这种方式照顾自己。吃饭变成了她每天给自己打气的一个小仪式。所以有一次她对我感慨说，吃饭理应是一件很神圣的事情。

对于老简来说，给海伦做饭，其实也是她当时唯一一件力所能及的事。口头的鼓励和安慰都显得挺苍白无力的。但是给海伦做饭，并且陪着她吃完，即便两人不说什么，也能让海伦感受到好朋友的力挺和忠诚。

就是这段经历，让老简找到了新的人生方向。以前她的梦想一直是成为一名战地记者。但是在照顾海伦的过程中，老简觉得比起改变战争这样遥远的事情，她完全可以通过食物这个简单的媒介，联结、支持更多的人，甚至给他们的生活带来切实的改变。

其实食物作为情感载体这一点，我相信你肯定一点都不陌生。

我曾经在一期头条节目里讲过，越是在极端环境下，吃饭这件事就越受重视。比如做石油勘探和北冰洋探测的人，  **好好吃饭是他们保持团队士气和生产效率的重要方式。** 再比如，对于宇航员来说，科学家们绞尽脑汁琢磨怎么能让他们吃饭吃得更好，怎么让做饭变得更有乐趣，因为吃饭、做饭被看作是我们作为人的文化基因的一部分。

对于中国人来说，理解食物的情感意义就更不难了。咱们中国人联络感情，不就总喜欢一起吃饭嘛。邀请对方到自己家里吃一顿家常菜，那更是最高礼遇。很多丰富的感情，比如对对方的感激、喜爱、思念，其实都藏在一道热腾腾、香喷喷的菜里面。

小红书有一句话，我觉得特别精准地概括了这种情感：  **爱的另一个名字，是做饭给你吃。**

如果这个春节假期，你也想用做饭的方式，向你爱的人表达你的在乎，那我必须给你推荐一下，老简和海伦准备的最新系列视频：12道“极简年夜饭”。这个系列里，都是一些特别简单但是又好吃的年夜饭食谱。

我把其中我喜欢的一道菜“咸蛋黄炒虾”的食谱放在文稿里了。如果想了解更多，你可以去看看她们在小红书上的账号  *吗哪源Manna Source（点击此处跳转）。*

假如过去这一年，你过得格外不容易，那就更要给自己好好做一顿饭。用这个动作，帮自己下个决心，在接下来一年更好地照顾自己。
