# 把自己打造成一个快乐节点，人间值得

策划人：李仲轲

你好，这里是《邵恒头条》，我是邵恒。

今天，我继续给你介绍小红书上一位拥有“10分快乐”工作的人。

这个人叫做吴承泽，他是一名成都人，在海南三亚的后海村开了好几间冲浪客栈，专门招待冲浪爱好者。他的品牌名非常有意思，叫做亼樂。这两个字比较难写，我给你描述一下，亼是上面一个人类的人，下面一个第一的一。樂就是音乐的乐的繁体字。

吴承泽告诉我，他给自己的客栈取这个名字，主要是很喜欢亼这个字。你可以在心里想一下这个字，特别像一个人站在冲浪板上。

![https://piccdn3.umiwi.com/img/202105/04/202105042115436913177280.jpg](https://piccdn3.umiwi.com/img/202105/04/202105042115436913177280.jpg)

如果你关注年轻人潮流的话，你可能会知道在最近1年内，冲浪这项运动在国内火了起来。三亚的后海村因为很适合冲浪新手，所以也成为了一个冲浪网红胜地。而吴承泽的亼樂客栈，更是这个胜地中的地标。 

我们公司有不少同事也曾经在后海村冲过浪，他们都说听过吴承泽的名字，亲切地把他叫做吴老板。我甚至还听吴承泽的一位朋友这样说：吴承泽就是一个为冲浪而生的人，是很多冲浪爱好者想要活成的样子。

那吴承泽他是怎么找到冲浪这个爱好的？冲浪的爱好者那么多，为什么吴承泽能成为圈内名人呢？

我觉得这些问题，都可以从冲浪对吴承泽的改变上得出答案。  **冲浪对于吴承泽来说，不仅仅是一个爱好，更是有一点像“救赎”一样的存在。**

为什么这么说呢？吴承泽第一次接触冲浪，也是因为机缘巧合。他在很年轻的时候就开始创业，因为给别人做担保被骗，背上了几百万的债务。这让他的人生一度跌入低谷，患上了精神疾病，生活状态也是浑浑噩噩的。

也正是在这段时间，他决定去海南散心，于是接触到了冲浪。吴承泽这样给我描述他第一次冲浪的心态：他说当自己踏上浪板的那一刻，会专注于当下，会觉得当前的世界里，只有眼前一个个等待他征服的浪，除此之外的别的事情都不重要，都会过去。

反复几次冲浪之后，吴承泽说自己是由表及里，完成了一次重生。在回到城市之后，他先是改变了生活方式，去了之前从来没去过的健身房，想改善自己的身体机能，更好地冲浪，整个人的生活也更健康了。

除此之外，他心态也变好了。在回到城市之后，他在事业上东山再起，还清了欠款，从之前的生活状态中解脱了出来。

吴承泽因为冲浪产生了巨大的改变，但他不想就此打住，他还想把冲浪的快乐分享给更多的人。带着这个想法，吴承泽在三亚后海村开设了亼樂冲浪客栈，想要把这里打造成冲浪爱好者的落脚点。

在和吴承泽的谈话中，我能特别明显感觉到，他是真心想把“冲浪”以及背后的一系列价值观，通过事业推广出去。

比如说，冲浪最早在国内还只是一个小众文化，没有多少人知道。为了推广这项运动，他就花钱赞助了中国的冲浪运动员，还号召了300多位爱好者，众筹拍摄了中国的第一部冲浪纪录片。

除此之外，因为冲浪文化和海滩是紧密相连的，所以吴承泽就特别希望也能宣传保护环境、保护海洋的意识。比如他通过亼樂这个品牌赚取的大部分收入，都会被用作推广、宣传保护海洋环境上。

这几年随着冲浪爱好者越来越多了之后，吴承泽也会花力气给冲浪者们科普。比如这个“五一”，他们就在后海村举办了一个环保主题日，号召所有游客不要往沙滩上丢烟头，也不要在海边放烟花，减少对沙滩的污染。

不过，我觉得吴承泽的故事最能打动我的，是他通过创建亼樂这个品牌，让很多人的生活也因为冲浪发生了一些改变。

比如，亼樂的几位冲浪教练，之前个性都比较叛逆，和家里人关系很紧张。但是他们通过教练的工作，获得了稳定的收入和生活，这让家里人对他们放下心来，家庭关系也有所缓解。

再跟你分享一个故事：亼樂有一位老顾客叫边忭，这个人在北京小有名气，因为她是一个美食和艺术集市“伍德吃托克”的联合创始人。她告诉我，因为在亼樂的体验，她不仅仅爱上了冲浪，而且还改变了自己的生活观。她  **从一个“结果导向”的人，变成了一个“过程导向”的人** 。

为什么冲浪会带来这样的改变呢？

因为她发现，  **冲浪者每一次下海，只有10%的时间在浪尖上，但是有90%的时间都是在等待一次好的浪。她觉得这个过程其实跟人生一样，我们一生中90%的时间，可能都在为一个高光时刻做准备。** 这让她知道，等待的过程本身就是人生的重要体验。在等待好浪的时候，她有不少时间和自己对话，从而真正走进自己的内心。

而亼樂这间客栈，也成了一个能让她“安放”的地方。她告诉我，亼樂的每一位房客在交流的时候，都会拿掉在城市生活中的标签，单纯以冲浪爱好者的身份交流。这让她觉得，大家都是被冲浪紧紧连接在一起的，彼此之间非常平等。

不知道你听了边忭的分享之后什么感觉。反正她的故事让我觉得，吴承泽让自己的亼樂客栈成为了一个分享快乐的节点，把他通过冲浪获得的快乐，不断分享给他人。我想，这也是吴承泽创办亼樂的初衷，以及他能获得一份“10分快乐”工作的真正原因。

好，我们和小红书一起策划的人间值得特别节目系列，到这里就结束了。在过去这3天里，我们一起认识了追求“即时满足”的中古店老板娘，追求美学表达的婚礼策划人，以及希望跟别人分享快乐的冲浪客栈老板。

和这三位小红书博主交流，给我一个感受：以前我觉得，工作快不快乐，要么取决于你做的事情是不是你的兴趣所在，要么取决于你在工作里的掌控感强不强。当然，收入足够高也是一个必不可少的因素。但是这几位博主的经历让我看到另外一个维度：  **工作快不快乐，还取决于你的工作，有多少跟别人共享快乐的机会。**

玖姐接触每一个顾客，都能分享中古文化给她的快乐；Siri服务每一个新娘，都能跟新娘分享人生重要时刻的快乐；吴承泽更是在他的客栈里，给每个顾客创造了跟彼此分享快乐的氛围和机会。

所以我觉得，咱们也不用羡慕这些小红书博主的生活。咱们不如琢磨一下，在你现在的工作当中，有没有什么跟别人共享快乐的契机呢？如果没有，能不能自己创造一些呢？好好把握这些契机，你或许也能拥有一份“10份快乐”的工作。

![https://piccdn3.umiwi.com/img/202105/04/202105042104060669203529.jpg](https://piccdn3.umiwi.com/img/202105/04/202105042104060669203529.jpg)

结束之前，我想分享给你一首特别的歌曲，叫《我们的力量》。这首歌我觉得就是一个“共享快乐”的好例子：得到高研院第8期，武汉校区雷神班的一位同学，叫杨凡，业余爱好音乐制作。这首《我们的力量》，是他拉着自己全班同学一起创作的一首班歌，歌词是23个同学一起写的。明天就是“五一”假期后第一天复工了，希望这首歌也能鼓励你，无论是在工作中，还是在生活中，都能记得，主动创造跟别人共享快乐的机会。

好了，这就是今天的人间值得。我是邵恒，我们明天见。

大卫邢：我看这三位小红书博主的故事下来，总体的感觉就是，意义真的太重要了。

吴伯凡在他的课程里讲过一个例子：

曾经有人效仿西西弗斯的传说做过实验，在监狱中迫使一群囚犯挖土坑，然后让他们填上，然后再挖开……如此一直进行下去，囚犯们的情绪很快就失控了。他们宁可去干其他更累但有用的活儿，也不愿忍受这种毫无意义的劳作。如果一直强迫囚犯这样做，他们会发疯。实际上，这种惩罚是如此之可怕，以至于最残酷的苦役营里，囚犯干的活儿，尽管非常繁重，但都会多多少少有一些用处、有一些意义。比如建造工程、道路、开掘矿产、开垦荒地等等，监狱不会让囚犯去做“西西弗斯式”的劳作。监狱管理者们本能地意识到，那样折磨囚犯太严厉了，那样的监狱也是无法管理的。。

再失落的人，都需要在生活里找到一点意义，这可能是我们和其他动物最本质的不同吧。

邵恒这几日的分享，其实让我们看到了现在的年轻人更多元化的工作和生活。为了理想和自己喜欢的事业而打拼。

因为工作和学习才是让自己激发创造力和赋予价值和意义的途径吧。

《人类简史》里提到，人类发展历程中，为什么“智人”能战胜其它古代人种，获得胜利呢？最根本的答案在于我们的祖先拥有一种更加发达的能力，这种能力就是语言能力。

他介绍了一个非常形象也非常有趣的理论：八卦理论。这也是第一个至关重要的革命：认知革命。所谓认知革命，就是指“智人”这种动物有发达的语言能力，超过了一般动物“河边有只狮子”的表达水平，它能八卦自己。而借着八卦自己的能力，智人培养出了描述虚拟对象的能力。而有了描述虚拟对象的能力，使得我们的祖先可以共同相信一件事物，这就让他们有可能跨越150人门槛，组建起复杂的社会，发展出高度的文明。

你看，我们的祖先也是靠“八卦自己”才构建起如今复杂的社会和高度的文明。我们想要在工作中获得快乐，也需要发展这样的能力。学会八卦自己，共享快乐！

凌繁荣：吴承泽的故事，让我联想到写“西西弗斯神话”的加缪用西西弗斯的故事来隐喻的人生。人生就是不停地推石头上山，人生也是荒诞的。加缪认为还有更荒诞的那就是一个人如果不推石头了，那又用什么来说明他的存在呢？
生活正是荒诞的，但只有这荒诞才能证明人的存在。加缪想象有两种人：一种人不知道自己的生活就是荒诞，而生活在荒诞中；另一种知道自己的生活就是荒诞，但仍然推石头上山，哪一种更像悲剧呢？
加缪认为前一种人更加悲剧。因为他的荒诞甚至不属于他自己！而后一种人，也就是西西弗斯，虽然他的命运也是荒诞，他的处境也没好到哪里去，但他因推石头而存在，他的荒诞属于他自己，他的石头也属于他自己，他支配了他自己的荒诞，因此我们可以认为他是幸福的。
