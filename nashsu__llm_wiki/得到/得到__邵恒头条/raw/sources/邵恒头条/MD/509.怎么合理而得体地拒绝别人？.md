# 怎么合理而得体地拒绝别人？

你好，这里是《邵恒头条》。我是脱不花，这是我帮邵恒代班的第十一天。

昨天分享了内向者的沟通锦囊，后台好多同学留言说因为不敢、不会、不好意思拒绝别人，不得不扭曲自己真正的需求，心累得很，希望展开讲讲。咱们新产品得到锦囊里，有一条锦囊，就是专门来教你学会拒绝的。今天，我们就来聊聊，怎么心安理得地拒绝别人。 

1.首先，得到锦囊的保留节目，咱先上个认知。  **不擅长拒绝别人，根本原因不是胆小或害羞，是边界感不好。**

过去我们总觉得边界感不好的人表现为行动过界、容易冒犯别人，其实，物极必反，那些一味退让、总是想要取悦别人的老好人，也是边界感不好，只不过是另一种表现形式。

2.  **边界感中最重要的，那就是自己与他人，尤其是重要他人 之间的边界，我管这个叫关系边界。** 你想想啊，办公室提携过我的前辈经常让我替他加班干活、异性领导让我晚上跟TA一起去吃个宵夜、身体很疲劳但是女朋友要求我陪她逛街、不爱应酬但是老公总叫我陪他出席饭局、我不去相亲我妈就说心脏疼等等等等。生活中的这些“日常性疼痛”可太多了。

不擅长拒绝的人面对这些问题通常表现为两种情况：一是张不开嘴只好满心不情愿地长期扭曲自己，心累；二是为了拒绝而编造借口，不知不觉间把自己陷在了一堆谎言之中，为了圆谎更累，早知道还不如答应呢。

3.好了，  **不擅长拒绝的根源就在边界感，请坚定这个认知，拒绝就是在保护自己的边界和底线** 。接下来咱们才能讲技术要领。

*拒绝的时候，态度一定要快速而坚定。* 有人会认为，拒绝会伤害到别人，错了，给人以错误的希望又剥夺别人的希望，才会伤害别人。你拒绝的不是人，而是某个人对你的某个要求。

就像一个姑娘如果在男生追求的第一时间就坚定地告诉对方：我现在享受单身独处，不想接受你的追求。这根本不会伤害别人。只有出于种种原因，不明确表态，若即若离，给人希望，磨叽到最后才说不行，对方才会觉得受伤害。

所以，如果你想要拒绝别人，一定要尽量直接表达。能当面说，就不微信说。能当场说，就不事后说。

4.  **第二个技术要领是，不要为了拒绝而撒谎。**

拒绝别人的时候，重点是表达拒绝，而不是提供理由。特别是不要没完没了地给理由。抱歉，我今天没法临时加班，家里有事。这就够了。你非得“哎呀，你看看，我家里亲戚来了，约好了要带他们去奥森散步，还要给老人买点东西”，明眼人一看就知道你在编造理由。

学会拒绝，是为了给自己减压，编造理由，会造成自己更大的心理压力。下次再习惯性地开始编理由的时候，就要在内心喊停，或者告诉自己，与其撒谎这么心累，干脆答应对方吧。

5.如果你觉得无法直接说“不”，那么得体的拒绝方法，简单来说可以分为两种。  *一种是“换方案，不换目标”；另一种是“换目标，不换方案”。* 这听起来肯定有点绕，咱们分开说。

换目标，不换方案，其实就是采取“yes，and大法”和“yes,if大法”。

之前我举过一个例子，就是有个人想要通过你到你单位求职，你不愿意，你可以说：好啊欢迎（yes）。然后说（and）：你把我们公司的产品都系统研究一下吧，等你整理简历的时候我可以给你辅导一下。你看，这就是换了目标，把帮他入职，换成了帮他准备简历。

再举个例子：

领导突然心血来潮，说“哎，咱们这个月再做个大型推广活动吧！”你别说“不行，没有精力了”，领导肯定是给你一顿训，嫌你上进心、奋斗精神不够。你可以说，“好啊（yes），过几天我认真准备个具体执行的思路去跟你沟通（and）”或者“明白（yes），我这边手上的活儿都满着，如果把那几个人调给我，我们磨合一下，我觉得可以开干（if）”。

*学会给对方换目标，本质上是为自己争取把不合理要求转变为合理化的机会。* 你让我做这个项目，我可以，但是我把“马上就干”这个目标偷换成了“过几天咱们讨论下执行方案”，或者“你能不能增加我的团队编制、扩大团队的力量”。

所以，再有前辈突然要求你帮忙加班，前辈开口不好拒绝，你可以加个条件、换个目标：“好啊，我跟家里说一声晚点回去，机会难得，正好跟您学一下这个数据分析的软件怎么用。”这样一来，你就把一起加班这个目标转换成了前辈能不能给你开个小灶传个手艺这个目标。

6.  **所谓“不换目标，换方案”，就是展现建设性的态度，为对方的目标提供新方案。** 比如，先生出于面子要求太太陪自己去应酬。太太并不想去，但是并不是非得说“不，我的独处神圣不可侵犯”，而是可以说：我腰有点疼坐不住，就不陪你们吃饭了，等你快结束的时候，我专门开车来接你，顺便把给朋友们的礼物专门送过来。先生的目的无外乎是带着老婆有面子，这是他的目标，如果太太围绕这个目标给出一个让他更有面子的方案，那太太就满足了先生的目标，还为自己争取了三个小时。这样的拒绝，别人无法拒绝。

7.当然啦，在不擅长拒绝这件事上，最扯的一种情况其实是“我不愿意但是我也不想拒绝，因为虽然我不愿意但是我想取悦对方”。这个，有的心理学家称之为取悦症。

*取悦症，是因为这个人的内心有一些错误的因果关系。* 比如，如果我老在替人加班，老板就会想着给我加薪。错，只有你绩效很高能力很强老板才会给你加薪。又或者，如果我虽然很累也陪女同事逛街，她就会喜欢上我。错，只有你很有魅力很有趣她才会喜欢上你。

如果你的不擅长拒绝已经到了取悦症的地步，乖，重新梳理一遍因果关系，建立一下正确的增强回路。

我找到了一张判断自己的取悦症程度有多严重的量表，很有趣，我附在文稿里，有空的时候不妨自己测试一下。

这里面有很多问题挺有启发，比如，它会问你是不是经常这么想：“如果我让别人生气了，我会觉得焦虑和不安”。或者“是不是很少把工作派给别人”。测一下，看看结果，你会对自己有一个新的认识。

8.  **拒绝他人的底气来自自己的手艺** 。有立身之本、有自信来源，内心的秩序就稳定，也就敢于作出决断。所以，如果上面的这些方法你觉得都不解渴，那么，你可以下定决心把心力都投入到长本事、学专业上，等你成了一个有本事、有水平、受尊重的人，那么，自然，这也就不是一个问题了。

最后，我可以推荐两本书给不擅长拒绝的人，一本叫《取悦症》，这本书最好玩的是提供了各种各样的测试，你可以体验一下。另一本叫《学会决断》，不仅仅说怎么拒绝，而是更积极地教我们提高决断力，当断则断。得到电子书都有，不妨一阅。

欧阳潇楠Merlin：隔壁吴军老师曾讲到边界感，这是职场、生活中非常重要的一个问题。

如何分清自己与他人的边界？
阿德勒的心理学理论中有个词叫“课题分离”。他认为，每个人都有自己的课题，不要把自己的课题和他人的课题搞混是建立边界感的重要方法。

比如，孩子不做作业，家长强行干预或直接替孩子去做。这就是家长的边界感不清造成的。做作业是孩子的课题，不是家长的，因此家长不能主动去干预孩子的课题。需要做的是帮助和引导孩子，让孩子认识到这是他自己的课题，需要自己按时完成和为什么需要这样做。
再比如，你给别人的信任，这是你的课题。别人是否要回报给你对你的信任，这就是别人的课题。搞清楚这一点，才不会觉得自己信任别人，别人也应该理所应当信任自己，在别人不信任你时，才能正确面对。

这就是课题分离的重要性，也是建立边界感的好方法。

谌逸：武志红老师在《自我的诞生》里把边界意识分为三类：身体边界，财产边界，地理边界。
今天的节目里脱不花老师提到了很多观点是武志红老师在课程中都有过具体分析。
1.不会拒绝是因为没有边界意识，每个人都有属于自己的边界，如果在自己地盘里自己不能做主，那么你的地盘可能就是别人的殖民地。（自己的地板包括自己的时间、精力以及财产。）
2.为了拒绝别人而不断编造理由，最终让自己的心灵受到折磨，武志红老师提出一个观点叫“躯体化”，是指当一种情绪或情感不能通过语言和行为自由表达出来时，就会通过身体来表达。比如，有人找帮忙的时候，不好拒绝就只能说我身体不大舒服，然后会发现自己的身体真的会不舒服。
3.拒绝别人只是拒绝了别人发出的一个请求，而不是拒绝否定了别人本身。害怕拒绝的人通常也会害怕去请求别人的帮助，因为同样害怕遭到别人的拒绝。没有形成独立完善自我的人会认为“我”等于“我发出的一个请求”，在面对别人的请求时也会难以区分“他”和“他发出的请求”，区分自我和自我发出的意志，你拒绝的不是人，而是某个人对你的某个要求。
4.武志红老师在课程里系统的讲解了如何保护自己的边界的办法，分为防御和进攻两个办法。最简单的防御手段就是做到心平气和的坚决，直接跟别人讲“我今天有事，不行”。进攻手段是在面对别人不断的侵入你的边界时不得不做的反击手段，比如我们尝尝会遇到有人跟你讲道理，让你听从他的意志，武志红老师的分析是首先得明确基本的逻辑关系“你说的很对，所以我就要听你的吗？”，其次明白“你的事是你的事，我的事是我的事。”
