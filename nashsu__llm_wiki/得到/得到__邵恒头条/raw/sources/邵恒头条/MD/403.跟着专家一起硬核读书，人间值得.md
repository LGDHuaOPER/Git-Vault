# 跟着专家一起硬核读书，人间值得

昨天，我提了一个倡议：如果“五一”待在家里，那不如跟三五好友拉个群，一起读读书。

如果你已经安排了出行计划，那么不如在路上的时候，看看我们的TOP148领读人怎么读书，这也是一件很有意思的事情。

我们公司负责领读项目的同事，跟我分享了一个内幕。他们根据领读人的风格，把他们分成了两个派别，一个是领读特别有专业水平的“剑宗”；一个是在领读的时候，会旁征博引的“气宗”。

今天的人间值得，我先来为你介绍几位“剑宗”的代表人物。

第一位我要为你介绍的领读人是张小玉老师（ [用户名：art张小玉](igetapp://user/detail?ddurlMinVer=5.2.0&uid=33877078) ）。张小玉老师是文化艺术作家，也是博物馆领域的KOL，她领读的一本书叫做 [《色彩的秘密生活》（戳此查看）]({"typeid":"28220","type":2}) 。

我发现在张小玉老师的眼中，我们平时生活中常见的色彩，背后都有很大一套学问。

比如张小玉老师问，为什么男人不容易区分口红的颜色？这可不是我们经常开玩笑说的什么“直男审美”，这是因为人类辨别红色的基因，是位于X染色体上的。那你知道，X染色体，女性有两条，男人只有一条。男性在这件事情上，天生就落了下风。

再比如说，为什么法国的第一夫人会公开表示，自己只喜欢穿蓝色。这可不仅是个审美的问题。张小玉老师说，在公元6世纪，人们开始从天青石中提取一种叫“群青”的颜色。天青石本来就很珍贵，而且开采之后还需要长途运输，这就导致“群青”这种颜色，只有在最重要的场合才能使用。就比如宗教作品中，圣母的袍子才能是群青色的，西班牙的王室会自称“蓝血贵族”，也是这个道理。

你看，在张小玉老师眼中，是不是生活当中每个常见的颜色背后都有一套运行的逻辑呢？

所以法国第一夫人喜欢穿蓝色，背后其实是个历史传统。

看了张小玉老师的领读，我感觉对这个世界，又多了一种观察的维度。

第二位我要为你介绍的领读人，叫做汤惟杰。这位领读人领读的是文学作品，而他的身份相当专业，他是同济大学人文学院的副教授、中文系硕士生导师（用户名：tygertyger）。他领读的书是《李健吾译文集》，因为这是一整套译文集，汤惟杰就挑选了其中的一本领读， [《包法利夫人》（戳此查看）]({"typeid":"20540","type":2}) 。

《包法利夫人》的故事，很多人都熟悉，但是看了汤惟杰老师的领读，你可能会觉得原来这个故事有很多细节，非常有嚼劲。

比如我就看到汤惟杰老师写到，窗户在这本书中有象征性意义。最开始，这本书的男主角，刚刚认识女主角爱玛，也就是未来的包法利夫人的时候，这位爱玛正坐在厨房里，窗户是紧闭的。汤惟杰老师说，这象征着爱玛在无聊的乡村生活中，个性受到了压抑。而当入夜了之后，男主角心中一边思念着爱玛，一边坐在床边，看着窗外夜空中的星星，这意味着他娶爱玛为妻的梦想，终将实现。

还有一个细节，也非常有趣。汤惟杰老师说，《包法利夫人》有个副标题，叫做“外省风俗”。这是什么意思呢？在故事中，包法利夫人从来没有去过巴黎，但是她一直把巴黎作为自己的精神故乡。因为在小说描写的19世纪，印刷术已经相当发达了，包法利夫人这样的外省女性，也可以通过购买巴黎的时尚杂志，来一睹上流社会的风采。这就是外省风俗的来源。

你看，汤惟杰老师的领读是不是把一本书抽丝剥茧？每一个小细节，都能聊出点门道。 [（汤惟杰用户名：tygertyger）](igetapp://user/detail?ddurlMinVer=5.2.0&uid=176543095)

除了这两位代表以外，知识城邦还有好几位硬核的领读人，比如领读《警察》的侯颖，之前的职业是刑警；领读《女生呵护指南》的乔苗苗，是一位妇产科主治医师。在领读人里，这个话题她最有发言权。如果你对这些书或者这几位领读人感兴趣，推荐你关注这几位领读人的知识城邦，加入这场读书盛宴。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。
