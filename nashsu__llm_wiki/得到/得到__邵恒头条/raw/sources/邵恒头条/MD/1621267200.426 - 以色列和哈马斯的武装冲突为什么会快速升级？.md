# 426 | 以色列和哈马斯的武装冲突为什么会快速升级？

你好，这里是《邵恒头条》，我是邵恒。 

以色列和哈马斯之间的武装冲突，最近备受国际社会关注。

你肯定也在新闻上看到了：从5月10号开始，以色列和加沙地带的武装力量哈马斯爆发了严重的军事冲突，如今已经持续了8天。冲突不仅没有停止的态势，而且还愈演愈烈。5月16号，以色列向加沙地区发起了冲突爆发以来最致命的一次袭击：以色列对加沙市区满是住宅楼和商家的繁忙街道发起空袭，摧毁了三栋建筑。这场袭击造成42人死亡，其中超过一半的人都是妇女和儿童。

同一天，联合国安理会紧急召开会议，在会上，联合国秘书长古雷特用了“完全骇人听闻”来形容这场冲突，并且督促双方立即停火。

关注这场冲突的人，在惊骇的同时也感到不解：我们都知道，以色列和哈马斯之间的恩怨由来已久。双方之间爆发冲突本来并不意外，可这次冲突的严重程度却超乎想象。我看到军事自媒体军武次位面评论说，  **这是2014年加沙战争以来，双方最严重的一次冲突。** 这到底是什么原因造成的呢？

《纽约时报》上有两篇分析文章，提出了两个让这场冲突不断升级的因素。核心观点我概括一下：  **第一，哈马斯的武装实力在过去7年里有了很大的提升。第二，哈马斯领袖和以色列总理，各自把这场冲突看作是巩固自身地位的政治筹码。**

这两篇文章来自于专栏作家托马斯-弗里德曼，以及一位驻开罗的记者莫纳-爱拿更（Mona El-Naggar）。在今天的《邵恒头条》中，我就来跟你分享一下他们的观点。

咱们先说托马斯-弗里德曼的观点。他一直很关注中东，在这轮冲突爆发后，他在一周内连续发表了两篇文章分析局势。第一篇主要描述了冲突的直接导火索——用希伯来大学一位专家的话来说，导火索是  **“神圣的日子”撞上了“神圣的领地”** 。

什么意思呢？这一轮的冲突是5月10号的一场骚乱引起的。那一天前的周末，犹太人和穆斯林刚好都有重大的节日要庆祝。  **周六，也就是5月8号，是穆斯林的“贵夜”，这一天被认为是先知默罕默德接受《可兰经》经文的夜晚，因此也是一整年里最神圣的一个夜晚。** 为了庆祝贵夜，上千名穆斯林涌向耶路撒冷老城，位于圣殿山的阿克萨清真寺。这个寺庙也被认为是伊斯兰教信仰当中的第三大圣地。

巧的是，在贵夜的第二天，也就是5月9号，是以色列的一个国家假日叫“耶路撒冷日”。这一天是什么日子呢？是为了纪念以色列在1967年获得了东耶路撒冷地区和圣殿山的控制权，统一了东西耶路撒冷。为了纪念这一天，以色列人会聚集在哭墙举办祷告活动。哭墙在哪呢？同样是在耶路撒冷老城的圣殿山。

那你想，这俩日子撞上意味着什么？意味着，  **几乎在同一时间，犹太人和穆斯林聚集在整个中东地区最有争议的圣地，各自庆祝在自己人看来很神圣，但是在对方看来完全不合理的节日。** 在这样的情况下，双方非常容易产生摩擦。

不仅如此。就在同一周里，在耶路撒冷还发生了一场政治抗议活动。为什么抗议呢？为了“神圣的领地”。简单来说，有6个巴勒斯坦家庭，居住在耶路撒冷里被认为是以色列领土的地区。一些犹太人此前向法院申请了一个驱逐令，要把这些家庭赶出去。巴勒斯坦人觉得这非常不公平，官司打到了以色列的最高法院。按计划，在贵夜和耶路撒冷日结束后的那个周一，最高法院就要宣判了。为了这件事，巴勒斯坦人走上耶路撒冷街头，举行了抗议活动。而抗议活动又恰好赶上了前面所说的节庆活动。骚乱就在这样的情况下爆发了。

但如果只是人们在街头发生摩擦，这件事后面还不会发展得这么严重。

麻烦的是，在骚乱发生后，以色列警方又做了一件在穆斯林看来，完全不可接受的事情：  **警方冲进了阿克萨清真寺，用催泪瓦斯、橡皮子弹等等工具驱散聚集在那里的巴勒斯坦人，造成上百人受伤。** 前面我们说了，阿克萨清真寺是伊斯兰信仰当中的第三大圣地，而且在以色列和巴勒斯坦的领土争端中，阿克萨也被认为是“最后的底线”。

就这么着，冲突的导火索被点燃了。

听到这，你可能会觉得，双方爆发冲突是可以理解的。但后面发生的一系列军事冲突，从规模和冲击力来看，这两方的反应也太夸张了吧？

如果你关注了新闻里的进展你就会知道，这哪是“爆发冲突”，这就是在打仗。

接下来发生的事情，咱们快速复盘一下：

首先是5月10号，哈马斯向以色列发射了火箭弹。接下来，从5月10号到13号，加沙地带的武装人员总共向以色列发射了1600多枚火箭弹。而以色列也立马开展报复行动，在三天内空袭了加沙地带600多个军事目标，打死了哈马斯多名高级指挥官。5月15号，以色列还攻击了加沙的一个媒体办公楼，声称那里窝藏了哈马斯组织的情报机构；紧接着5月16号，又发生了我们在开头描述的，以色列攻击加沙的住宅和商业区。

截止到5月17号，这场冲突已经造成了巴勒斯坦一方192人死亡，超过1200人受伤；以色列一方10人死亡，50人重伤，另有数百人受伤。伤亡人员当中有大量的平民，其中不乏妇女和儿童。

那么，为什么冲突会快速升级到这么严重的程度呢？难道以色列和哈马斯想靠打一场仗，彻底解决双方的领土问题吗？这完全不现实啊。

《纽约时报》的观点是什么呢？据《纽约时报》的文章分析，有两个因素，可能扮演了“催化剂”的角色，导致冲突的严重程度超乎想象。

一个因素是，哈马斯近些年来的武装力量有相当大的提升。《纽约时报》记者莫纳-爱拿更在她的文章里引用了一组数据，这组数据显示，在这轮冲突当中，前24小时，加沙地带发射出来的火箭弹有470颗。相比之下，在2014年的冲突当中，这个数字平均只有192。

除此之外，这次的火箭类型跟以前相比也有不同。2014年的时候，哈马斯大部分的火箭弹都是短程的土火箭，射程只有10千米左右。而远程的火箭弹当时只占8%左右。但是这一次，在冲突发生后的24小时里，有130颗火箭弹射到了90千米以外的特拉维夫，这在当时发射的所有火箭弹中占比高达17%。

也就是说，在过去7年里，哈马斯不仅增加了他们武器库的库存，而且还提升了远程打击的能力。这很大程度上得益于伊朗的帮助，因为伊朗协助哈马斯升级了他们在本地生产火箭弹的能力。据莫纳-爱拿更报道，哈马斯的武装实力让一些以色列指挥官都颇感意外。

**这是促成这场冲突快速升级的第一个因素，哈马斯有了足够强大的火箭弹生产能力。**

**第二个因素是，无论是以色列，还是哈马斯的政治领导人，可能都有一定的动机让冲突持续下去。** 这是托马斯-弗里德曼的观点。

托马斯-弗里德曼在他的专栏里，把当前的情况称为“1月6号时刻”。他认为，无论是对以色列总理，还是对于哈马斯，在这场冲突中都在经历一个对他们有利的“1月6号时刻”。

这是什么意思呢？

他这个类比是拿特朗普来说事。你肯定也记得，在1月6号，支持特朗普的抗议者冲进了美国国会山，特朗普因为煽动骚乱而受到了第二次弹劾。这起事件被看作是特朗普和他的支持者为了组织政治变革所作做出的“最后一搏”。

弗里德曼认为，类似的事情也在以色列上演。具体来说，是阻止了以色列总理内塔尼亚胡卸任、新内阁组建。

要知道，以色列总理内塔尼亚胡被称为是“屹立不倒”的总理，他已经连续担任总理长达12年时间。

但是从2020年初开始，他深陷腐败传闻，以色列总检察长在2020年1月对他提起诉讼，说他受贿、欺诈并且违背公众信任。2020年5月，内塔尼亚胡的贪腐案开庭，这让他成了以色列首位接受司法审理的在任总理，如果罪名成立，他可能要坐10年的牢。

因为这些原因，内塔尼亚胡的声望和地位开始下降。就在过去2年里，以色列举办了4次提前大选，你可以理解为，这几次大选都相当于是对内塔尼亚胡还胜不胜任的全民公投。

结果如何呢？虽然没有把内塔尼亚胡搞下去，但是情况对他也不乐观。这体现在，在每一次选举里，内塔尼亚胡都没能成功组建内阁，因为组建内阁需要内塔尼亚胡的政党确保或者证明，他们能获得议会一半以上的议席。就在这个月的5月4号，内塔尼亚胡再一次组阁失败了。

这时候，以色列政坛传出一个大新闻。5月9号，也就是以色列和哈马斯爆发武装冲突的前一天，以色列当地报纸报道说，一个反对党的领导人有可能能获得议会超过半数议席，组建新的政府。这个反对党领导人叫纳夫塔利·贝内特，曾经在内塔尼亚胡手底下当国防部部长。

而且更不寻常的是，这位反对党领导人为了组阁，和一个叫做“联合阿拉伯名单”的政党形成了同盟。从名字你也能猜到，这个政党的成员，是阿拉伯裔的穆斯林。托马斯-弗里德曼分析说，  **如果这样的内阁组建成了，那在以色列政坛是一件划时代的事：这将是近代以色列历史上，内阁第一次同时容纳以色列的犹太人和以色列的阿拉伯裔穆斯林。**

这件事要是干成了，内塔尼亚胡就彻底过气了。不仅是过气。如果他从总理的位置上退下来，还有可能马上会面临牢狱之灾。5月9号那天，以色列当地的报纸还引用消息人士的情报，报道说，新内阁可能在接下来一周就会形成。

但是，就在这个时代交替的时刻，5月10号，以色列和哈马斯的冲突爆发了。

冲突爆发的48小时之内，以色列的政局就发生了逆转。为什么呢？

**第一， 冲突很严重，在这个时候更理性的选择是，不要临时更换内阁和总理，保持稳定应对危机高于一切。**

**第二， 反对党本来想和阿拉伯裔的穆斯林组建一个“统一政府”，但是在当下，巴勒斯坦的穆斯林武装组织正在死命攻击以色列，这时候再组织“统一政府”，无疑会面临巨大的舆论压力。**

这时候最大的赢家是谁呢？你肯定也想到了，就是内塔尼亚胡。他可以继续稳坐总理的位子，直到危机结束，想出下一步应对对手的方案。

这就是他的“1月6号时刻”。也就是说，即便内塔尼亚胡不是发起冲突的一方，但是迎接冲突，对他的政治地位是有利的。

同样的，对于哈马斯来说，这场冲突也有类似的效果。根据弗里德曼分析，哈马斯是乐意看到内塔尼亚胡继续当总理的。这是因为哈马斯是一个立场比较极端的组织，他们认为在巴勒斯坦领土问题上，没有谈和一说，巴勒斯坦人必须消灭以色列人。

那他们怎么让巴勒斯坦人接受这样的理念呢？有一个简单的方法，就是让巴勒斯坦人看到，以色列的领导人很强硬，就算你不去消灭他们，他们也不会放过你，他们还要来夺取你们的家园。内塔尼亚胡，恰恰就是这样一个强硬的以色列领导人。也就是说，他是一个不错的靶子。

说到这，你肯定也明白了：在弗里德曼看来，无论是以色列的内塔尼亚胡，还是哈马斯，可能都把这场冲突看成是政治筹码。

好，弗里德曼的观点和《纽约时报》的报道我就给你介绍到这了。

当然，刚才分享的，只是他的一家之言。如果你有不同的观点，或者你看到其他有价值的分析，欢迎你在留言区分享，咱们一起探讨。这场冲突的后续进展，我也会为你持续关注。

好了，这就是今天的《邵恒头条》。我是邵恒，我们明天见。

礼之贤士：说起巴以冲突，就不得不提及宗教因素。不管多么理解的冲突，背后都有宗教的影子在起作用。这此事件中，是以色列方面主动挑衅，进入巴方的宗教场所，从而激发起对方的愤怒，使得冲突变得难以收拾。

那以色列为何敢于主动挑衅对方的宗教场所呢？这个问题就跟以色列人信奉的犹太教有关系。

犹太教是一神二元的宗教，一神也就是犹太教设定的“超余”是一个，二元意思是在这个设定内部，存在两个对立面。二元的其中一个，是真神雅威，而另一个，就是真神的对立面。谁是犹太教现实中发展的敌人，谁就是那个站在对立面的假神。

犹太教之所以要创立二元的结构，就是为了让全知全能的神，能够与犹太民族的命运绑在一起，让犹太人能够在犹太教中寻找生存下去的意义和答案。

为了自身的生存和发展，犹太人不断强调反对假神、强调对立面，而这就会陷入排他思维。犹太教里始终有一种紧张气氛，就来自这种总是树立对立面的思维方式。

这种思维方式让犹太人对他们的宗教既怕又爱，这当然是这种宗教的特色，但在现实中延续这种思维方式，后果将会是可怕的。

我们可以看到，迟迟得不到解决的巴以冲突背后，就隐藏着这种树立对立面的思维方式。
