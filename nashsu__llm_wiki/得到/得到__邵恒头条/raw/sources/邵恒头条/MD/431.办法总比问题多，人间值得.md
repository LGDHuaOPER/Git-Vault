# 办法总比问题多，人间值得

今天的人间值得，我想跟你分享两家幼儿园的故事。 

第一个故事是一家山东济南的幼儿园决定临时转行卖烧烤。我在文稿中附上了一张图。你可以看一下，虽然幼儿园和烧烤这两个词，平时我们不会放在一起，但这个幼儿园烧烤店看起来还真是有模有样，挺热闹的。

![https://piccdn3.umiwi.com/img/202005/19/202005192319028844537807.jpg](https://piccdn3.umiwi.com/img/202005/19/202005192319028844537807.jpg)

那为什么这家幼儿园要突然转行呢？

疫情期间，学校普遍封闭停课，学生和老师都被隔离在家。

大中小学的学生和老师，还是可以上网课，甚至还可以在家里举行升旗仪式，正常的教学活动其实没有被打乱，不过是被搬到了线上。

但是幼儿园可不一样，学生一回家，老师就彻底赋闲了。而且山东济南的这家幼儿园的性质还比较特殊，它是一家非普惠性民办幼儿园，按相关规定，这家幼儿园无法享受当地的扶持政策。幼儿园园长担心再这么下去，就算幼儿园复课了，老师也不在了。

所以他们就决定做一个尝试，开个烧烤摊。

烧烤摊需要场地吧？幼儿园的操场就正合适。

卖烧烤，得有餐饮服务许可证吧？幼儿园因为有食堂，所以证件齐全。

至于椅子、凳子，幼儿园也是应有尽有，只需要给老师做一下服务员的培训，就齐活儿了。

还真别说，这家幼儿园烧烤店的生意还真不错。园长说，虽然他们这个尝试只做了3天，但最多的一天营业额达到了9000元。对于一个餐饮业外行来说，这已经是很好的成绩了。

这还不是个案，我还看到云南丽江的一家民办幼儿园，转型成为一家包子铺，接下来再跟你说说他们的故事。

这家幼儿园面临的困境，也是缺乏收入。它一共有70多位教职工，维持每个月的运转大概需要30万元。在转型做包子铺之前，这些钱都是园长想办法，通过各种方法筹集的。

在今年三月，为了自救，园长就有了转型做包子的想法，后来，他们之所以有做包子铺的想法，其实也是一个巧合。是在好多年前，幼儿园孩子的家长就提过，说这家幼儿园的包子和面食很好吃，应该拿出来单独卖才对。没想到，多年前这么一句玩笑，居然成真了。

在疫情期间，这家幼儿园先是从儿童营养餐做起，在家长群里推广。一段时间后，发现家长的反馈都很不错。随着需求量越来越大，园长就申请了个体营业执照，租赁了新的铺面，正式卖起了包子。现在每天平均能卖70单，也算是缓解了员工薪水的问题。

我看有不少网友评论这条新闻，都用了一句老话，那就是：只要思想不滑坡，办法总比问题多。多想想办法，总有出路。

在看丽江的幼儿园院长采访的时候，我看到园长说了一段话，特别好，分享给你。

幼儿园园长说：“我身后有70多个教职工，就是70多个家庭。在这样的时候，责任和担当这两个词就相当重要，哪怕收入少一点，也要带着大家一起扛过去。”

这句话挺让我感动的。  *平时，面对困境，我们往往依赖智慧，但是对他人的责任心，也能成为我们突破困境的动力。*

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。
