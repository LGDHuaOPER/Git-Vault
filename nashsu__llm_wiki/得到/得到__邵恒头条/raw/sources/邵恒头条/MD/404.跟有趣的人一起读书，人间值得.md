# 跟有趣的人一起读书，人间值得

昨天，我为你介绍了我们148位领读人中，用专业视角解读图书的“剑宗”，今天我想给你介绍另一个流派，也就是在领读的时候，会跳出书本身，分享一些有趣故事的“气宗”。

我想跟你分享的第一位“气宗”领读人叫做 [王蓉蓉（戳此关注）](igetapp://user/detail?ddurlMinVer=5.2.0&uid=911576) ，她领读的书是 [《货币、权力与人》（戳此查看）]({"typeid":"23413","type":2}) 。这本书你一听名字就知道，很硬核，书名中的这三个词，哪个拿出来都足够写好几本书。

但是我看了王蓉蓉老师发的几条领读笔记，都很“接地气”。在领读这本书的时候，王老师有一个很特别的方法，就是每条笔记的开头，都用一个我们生活中熟悉的话题聊起。

比如“为什么最近原油价格暴跌？”“人民币今年会不会跌到7.5？”“生活中的那些经济指标，对我们有什么意义？”你看，这几个问题，是不是我们都觉得挺感兴趣的？

而且，王老师不仅会提问题，她的每一个问题，都会通过《货币、权力与人》这本书的观点来回答。我读王蓉蓉老师的领读，有一种看八卦的感觉，而且还是高级外行看的八卦。

第二位我想为你介绍的领读人，是一位彻头彻尾的行动派。

这位领读人叫做 [牛牛的Annie（戳此关注）](igetapp://user/detail?ddurlMinVer=5.2.0&uid=18136725) ，她领读的书是 [《第三道门》（戳此查看）]({"typeid":"14520","type":2}) 。这本书讲的是一个叫做班纳言的美国大学生，自己摸索出一套方法，在7年之内采访到了比尔·盖茨、扎克伯格、斯皮尔伯格这一系列大佬。

牛牛的Annie是怎么领读这本书的呢？她可不是简单地勾重点、列关键词。她自己准备做一个实验，就是采用《第三道门》中提到的方法，去采访这本书的作者班纳言。她采用的一个方法叫做“借来的公信力”。

在给班纳言写信的时候，牛牛的Annie是这样介绍自己的身份的，她说有一个3000万注册用户的平台，也就是咱们得到。这个平台发布了一份年度书单，《第三道门》在这份书单里面，而她自己是这本书的领读人。你看，这个借来的公信力，指的就是借得到平台的这种公信力。

这封邮件听起来可能很普通，但是，还真管用。邮件是4月21号写的，在4月23号，牛牛的Annie就收到了班纳言的回信。你看，这至少证明，《第三道门》书里的方法是有效的。

我的好几位同事都和我说，他们这几天，每天都等着牛牛的Annie的更新，觉得看她领读，就像在追一部真人秀节目一样。 

这样有意思的领读人，还有好几位。

比如领读人文心民老师，他领读的是《穗子的动物园》，他大学学的是中文系，但是工作之后，没有从事相关工作。在领读的过程中，他每天都会根据书中的情节，仿写一段，他说自己找回了当年读书的感觉。

再比如得到大学的学员许晶，他领读的是《原宿牛仔》。许晶在日常的生活中是个喜欢潮牌的人，他在领读这本书的时候，不仅能和你说明白潮牌的发展史，还能和你解释背后日本宏观环境的变化。

好了，连着三天，我都在和你说读书这件事，明天我再和你聊另外一件，特别适合在“五一”假期做的事情。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。

有趣的人对于读书也有不一样的打开方式，分享几种有趣的读书法：
   
多维研读法 ：从多个角度去读一本书；
角色扮演法：读书时，作为书中的一个角色，让你的情感融入故事之中；
提炼精华法：对于一些作品，不仅要精读，还要总结归纳，提炼出其中的精华；
时空穿越法：作为一个时空穿梭者，进入书中的世界；
举一反三法：读一本书，进行头脑风暴，从而悟出更多的道理；
高山仰止法：以欣赏的眼光去读书；
居高临下法 ：站高一层，像老师审查学生作业一样去读书。
 
多种有趣的阅读方式可以帮你多维度了解书中的精髓。而读书的快乐，往往莫过于突然发现“我心里潜伏着的某个想法”，一下就被书中的某个句子唤醒了，忍不住拍腿大叫：“说得好，痛快这不正是我想要说的么。”
