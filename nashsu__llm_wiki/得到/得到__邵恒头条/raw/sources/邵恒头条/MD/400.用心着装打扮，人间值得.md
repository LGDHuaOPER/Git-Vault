# 用心着装打扮，人间值得

最近我注意到，我们公司的好几位女同事，每天的穿着打扮都非常讲究。

先和你介绍一位同事，我叫她小鹿姐。她的讲究，可不是每天要穿大牌的衣服，背贵重的包。而是她每天佩戴的口罩，都和她衣服的颜色相呼应。比如今天穿的是绿色衣服，就戴绿色的口罩；红色的衣服，搭配的就是红色的口罩；前段时间，有一天小鹿姐穿了一件翻毛皮的棕色外套，她戴的口罩也是棕色的，而且看起来材质，也非常像翻毛皮。

![https://piccdn3.umiwi.com/img/202004/29/202004292302525742335563.jpg](https://piccdn3.umiwi.com/img/202004/29/202004292302525742335563.jpg)

不过小鹿姐和我说，她每天专门花时间选择口罩的颜色，可不仅仅是为了让自己每天的穿搭看起来协调。

小鹿姐专门给我秀了一下她买口罩的淘宝链接。我发现一件很有意思的事情，就是淘宝店家在商品名上，除了写上了口罩的基本信息以外，还会额外附上一句“每天一种心情”。

你看，哪怕在疫情期间，大家必须每天戴着口罩，也总是有人能找到办法，让自己每天的生活都丰富多彩。

除了买不同颜色的口罩以外，我一位叫天云的女同事告诉我，她的化妆技术，在疫情期间得到了大大的提升。

早在2月初的时候，我就听到一句玩笑话，说疫情对于口红的影响非常大，因为大家都戴口罩，涂口红纯属浪费。

不过天云可不这样想，她和我聊了一下自己的心路历程。她说自己之前是一个不怎么化妆的人，出门之前只干简单的三件事：打粉底、画眉毛、涂口红。但是因为疫情期间要戴口罩，她就发现，一个人的眼妆，最能够反映她的精气神。于是她就报了化妆的视频课程，每天在线学习、拍照打卡。

天云告诉我，她现在化妆的精致程度，比疫情之前上了一个台阶。每天出门之前，都会化全套的妆，当然，眼妆格外地用心，而且在选择眼影的时候，还会考虑它和衣服的颜色是否搭配。

天云还和我说了一段话，我觉得挺有意思的，分享给你。她说其实花心思化妆这件事情，不仅仅是为了让自己心情好，更是在给自己鼓劲、加油。告诉自己在特殊时期，反而应该做更充分的准备。

不过，在每天的打扮上能花心思，可不仅仅是女生的特权。我这几天在新闻里看到一件特别有意思的事，说杭州养正小学开学了，为了让学生养成良好的卫生习惯，学校就做了一个很有创意的方案，那就是让学生必须佩戴“一米帽”上学，而且在上学的过程中，帽子必须保持完好无损，还不能够碰到他人。

我在文稿中插入了一张图片，你可以看到，一米帽其实特别像宋朝的官帽，帽子上有两根长长的翅膀，戴在小朋友头上，特别可爱。

![https://piccdn3.umiwi.com/img/202004/29/202004292303332650037010.png](https://piccdn3.umiwi.com/img/202004/29/202004292303332650037010.png)

那你想，孩子的天性是爱玩，愿意挤在一起凑热闹，戴上了一米帽，孩子对于一米安全距离这个概念，有更直观的认知。而且，小朋友们戴的一米帽，还不是学校发的，而是他们自己动手做的，各种样式的都有，甚至在同学中间，他们还会评选自己最喜欢的“一米帽”。

好了，今天我跟你分享了三种特殊时期、特别花心思的着装思路。如果在疫情期间，你也会在穿搭上额外花功夫，欢迎你把你喜好或者习惯分享给我。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。
