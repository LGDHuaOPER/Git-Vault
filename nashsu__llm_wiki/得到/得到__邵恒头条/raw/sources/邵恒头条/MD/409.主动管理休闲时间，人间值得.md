# 主动管理休闲时间，人间值得

前两天，罗辑思维的节目分享了古典老师的一个理念，叫“OFF学”，也就是休闲的学问。

古典老师说，想要真正实现放松，你得把休闲当做一件项目来管理，有详细的计划。比如他建议，在年初就列好自己的休闲安排，提前和公司请假、和同事协调，让别人不好意思打扰你。这样你才能全身心地投入到休闲这件事情中。

最近，我发现了一个有趣的小产品，这个产品其实就是在实践“OFF学”这个理念。

我在文稿里放了一张图片，你可以看一下：这个产品，其实是一本薄薄的小册子，是印象笔记和美团外卖联合出品的，名字非常直接，叫做：等外卖的时候，你可以做什么。它讲的其实就是除了刷手机以外，你还能怎么打发等外卖的这段碎片时间。

![https://piccdn3.umiwi.com/img/202005/06/202005061905315703371624.jpg](https://piccdn3.umiwi.com/img/202005/06/202005061905315703371624.jpg)

上面总共列举了24件小事，都很简单。比如建议你写一首三行诗，记录一下当下的心情，或者建议你拿出手机，拍摄一下窗外的云。

有一些建议，走的是暖心路线，比如主动给家里人打个电话。我一位同事小尹，还真的实践了这个建议。她说，一个人在外漂泊，其实时时刻刻都挺想家的，但每次和家里打电话，也只是简短地问候几句身体和工作。但在拿外卖之前给家人打电话，天然有话题，聊一聊接下来要吃什么，话匣子很自然地就打开了。

当然，我觉得对于大多数人来说，拿到这个小册子也就是看个乐子，这里面也有一些有趣味的冷知识。比方说，第16条写着，香菜、大蒜和芝麻，都是张骞打通西域后带回来的，没有他就没有香油碟。

第9条写着，在宋朝的时候，首都人民也爱叫外卖。我专门去查证了一下，还真有这么一回事。宋朝人点外卖，主要靠店小二跑腿，把食物装在能保温的温盘里，用木质或者竹质的食盒提着。

不过，对于我来说，小册子里的内容倒是次要的。我觉得这本小册子的价值，主要还是在于它提醒我们休闲时间，也值得更精细地管理。

你想，为什么我们在等外卖的时候，都习惯刷刷朋友圈，打打游戏？还不是因为我们把这段时间，当做工作的空隙，想趁此抽离出来，喘一口气。可刷手机，并不是什么高质量的放松。

但如果我们模仿这个小册子的思路，更主动地管理这段时间呢？比如戴上耳机，让自己沉浸在一首歌中，或者观察一下公司附近的便利店，又上新了什么新商品。那么这样，即便是等外卖的那几分钟，也能变成一段高质量的休闲时间。

如果你还有什么好点子，也能帮助自己主动管理休闲时间，欢迎你分享给我。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。

胡大壮儿～🤪：从当前的作息规律中找到空闲时间。

你可以观察自己一周的时间，采用时间统计法，客观记录每半小时自己做的事情，从中找到能够马上就能利用起来的空闲时间。

比如，原来上下班的通勤时间里，你一直都是带着耳机听歌。那么这段时间就可以利用起来，阅读电子书。

又如，你去吃饭的时候，等候朋友或者等座位的时间，原来是用来刷手机的，那么这段时间也是可以用来读一点书的。

再如，每天吃完午饭后都会和同事在办公室聊八卦新闻，这个时间可以选择饭后散步，消化食物。

这样做的好处在于，这些空闲时间是原有作息规律中就有的，所以更好适应。

还有就是它们一般是处于每日必做事情（如工作，睡觉，吃饭）的间隙，很容易将其模式化，习惯化。
