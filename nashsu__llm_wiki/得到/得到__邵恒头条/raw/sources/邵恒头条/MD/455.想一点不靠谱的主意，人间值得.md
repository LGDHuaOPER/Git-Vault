# 想一点不靠谱的主意，人间值得

今天的人间值得，我想邀请你和我一起，给一些问题想一些不靠谱的解决方案。

之所以会有这样的想法，是因为我最近看了一本书，叫做《how to：如何不切实际地解决实际问题》。 

这个书名是不是一听就不怎么靠谱？我再给你读一下它的第一页：

免责声明：不要在家中尝试书里提到的任何东西。本书作者是一位互联网漫画家，并非健康和安全领域的专业人士。他喜欢把东西点燃或者引爆，这说明他没有为你的人身安全着想。出版方和作者不会为本书所含内容直接或间接导致的任何后果负责任。

你看，这本书真是从书名到免责声明，都透露出三个字：不靠谱。

不过，我其实从这本书中，感受到了一些不靠谱的价值。

我得先从这本书的作者介绍起，这是一个叫做兰道尔·门罗的人，他之前是NASA的机器人专家，离职之后当起了全职的科普作家。他做科普的方式很特别——他创立了一个网站，叫做“what if”，专门搜集和回答网友提出的稀奇古怪的问题，比如“如果所有人都拿着激光笔，同时照向月亮，月亮的颜色会发生变化吗？”或者是“如果把牛排从天上扔下来，需要多高的距离，可以让牛排刚好烤熟呢？”

兰道尔把这些问题搜集起来，然后特别用心地回答，最后成了一本书，叫做《what if 那些古怪又让人忧心的问题》。

而这次他写的《how to》这本书，则是在《what if》的基础上，又往前迈了一步。兰道尔会用一些稀奇古怪的方法，解决一些日常生活中的问题，比如“如何过河”，兰道尔会从“把水煮干”这个角度去回答。你看，这种方法真的实施起来，一点都不靠谱，甚至还有点危险，所以在书的一开头，写上免责声明，也算是情有可原。

我给你说个印象比较深刻的，这本书的第19个问题，是怎么传输文件。

当然，兰道尔给出的解决方案，绝对不仅仅是通过邮件，或者是u盘传送那么简单。他说，有时候我们会遇到一种情况，那就是给一个在密林深处的人传输文件，而且山里没有任何信号。

你可能会想到用无人机，但是兰道尔说，因为无人机的电池容量有限，它飞不了一会儿，电量就会耗尽。

那怎么办呢？兰道尔给了个特别开脑洞的方法，他说有一种蝴蝶，叫做君主斑蝶，它是一个飞行高手，只需要一个季节，就能迁徙几千公里，从加拿大一直飞到墨西哥。

所以你如果想要把文件传输给别人，特别是这个人刚好在蝴蝶的迁徙路线上，那就可以试试君主斑蝶。而且，别担心蝴蝶体型太小，载不动储存文件的芯片，你可以把文件拆成好几份，用一群蝴蝶帮你运输，甚至还可以选几只运送备份的文件。

别看这个方法不怎么切实际，但他提醒了我一件事。我们总是觉得，科学是一个界限明确的东西，比如解决物理问题，就需要用物理方法。但其实针对每一个问题，这个世界都准备了成千上万、涵盖各个领域的知识，来帮我们解决问题。比如传输文件，是个通讯领域的问题，但是没想到，它有来自生物领域的方法。

除了这个之外，我还有个预感，兰道尔的思考过程，也许还可以点亮别人。比如有没有可能一个人觉得用蝴蝶传输的脑洞很好，然后以此为契机，写出一本科幻小说呢？

我提议今天，我们都可以做一个小尝试，说一个现实生活中的难题，然后提出一个天马行空的解决方法，并且试着去证明它。比如你可以尝试回答一下，如何在不用任何通讯设备的情况下，在一个2000万人的大城市，和一个特定的人见面？我在评论区期待你的脑洞，看看我们能不能互相启发、互相点亮。

好了，这就是今天的#人间值得#，我是邵恒，我们明天见。
