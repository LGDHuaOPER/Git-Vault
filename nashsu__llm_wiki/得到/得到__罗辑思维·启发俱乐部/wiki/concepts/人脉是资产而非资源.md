# 人脉是资产而非资源

## 定义

“人脉是资产而非资源”是[[罗振宇]]在[[启发俱乐部第3期 - 你逃出“高考模式”了么？（音频版）]]中，引用一位行业协会会长的经营哲学。它从[[有限与无限的游戏]]的视角，重新定义了人脉的本质。

- **资源**：需要被开采、消耗、变现，以实现一次性价值的东西。例如，煤矿是资源，需要挖出来发电才能使用。将人脉视为资源，意味着会急于利用关系来获取短期利益，是一次性的有限游戏玩法。
- **资产**：需要被保值、增值，以产生长期、持续价值的东西。例如，房产是资产，其价值增长本身就是目的，而非急于出售变现。将人脉视为资产，意味着要用心维护、帮助他人成长，让关系的长期价值不断增长，是可持续的无限游戏玩法。

## 核心区别

| 视角 | 人脉是资源 | 人脉是资产 |
| :--- | :--- | :--- |
| **游戏类型** | 有限游戏 | 无限游戏 |
| **核心动作** | 开采、利用、变现 | 维护、保值、增值 |
| **关系导向** | 一次性交易 | 长期共生 |
| **典型行为** | 向朋友推销产品（微商） | 无私帮助，不求即时回报 |
| **最终结果** | 关系可能被消耗殆尽 | 关系网络生生不息 |

## 相关概念

- [[有限与无限的游戏]]：这一概念是区分“资源”与“资产”视角的底层哲学框架。
- [[关系价值]] 与 [[人和人的连接]]：这一概念深化了对关系价值的理解，强调其长期性和成长性。
- [[高考模式]]：高考模式倾向于将一切（包括人）视为实现目标的工具或资源，而“人脉是资产”正是超越该模式的一种体现。
