# 生命1.0 / 2.0 / 3.0 框架

该框架由迈克斯·泰格马克在《生命3.0》中提出，根据软件（行为/智力）和硬件（躯体）的可设计性将生命分为三个演化阶段：

- **生命1.0**：硬件和软件均由演化缓慢迭代，个体无法主动适应。典型代表为单细胞生物。
- **生命2.0**：硬件靠演化，但软件（知识、文化、行为）可在个体有生之年自我设计和升级。典型代表为人类。
- **生命3.0**：软硬件皆可自我设计、不断升级的生命形态。这正是超级人工智能（AGI）的特征。

这一框架将人工智能定位为地球生命演化的内在延续，而非外在工具，从而颠覆了以人类为中心的技术观。
