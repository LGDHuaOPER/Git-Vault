# 一朝天子一朝臣：清代制度化清洗

“一朝天子一朝臣”在清朝发展成极为典型的制度性权力交接仪式。新皇帝登基后，几乎无一例外地会清除前朝最受重用的宠臣，以确立自己的绝对权威。这一行为虽然有具体个人恩怨或政绩评价的说辞，但深层逻辑是结构性而非个人性的。

## 清代的清洗链条

| 新君 | 处置对象 |
|------|----------|
| 顺治 | 多尔衮（死后鞭尸） |
| 康熙 | 鳌拜 |
| 雍正 | 隆科多、年羹尧 |
| 嘉庆 | 和珅 |
| 咸丰 | 穆彰阿 |
| 慈禧（同治初） | 肃顺 |

每一起清洗都伴随着“奸邪误国”“结党营私”之类的罪名，但其背后是新君急于摆脱父皇阴影、树立个人权威的政治需要。咸丰指责穆彰阿“揣摩以逢主意”，实际上正是在否定其父道光皇帝的决策，穆彰阿不过是这一符号游戏的替罪羊。

## 对历史认知的影响

制度化清洗直接导致大量高级官员在历史上被符号化为“奸臣”，因为这些官员的起伏成败往往取决于清洗的政治需要，而非其实际操守和政绩。理解这一传统，有助于我们在阅读相关人物时剥离道德标签，看到其背后的结构性力量。穆彰阿的案例正是这一逻辑的产物。
