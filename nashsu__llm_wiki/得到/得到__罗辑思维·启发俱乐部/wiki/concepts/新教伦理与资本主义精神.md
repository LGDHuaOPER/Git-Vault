# 新教伦理与资本主义精神

马克斯·韦伯提出的经典社会学命题，主张欧洲宗教改革后，新教伦理与资本主义精神之间存在因果关系，新教国家因此发展更好。该理论影响深远，但在《罗辑思维》第316期中被作为“经典失效”的典型案例进行解构。

## 核心主张
信仰新教的人群在伦理上与资本主义精神有内在亲和力，这解释了为什么新教国家（如英国、德国、美国）经济发展较好，许多成功商界人士都是新教徒。

## 批评与反例
据段宇宏的批评，该论述从未得到西方主流历史学家的认同：

| 反例 | 说明 |
|------|------|
| 德国 | 天主教徒占30.8%，主要分布在富裕的西部和南部；新教徒占30.3%，主要分布在经济较落后的东部 |
| 东亚（中国、日本） | 经济崛起与新教伦理无关 |
| 爱尔兰 | 地道的天主教国家，发展良好 |
| 利比里亚 | 新教徒占85%，却是失败国家，人类发展指数排名第175名 |

## 评价
韦伯的论断作为研究思路具有新颖性，但若作为确切结论接受则距离真相甚远。这体现了经典受限于时代背景和研究方法的局限性，是“从经典到经验”范式转向的重要论据。
