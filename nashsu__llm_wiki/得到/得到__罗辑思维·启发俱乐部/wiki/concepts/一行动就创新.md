# 一行动，就创新

**提出者**：罗振宇在2024“时间的朋友”跨年演讲中归纳的三大核心行动主张之一。

**定义**
在面对未来不确定性与悲观预期时，**在给定的约束条件下展开具体行动**，行动本身就会自动催生创新，而不是等创新方案想清楚了再行动。创新不是行动的前提，而是行动的副产品。

**核心叙事**
演讲用林森和“麒麟大口茶”的故事说明这一原则。林森预感到茶饮行业未来人工成本必然升高、目标消费人群必然减少，于是决心研发一种**只需一个人就能运营的茶饮店店型**。为此，他把产品精简到一种，砍掉导购收银岗位，将所有设备集成到单人臂展范围内，甚至聘请武术老师为店员设计表演性动作。最终在103家门店中有48家实现了“一人店”模式，部分门店月营收 3 万元仍能净赚 1 万元。罗振宇评价：“如果一个普通人能在给定条件下做点什么，让明天比今天好一点，行动就会打开创新的空间，突破就在其中。”

**与相关概念的关系**
- 与 [[一具体就深刻]] 并列：前者强调行动作为创新的前提，后者强调把笼统问题变成具体动作才能深刻推动变革。
- 与 [[乐观者先准备好雨伞]] 配套：因为悲观而行动，行动催生创新，从而形成真正的乐观。
- 与 [[一困惑就出门]] 呼应：出门是行动的一种，也是获得创新的重要途径。

**证据强度与边界**
本概念主要以林森的个案叙事作为支撑，缺乏量化的失败率或成功比例分析（48家成功，55家仍在研发或遇其他约束）。行动是否必然导向创新，依赖于行为者的资源、行业特性与市场运气，不可简单外推为“只要行动就能成功”。该概念更适合作为激发行动的启发式，而非可复制的管理工具。
