# 制度演化

制度演化是指制度通过逐段解决上一阶段暴露的问题而接力演变的过程。这一概念强调，制度的最终形态并非由宏大计划或单一因素决定，而是在每一个阶段回应具体问题、做出微小选择的过程中逐步形成的，且这一过程具有不可逆性。

## 核心特征
1. **逐段接力**：每一个阶段都是上一阶段问题的解决方案，同时产生新问题，推动下一阶段的演化
2. **无计划性**：初始计划不重要，演化方向由过程中每一个微小选择决定
3. **路径依赖**：每一个选择都不可逆，后续演化受限于之前的路径
4. **价值观嵌入**：每一个解决方案背后都有自我约束和价值观指针

## 军事史案例：雇佣军到常备军
雇佣军向常备军的演化经历了六个阶段，每个阶段都是对上一阶段问题的回应：
1. 单个雇佣兵签合同 → 士兵不懂合同
2. 包工头整包合同 → 临时拼凑战斗力差
3. 固定军团组织 → 合同过于复杂
4. 意大利本地人成为军头 → 形成军阀
5. 城邦吸纳优秀雇佣军（交易费用内部化）→ 剩余城邦无优质雇佣军可用
6. 自行招募散兵游勇，建立常备军

## 中国历史平行案例
唐代从[[府兵制]]到[[募兵制]]的转变遵循类似的演化逻辑：府兵制在战争频繁时无法维持，募兵制作为“解药”出现，但带来了藩镇割据的副作用。这与欧洲雇佣军到常备军的演化形成跨文化呼应。
