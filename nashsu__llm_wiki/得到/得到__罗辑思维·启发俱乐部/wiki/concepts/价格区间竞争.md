# 价格区间竞争

## 定义
价格区间竞争是指商业竞争的战场不再按行业品类划分，而是按价格区间划分。所有处于同一价格区间的商品，无论品类，都在争夺消费者赋予该笔支出的“意义”。

## 核心逻辑
1. **消费升级的体验转向**：基本消费需求满足之后，人们开始追逐体验和意义。在很多情况下，体验和意义就是追逐自己买得起的商品的价格区间，以便把社会地位呈现出来。
2. **先定价格，再定产品**：过去熟悉的商业逻辑是先给消费者合适的产品，然后考虑定价。新出现的商业逻辑是先考虑产品的价格区间，这个价格区间本身就是体验的一部分，然后再考虑产品怎么定位和优化。
3. **营销的本质**：引用科特勒名言——“营销，就是价格以产品为载体卖出去。”卖出去的不是产品，那只是载体，真正卖出去的是那个价格。

## 价格区间的消费阶梯
每个价格区间都会出现一个消费者渴望的商品和一家伟大的企业：

| 价格区间 | 代表性商品/品类 |
|---------|---------------|
| 几元 | 可口可乐 |
| 二三十元 | 星巴克 |
| 五十元 | 电影 |
| 一两百到三五百元 | Zara等快消服饰 |
| 1000-3000元 | 安卓手机 |
| 5000-10000元 | iPhone |
| 两三万元 | 出境游 |
| 十万元级 | 爱马仕、手表、入门车 |
| 几十万元 | 升级的车 |
| 百万元级 | 房子或进一步升级的车 |
| 千万元级 | 房子 |
| 更高 | 游艇、私人飞机、艺术品、足球队 |

## 奢侈品定价的艺术
奢侈品行业深谙此道。德比尔斯（De Beers）用钻戒代表爱情，并非因为广告词写得好，而是因为它为人们追逐更贵的婚礼提供了一个新的价格区间。奢侈品定价的艺术是“量化产品对消费者的价值，不考虑成本、竞争对手或市场价”。

## 人性基础
人性当中有一个特点：人们总是对勉强够得着、但还不能轻松得到的东西充满期待。消费者总是选择一场与价格区间门当户对的“婚姻”。
