# 四步自我介绍框架

罗振宇在罗辑思维第570期中提出的一套口头自我介绍套路，目的是在任何陌生场合快速将自己“嵌入”到现场的人际网络中。该框架后被映射为[[每天听本书]]产品的底层逻辑，成为[[知识转述]]的实践基石。

## 四步内容

1. **硬信息（我是谁，从哪来）** — 即姓名、背景等可验证的事实，为听众建立一个“记忆锚点”。
2. **机缘（为什么出现在这里）** — 描述与现场、听众或事件的关系，拉近心理距离。
3. **我能带来的价值（对需求的判断）** — 主动展现自己对听众需要的洞察，并提出可提供的帮助。
4. **我需要得到的帮助（对价值的判断）** — 认可对方的价值，向现场提出具体的支持请求，完成双向连接。

## 本质：逐步接入人际网络

每一步都在逐步深入连接：
- 第一步 → 锚点建立
- 第二步 → 亲近感建立
- 第三步 → 展示需求判断能力（我懂你需要什么）
- 第四步 → 展示价值判断能力（我认可你能给我什么）

完成四步后，介绍者已从“陌生人”被编织进现场的关系网中。

## 产品映射

在《每天听本书》中，这四个步骤对应为：

| 自我介绍 | 产品逻辑 |
|---------|---------|
| 硬信息 | **硬知识** — 准确还原书的核心内容与结构 |
| 机缘 | **软连接** — 说明书与当下语境、用户已有认知的关联 |
| 带来的价值 | **价值发现** — 明确该书能为用户解决什么问题、带来什么启发 |
| 需要的帮助 | **应用场景** — 提示用户在何种情境下可以运用这些知识 |

## 认知意义与边界

- 作为**套路**，它提供了高度可复制、低认知负载的交流模板，与[[模式化思考]]和[[标签化]]有相通之处。
- 但套路本身不保证深度；若只停留在形式，可能落入“肤浅社交”的批评——正如部分用户对知识产品的质疑（见[[知识转述是否必然牺牲知识的深度与准确性？]]）。
- 其价值在于“嵌入网络”，而非“完备表达”。短短几十秒不可能完全介绍一个人，但可以完成一次有效的连接。
