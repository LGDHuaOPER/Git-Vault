# C形曲线

出自何帆《变量3》，描述一种技术与社会博弈的轨迹：当技术变化的速度超过社会适应的速度时，社会会反过来对技术创新进行管制，形成一条先扬后抑的 C 形曲线。2021 年互联网行业的强监管被何帆看作是 C 形曲线的自然结果——技术跑得太快，社会需要时间适应。

这进一步佐证了“确定性”论断：行业的遭遇不是突如其来的不确定性，而是技术-社会互动的内在规律。
