# 股价对内部士气的塑造

**股价对内部士气的塑造**指出，上市公司的股价不仅反映市场交易，更对内部员工起到强烈的信号作用，进而影响士气与人才留存。这是[[内部优先原则]]在商业领域的具体体现。

## 来源
红杉资本沈南鹏提出：许多老板认为不卖股票则股价高低无关，但实际上股价是整个市场对公司的评价。股价暴跌会打击员工信心，使之怀疑公司前景，导致核心人才流失，加速公司衰败。因此，没有老板能真正不关心股价——它首先作用于内部。见[[沈南鹏]]。

## 逻辑链条
1. 股价 = 市场对公司未来价值的评价（外部信号）
2. 员工感知此信号 → 判断个人职业前景（内部心理）
3. 若评价负面 → 士气低落、能人离职 → 公司竞争力下降（内部崩溃）
4. 公司竞争力下降 → 股价进一步下跌 → 恶性循环

可见，股价的外部价格发现功能，最终是通过内部渠道发挥作用。管理者必须意识到这点，维护内部信任比短期市值管理更重要。

## 与数据造假类比
数据造假同样向内部释放“老板无诚信”的信号，破坏内部信用，最终自毁根基。
