# 杨乃武

杨乃武是晚清四大奇案之一“杨乃武与小白菜案”的男主角，浙江余杭人，举人出身。因被诬告与小白菜通奸并合谋毒杀其夫葛品连而蒙冤入狱，遭受刑讯逼供，双腿被夹断致残。其案最终在复杂的人脉运作、舆论压力和政治博弈下得以翻案，但本人已落下终身残疾。

杨乃武案的翻案被视为极端幸运的“小概率事件”，其得以昭雪的关键链条为：杨乃武 → 同学吴以同（胡雪岩幕僚）→ [[胡雪岩]] → 夏同善 → [[翁同龢]] → 两宫皇太后。此外，浙江籍京官的联名上书、《申报》的舆论转向以及清廷借机打压湖湘系地方势力的政治需要，均为翻案的重要因素。
