# 纳粹德国

## 概述

纳粹德国（1933—1945）是阿道夫·[[希特勒]]领导的法西斯政权。本文从战争动员能力的角度，重新审视了纳粹德国在二战中失败的结构性原因。

## 政治基础

与通常印象不同，纳粹党的社会基础实际上相当薄弱：

- **出身底层**：纳粹党从成立到掌权仅14年，党员基本出身社会底层和边缘群体。
- **精英不买账**：德国的工业家、国防军和知识阶层并未真正支持纳粹。据[[德鲁克]]在《[[经济人的末日]]》中的观察，直到纳粹上台前，所有宣传工具都掌握在反法西斯者手中，支持纳粹的报纸乏人问津。
- **合法性依赖绩效**：纳粹的统治合法性高度依赖于经济绩效和民众生活水平的维持，而非真正的意识形态认同。

## 战争动员模式

纳粹德国的战争动员呈现出一种**自我设限**的特征：

| 指标 | 数据 |
|------|------|
| 战前六年军事工业占比 | 6%～7% |
| 1942年军工厂一班制比例 | 90% |
| 1943年工人周工时 | 49.2小时 |
| 战争期间女佣人数 | 140万人 |

这些数据揭示了一个悖论：一个发动了世界大战的政权，却始终不敢将国民经济切换到真正的战时状态。

## 失败的结构性解释

纳粹德国的失败不能简单归因于“疯狂”或“邪恶”，而应从以下结构性矛盾来理解：

1. **一战创伤**：[[总体战]]导致后方崩溃的教训，使希特勒极力避免重蹈覆辙。
2. **合法性悖论**：统治依赖于维持高福利，而战争胜利又需要牺牲福利进行总动员。
3. **闪电战的局限**：[[闪电战]]作为规避总体战的政治策略，在遇到苏联这样的对手时失效。
4. **动员不足**：当战争被迫延长，德国因政治脆弱性而无法释放全部战争潜能，最终在国运相赌中败北。
