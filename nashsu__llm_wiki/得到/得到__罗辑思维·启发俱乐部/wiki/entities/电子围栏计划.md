# 电子围栏计划

## 基本信息

- **提出时间**：1966年
- **提出方**：美国五角大楼顶尖科学家
- **目标**：监控并切断北越军队的“胡志明小道”补给线
- **保密级别**：国家最高优先计划，绝密级别
- **总花费**：18亿美元
- **结果**：在越战中完全失败

## 原始设想

在“胡志明小道”上部署由高科技传感器组成的电子隔离带，通过空投方式投放地震、人体、机械引擎、电子设备等传感器。北越军队行动时的声音、体温、地面震动被空中侦察机监测，数据传回空军基地由计算机系统分析，一旦发现情况立即派出飞机轰炸。

当时普林斯顿大学为美国国家安全部服务的最先进计算机仅有“令人震惊的32K内存”。

## 失败原因

1. **传感器灵敏度不足**：猩猩、猴子、水牛等动物也会触发传感器，无法区分人与动物
2. **环境适应性差**：越南丛林高温导致传感器宕机
3. **投放精度不足**：当时没有激光制导，大量设备投放偏离目标
4. **技术整体不成熟**：1966年的传感器、计算机、通信技术无法支撑这一设想

## 后续影响与技术遗产

尽管在越战中失败，电子围栏计划的技术路线被证明是正确的，其后续发展包括：

1. **传感器技术**：为现代智能硬件（电子手环、智能家电、iWatch等）奠定基础
2. **隐形技术**：研究如何逃避敌方侦察的技术路线，最终催生了F-117隐形战斗机
3. **互联网**：传感器数据回传计算机中心进行分析的设想，推动了信息终端融合系统的发展，包括传感器、无人机、激光制导武器和局域网的互联
4. **现代作战模式**：无人机、特种部队、三人小组等分散化作战模式的思想发源地
