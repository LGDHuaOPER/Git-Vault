# 刘勃

中国学者、历史作家，微博 ID @南郭刘勃。研究领域涵盖中国历史与古典文学，善于从独特视角提出具有穿透力的问题。罗振宇在启发俱乐部中多次引用其观点，并评价其著作“每一本都值得看”。

## 主要观点与贡献

### 对秦朝崩溃的追问
刘勃在历史写作中提出新颖的质问，例如针对秦朝崩溃，他追问“秦始皇在灭六国前做错了什么”，将关注点从传统儒家的仁义批评转向统一战争的发动时机与隐性代价，为[[看不见的仪表盘]]概念提供了关键的历史学养分。

### 对《史记》结构的功能主义解读
刘勃在其讲座中指出，《史记》开篇的《五帝本纪》《夏本纪》《殷本纪》《周本纪》并非单纯的客观历史记录，而是通过“同一祖先—同一土地—同一天命”的叙事序列，在汉代强化中华民族认同。这一视角揭示了早期中国如何通过历史书写完成文化共同体的构建，被[[罗振宇]]援引为理解汉代“价值建设与凝聚力建设”的关键证据，是[[价值建设与凝聚力建设]]概念的直接出处。
