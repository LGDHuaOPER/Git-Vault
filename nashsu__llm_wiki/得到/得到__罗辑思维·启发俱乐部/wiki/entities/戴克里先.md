# 戴克里先

戴克里先（Diocletian）是罗马帝国后期皇帝，在卡拉卡拉普发公民权引发的73年混乱（22位皇帝被杀）之后上台。他出身农民，以铁腕手段试图挽救帝国。

## 三招治乱

《罗辑思维》将戴克里先的统治策略归纳为“三招治乱”：

1. **以乱治乱**：将帝国一分为二（东西罗马），设立四帝共治（两个正皇帝、两个副皇帝），分头弹压各地叛乱。
2. **以躲治乱**：为免遭禁卫军杀害，躲入深宫，蓄养宦官作为权力中介，以家奴的忠诚替代军队的忠诚。
3. **以威治乱**：抛弃罗马传统的“第一公民”身份，引入东方式威权君主制，更换皇冠、袍服，要求臣民称其为“主上”，以威势号令天下。

## 历史评价

戴克里先的改革标志着罗马皇权性质的蜕变：从“主权在民”的**第一公民**转向东方式的**威权君主**。然而，这些措施效果短暂，他死后帝国再次陷入内战，最终由君士坦丁尝试另一条道路——思想控制。
