# Hendrik Bessembinder

Hendrik Bessembinder是美国亚利桑那州立大学（Arizona State University）金融学教授。他于2017年发表了一项关于美国股市长期财富创造的突破性研究：分析1926年至2016年间上市的25332家公司，发现其中约96%的公司（24240家）基本未创造超额价值；表现最好的4%公司贡献了全部新增财富；而最顶尖的90只股票（约占0.3%）创造了整个股市总财富的一半。

龙向东在[[第45期-1 | 你给房子买过保险吗？]]中重点引用了这一成果，用以说明优秀公司的分布并非正态分布，而是极端的幂律分布——真正的卓越机会比“百里挑一”更为稀缺。该数据为价值投资中“长期持有极少数顶尖公司”的策略提供了扎实的实证基础，也支撑了[[投资中的幂律分布]]这一概念。
