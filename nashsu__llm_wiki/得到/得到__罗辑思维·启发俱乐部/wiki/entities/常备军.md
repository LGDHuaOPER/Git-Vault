# 常备军

常备军是由国家直接政治控制和军事管理的常设武装力量。在欧洲历史上，常备军是雇佣军制度经过六个阶段演化后的最终形态，大约在16世纪完成转变。

## 形成过程
常备军的出现并非源于宏大计划，而是雇佣军制度逐段解决问题的结果：
1. 单个雇佣兵签合同 → 士兵不懂合同
2. 包工头整包合同 → 临时拼凑战斗力差
3. 固定军团组织 → 合同过于复杂
4. 意大利本地人成为军头 → 形成军阀，赖着不走
5. 城邦吸纳优秀雇佣军（交易费用内部化）→ 剩余城邦无优质雇佣军可用
6. 自行招募散兵游勇，建立常备军

## 与雇佣军的区别
- **雇佣军**：以商业合同为基础，雇主与军人之间是市场交易关系
- **常备军**：以政治控制为基础，军人与国家之间是组织内部管理关系

这一转变的核心机制是[[交易费用内部化]]——将外部市场交易转化为组织内部管理，以降低交易成本。
