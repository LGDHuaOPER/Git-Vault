# 魏征

魏征（580年－643年），字玄成，唐朝政治家，以直言敢谏著称，是唐太宗李世民时期最重要的谏臣之一。

## 与唐太宗的关系

### 传统叙事

魏征以犯颜直谏闻名，唐太宗以虚心纳谏著称，二人关系被视为中国古代君臣关系的典范。

### 深层解读

根据郭灿金教授的分析，魏征与唐太宗的关系并非纯粹的道德佳话，而是一场精心配合的政治表演：

1. **生存策略**：魏征在玄武门之变后，通过回答李世民的质问（"当日皇太子若听从我的劝告，哪会遭逢今日之祸"），为李世民政变提供了来自敌对阵营的合法性证词，从而保全性命。

2. **良臣契约**：魏征提出[[良臣与忠臣之辨]]，与李世民达成双赢的合作方案——他尽情进谏，李世民尽量容忍，双方共同成就美名。

3. **相互成就**：魏征通过进谏为李世民提供展示宽容的机会，李世民通过纳谏为魏征提供展示忠诚的舞台。参见[[相互成就]]。

4. **墓碑事件**：魏征死后私留谏言副本给史官，破坏了双方共同表演的契约，导致李世民怒毁其墓碑。这从反面证明了二人关系的契约性质。

## 历史评价

魏征的"直臣"形象，部分源于他与唐太宗之间达成的默契。他的智慧在于认识到：美德不是一个人的事，而是需要环境和伙伴共同成就的。参见[[美德的条件]]。
