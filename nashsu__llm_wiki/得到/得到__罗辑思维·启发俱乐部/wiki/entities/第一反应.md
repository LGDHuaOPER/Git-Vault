# 第一反应

“第一反应”是一家专注于急救数字化的公司，创始人陆乐。其核心业务是通过二维码调度系统、志愿者培训和AED网络，缩短心脏骤停的救援响应时间，将“黄金四分钟”从偶然变为可获得保障。

**运作模式**
1. **大规模培训普通人**：在写字楼、机场等场所对白领、服务员、快递员进行一日急救培训，赋予他们基础心肺复苏技能。
2. **二维码呼叫**：办公区域、公共场所张贴二维码，紧急情况时扫码即可召唤距离最近的受训志愿者，据测算到达时间可控制在58秒内。
3. **三棒接力调度**：系统自动分配任务，第一棒（心肺复苏）58秒内到位；第二棒（送AED除颤仪）90秒内到位；第三棒帮助呼叫医院、引导急救车并保持生命通道畅通。
4. **商业化模式**：场所运营方购买服务，以[[深圳机场]]为例，年客流量5,000万，预计每年可挽救5例心脏骤停生命。

**数字化思维的体现**
该系统技术并不高深（主要是二维码和后台调度），但充分展现了“从人出发”的[[数字化思维]]：让普通人获得救人技能和荣耀感，让场所展现对人群的关怀，正是“[[初心之外还要用心]]”的生动实践。

**数据背景**
演讲中提到的58秒和90秒均为测算值，实际大规模部署中的响应时间稳定性和波动范围尚未公布，有待后续验证。
