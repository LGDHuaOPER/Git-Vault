# 第144期丨什么是好的经济学

本期节目以秘鲁经济学家[[德索托]]如何通过经济学理论击败恐怖组织[[光辉道路]]并推动国家改革的故事为主线，论证两个核心命题：

1. **经济学改造世界观的强项可以间接改造世界**：经济学通过改变人的思维方式，进而影响制度设计，最终改变国家命运。
2. **好的经济学家的三条标准**：立德（用脚做学问，拒绝黑板上的经济学）、立功（推动制度性变革而非充当技术幕僚）、立言（恪守保护私有产权和自由交易两条金线）。

## 关键概念

| 概念 | 定义 |
|------|------|
| 产权保护 | 政府对私有财产的法律确认和保障，是市场交易和资本形成的基础 |
| 自由交易 | 市场参与者自愿达成的交易不受强制干预，包括劳动力市场的雇佣自由 |
| 黑板上的经济学 | 只做数理推演、脱离真实经济生活的经济学研究方式 |
| 用脚做学问/田野考察 | 通过实地调查和定量数据研究经济现象的方法 |
| 另一条道路 | 德索托提出的以自由市场经济和产权保护替代暴力革命的发展路径 |
| 地下经济/黑色经济 | 在法律体系之外运行的经济活动，因制度成本过高而被排斥出合法市场 |
| 经济学的两条法印 | 判断好经济学家的标准：主张保护私有产权、主张自由交易 |
| 自我政变 | 藤森1992年解散议会、修改宪法的独裁行为 |

## 主要论证与证据

1. **秘鲁失败国家的根源在于产权缺失**：德索托通过田野调查发现，秘鲁56%的市场非法、70%的房屋非法、60%的食品黑市交易，卷入80%人口。原因是政府法律体系过度复杂（一年颁布28000条经济法律），导致合法经营成本过高（注册企业需283天、1100多美元），民众被迫转入地下经济。

2. **产权保护是激活经济的关键**：德索托用“高山湖泊”比喻——秘鲁并非没有财富，而是财富因缺乏产权保护而无法转化为资本。确权后，房产可抵押、交易，资本得以盘活。

3. **经济学理论可以击败暴力革命**：德索托的《另一条道路》在底层民众中产生巨大影响，因为它承诺保护“你现在拥有的东西”，比光辉道路的“打翻一切再承诺未来”更具现实吸引力。光辉道路被迫转型为“黑社会式”的产权保护者，理论战场先败。

4. **藤森-德索托改革的效果**：1990-2000年，190多万所房屋确权，75%黑市转合法，企业注册从一年缩至一天。配合民兵合法化策略，1992年光辉道路领导层被一网打尽。

## 矛盾与张力

1. **藤森评价的两极化**：节目承认藤森是“独裁者”，但又肯定其奠定了秘鲁经济起飞的制度基础。这种“强人发展模式”的评价困境在节目中被明确提出但未解决。
2. **德索托与藤森的关系**：德索托在藤森自我政变后退出政府，节目将其解释为“学者初心不改”，但也提到藤森私下说德索托坏话、政敌骂藤森是傀儡。两人关系的真实性质存疑。
3. **产权民粹主义的批评**：节目提到有人称德索托为“产权民粹主义者”，但未展开反驳，仅以“不知道什么叫经济学家立言的根本”带过。
4. **张五常反对劳动合同法和最低工资标准**：节目承认这“听起来像替资本家说话”，与大众直觉冲突，但仅以“雇佣也是交易，应保护其自由度”简要辩护。
