# 资源诅咒在国家兴衰中的作用机制

西班牙从美洲掠夺大量金银，本应致富，却导致产业空心化和长期衰落。这一现象与"资源诅咒"理论高度相关。

## 核心问题

1. "来得容易的财富"如何扭曲经济结构？
2. 资源诅咒的作用机制是什么？是通过文化（如伊比利亚文化）、制度（如宗教裁判所），还是经济（如荷兰病）？
3. 西班牙衰落中，宗教因素与经济因素哪个权重更大？

## 相关案例

- 西班牙：美洲金银 → 轻视生产 → 进口依赖 → 产业空心化
- 荷兰：北海天然气 → 制造业萎缩（荷兰病）
- 委内瑞拉：石油财富 → 经济结构单一 → 崩溃

- 制度质量在其中的调节作用
