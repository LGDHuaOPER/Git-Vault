# 冯雪：不同年龄阶段，女性体检重点查什么？

你好，欢迎来到《得到精选》，我是李南南。

今天的内容来自冯雪老师的新课《女性健康管理60讲》。

我们要说的是一个每个人都会遇到的情况，就是体检。你看，体检的时候，面对那张密密麻麻的项目单，很多人都不知道到底该选哪个。

关于这个问题，冯雪老师说，体检并不是项目越多越好，而是要在对的年龄、对的阶段，做好加法和减法。尤其对于女性来说，这个问题就更加重要。

接下来，咱们就有请冯雪老师展开说说。 

![https://piccdn2.umiwi.com/uploader/image/ddarticle/2026070616/1914830838003045096/070616.jpeg](https://piccdn2.umiwi.com/uploader/image/ddarticle/2026070616/1914830838003045096/070616.jpeg)

我是冯雪，欢迎回到《女性健康管理60讲》。 

从这一讲开始，我们进入课程的第一个模块：防住身体的重大风险。而防风险的第一步，就是体检。

不知道你身边有没有这样的人：年年体检，可体检报告一拿到手，扫两眼没啥大事，就塞进抽屉里。你还记得上次体检你的血压是多少，你的血脂又是多少？我在门诊每次问起这些问题，最多的回答就是“不记得了，但没有什么问题啊！”说这话的人，并不是不重视健康，而是把体检理解成了一场查病考试，没查出病，就算过关了。

但我要老老实实告诉你，  **体检真正要看的，不是你有没有患病，而是你的疾病风险** 。我们的大多数慢性病，比如心脑血管疾病、糖尿病，基本上都有一个在身体里慢慢酝酿的灰色阶段。等到查出明确的病，往往已经过了最好的干预时机。

那么问题来了：体检项目这么多，女性到底应该怎么选呢？这一讲，我们就把这件事完完整整讲清楚。

一份完整的体检清单应该包括三个部分：基础疾病筛查、心理健康筛查和特殊情况下的风险筛查。

# 基础疾病筛查

我们先来说基础疾病筛查。

根据女性不同年龄段常见的健康风险，我们可以把基础疾病筛查拆成7份清单。当然，是大致的年龄划分，并不绝对，你可以根据自己和家人的身体的情况作出选择。

**第一份是给18岁以下的女孩的。**

这个阶段，一般由学校按照国家规定统一安排体检，我们不需要额外给孩子堆很多检查，只需要把学校的体检结果看明白就行。看的时候，有几个指标需要额外留意一下：

首先，就是身高体重。我在文稿区放了一张图，对照这张图，你就可以知道孩子是不是有超重、肥胖、身高发育缓慢的问题，早发现早干预。干预的方法后面的课程会细说。

![https://piccdn2.umiwi.com/uploader/image/ddarticle/2026070514/1914731079870353328/070514.png](https://piccdn2.umiwi.com/uploader/image/ddarticle/2026070514/1914731079870353328/070514.png)

其次，要看血红蛋白。尤其是14到15岁的女孩，这是贫血的高发期，血常规里的血红蛋白低于120g/L就要格外关注。

最后，要重视孩子的发育程度。如果女孩7岁半前出现乳房发育，或10岁前来月经，就需要去评估性早熟的问题。如果13岁乳房仍没有发育，或者15岁还没有来月经，就属于发育迟缓。这两种情况都要去看儿科内分泌专科。

多说一句，现在很多家长会想着给孩子测骨龄，其实这个检查，不需要在体检的时候做，反而是上面三个指标出了问题，才需要考虑。

**第二份清单，是给18岁到24岁之间的女性。**

出了高中校园，我们就要自己安排体检了。这个阶段，重点是把体重、腰围、血压、血脂这些基础指标管理起来。血脂检查没有问题的话，之后可以每五年检查一次。如果有性生活，可以单独加一个HIV的筛查。

你可能会问，宫颈癌、卵巢癌、乳腺癌这些呢？不用每年都查吗？

答案是，这个年龄段基本不用。除非你出现了相应的症状。

**第三份清单，是给25到29岁女性的。**

如果你正好处于这个阶段，体检项目就要再增加两项：一是乳房的医学检查，也就是医生专业的手法触诊；二是宫颈癌筛查。

我们这里重点说说宫颈癌筛查。目前最好的宫颈癌筛查手段，是做高危型HPV核酸检测，这也是目前很多指南优先推荐的方法。如果查出来没有问题，之后五年查一次就可以了。如果没有条件做HPV检测，你也可以每3年做一次宫颈的细胞学检查，叫TCT。需要提醒的是，即便打过HPV疫苗，这个检查也不能免掉。

简单说，  **30岁前，女性体检别贪多。** 18岁前跟着学校体检走，18岁后把基础项目做好，25岁后再重点加上乳房检查和宫颈癌筛查，就可以了 。

这里额外提醒一句：18到29岁女性看血压，别等到140/90才重视。血压经常超过120/80就要留意；反复超过130/85，或者有妊娠期高血压史，建议你去医院做24小时动态血压监测。

**第四份清单，是给30到39岁女性的。**

这个阶段的重点是检查你的代谢情况。这其中最有代表性的是身体成分。

30岁以后，女性的肌肉会开始流失，所以你不能再像以前一样，只是看体重秤上的数字，而是要看肌肉量、体脂比等更加精细的数据，重点看体脂有没有增加，肌肉有没有不达标。女性的上肢肌肉更容易缺乏，可以重点关注。

这个阶段还要增加对血尿酸、血糖的检测。因为35岁以后，糖尿病和糖尿病前期的风险会明显上升，所以选体检项目时，要特别看看项目单里有没有空腹血糖和糖化血红蛋白检测。如果查出有问题，要单独做OGTT，也就是糖耐量试验，去明确诊断。

其实，不管有没有糖尿病，我都非常建议女性35岁之后给自己戴一次CGM，也就是连续血糖监测。它贴在上臂，或者小肚皮上，可以连续14天监测你的血糖，帮你看清哪些食物会让血糖波动，也为个性化的饮食管理和抗衰提供依据。

另外，中国专家的共识是，30岁以后，我们要把抽血查甲状腺功能纳入基础体检。

**再来看第五份清单，这是给40-49岁女性的。**

你会发现，这个阶段，筛查开始明显升级。

除了血糖、糖化血红蛋白、血脂、血尿酸每年1次，血压这个指标要拿出来重新审视。如果随机血压超过120/80，我建议你可以买个血压计，不定时地多测几次。如果超过130/85，那么我的经验是很有必要去医院做24hr动态血压。 女性的血压数值在远比男性要低的时候，就已经有心脑血管风险了 。这点在后面的任何一个年龄段都适用。

乳腺筛查和骨密度筛查也要提上日程了。如果没有骨质疏松，骨密度每1-2年1次。

此外，如果你属于结肠癌或直肠癌的高风险人群，这时候，也要安排结肠镜检查。怎么判断自己是不是高风险人群呢？我把判断标准放在了文稿区，你可以对照自己的情况算一算。

另外，45岁之前，建议你完成一次女性激素检查，作为更年期激素管理的参考。这个检查需要在月经来的第2-4天去做，所以不一定能刚好赶上体检时间，可以额外去一次医院。

**第六份清单是给50-64岁的女性的。**

这个阶段，女性进入身体大调整期，更需要细致地了解和管理自己的身体。

首先，之前各个阶段该查的，这时候一样也不能少。而且这个年龄段，乳腺癌发病率明显上升，所以乳腺筛查必须更加重视。

此外，不管你是不是高风险人群，都要开始安排结肠镜检查。骨密度如果有下降，也要增加到每半年一次。

**第七份清单，是给65岁及以上女性的。**

和大多数人以为的可能不一样，这个阶段的体检清单，不会随着年龄的增加而变长，反而会逐步减少。因为这时候，我们要以解决已知问题为主，风险排查反而不是重点了。

比如，宫颈癌筛查，如果之前你一直按时进行筛查，且结果正常，就可以在65岁停掉。乳腺检查和胃肠镜，如果既往检查结果正常，也可以考虑在74岁停掉。

但是，有三个项目要增加，那就是听力测试、跌倒风险评估、认知功能筛查。

听到这里，7份女性专属的基础疾病筛查清单，我们就讲完了。你会发现，  **女性体检不是项目越多越好，而是要在对的年龄，查对的风险** 。

# 心理健康筛查

除了基础疾病筛查，心理健康筛查也同样重要。

**身心共查是女性体检非常重要的一环** 。整体来说，女性终生承受的心理压力更大，遭遇的心理问题也更隐蔽。在我的门诊里，女性对自己心理问题不自知的比例，要远远高于男性，羞耻感也更强烈。这些积累下来，就会给身体带来负担。所以，  **像对待身体一样对待心理，是体检的基本态度** 。

心理健康筛查，不用分年龄，每个年龄段都要配合针对焦虑的筛查。一些重点的年龄段，比如产后、更年期、65岁以后，还要配合针对抑郁的筛查。

# 特殊情况下的风险筛查

前面这7份清单，再加上心理筛查，属于基础体检。

然而，每个人的身体都有自己的薄弱系统，压力越大、家庭担子越重，薄弱系统越容易先出问题。所以，除了基础项目，还要根据自己的情况，额外做风险筛查。

怎么判断自己的薄弱系统在哪里呢？  **你不用凭感觉乱加项目，就从三个方向找** ：

一是你从小就容易出问题的系统；

二是直系亲属，尤其是妈妈和亲姐妹，已经患上的疾病；

三是你目前经常出状况的系统。

找到薄弱系统后，再把对应项目加进你的体检清单里。比如，你从小就经常咳嗽、动不动就肺炎，就要注意呼吸系统筛查，可以把肺功能加进体检清单。如果一级亲属有阿尔茨海默病，50岁以后就要额外做认知功能量表和记忆力筛查。

以上所有提到的筛查项目、检查清单，你可以先和体检中心沟通，如果确实没有的，再去医院专科咨询。

# 总结

好，这一讲到这里就结束了，总结一下：

第一，体检的目的不是查病，而是搞清楚疾病风险。

第二，女性体检不是项目越多越好，而是要按年龄抓重点。

第三，基础筛查、心理健康筛查和风险筛查，三个部分都具备，才是真正有价值的体检。

最后，我还想提醒你一句：  **体检不是做完就结束了，真正重要的是体检后的管理。**

如果在基础检查里发现了明确的疾病，要赶紧去挂专科医生，搞清楚；

如果心理健康筛查发现了问题，可以先到课程的模块四找解决思路，也可以挂医院的心理专科、身心医学科、精神专科，部分医院的双心医学、神经内科，也是可以的。

如果是风险指标有问题，也不用慌。接下来，我们会重点拆解女性面临的八大健康风险，帮你把看似复杂的健康风险，逐步变成一套清晰、可管理的系统。
