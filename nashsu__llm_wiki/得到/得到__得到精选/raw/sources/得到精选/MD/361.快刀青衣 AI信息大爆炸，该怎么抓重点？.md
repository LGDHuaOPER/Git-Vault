# 快刀青衣：AI信息大爆炸，该怎么抓重点？

你好，欢迎来到《得到精选》，我是李南南。

今天的内容，来自快刀青衣老师主理的“AI学习圈”，说起这个产品非常有意思。首先，这里面有很多相关的AI课程，都非常实用。但是，这又不是一个简单的课程组合。它更像是一个AI生态，也就是，把各行各业那些AI的高手都集中到一起。这里面有消息灵通的，有本领过硬的。换句话说，关于AI，咱们普通人该掌握的技能，以及该知道的消息， AI学习圈几乎是一个都不落。

这不最近，关于AI又出了两个大新闻，一是马斯克把OpenAI告上了法庭，二是 Claude3大模型上市，号称在功能上是全面超越GPT4。那么，这两个新闻又为了什么呢？其中又透露出哪些新趋势、新机会呢？

来，咱们听听快刀青衣老师的解读。

你好，我是AI学习圈主理人快刀青衣。 

过去这几天，全球AI圈非常热闹，又有大事发生。大家讨论最多的，一个是马斯克把OpenAI和它的创始人奥尔特曼告上了法庭；另一个是大模型Claude3发布，某些技术维度确实已经超越了ChatGPT4。咱们一个一个来看。

首先是马斯克起诉奥尔特曼，作为AI世界的顶尖大佬，爆出这种惊天大瓜，一定会在今年的年度大事记上留下重重的一笔。并且这俩人，都是我很崇拜的大神，所以我把马斯克上万字的起诉书看完了。

我先尽量用直白的语言，给大家介绍一下来龙去脉。马斯克很早就认为，AI会对人类造成巨大的威胁，他一直呼吁用各种方式来监管AI的发展，尤其是AGI，也就是通用人工智能。通用人工智能指的是AI已经具备跟人类同等的智慧或者超越人类的智慧，例如可以自主定义任务、能通过图灵测试等等。马斯克说，如果有一台机器能比我们人类更好地解决几乎所有任务，那么这台机器就比人更有价值。所以他从2012年开始，就经常公开呼吁要监管AI的发展。

DeepMind，也就是那个制造出阿尔法狗击败李世石的公司，当年要被谷歌收购的时候，马斯克还联合朋友，劝阻DeepMind创始人哈斯比斯不要加入谷歌。只不过谷歌还是顺利拿下了当时AI技术能力最强的DeepMind，这就让马斯克更加焦虑了。

2014年开始，马斯克发起了很多次的晚餐讨论，邀请不同领域的朋友探讨如何对抗谷歌和监管AI，还联系了奥巴马，希望政府可以对AI进行监管。不过这些都没有什么效果。但是在2015年，马斯克终于遇到了和他志同道合的人，现在的OpenAI CEO山姆·奥尔特曼。

当时的奥尔特曼给马斯克发了一封邮件，邮件里写的第一句话是“我们的使命是创造第一个通用人工智能，并用它来给个人赋能。”这封邮件开启了两个人的蜜月期。他们联合创建了一个新的实验室，并且明确它是一个开源的非盈利组织。

实验室成立后，马斯克真的是出钱出力，并且全力去挖伊利亚·苏茨克维（也就是后来OpenAI的首席科学家），和一些顶尖的人工智能专家和计算机工程高手。正是因为马斯克的背书，OpenAI的创始团队才搭建了起来。而在资金支持方面，马斯克从2016年到2020年一共向OpenAI捐赠了超过4400万美元。

那两个人为什么会走到了法庭对峙的地步呢？其实核心在于OpenAI推出了ChatGPT和GPT4，特别是GPT4的超强能力，马斯克担心继续往后发展，AI的能力会无法控制。并且当初虽然一起创立了这个非盈利组织，但是2019年山姆·奥尔特曼还另外创建了一个商业子公司，接受了微软的投资。

我觉得，单就这个官司来说，其实很难出一个明确的结果。因为马斯克的出发点是现在的GPT4已经接近或达到通用人工智能的水平，奥尔特曼违反了当初他们创立OpenAI时的承诺。实际上，通用人工智能是一个非常模糊的定义，放在网上聊聊可以，但是作为法庭上的定义，就非常难了。其次，马斯克的条件都是类似“GPT4立刻开源”这样的要求，里面还牵涉到全球法务能力最强的微软，所以  **这场官司，舆论价值可能远远高于实际的结果。**

这个官司的输赢结果其实并不重要，但是我们可以看出，不管是马斯克还是奥尔特曼，对自己认准的事情，都会坚定地投入进去。整个事件的核心根源，都是AI的高速发展。  **对咱们学习圈同学来说，我觉得更有价值的做法是，直接跳过“AI到底有没有用”这样的问题，我们只问“自己应该怎么用好AI”。**

好，说完马斯克和OpenAI的官司，我们再来聊聊那个超越ChatGPT4的新模型，Claude3。

其实，这次Claude3一共发布了三个版本，其中Haiku这个版本的速度是最快的，Sonnet这个版本的能力是最均衡的，而Opus版本则是能力最强大的。各种评测说Claude3超过了GPT4，指的就是这个Opus版本。

我体验了Haiku和Sonnet，这两个在产出速度上，确实远胜之前的版本。并且因为他们主打的是安全牌，所以在过去经常出现的“拒绝回答”的情况，这次明显少了很多。另外，他们对图片的识别、长文的识别都非常准确，速度也很快。

至于最强大的版本Opus，虽然我没有体验到，但是我看了不少的评测视频和报告，感受是确实很厉害，但跟GPT4还处在一个水平线，如果GPT4是85分，Claude3在某些场景下可以达到87分。

相比于介绍新出的模型，我觉得Claude3背后的公司，Anthropic，更值得聊一聊。

这家公司的名字来源于一个非常拗口的宇宙学和哲学交叉的理论，叫做“人择原则”。简单说就是探讨宇宙对人类适应性的问题。而你从公司名大概率就能猜到，他们的核心概念是人工智能的发展必须可控，应该服务于人类、符合人类的价值观和伦理标准。

硅谷目前有两大AI流派，一个是有效加速派，一个是超级对齐派。有效加速派认为人类应该无条件加速技术创新，因为这会促使社会的各个方面发生颠覆性变化，所谓的风险也会随着安全技术的加速而得到解决。而超级对齐派希望的是，让人工智能与人类的价值观保持一致，需要引导和控制人工智能的发展。

Anthropic这个公司的创始团队就属于典型的超级对齐派。这个公司和OpenAI有着非常藕断丝连的关系。创始人是兄妹俩，哥哥达里奥·阿莫迪是现在的CEO，妹妹丹妮拉·阿莫迪是现在的总裁。不过，他们在2021年之前都是OpenAI的员工。当时他们就是因为觉得OpenAI在商业化上走得太快、太远，背离了为人类福祉发展人工智能的初衷，所以就和五个同事一起出来创业了，其中一个同事Tom Brown曾经是OpenAI研发GPT3的负责人。

他们对AI一直以来的主张就是“有用且无害”。如果你对人工智能的安全风险感兴趣，强烈建议你关注他们团队和每一个创始成员的动态。你会发现，他们用各种方法来制定人工智能领域的安全规则，比如把模型可能带来的人类社会风险进行评级，再比如会用类似严守准则的小模型来代表人类，去审查其他模型产生的结果。

他们在2023年9月提出了一个AI安全等级的系统，模仿的是国际上比较成熟的处理生物材料时的很多规则。例如ASL-1级别代表没有任何风险的模型，陪你玩国际象棋的AI就是这种。我们现在用的AI，被划分在了ASL-2级别，意思是说这类模型具有各种隐藏风险，但是尚未展示出真正危险的能力。

再升一级，也就是第三级别，可能在操作上能够产生类似化学、生物、放射性和核风险的信息。面对这种级别的风险，AI模型必须在推出前就经过非常充分的红队攻击测试。最高级别，也就是第四级，除了会滥用第三级别那些生化信息之外，还增加了一个风险，就是人工智能如果加速发展，最终到了能逃脱人类控制，并对社会造成重大威胁。

在介绍这套系统时，他们的创始人、CEO达里奥表示，自己在三个月里花了20%的时间来写规则、草稿，写代码，另外一个联合创始人花了一半的时间来做这件事。从这儿也能看出，他们核心是个研究团队，做商业化挣钱其实是为了支援后面的研究。

对了，达里奥是非常典型的技术大神，他毕业的本硕博学校分别是加州理工、斯坦福和普林斯顿。2014年，他先加入了百度的硅谷实验室，成为一名研究科学家。第二年他进入了谷歌大脑团队，2016年加入OpenAI，从安全研究负责人一直做到了研究副总裁。

好，Claude3大模型和它背后的公司Anthropic，我介绍完了。我们把视线从这个新闻拉回来，估计我们同学里面，跟我同一年龄段的都读过金庸先生的《倚天屠龙记》，那我问一个问题，你能列举出来倚天剑或者屠龙宝刀都在谁手里待过吗？

反正在我的记忆里，倚天剑至少在莫声谷、陈友谅、赵敏、灭绝师太、周芷若手里流转过，最后到了张无忌的手里。而屠龙刀从元朝官府到谢逊到胡青牛到张无忌到周芷若再到张无忌，也是兜兜转转。

我之所以扯这么远说这个小说，就是想告诉你，哪怕是倚天剑或者屠龙刀这种神兵利器，也要使用的人本身要强。不强的话，再厉害的工具在自己手里都发挥不出作用，没办法走上武林巅峰。

**不管是用ChatGPT还是Claude3，不管是用智谱清言还是文心一言，或者是用Kimichat，工具只有在你反复用的情况下，才能跟你的磨合越来越好。** 所以不要被这些震惊体的新闻干扰，重点是找到自己的使用场景，持续使用起来，这样就不会被一些浮躁的新闻分散注意力了。

科学家布赖恩·沃克以及作家戴维·索尔特，2006年曾经合作撰写过一本相关的书，书名叫《韧性思维》，副标题特别长，叫做“在变化的世界中维持生态系统和人类的生存”。核心内容其实是告诉我们每个人，需要锻炼自己的“韧性”，就是你要先保证自己的基本能力和注意力，拥有一种可以在复杂的世界里，面对不可避免的干扰时，具有吸收冲击波的能力。

不过我觉得更好的解释，是绿洲资本的张津剑老师提出来的“信号与噪声”理论。  **现在的很多AI动态，对一部分人来说是信号，但对另一部分人来说是噪声，我们要保证自己的注意力花在最有价值的地方。**

最后说一句，如果你还没有体验到Claude3，如果你并不是AI专业从业者，完全不必去研究和体验，花时间用在一个你已经习惯的AI产品上，去对话和体验，那样的价值感更强。

所以可以简单的理解成：Claude 3 Opus（超大杯），Claude 3 Sonnet （大杯），Claude 3 Haiku（中杯）。目前，「超大杯」和「大杯」——Opus和Sonnet，已经可以在claude.ai以及覆盖159个国家的Claude API上使用了。而「中杯」Haiku模型，也将很快推出。

Jing Zhang：想象一下，你正在一家餐厅的菜单前纠结——是选择今晚尝试全新的料理，还是点上那道熟悉又美味的招牌菜？现在，把这个情景换成在AI工具的世界里。你是要冲向每一个闪亮的新技术，还是坚持使用那个早已熟悉的、能够稳稳地解决问题的老朋友？

在AI技术日新月异的今天，我们面临的选择远比餐厅里的菜单复杂得多。每隔一段时间，就会有一个全新的AI工具，它们像是最新款的甜品，诱惑着我们去尝试。但这里有个小秘诀：找到那个“招牌菜”，然后坚持使用它，可能是更加聪明的选择。

就拿ChatGPT、Claude3或是任何其他的AI工具来说，它们就像是厨师精心准备的美食，每个都有其独特的风味。但真正重要的不是它们是不是最新推出的，而是它们能否满足你的“胃口”——也就是你的具体需求和使用场景。

持续使用一个AI工具，就像是和一位老朋友深度交流。你们之间的默契和理解随着时间的推移会越来越深。它会更好地理解你的语言习惯，更准确地回应你的需求，就像是那个总能做出你最爱吃的那道菜的老厨师。

而且，这种持续的使用和探索，就像是在厨房里不断实验，最终会找到让这道菜味道更上一层楼的小窍门。这不仅使你的生活或工作效率大大提升，也会让你在AI的世界里游刃有余，而不是被每一个新工具的闪亮外表所迷惑。

虽然尝试新事物总是令人兴奋，但在AI的选择上，“守旧”有时候也是一种智慧。就像那道你总是点的招牌菜，它可能不是菜单上最惊艳的选择，但它总能让你满足而归。所以，找到你的AI“招牌菜”，然后坚持下去，让它成为你可靠的伙伴，这才是玩转AI的真正秘诀。

罗宏伟：在AI领域，专家们通常关注两个主要问题：一是AI技术的发展和创新，二是如何将AI技术应用于实际生活和工作中。
AI技术的发展，如同开启未来的钥匙，我们不应只关注其存在与否，哪个技术更牛。而应思考如何利用这把钥匙解锁新的可能。回到自己的专业场景，解决以前很难解决的问题，积累有价值的能力和数据，才是我们属于个体在ai时代光明的未来。
