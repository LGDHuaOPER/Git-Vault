# 蔡钰：在同质化时代如何用情绪价值突围？

《得到精选》2024年4月7日期，主持人李南南，嘉宾蔡钰推介其新书《情绪价值》。蔡钰是中国商业语境中最早提出“情绪价值”概念的观察家之一，本书是在其得到课程《情绪价值30讲》基础上修订增补而成。

## 核心主张
在供给过剩、产品功能均质化的时代，**提供情绪资源，满足情绪需求，就能变现情绪价值**。产品总价值可拆解为：
**产品价值 = 功能价值 + 情绪价值 + 资产价值**

## 关键框架
书中提出四大等式与方法论：

1. **产品价值 = 功能价值 + 情绪价值 + 资产价值**
2. **情绪 = 感受 + 动机 + 行为**
3. **空间 + 内容 = 情绪场**
4. **情感价值 = 情绪资源 × 稳定预期**

以及叙事能力、双故事线、配角意识、感受基本盘等视角。

## 叙事能力
叙事能力被定位为调动情绪的最直接能力，应成为产品设计的起点。案例：小米 SU7 发布用致敬同行和悬念式参数叙事暗示水位与独特性，换取大量订单。叙事能力不止于讲故事，还包括梳理价值观、寻找缪斯用户、定义用户关系、用行为强化意义。

## 适用性与边界
作者承认对数字世界有“走不出来的局限性”，高频露出声音已是赛博极限；同时指出情绪劳动的代价（情绪透支、情绪反噬），并希望在数字社交人格构建中提供保护方法。

## 与现有维基的关联
- 将情绪价值框架置于[[获得感]]、[[陪伴感]]等概念的上层，补充情绪生成机理。
- 可与[[叙事能力]]（若已有相关概念）共同构成产品设计的方法论。
