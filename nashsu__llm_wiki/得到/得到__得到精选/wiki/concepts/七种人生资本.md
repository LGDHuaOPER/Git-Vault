# 七种人生资本

借鉴皮埃尔·布迪厄对“资本”的扩展性理解，万维钢在《现代思维工具100讲》中提出七种可通过复利积累的人生资本。这些资本不是互相排斥的，而是可以互相叠加和转化，形成一个自我强化的正反馈循环。

## 七种资本的定义

1. **金钱资本**：现金、股票、房产等可直接量化和继承的资产。往往只是其他资本的副产品。
2. **人力资本**：知识、技能、判断力和学习能力。诺贝尔经济学奖得主加里·贝克尔指出，人力资本的回报期特别长，因此越早投入越好。
3. **健康资本**：体能、精力和慢性病风险。是像耐用资本存量一样的底层支撑，年轻时容易被忽视，中老年后才凸显其重要性。
4. **社会资本**：关系网络以及其中的互惠和信任。马克·格兰诺维特的“弱联系”理论表明，许多关键机会来自“朋友的朋友”，而非最亲近的熟人。
5. **声望资本**：品牌价值与他人对你是否靠谱的整体印象。是马太效应最典型的战场：口碑越好，机会越多。
6. **心理资本**：自控力、韧性、情绪稳定和意义感，尤其需要尽责性。被视为整套复利系统的“操作系统”，决定是否能长期稳定地做正确的事情。
7. **体验资本**：做过的高质量事务、到过的地方、与谁共同经历的叙事。研究表明，体验型消费比纯物质消费更能提升长期幸福感，体验沉淀为判断力与身份认同。

## 资本的相互转化

这些资本构成一个美妙的飞轮：心理资本和健康资本 → 办事靠谱、长期守信 → 声望资本 → 更多合作机会 → 社会资本 → 高质量项目 → 加速成长 → 人力资本 → 丰富的体验资本 → 更强的心理资本和金钱资本。

系统一旦启动，积累复利会变成一种“上瘾”的正反馈过程。但需警惕外部冲击（如疾病、危机）可能打断循环的系统脆弱性。
