# 错信漏斗

**错信漏斗**是丹·艾瑞里在《怪诞行为学7》中提出的模型，用以解释一个正常人是如何逐渐陷入阴谋论的。漏斗有四层，从易到难逆转：

## 1. 情感的土壤
成年人常遭受**三把刀**的摧残：
- **不可预测的压力**：突发疾病、失业等不可控事件，产生习得性无助，使人寻求外部的“坏人”解释。
- **稀缺心态**：缺钱或缺时间会降低认知带宽，让人没有余裕进行理性判断。印度蔗农实验显示，收获前的认知测试得分比收获后低25%。
- **孤立感**：感觉自己被世界抛弃，别人都过得很好，由此推断出一定有一个不公平的、迫害自己的优势集团。

三把刀叠加时，阴谋论的土壤便成型——人们需要找一个“坏人”来归因苦难，并进入证据自我强化的循环。有**安全依恋**的人则更能抵御这种情感侵蚀。

## 2. 认知的陷阱
- **确认偏误**（第一阶段）：只接受支持已有信念的信息，忽略反面证据。沃森选择任务中90%的人只验证规则而不会证伪规则。
- **动机推理**（第二阶段）：主动搜集有利证据并解释掉反面证据。艾瑞里以前自己对待间歇性断食研究的辩解为例，说明专家也难免此偏误。

## 3. 人格的底色
某些人具备更容易相信阴谋论的**魔怔人格**：
- 相信超自然因果（如占星术、意念伤人）
- 记忆易于虚构（“无中生有”错误率是常人两倍）
- 病态自恋，极度渴望关注
这样的性格在面对睡眠瘫痪等正常现象时，更可能建构出“外星人绑架”一类解释。

## 4. 社会的漩涡
社会排斥带来大脑中与身体疼痛相似的刺痛感（吉卜林·威廉姆斯的扔飞盘实验）。被排斥者一旦找到接纳自己的阴谋论社区，就会因为强烈的归属感而难以脱离。社区内极端的互相赞赏会加速认知失调（越投入越难回头）和组织极端化（忠程度测试取代事实核查），使人彻底陷入。

## 突破路径
- **辩论无效**：逻辑说服往往适得其反。
- **富兰克林效应**：让对方帮你一个小忙，可能唤醒反向认知失调，建立善意连接。
- **根本出路**：重建信任。鼓励人们**加入主流**（保留自身特色的和而不同），理解他人不完美，通过贡献获得接纳，从而切断阴谋论的情感根源。
