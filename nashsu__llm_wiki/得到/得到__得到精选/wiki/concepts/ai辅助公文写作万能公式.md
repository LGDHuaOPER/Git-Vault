# AI辅助公文写作万能公式

梅俊在《如何用AI辅助高效写公文》课程中提出的结构化提示词框架，其核心公式为：**【角色 + 背景 + 任务 + 要求】 + 调试**。该公式旨在解决AI写作中内容空洞、遣词生硬的问题，通过标准化提问倒逼使用者理清任务本身。

## 公式组成

### 1. 角色设定（角色 = 单位 + 身份 + 能力）
- **单位**：指明单位类别，如“省政府办公厅”“大学教务处”。
- **身份**：设定领导职务（办公厅主任、市长等）或专家身份（历史学教授等）。
- **能力**：描述专业能力，如“深刻理解新型工业化的特点”“擅长政策分析”。

### 2. 背景描述（宏观 / 微观 / 受众三角度）
- **宏观背景**：上级政策精神、整体形势等。
- **微观背景**：任务起因、要做什么、具体场景。
- **受众背景**：目标听众/读者及其层次，影响文风与语气。

### 3. 任务界定
- **立意构思任务**：辅助分析思路，包含正向提问（明确问题）和反向提问（让AI向人提问启发思考）。
- **文本输出任务**：直接生成内容，可整篇输出或分段/分句完成。

### 4. 明确要求
- 常规要求：语言风格、字数、分段等。
- 进阶方法：
  - **指定内容要点**：强制AI输出特定要素（如会议通知必须包含时间、人员、议程）。
  - **框定内容结构**：通过[[写作公式]]（如总结类公文的帽段→主体做法→问题→计划）或“内容模块”（提炼范文模版）来控制行文逻辑。

### 5. 调试优化
- 修改提示词本身以适应预期偏差。
- 指出AI答案的具体问题并提供修改建议。
- 同一提示词多次生成，优中选优或组合最佳部分。

## 关键洞察
- 该公式的“万能性”建立在**使用者对任务本身有清晰把握**的前提下，是一种思维脚手架而非捷径。
- 最终输出仍需**“加人味”**，即人工润色、代入企业场景和个人特色，避免机械感。
- 框架具有跨场景通用性，与其他元prompt公式（如李奕霆总结的“角色+背景+任务+要求+目标”）形成共通模式。
