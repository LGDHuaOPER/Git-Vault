# 上瘾模型（Hook Model）

上瘾模型是由尼尔·埃亚尔提出的用户行为设计框架，旨在通过一个自我强化的四步循环让用户对产品形成依赖：

1. **触发（Trigger）** — 内部触发（如无聊、好奇心）或外部触发（如推送通知、视觉提示）。
2. **行动（Action）** — 用户做出简单行为，门槛越低越容易发生。
3. **酬赏（Reward）** — 行为后获得即时、不确定性的奖赏，驱动大脑释放多巴胺。
4. **投入（Investment）** — 用户投入时间、数据、社交资本，增加下一次触发的可能性。

《让思考上瘾：再来一题！》将这一模型正向化：

- **触发**：书放在随手处，孩子无聊时自然拿起。
- **行动**：题目无需知识储备，翻开即做。
- **酬赏**：想通瞬间的顿悟（慢多巴胺）作为即时内在奖励。
- **投入**：每天一题打卡、晚上考父母，持续投入滚雪球。

## 与快/慢多巴胺的结合

游戏与短视频利用该模型产生快多巴胺，绕过前额叶；而思考类活动通过同样闭环激活慢多巴胺，锻炼前额叶，实现“用魔法打败魔法”。
