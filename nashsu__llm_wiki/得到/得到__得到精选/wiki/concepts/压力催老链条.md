# 压力催老链条

“压力催老链条”是尹烨在《压力大为什么会让人变老？》中梳理的一条从心理压力到细胞衰老的因果路径，将模糊的民间认知“愁一愁，白了头”还原为具体的生物学机制。

## 完整链条

1. **慢性压力** → 激活交感神经系统
2. → **去甲肾上腺素** 持续高水平 → 促进促炎介质基因表达
3. → 诱发 **慢性低度炎症**（无明显红肿热痛但持续损害组织的炎症）
4. → 炎症因子损伤 **线粒体** (能量工厂) → ATP产量下降、自由基泄露增加
5. → 过量 **自由基** 攻击细胞膜、蛋白质、DNA
6. → 加速 **端粒** 缩短，削弱干细胞修复能力
7. → 细胞能量枯竭、修复衰退 → 宏观衰老表现

## 核心中介角色

- [[去甲肾上腺素]]：链条启动的下游关键信号
- [[慢性炎症]]：心理压力转化为物理损伤的核心中介
- [[线粒体]]：损伤汇集点，同时也是损伤放大器
- [[自由基]]：最终执行氧化破坏的化学分子
- [[端粒]]：细胞寿命的“计数器”，缩短标志着衰老

## 学说定位

尹烨在叙述中承认，将线粒体作为衰老的“关键真凶”源自[[线粒体衰老学说]]，但该学说自1980年至今仍存争议：有人视其为衰老的核心驱动；也有人视其为次要角色。因此，这条链条是当前科学认识的一个清晰版本，但并非定论。

## 干预靶点

基于这条链条，对抗压力性衰老可以从以下节点入手：

- **压力管理**：正念冥想、良好的社交支持、规律作息
- **控制炎症**：抗炎饮食、避免肥胖、适度运动
- **保护线粒体**：运动可改善线粒体功能，均衡营养提供辅酶
- **抗氧化**：新鲜蔬果提供抗氧化物，协助清除自由基

理解这条链条不是为了增加焦虑，而是为了找到更精确的日常行动方向。
