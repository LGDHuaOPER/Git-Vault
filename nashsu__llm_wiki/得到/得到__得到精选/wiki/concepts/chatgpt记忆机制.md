# ChatGPT记忆机制

ChatGPT 的“记住你”并非真正意义上的全量记忆，而是一套分层感知设计。目标不是完整记录用户，而是让用户**感觉到被记住**。该机制由红队测试者 Manthan Gupta 通过对话破解得出，并由卓克在《科技参考》中详细拆解。

## 四级记忆结构

### 1. 元对话数据
保存设备、浏览器、语言、时区、订阅类型、使用频率与在线时长等环境指纹。这些数据在每次对话开始时读取，用于判断用户合法性、设定对话基本框架，并据此动态分配算力资源。例如，高活跃用户会获得更多 token，以降低反复追问或差评的总消耗。

### 2. 用户记忆
显性保存的用户信息（职业、兴趣等）。来源包括用户直接声明（“记住我是科普工作者”）和模型自动提取的特征。该层可被用户随时编辑，使得用户保留对自身画像的掌控感，同时让 GPT 用最接近用户偏好的风格对话。

### 3. 近期对话摘要
最出人意料的设计。GPT 不检索任何历史对话，而是在每段新对话开启前，自动生成一份仅包含**用户最近 15 轮发言**的摘要（不记录 GPT 自己的回复）。这份摘要只消耗几百 token，大约能对用户即将聊到的话题做出七成准确率的预测，模拟了熟人社交中只记得近期关键话题的弱联系习惯。

### 4. 当前对话上下文
唯一进行精确全量记忆的层级。在当前对话窗口内，GPT 对全部内容保持准确记忆，直至达到上下文长度上限（GPT-5 API 约 27 万 token）。这一层是保障会话连贯性的底层支撑。

## 设计哲学

这四级设计整体贯彻了 [[gan-zhi-you-xian-she-ji-zhe-xue]]：不追求大而全的功能，而是用极简、低成本的工程手段制造“被记住”的信任感。工程师们用算力最经济和客户感知最显著的方式，实现了人际交互般的对话效果。
