# 游戏化能力训练九大能力框架

源自《陪孩子玩的100种游戏》的组织逻辑，将儿童发展所需的核心能力划分为九个维度，并为每个维度设计了对应的游戏，使得每一次陪玩都指向明确的能力目标。

## 九大能力
1. **控制力** — 自我约束与情绪管理
2. **注意力** — 集中与维持专注
3. **感受力** — 对内外刺激的感知与体验
4. **观察力** — 细致辨识与识记
5. **思考判断力** — 分析、推理与决策
6. **反应力** — 快速信息处理与行动
7. **表现力** — 表达与展示
8. **想象力** — 创造与联想
9. **记忆力** — 识记、保持与提取

## 能力与游戏的对应（部分示例）
| 游戏 | 主要训练能力 |
|------|-------------|
| 《几何图案变变变》 | 想象力、创造力 |
| 《指偶表演》 | 想象力、表现力、编讲能力 |
| 《五颜六色》 | 观察力、识记力 |
| 《今天去哪里》 | 联想能力、记忆力 |
| 《旅行探险家》 | 感受力 |
| 《唱反调》 | 反应力 |
| 《五处更动》《调皮的数字》《家人的照片》 | 观察力 |

## 设计理念
- **游戏即训练**：每个游戏的设计都围绕一项或多项能力，让孩子在愉快的互动中获得可迁移的学习能力。
- **道具轻量化**：多数游戏仅需纸笔、手势、语言，随时随地可用。
