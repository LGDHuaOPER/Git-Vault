# 分龄体检清单

“分龄体检清单”是冯雪在《[[女性健康管理60讲]]》中提出的女性健康管理框架的核心部分。它主张女性体检不应追求项目数量，而应根据不同年龄段的生理特点和常见疾病风险，制定有针对性的基础疾病筛查方案。

## 清单结构

整个清单按7个年龄段划分，每个阶段对应一组优先筛查方向：

| 年龄段 | 新增或强化的筛查重点 |
|--------|------------------|
| <18岁 | 身高体重百分位、血红蛋白（贫血）、发育评估（性早熟/延迟） |
| 18–24岁 | 体重、腰围、血压、血脂（5年1次）、性生活后+HIV筛查 |
| 25–29岁 | 乳房触诊、宫颈癌筛查（高危型HPV检测优先，5年1次；或TCT 3年1次） |
| 30–39岁 | 身体成分（肌肉量/体脂比）、血尿酸、空腹血糖+糖化血红蛋白、甲功、OGTT（必要时） |
| 40–49岁 | 乳腺影像检查（超声/钼靶）、骨密度、APCS评分→结肠镜（高风险者）、女性激素基线 |
| 50–64岁 | 心血管风险评估（每年自算）、乳腺筛查强化、结肠镜（人人）、骨密度（每半年如下降）、更年期相关检查 |
| ≥65岁 | 逐步停止部分筛查（如宫颈癌65岁停，乳腺/肠镜74岁停），增加听力、跌倒风险、认知功能 |

## 血压管理中的性别差异

该清单特别强调，女性血压风险阈值低于传统标准：血压经常超过 **120/80 mmHg** 就应留意；反复超过 **130/85 mmHg** 或曾有妊娠期高血压史，建议做24小时动态血压监测。这一观点与[[性别差异医学]]中女性心血管风险在较低血压即上升的发现一致。

## 与其他筛查体系的关系

分龄体检清单是“基础疾病筛查”的骨架，另需搭配[[身心共查]]（心理健康筛查）与[[薄弱系统筛查]]（针对个体薄弱系统的精准加强），三者共同构成完整的女性体检方案。
