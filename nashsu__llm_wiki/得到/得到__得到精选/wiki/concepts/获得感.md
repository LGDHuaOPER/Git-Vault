# 获得感

脱不花在推出「[[职场学习圈]]」时提出的核心价值主张，指在职场上不仅通过有效努力获取成就，更要在奋斗过程中兼顾身心健康，体验生活的乐趣与美好，从而实现一种「既有收获，又有享受」的圆融状态。

## 核心内涵
- **双重追求**：既要「工作开展更顺利」（工具、技能、信息），也要「兼顾身心健康」（运动、读书、音乐等治愈活动）。
- **从急行军到长期伴随**：传统训练营强调密集冲刺，而获得感注重根据个人发展节奏持续获得知识与情感支持，不因透支而丧失幸福感。
- **回应与连接**：花姐信箱代表的「有回应」体验，是获得感的重要情感来源 —— 在职场挑战中不被孤立，获得切实建议与精神陪伴。

## 与相关概念的关系
- 与 [[小事主义]] 相通：不做宏大叙事，而是通过具体微小的行动（如每周工具、每月课程）积累获得感。
- 与 [[人生的艺术化]] 有精神交集：将职场日常视为修炼，同时追求美感和诗意，「打工人的音乐会」等活动即试图在日常中注入艺术性。
- 与 [[韧性思维]] 互补：梅赐琦寄语「不要让世界完全得手」强调对抗外部侵蚀，而获得感则提出在对抗中同时捕获内在的满足与快乐。
- 区别于「确定性」或「能力感」：得到其他产品可能更强调认知升级的确定性，获得感则明确将情感体验和生活平衡纳入目标体系。

## 实践路径
- **信息对标**：通过猎头岗位分析，避免盲目内卷，只做能带来真正市场回报的努力。
- **工具赋权**：借助可立刻使用的工具降低工作负担，释放时间与心力。
- **社群陪伴**：在同学社群中彼此支持，减少职场孤独感。
- **生活透镜**：运动会、读书会等活动迫使学习者从单一职业身份中抽离，重获生活主体感。

获得感因此既是这个产品的营销话语，也是一种与传统「事业成功学」拉开距离的成长理念。
