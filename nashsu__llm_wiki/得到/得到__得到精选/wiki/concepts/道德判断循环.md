# 道德判断循环

指人际互动中一种自我强化的认知恶性循环，是许多冲突和戾气不断升级的核心机制。

## 循环链条

看见行为 → 道德判断 → 搜集证据 → 自我验证 → 加深判断 → 更强烈的道德判断……

1. **看见行为**：观察到对方某个具体动作（如躺在沙发上看手机）。
2. **道德判断**：立即给该行为附加一个道德层面的归因（如“他就是懒”）。
3. **搜集证据**：下意识搜寻符合该归因的其他线索，忽略不符信息。
4. **自我验证**：确认最初的判断，形成“我早就看透他了”的确认感。
5. **加深判断**：固化负面标签，使后续互动中对方的任何行为都更容易被负面解读。

## 后果

误解不断加深，戾气越积越重，双方都看不到彼此的真实需求和脆弱，只剩下标签化对抗。这与[[痛快系统与渴望系统|痛快系统]]的即时发泄冲动相互强化，使人深陷其中。

## 打破方法

[[非暴力沟通四步法]]要求第一步就禁止道德判断，从客观观察出发，直接切断循环的启动点，从而将互动方向导向真实的需要和请求。
