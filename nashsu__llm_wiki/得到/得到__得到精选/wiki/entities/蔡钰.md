# 蔡钰

蔡钰（自称“带货大表姐”）是中国商业观察家，得到App《商业参考》专栏主理人。她是**“情绪价值”在中文商业语境中的最早提出者之一**（据其专栏所述，于2020年首次在商业语境中提出**[[情绪价值]]**概念），随后在专栏中持续追踪大量新消费品牌在情绪价值上的实践。

2023年，她将相关方法论首次体系化为课程《[[产品魅力30讲]]》。此后修订扩展为《情绪价值30讲》音频课程，并在此基础上出版书籍《情绪价值》（系其方法论在图书形态上的体系化输出）。

她主讲《商业参考》专栏（已进行至第四季），擅长从社会学视角观察商业变化，自创“商业社会学”方法论，关注商业如何改变社会以及社会如何改变商业。在第四季发刊词中，她提出了“配角时代”的核心判断，认为商业力量正从主导者退为协作者，并首次公开其基于“反熵增历史观”的观察方法体系。

---

## 核心方法论与建模

蔡钰在实践与教学中建立了一套围绕情绪价值的分析框架，核心建模包括：

| 公式 | 说明 |
|------|------|
| **产品价值 = 功能价值 + 情绪价值 + 资产价值** | 将情绪价值作为产品价值的关键成分，与功能和资产价值并列 |
| **情绪 = 感受 + 动机 + 行为** | 对情绪的内部结构进行拆解，以便产品设计时精准匹配 |
| **空间 + 内容 = 情绪场** | 指导如何通过环境与内容组合营造可复用的情绪氛围 |
| **情感价值 = 情绪资源 × 稳定预期** | 强调持续、可预期的情绪供给才能形成稳定的情感价值 |

她还特别强调**叙事能力**是调动情绪的直接能力，并将其提升为当代产品设计的起点。在整体方法论中，她主张回避PUA式的操控，推崇“明牌”式的、可复用的情绪资源创造与匹配。

**产品价值公式的引用与影响**：该公式被梁宁在《[[真需求]]》一书中借鉴引用，梁宁在互动中确认蔡钰是其好友并提供了这一公式。在梁宁对[[网红品牌]]和[[大牌]]的分析中，该公式被作为产品价值的基础维度。

---

## 分析特色与商业主张

蔡钰的分析以洞察人心、梳理情绪生成机制为特色，长期呼吁中国产品家的创新方向应从性价比创新转向情绪价值创新。她的方法论力求透明、可复用，不依赖话术操纵，而是通过系统化设计为用户持续提供积极的情绪资源。

在此基础上，蔡钰通过“商业社会学”视角进一步扩展了观察维度。在《商业参考》第四季中，她提出“配角时代”的判断，认为商业力量正在从社会发展的主导者退为协作者，商业策略需要适应这一角色转换。她同步公开的“反熵增历史观”将商业与社会变迁的关系纳入动态分析，由此构成其“清醒的商业社会”观察框架的核心。

## 主要作品

- **《商业参考》** – 得到App专栏，2020年起持续更新至第四季，为情绪价值概念的发源地及长期案例追踪阵地，“商业社会学”与“配角时代”等观察亦通过本专栏系统输出  
- **《产品魅力30讲》** – 2023年推出的课程，首次将情绪价值方法论体系化交付  
- **《情绪价值30讲》** – 后续修订扩展的音频课程  
- **《情绪价值》** – 基于以上课程内容修订出版的商业书籍
