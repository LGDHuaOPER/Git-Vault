# Codex

OpenAI 推出的 AI 工具，定位为将编程与自动化能力封装成对话界面，让非技术背景的普通用户也能直接调度软件、数据和自动化流程。

## 核心特征

- **界面极简**：以对话框形式交互，无需命令行、终端或依赖配置知识。
- **关系反转**：从“人学习使用工具”转变为“工具揣摩人”。用户给出模糊意图，Codex 自行拆解步骤、判断策略、补充细节，甚至纠正错误指令。
- **功能整合**：能够读取本地文件、操控桌面应用、连接外部服务（如飞书），完成自动化工作流。

## 与竞品的关键差异

与 OpenClaw（龙虾）、Claude Code 等相比，Codex 的功能本身并非首创，但其核心差异化在于彻底消除了上手门槛。其他工具即使在能力上更早实现类似功能，仍需命令行或编程知识；Codex 则让任何用过 ChatGPT/Kimi/豆包的人都能立即上手。

## 应用案例（来自快刀青衣）

- **视频剪辑**：处理 4 小时直播素材，找到特定书籍片段，自主选择封面、插入画中画并调整音量。
- **消息值守**：每半小时扫描飞书未读消息，标记重要遗漏对话，提供背景与建议回复。
- **原型设计**：4 分钟生成可点击的高保真 App 原型。

## 定位思考

Codex 的价值不在于技能炫耀，而在于让普通上班族能完成原本需要专业技术才能做的事情，使 AI 从“顾问”转向“同事”角色。
