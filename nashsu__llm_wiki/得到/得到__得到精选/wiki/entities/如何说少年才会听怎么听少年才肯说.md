# 如何说少年才会听，怎么听少年才肯说

原著英文名 *How to Talk So Teens Will Listen & Listen So Teens Will Talk*，由阿黛尔·法伯和伊莱恩·玛兹利施合著。本书是亲子沟通的实操教材，提供了一系列反映孩子感受、促进合作、鼓励自立、赞赏孩子的具体技巧。被《纽约时报》评为家庭教育年度十大畅销书，美国公共电视台曾据此制作六集系列节目。

## 核心技巧框架
1. 反映孩子感受的四个技巧（全神贯注倾听、语气词回应、说出感受、幻想实现愿望）
2. 基于合作的管教方式（描述事实、提示后果、简单词语、说出感受）
3. 鼓励孩子自立的五个方法（选择、尊重努力、少问问题、引导外部资源、给予希望）
4. 描述性赞赏（描述事实、表达感受、概括行为）

本书强调教育目标是培养自主性和合作能力，而非控制行为。
