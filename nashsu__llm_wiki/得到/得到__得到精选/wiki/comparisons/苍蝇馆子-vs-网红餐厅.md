# 苍蝇馆子 vs 网红餐厅

下面对比梳理两种当代餐饮极端形态的关键差异。

| 维度 | 苍蝇馆子 | 网红餐厅 |
|------|---------|---------|
| **核心驱动** | 手艺、老板对菜肴的偏执 | 视觉冲击、社交网络传播 |
| **核心竞争力** | 极致好吃 | 适合拍照、有故事性 |
| **环境** | 简朴、甚至破旧 | 装修讲究、场景感强 |
| **经营者** | 厨师即老板，全链条控制 | 资本家或运营团队，善用营销 |
| **菜品质量** | 高，但对环境无兴趣 | 参差，菜品可能成为道具 |
| **传播路径** | 口碑，食客自发 | 点评榜单、社交媒体推广 |
| **目标客群** | 真正讲究味道的食客 | 追求打卡、拍照与社交货币的广泛人群 |
| **持久性** | 较长，靠手艺积累 | 周期短，靠流量维持 |
| **典型代表** | 杭州某小馆老板每日去渔船上买鱼；四川女老板手工去净猪脑血丝 | 粉红色汤、龙虾汉堡、拿破仑蛋糕等视觉爆款 |

两者的悖论揭示了当代评价体系中“好吃”与“好看”的割裂，以及互联网资本如何通过算法重塑餐饮竞争的坐标系。详细背景分析见 [[苍蝇馆子与网红餐厅的悖论]]。
