# 人格可变性：李松蔚 vs 王芳

| 维度 | 李松蔚 | 王芳 |
|------|--------|------|
| 核心主张 | 部分人格特质不可改变，由基因或稳态框架决定；自责无效，接纳后扬长避短。 | [[人格作为动词]]：人格可以通过选择和行动塑造，具有能动性。 |
| 理论来源 | 人格测试、稳态理论、临床观察 | 人格心理学、社会认知理论 |
| 对改变的态度 | 接纳不可变的，区分可塑部分；减少无谓内耗。 | 强调主动选择和适应，人格具有成长空间。 |
| 案例 | 暴躁创业老板——承认脾气，团队关系反变好。 | 成长过程中的自我重塑、情境适应性人格表达。 |
| 交汇点 | 二者并不绝对矛盾：李松蔚承认人格也有可塑变量；王芳也认可人格存在稳定特质。二者共同指向**认识自己，善用自己**的终极目标。 | |
| 适用场景 | 强烈自责、因性格问题反复内耗的个体。 | 希望主动塑造自我、突破固定标签的人。 |
