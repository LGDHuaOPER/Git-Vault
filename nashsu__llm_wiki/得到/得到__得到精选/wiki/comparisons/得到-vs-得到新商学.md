# 得到 vs 得到新商学

| 维度 | 得到 APP | 得到新商学 APP |
|------|----------|----------------|
| **核心定位** | 知识服务平台，提供系统化课程、听书、电子书 | 创业服务社区，解决中小创业者的真实生意难题 |
| **内容生产方式** | 平台组织名师、专业团队进行课程和内容生产 | 用户生成式：由创业者的提问驱动，专家推荐打法，社区萃取案例 |
| **服务对象** | 终身学习者、职场人 | 创业者，尤其是中小创业者 |
| **核心价值主张** | 省时间、碎片化学习、知识体系构建 | “你有一个问题，我有一个安排”——连接做成过的人 |
| **学习方式** | 被动接收结构化的课程或听书内容 | 主动提出真问题，参与多学科会诊，观摩他人案例分析 |
| **社区特性** | 相对弱，以课程评论、知识城邦等轻社交为主 | 强社区：每周工作例会直播、案例共建、会员反馈 |
| **与专家的关系** | 专家作为内容提供者，授课为主 | 专家作为案例推荐人和会诊嘉宾，提供具体打法 |

这一对比凸显了新商学的突破：从“教知识”转向“解难题”，从“人找内容”转向“内容围绕人走”。但两者在品牌认知和用户资源上可能存在重叠与竞争，其协同效应尚需观察。
