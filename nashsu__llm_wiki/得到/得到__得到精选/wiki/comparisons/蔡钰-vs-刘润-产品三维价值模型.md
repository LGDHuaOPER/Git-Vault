# 蔡钰 vs 刘润：产品三维价值模型

两位商业观察家在不同语境下提出了高度一致的公式：**产品价值 = 功能价值 + 情绪价值 + 资产价值**。

| 对比维度 | 刘润 | 蔡钰 |
|----------|------|------|
| **提出背景** | 宏观赛道分析，讨论“卷的下半场”中情绪作为下一个赛道 | 微观产品设计和消费者心理学，探讨在供给过剩时代如何用情绪价值突围 |
| **侧重点** | 商业竞争的阶段性演化，从功能到情绪再到资产价值的转移趋势 | 情绪价值的创造方法论、品牌角色转型、叙事能力与情感连接 |
| **案例类型** | 场景化、趋势式说明 | 详实的个案拆解，如洁柔、椰树牌椰汁、小红书、《甄嬛传》 |
| **理论输出** | 强调赛道切换的迫切性，公式作为说明工具 | 公式成为方法论骨架，配套三大公式+叙事工程，直接指导实践 |
| **出处** | 《刘润：情绪，是下一个赛道》（2024年得到精选） | 《情绪价值》（书籍及课程，蔡钰） |

## 关键差异

刘润的模型更多服务于**战略判断**，提醒企业和创业者关注价值重心的迁移；蔡钰的模型则是一套**可操作的产品语言**，不仅拆解了价值的构成，还通过情绪三要素公式、情感价值公式以及叙事能力方法，给出了创造情绪价值的完整路径。

## 源起与影响

目前尚无公开资料显示两人谁首先提出这一公式。但可以肯定的是，两人从各自的观察角度独立提炼出了相同的结构，反映了业界对“产品价值＝功能+情绪+资产”这一分析框架的共识。在借鉴和应用时，应根据具体需求选择侧重：需要战略视野时参考刘润的框架，需要落地方法与案例时深入蔡钰的系统。
