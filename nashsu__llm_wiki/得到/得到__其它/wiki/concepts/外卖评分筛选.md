# 外卖评分筛选

外卖评分筛选是指在外卖平台（如[[美团]]）上通过多维度指标判断商家和菜品质量的方法，帮助用户在海量商家中做出合理选择。这是[[手机点外卖]]过程中的核心决策框架。

## 筛选维度

| 指标 | 说明 |
|------|------|
| 五角星评分 | 顾客对商家的综合满意度，分数越高越好 |
| 月销量 | 店铺当月所有菜品的总销量，反映受欢迎程度 |
| 预计送达时间 | 配送预计需要的分钟数，影响用餐时效 |
| 距离 | 餐馆距收货地址的位置，影响配送速度和可选范围 |
| 起送金额 | 需点满的最低消费金额，低于此金额无法下单 |
| 配送费 | 是否收取额外配送费用，部分商家免配送费 |
| 单品好评度 | 具体菜品的顾客评价，进入商家页面可查看 |

## 使用建议

- 优先选择评分高、月销量大的商家
- 综合考虑距离和配送时间，确保在预期时间内收到餐食
- 注意起送金额，避免因金额不足无法下单
- 灰色显示的店铺表示当前不可配送（休息、打烊或距离过远）
