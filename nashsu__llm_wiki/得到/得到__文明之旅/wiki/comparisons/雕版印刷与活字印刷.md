# 雕版印刷与活字印刷

## 对比维度

| 维度 | 雕版印刷 | 活字印刷 |
|------|----------|----------|
| **技术原理** | 一整块木板反向刻字，一次成版 | 单个活字拼合为版，可重复使用 |
| **起源** | 唐代成熟 | 北宋庆历年间毕昇泥活字 |
| **成本结构** | 固定成本高（每页一块板），但重复印边际成本低 | 字库初始投资大，排拆版人工成本高 |
| **经济分水岭** | 3800页以下占优 | 3800页以上占优，但古代极少见 |
| **劳动力要求** | 刻工可不识字（文盲可操作） | 排字、拆版、归字全过程需识字工匠 |
| **劳动力可得性** | 庞大刻工群体（宋代已三千人），工资低 | 识字工匠稀缺且工资为普通刻工数倍，社会身份壁垒 |
| **技术迭代** | 有持续微创新（如宋体字、分刀工艺） | 仅靠个别士大夫或官方投入，缺乏稳定迭代网络 |
| **品质面貌** | 字体美观，版面稳定，能适应木纹 | 早期字距不齐、墨色不均，后期虽能提升但缺乏统一网络 |
| **应用占比** | 占古代书籍99%以上 | 不足1%（活字本仅150多部/1.1万善本） |
| **存活市场** | 全面主宰 | 仅在“谱师经济”等极窄领域持续 |
| **扩散前提** | 强大的社会协作网络：工匠分工、原料配套、市场需求 | 依赖识字阶层的参与和稳定的大规模需求，这些在古代中国欠缺 |
| **跨文明对比** | — | 古腾堡活字在欧洲成功（宗教需求+油墨+识字修道士），朝鲜因官方强制推进 |

## 关键解释

雕版印刷的成功本质上是社会协作网络的成功；活字印刷的失败则是这种网络未能成型的结果。两者的消长并非由技术本身的美观或文字特性决定，而是取决于分工体系、劳动力供给、成本结构和市场需求等生态因素。
