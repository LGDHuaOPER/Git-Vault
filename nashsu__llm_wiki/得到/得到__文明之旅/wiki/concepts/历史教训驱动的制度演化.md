# 历史教训驱动的制度演化

一种理解中国古代制度变迁的核心视角，由本期《文明之旅》在梳理[[宗室管理制度]]时明确提出。

## 基本主张

中国古代史因基本框架（皇帝制度、官僚体系、儒家意识形态）长期稳定，类似一个能控制变量的**大型制度实验室**。制度的演进并非简单循环或螺旋上升，而是一个**持续修补 Bug、吸取“教训”**的过程：

- 殷商覆灭 → “殷鉴”
- 秦朝速亡 → “过秦”，汉朝人天天检讨秦的过失
- 隋朝崩塌 → 整个唐朝前期，君臣对话动辄以隋为戒
- 每一次朝代更迭，后朝都针对前朝明显的制度漏洞进行修正

## 在宗室问题上的体现

宗室管理制度的演化清晰展示了这一逻辑：周朝内乱 → 秦朝屠杀宗室 → 秦孤立速亡 → 汉朝折中严管 → 曹魏沿袭过严致宗室无力抵抗权臣 → 晋朝反向重用宗室 → 八王之乱 → 唐宋找到“中道”。

每一个补丁都在堵上一个漏洞，但也往往在另一个意想不到的方向打开新窟窿。例如宋朝完美解决了宗室内乱，却因此造成宗室整体无能、靖康时被一锅端。

## 与已有概念的关系

该视角与之前出现的[[利益结构锁定]]相互补充：一个制度一旦确立并逐渐强化，就会形成新的利益格局，导致后续修正困难；而“教训驱动”则解释了制度为何会向某个方向持续锁定。也与[[预期决定行动]]勾连，因为决策者对历史的解读（预期中的教训）直接塑造了他们的制度选择。

## 警示

节目指出，中国人因历史漫长而对“历史终结论”天然免疫，深知堵住一个漏洞后必有新漏洞冒出。这种洞见本身亦构成一种思维方法：永远保持对制度演化中意外后果的警觉。
